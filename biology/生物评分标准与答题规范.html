2026年6月14日6分钟阅读

基于 2023 年全年度（Feb/Mar, May/June, Oct/Nov）的 9700 Paper 2 评分标准（MS）与考官报告（ER）

1. [酶促反应：环境因子影响 (pH/Temp)]

  • 触发情境：曲线图下降、对比不同酶的活性、解释为什么在某 pH/温度下速率低。
  • 答题模板： [At {非最适条件}], ionic / hydrogen bonds [broken / altered] → tertiary structure of enzyme [changed] → active site shape [altered] → [no longer / less] complementary to {substrate} → [fewer] enzyme-substrate complexes (ESCs) formed.
  • 得分点拆解：
    1. 指出具体的化学键（离子键/氢键）。
    2. 强调“三级结构”改变导致“活性位点形状”改变。
    3. 核心词：Complementary（互补）和 ESC（酶-底物复合物）。
  • 禁忌警告：
    • 严禁说“酶被杀死 (enzyme killed)”，只能用 denatured。
    • 严禁只说“活性位点变了”，必须提到“与底物不再互补”。
    • 温度题目不要混淆“动能 (kinetic energy)”与“变性 (denaturation)”。

2. [植物运输：韧皮部装载 (Phloem Loading)]

  • 触发情境：解释伴胞 (companion cell) 如何将蔗糖移入筛管。
  • 答题模板： [Protons / H+] pumped out of companion cell [into cell wall / apoplast] → using ATP / active transport → creates proton gradient → [Protons] diffuse back [into companion cell] through cotransporter protein → carrying sucrose [against its concentration gradient] → sucrose moves into sieve tube element via plasmodesmata.
  • 得分点拆解：
    1. 泵出质子（消耗 ATP）。
    2. 建立浓度梯度。
    3. 协同运输（Cotransport）进入伴胞。
    4. 通过胞间连丝（Plasmodesmata）进入筛管。
  • 禁忌警告：
    • 考官报告指出：学生常漏掉 Cotransporter protein 这个词。
    • 蔗糖进入筛管是 扩散（通过胞间连丝），不是主动运输。

3. [免疫：抗体作用 (Antibody Action)]

  • 触发情境：抗体如何减少病原体扩散、抗体特异性解释。
  • 答题模板： [Antibody / Variable region] has complementary shape to [antigen / epitope] on {pathogen} → binds to form antibody-antigen complex → [prevents entry] into host cells → agglutination [to clump pathogens] → facilitates phagocytosis [by marking pathogen / opsonisation].
  • 得分点拆解：
    1. 形状互补（Complementary shape）。
    2. 形成复合物。
    3. 阻止进入细胞（Neutralisation）。
    4. 凝集（Agglutination）或标记（Opsonisation）。
  • 禁忌警告：
    • 严禁说“抗体杀死病原体”，抗体只是标记或阻止，杀死是由吞噬细胞或补体完成的。
    • 不要混淆 Antibiotic（抗生素）和 Antibody（抗体）。

4. [核酸：DNA 复制/转录差异]

  • 触发情境：解释为什么基因长度比多肽链长、解释突变影响。
  • 答题模板： {Gene} contains introns which are non-coding sequences → removed from primary transcript during RNA splicing → only exons [joined together] to form mRNA → [STOP codon] does not code for amino acid → [Post-translational modification] removes {Met / start amino acid}.
  • 得分点拆解：
    1. 内含子（Introns）是不编码序列。
    2. RNA 剪接（Splicing）发生在转录后。
    3. 终止密码子不对应氨基酸。
  • 禁忌警告：
    • 考官报告强调：必须明确 Introns 是在 mRNA 形成前 被切除的。
    • 严禁说“DNA splicing”，必须是 RNA splicing。

5. [哺乳动物运输：波尔效应 (Bohr Shift)]

  • 触发情境：解释二氧化碳增加如何导致氧气释放。
  • 答题模板： [More] CO2​ diffuses into RBC → carbonic anhydrase catalyses reaction with water to form carbonic acid → dissociates into H+ and HCO3−​ → haemoglobin binds to H+ to form haemoglobinic acid (HHb) → causes allosteric effect [change in tertiary structure] → decreases affinity for oxygen → oxygen released [to respiring tissues].
  • 得分点拆解：
    1. 酶的名字（碳酸酐酶）。
    2. 氢离子（H+）的产生。
    3. 形成血红蛋白酸（HHb）。
    4. 亲和力（Affinity）下降。
  • 禁忌警告：
    • 必须写“More”：2023 MS 明确规定，如果不写“More CO2​”或“More H+”，最高只能给 3 分（满分 4）。
    • 严禁说“CO2​ 挤走了氧气”，是 H+ 改变了 Hb 的结构。

6. [细胞循环：有丝分裂后期 (Anaphase)]

  • 触发情境：描述图中细胞 A 的染色体行为。
  • 答题模板： Centromeres [divide / split] → sister chromatids separate → pulled to opposite poles → by spindle fibres [shortening / contracting] → chromatids now called [daughter] chromosomes → move V-shape [centromeres leading].
  • 得分点拆解：
    1. 着丝点分裂。
    2. 姐妹染色单体分离。
    3. 纺锤丝收缩拉向两极。
  • 禁忌警告：
    • 严禁在 Anaphase 阶段还叫它们“Chromatids”，一旦分开必须叫 Chromosomes。
    • 严禁说染色体被拉向“两边 (sides)”，必须说 poles（极）。

考官视角：避坑指南 (Examiner’s “Red Lines”)

  1. 描述图表数据：如果题目要求 “Describe the data”，必须包含“起始点、终点、转折点”的具体数值，且必须带单位。
  2. 水分泌/吸收：永远不要只写“水移动”，必须写 “Water moves by osmosis, down a water potential gradient”（全句背诵）。
  3. 显微结构：看到线粒体，必须提到 “Double membrane” 或 “Cristae”；看到叶绿体，必须提到 “Thylakoid” 或 “Grana”。
  4. 计算题：必须写出公式（如 M=I/A），即使结果错，公式和中间步骤也能给分。注意单位换算（1mm=1000μm）。
