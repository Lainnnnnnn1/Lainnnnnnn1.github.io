核心规律（人话版）

1. 氧化物酸碱性变化

  • 从左到右： 碱性 → 两性 → 酸性
  • Na2​O / MgO： 溶于水成碱（NaOH, Mg(OH)2​）
  • Al2​O3​： 两性（既溶于酸又溶于碱）
  • SiO2​： 酸性（只溶于碱，不溶于酸 — 除 HF）
  • P4​O10​ / SO2​ / SO3​： 溶于水成酸（H3​PO4​, H2​SO3​, H2​SO4​）

2. 氯化物结构变化

  • 从左到右： 离子晶体 → 共价分子
  • NaCl / MgCl2​： 离子晶体，熔点高
  • AlCl3​： 过渡地带 — 固态是离子，气态/液态共价二聚体 Al2​Cl6​
  • SiCl4​ / PCl3​ / PCl5​： 共价简单分子，液体/气体

3. 氯化物与水反应

  • NaCl： 溶解不反应，pH 7
  • MgCl2​： 微弱水解，pH ~6.5
  • AlCl3​： 强烈水解，pH ~3（释放 HCl 气体，冒白烟）
  • SiCl4​： 剧烈水解，生成 SiO2​ 白色沉淀 + HCl
  • PCl3​ / PCl5​： 水解成酸（H3​PO3​ / H3​PO4​ + HCl）

详细拆解：period-3

电离能的两个「反常」

对比数值关系原因
Mg (3s²) vs Al (3p¹)IE1​(Mg)>IE1​(Al)Al 的 3p 电子离核更远、受 3s 电子屏蔽，更容易丢
P (3p³) vs S (3p⁴)IE1​(P)>IE1​(S)3p3 半满稳定；S 的第 4 个 p 电子要成对，有电子排斥

二级结论： 考试画电离能曲线，Al 和 S 两个「坑」必考；答题永远说「半满/全满稳定」+「电子配对排斥」。

二、过渡金属 (Transition Metals)

什么是过渡金属？

定义（A-Level 满分版）： An element that forms at least one stable ion with an incomplete d-subshell.

  • ⚠️ 锌不是过渡金属：Zn2+ 的 3d 是满的（d10）
  • ⚠️ 钪也不是：Sc3+ 的 3d 是空的（d0）

过渡金属四大特性

特性解释
可变氧化态3d 和 4s 轨道能量相近，可失去不同数量的电子
形成有色化合物d-d 跃迁吸收可见光（见下文晶体场理论）
形成络合物有空 d 轨道接受配体孤对电子形成配位键
催化活性可变氧化态 + 空轨道 = 提供反应路径的「中转站」

颜色与 d 电子数关系

d 电子数典型离子颜色原因
d0Sc3+,Ti4+无色无 d 电子可跃迁
d1Ti3+紫色1 个 d-d 跃迁
d3Cr3+绿色/紫色d-d 跃迁
d4Mn3+紫色d-d 跃迁
d5Mn2+,Fe3+极浅（近无色）高自旋 d5 的 d-d 跃迁自旋禁阻
d6Fe2+浅绿d-d 跃迁
d7Co2+粉红d-d 跃迁
d8Ni2+绿色d-d 跃迁
d9Cu2+蓝色d-d 跃迁（Jahn-Teller 畸变）
d10Zn2+,Cu+无色d 轨道全满，无空轨道可跃迁

二级结论： 「有色 ⇔ 有 d-d 跃迁」；d0 和 d10 必无色。Zn2+ 无色 + 不是过渡金属 + d10——三个考点一个离子全包。

磁性（顺磁性 / 抗磁性）

  • 顺磁 (Paramagnetic)： 有未成对电子 → 被磁场吸引
  • 抗磁 (Diamagnetic)： 全部成对 → 被磁场排斥
  • 磁矩公式： μ=n(n+2)​ BM（n = 未成对电子数）

例 1（磁性计算）： Fe3+（高自旋 d5）有几个未成对电子？磁矩多少？

解： 高自旋 d5：5 个 d 轨道各占 1 个电子 → n=5；μ=5×7​=35​≈5.9 BM。

例 2： Cu2+（d9）呢？→ 9 个电子填满 5 个轨道 → 1 个未成对，μ=3​≈1.7 BM。

常见过渡金属离子颜色

离子水合离子颜色备注
[Cu(H2​O)6​]2+蓝色铜离子
[Fe(H2​O)6​]2+浅绿色亚铁，易氧化

三、配位化学 (Coordination Chemistry)

配体分类

类型手数代表结构特征
单齿 (Monodentate)1H2​O,NH3​,Cl−,CN−一个配位原子
双齿 (Bidentate)2en (乙二胺), C2​O42−​ (草酸根)两个配位原子，「手铐」
多齿 (Multidentate)多个EDTA4− (6手)「八爪鱼」
桥接 (Bridging)—OH−,Cl−同时连接两个金属离子

螯合效应 (Chelate Effect)

人话版： 用多齿配体替换单齿配体 → 粒子数暴增 → 熵大增 → ΔG 极负 → 生成极其稳定的络合物！

[Co(H₂O)₆]²⁺ + EDTA⁴⁻ → [Co(EDTA)]²⁻ + 6H₂O
   左边 2 个粒子  →  右边 7 个粒子
   ΔS ≫ 0  →  极其稳定

配位数与几何构型

配位数几何构型例子
2直线形[Ag(NH3​)2​]+（银氨溶液！）
4四面体[ZnCl4​]2−,[CoCl4​]2−（蓝色）
4平面四方[Pt(NH3​)2​Cl2​]（顺铂）
6八面体[Fe(CN)6​]4−,[Co(NH3​)6​]3+（最常见）

配合物命名（IUPAC 规则）

规则四步：

  1. 配体在前，金属在后（配体间按字母顺序，不管电荷）
  2. 配体词尾： 中性配体原名（H2​O = aqua，NH3​ = ammine）；阴离子配体 -o 词尾（Cl− = chloro，CN− = cyano，OH− = hydroxo）
  3. 氧化态用罗马数字写在金属后括号里
  4. 整体带负电时金属改 -ate（Fe → ferrate，Cu → cuprate，Ag → argentate）

命名例题：

化学式名称
[Co(NH3​)6​]Cl3​hexaamminecobalt(III) chloride
K3​[Fe(CN)6​]potassium hexacyanoferrate(III)（赤血盐）
[Cu(NH3​)4​]SO4​tetraamminecopper(II) sulfate
[Pt(NH3​)2​Cl2​]diamminedichloroplatinum(II)（顺铂）

二级结论： 见到「金属名 + ate」→ 配合物整体带负电，外面一定还挂着一个阳离子（如 K+）。

配合物异构

异构类型条件例子
顺反异构 (cis/trans)MA4​B2​ 八面体Co(NH3​)4​Cl2​
面-经异构 (fac/mer)MA3​B3​ 八面体[Co(NH3​)3​(NO2​)3​]
旋光异构 (Optical)无对称面/中心[Co(en)3​]3+
顺反异构MA2​B2​ 平面四方Pt(NH3​)2​Cl2​ (顺铂)

例 3（异构体计数）： [Co(NH3​)4​Cl2​]+ 有几种异构体？

解： MA4​B2​ 八面体 → 2 种：cis（两个 Cl 相邻，90°）和 trans（两个 Cl 相对，180°）。cis 型有旋光异构吗？——MA4​B2​ 的 cis 存在对称面 → 没有旋光异构。

例 4： [Co(en)3​]3+ 呢？

解： 三个 en 像三个「桨叶」→ 形成左手（Λ）和右手（Δ）两种镜像，互为镜像不可重叠 → 2 个对映体（旋光异构）。

异构建表详见：Chemistry/化学

四、晶体场理论 (Crystal Field Theory)

核心概念

  1. d 轨道分裂： 配体接近金属时，5 个 d 轨道不再简并，分裂成两组
  2. 八面体场： dz2​ 和 dx2−y2​（eg​）能量升高，dxy​,dxz​,dyz​（t2g​）能量降低
  3. 分裂能 Δoct​： 两组轨道之间的能量差

决定颜色的因素

  1. d 轨道分裂成两组能量级
  2. 电子吸收可见光从低能级跃迁到高能级（d-d transition）
  3. ΔE=hν=λhc​
  4. 看到的颜色是补色（complementary colour）

影响 Δ 大小的因素

因素趋势
配体类型（光化学序列）I−<Br−<Cl−<F−<OH−<H2​O<NH3​<en<CN−<CO
金属氧化态氧化态越高 → Δ 越大（正电荷多，拉配体更紧）
金属在周期表中的位置同族往下 → Δ 增大；5d > 4d > 3d

高自旋 vs 低自旋

  • 弱场配体（H2​O,F−）：Δ 小 → 电子优先分占轨道（高自旋）
  • 强场配体（CN−,CO）：Δ 大 → 电子优先成对（低自旋）
  • 判据： Δ>P（成对能）→ 低自旋；Δ<P → 高自旋
构型弱场（高自旋）强场（低自旋）
d4t2g3​eg1​（4 未成对）t2g4​eg0​（2 未成对）
d5t2g3​eg2​（5 未成对）t2g5​eg0​（1 未成对）
d6t2g4​eg2​（4 未成对）t2g6​eg0​（0 未成对，抗磁）

例 5（自旋态判断）： [Fe(H2​O)6​]2+ 高自旋（4 未成对，顺磁）；[Fe(CN)6​]4− 低自旋（0 未成对，抗磁）——同一个 Fe2+，配体决定磁性！

晶体场稳定化能 CFSE（八面体）

CFSE=(−0.4nt2g​​+0.6neg​​)Δ

例 6（CFSE 计算）：

  • d4 高自旋（t2g3​eg1​）：3×(−0.4Δ)+1×(0.6Δ)=−0.6Δ
  • d4 低自旋（t2g4​eg0​）：4×(−0.4Δ)=−1.6Δ（但要额外付成对能 P）
  • 结论：只有 Δ>P 才选低自旋——这就是强场配体「更稳」的数学原因

d-d 跃迁波长计算

ΔE=hν=λhc​(h=6.63×10−34 J s, c=3.00×108 m s−1)

例 7：[Ti(H₂O)₆]³⁺ 吸收峰 λ ≈ 500 nm，分裂能 Δ 是多少？

解： ① 转单位：λ=500 nm=5.00×10−7 m ② ΔE=5.00×10−76.63×10−34×3.00×108​=3.98×10−19 J ③ 换算成每摩尔：3.98×10−19×6.02×1023≈2.4×105 J mol−1=240 kJ mol−1 ④ 吸收 500 nm（绿光附近）→ 看到的是补色 → 紫色

例 8：[Cu(H₂O)₆]²⁺ 吸收约 600 nm（橙红光）→ 为什么是蓝色？

解： 吸收橙红 → 看到补色 = 蓝色。若换强场配体 NH3​：Δ 增大 → 吸收波长变短（向紫移）→ 补色加深 → [Cu(NH3​)4​]2+ 呈深蓝色。

颜色变化题满分答法

为什么加 NH3​ 后颜色变深？

  1. NH3​ 在光谱化学序列中比 H2​O 靠前
  2. 所以 NH3​ 作为配体造成更大的 d 轨道分裂（Δ 增大）
  3. ΔE 变大 → 吸收的光波长变短（向蓝紫方向移动）
  4. 补色向相反方向移动 → 观察到的颜色发生变化

常见丢分点

  1. 过渡金属定义必须完整： 缺「至少一种稳定离子」直接扣分
  2. 锌不是过渡金属： Zn2+ 的 d 轨道是满的！
  3. 颜色解释必须落到补色： 只说「吸收光」不够，要说明看到的是未被吸收的补色
  4. AlCl3​ 是共价二聚体 Al2​Cl6​，不是离子晶体
  5. 命名词尾别写错： 阴离子配体是 chloro/cyano/hydroxo，不是 chloride/cyanide/hydroxide；金属在阴离子配合物里要变 -ate
  6. 磁矩公式别用错： μ=n(n+2)​，n 是未成对电子数，不是 d 电子总数
