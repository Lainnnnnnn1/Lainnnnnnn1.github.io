有机化学

有机化学的核心只有两件事：电子往哪流，和分子结构怎么变。 抓住这两条线，所有的反应机理都是纸老虎。

二、反应机理 (Reaction Mechanisms)

无脑判断法（两步走）

Step 1：看「进攻试剂」→ 判断亲核还是亲电

  • 亲核 (Nucleophilic)： 富电子。有孤对电子 / 带负电（OH−,CN−,NH3​,H2​O）
  • 亲电 (Electrophilic)： 缺电子。带正电 / 电子不满（H+,NO2+​,Br2​,AlCl3​）

Step 2：看「底物」→ 判断加成还是取代

  • 加成 (Addition)： 发生在不饱和键上（C=C,C≡C,C=O）。双键断开 → 变饱和
  • 取代 (Substitution)： 发生在饱和碳或苯环上。一个换一个，结构框架不变
  • 消去 (Elimination)： 从分子里拆掉小碎片 → 生出双键

终极总结表

底物进攻试剂反应名称口诀
烯烃 C=C缺电子 (H+, Br2​)亲电加成 (EA)双键电子多，吸引亲电试剂
醛/酮 C=O富电子 (CN−, H−)亲核加成 (NA)碳带 δ+，吸引亲核试剂
卤代烃 C−X富电子 (OH−, NH3​)亲核取代 (NS)亲核试剂踢走卤素自己坐下
苯环缺电子 (NO2+​, Cl+)亲电取代 (ES)苯环电子云吸引亲电试剂，踢 H 保持芳香性
酰氯 R−COCl富电子亲核加成-消去先加成踢双键，再消去踢 Cl

三大机理类型详解

亲电机理 (Electrophilic)

  • 特征： 缺电子试剂进攻富电子位点（双键 π 电子云、苯环、氧/氮孤对电子）
  • 典型试剂： H+,NO2+​,Br+,Cl+,AlCl3​,FeBr3​
  • 代表反应： 烯烃 + HX（亲电加成）、苯的硝化（亲电取代）
  • 判据： 底物有 π 键或孤对电子 + 试剂缺电子 → 亲电机理

亲核机理 (Nucleophilic)

  • 特征： 富电子试剂进攻缺电子位点（δ+ 的羰基碳、C−X 上的碳）
  • 典型试剂： OH−,CN−,NH3​,H2​O,H−（NaBH4​）, RMgX
  • 代表反应： 卤代烃 + NaOH（亲核取代）、醛 + HCN（亲核加成）
  • 判据： 底物有 δ+ 碳 + 试剂有孤对电子/负电荷 → 亲核机理

自由基机理 (Radical)

  • 特征： 中性、带单电子的活泼物种（Cl⋅,Br⋅,CH3⋅​）；需要光照 / UV / 高温引发
  • 代表反应： 烷烃卤代（CH4​+Cl2​UV​）
  • 三步曲： 引发 → 链增长 → 链终止
  • 判据： 题干出现「光照」二字 → 几乎必是自由基

自由基取代完整机理（以甲烷氯化为例）

Step 1 引发 (Initiation)： 均裂 (homolytic fission) Cl2​UV​2Cl⋅

Step 2 链增长 (Propagation)： 两步循环，自由基「再生」 Cl⋅+CH4​→HCl+CH3⋅​ CH3⋅​+Cl2​→CH3​Cl+Cl⋅

Step 3 链终止 (Termination)： 自由基两两结合 Cl⋅+Cl⋅→Cl2​CH3⋅​+Cl⋅→CH3​ClCH3⋅​+CH3⋅​→C2​H6​

二级结论： 产物必是混合物（一氯/二氯/多氯代 + 少量乙烷）；反应需要持续光照——光照一停，链增长就断。

马氏规则 (Markovnikov’s Rule)

规则： 不对称烯烃加 HX 时，H 加到含氢较多的碳上。

CH3​CH=CH2​+HBr→CH3​CHBrCH3​ (2-溴丙烷，主产物)

解释： 中间体碳正离子稳定性 3°>2°>1°——H 加到 H 多的碳，正电荷就落在取代基更多的碳上，更稳定。

反马氏例外： HBr + 过氧化物（ROOR）→ 走自由基机理，产物反马氏。只有 HBr 有这个例外（HCl 自由基太慢、HI 自由基太不稳定）。

四、酸性强弱

核心逻辑

酸性 = 电离后阴离子有多稳定。

  • 阴离子越稳定 → 越容易掉 H+ → 酸性越强
  • 稳定的方法：把负电荷分散（离域 / 吸电子效应）

无脑排序链

二氯乙酸 > 氯乙酸 > 乙酸 > 苯酚 > 水 > 乙醇

酸pKa阴离子稳定化来源
CH3​COOH4.76基准（羧酸根共振离域）
ClCH2​COOH2.86Cl 吸电子 −I 效应
Cl2​CHCOOH1.29两个 Cl 叠加
C6​H5​OH9.95负电荷离域进苯环
H2​O15.7基准弱酸
C2​H5​OH≈16烷基推电子 +I
  • Cl（吸电子）最强；烷基（推电子）最弱
  • 答题永远绕着「阴离子稳定性」和「电荷分散程度」转
  • 详细逻辑：Chemistry/有机物酸性强弱

五、碱性强弱

核心逻辑

碱性 = N 上孤对电子的「可及性」(Availability)

  • 烷基（CH3​,C2​H5​）：推电子 +I → N 电子密度 ↑ → 碱性 ↑
  • 苯环：离域 π 体系 → N 电子密度 ↓ → 碱性 ↓

排序

甲胺 > 氨 > 苯胺

合成路线例题

例 1：从乙醇合成乙酸乙酯

思路： 目标分子 = 乙酸 + 乙醇的酯 → 先造酸，再酯化。

① CH3​CH2​OHK2​Cr2​O7​/H2​SO4​,加热回流​CH3​CHO（一级醇氧化到醛） ② CH3​CHOK2​Cr2​O7​/H2​SO4​,加热回流​CH3​COOH（继续氧化到酸） ③ CH3​COOH+CH3​CH2​OH浓H2​SO4​,加热​CH3​COOC2​H5​+H2​O（酯化）

检查： 碳数全程 C2​→C2​→C2​，无增减 ✓

例 2：从 1-溴丙烷合成丁酸（碳链 +1）

思路： 碳链增长只有两招——KCN 或 Grignard；卤代烃用 KCN 最直接。

① CH3​CH2​CH2​Br+KCN乙醇/水,加热​CH3​CH2​CH2​CN+KBr（亲核取代，+1 C） ② CH3​CH2​CH2​CNH+/H2​O,回流​CH3​CH2​CH2​COOH（腈水解成羧酸）

二级结论： 「碳链 +1 且终点是羧酸」→ 默认路线 = 卤代烃 + KCN → 腈 → 水解。

例 3：从乙醛合成乳酸（2-羟基丙酸）

思路： 羟基腈是 α-羟基酸的「前体」——醛 + HCN 一步到位。

① CH3​CHO+HCN→CH3​CH(OH)CN（亲核加成：CN− 进攻 δ+ 羰基碳） ② CH3​CH(OH)CNH+/H2​O​CH3​CH(OH)COOH（水解）

例 4：从苯合成苯甲酸

思路： 苯环本身抗氧化 → 先装烷基侧链，再氧化侧链。

① C6​H6​+CH3​ClAlCl3​​C6​H5​CH3​+HCl（Friedel-Crafts 烷基化，亲电取代） ② C6​H5​CH3​KMnO4​/H+,加热回流​C6​H5​COOH（侧链氧化，苯环不动）

例 5：从溴乙烷合成乙胺

思路： 卤代烃的亲核取代；必须过量 NH3​ 防止多取代。

CH3​CH2​Br+NH3​ (过量)乙醇,密封加热​CH3​CH2​NH2​+HBr

为什么过量？ 乙胺产物仍是亲核试剂，会继续取代生成仲胺、叔胺、季铵盐——过量 NH3​ 提高一取代比例。

例 6：从乙醇合成 1,2-二溴乙烷

思路： 目标分子 = 乙烷 + 相邻两个 Br → 由乙烯加成而来；乙烯由乙醇消去得到。

① CH3​CH2​OH浓H2​SO4​,170°C​CH2​=CH2​+H2​O（消去） ② CH2​=CH2​+Br2​→CH2​BrCH2​Br（亲电加成，溴水褪色）

二级结论： 消去（造双键）与加成（用双键）永远是配对出现的「前后两步」。

七、光谱解析 (Structure Elucidation)

结构解析四步法

  1. 分子式 → 不饱和度 (DBE)： DBE=C−2H​+2N​+1（每个双键或环 = 1）
  2. IR 找官能团： 有没有 O−H（醇/酸）、C=O（醛/酮/酸/酯）、C≡N
  3. ¹H NMR 数环境： 峰数 = 几种氢；积分比 = 氢数比；化学位移定类型
  4. 拼图验证： 全部信息拼起来，检查碳数、氢数、不饱和度全部吻合

光谱例题

例 7： 化合物分子式 C3​H6​O2​。IR 显示 2500–3300 cm⁻¹ 极宽强峰、1710 cm⁻¹ 强峰。推断结构。

解： ① 不饱和度：DBE=3−6/2+1=1 → 一个双键 ② 极宽 O−H（2500–3300）+ C=O（1710）→ 羧酸 −COOH ③ 羧酸已占 1 个 C + 2 个 O + 1 个不饱和度；剩下 C2​H5​ ④ 拼图：CH3​CH2​COOH（丙酸）✓

例 8： 化合物分子式 C4​H8​O。IR 无 O−H 宽峰，有 1720 cm⁻¹ C=O。¹H NMR 只有 2 组峰，积分比 9 : 1。推断结构。

解： ① 不饱和度 =4−8/2+1=1 → 一个 C=O ② 无 O−H + 有 C=O → 醛或酮 ③ NMR 仅两组峰：9H（三个等效 CH3​）+ 1H（醛氢）→ 三个甲基连在同一个碳上：(CH3​)3​C−CHO，即 2,2-二甲基丙醛 ④ 验证：碳数 4 ✓，氢数 9+1 = 8 ✓

例 9： 化合物分子式 C3​H6​O，¹H NMR 只有一组单峰（6H），无醛氢。推断结构。

解： 6H 全等效 → 两个 CH3​ 连在同一个 C=O 上 → 丙酮 CH3​COCH3​ ✓

常见丢分点

  1. 机理名称不要写反：「亲电加成」≠「亲核取代」，先看底物再看试剂！
  2. Tollens ≠ Fehling：Tollens 测所有醛；Fehling 只测脂肪醛（苯甲醛不反应）
  3. NaBH4​ vs LiAlH4​：NaBH4​ 只还原 C=O；LiAlH4​ 更强，能还原 −COOH 和 −CN
  4. 酸性/碱性解释：永远落到「阴离子稳定性」或「孤对电子可及性」，不要说「键断了」
  5. 自由基反应必写三步：引发/链增长/链终止缺一不可，且要写「均裂」
  6. 光谱题必须验证：推断完结构后回头数 C/H/O 和不饱和度，对不上就是错了
