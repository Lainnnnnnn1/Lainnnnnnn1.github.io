物理化学

物理化学 = 用数学工具理解化学反应「为什么发生」和「多快发生」。 两条腿走路：热力学（能不能） + 动力学（快不快）。

一、热力学 (Thermodynamics)

人话核心

  • 能不能发生？ → 看 ΔG（吉布斯自由能）
  • 吸热还是放热？ → 看 ΔH（焓变）
  • 变乱了还是变整齐了？ → 看 ΔS（熵变）

核心公式

ΔG=ΔH−TΔS

ΔHΔSΔG反应？
−（放热）+（更乱）永远 −自发 (feasible)
+（吸热）−（更整齐）永远 +不可能自发
−（放热）−（更整齐）低温 −；高温 +低温可行
+（吸热）+（更乱）低温 +；高温 −高温可行

例 1：可行性判断与转折温度

题目： 合成氨 N2​+3H2​→2NH3​，ΔH°=−92.2 kJ mol−1，ΔS°=−198 J K−1mol−1。298 K 下是否自发？什么温度以上不自发？

解： ① 统一单位：ΔH°=−92200 J mol−1，ΔS°=−198 J K−1mol−1 ② 代入：ΔG=−92200−298×(−198)=−92200+59004=−33196 J<0 → 298 K 自发 ✓ ③ 转折温度：ΔG=0⇒T=ΔSΔH​=19892200​≈466 K ④ 结论：T > 466 K 时 ΔG > 0，不自发——放热但熵减的反应，高温是敌人（工业合成氨用高压而不用高温，正是这个道理）

二级结论： 放热 + 熵减 → 低温可行；「转折温度 = ΔH/ΔS」每年必考，注意单位统一（kJ → J）。

例 2：量热实验计算

题目： 25.0 cm³ 2.00 mol dm⁻³ HCl 与 25.0 cm³ 2.00 mol dm⁻³ NaOH 混合，温度上升 6.8°C。求中和焓。（c=4.18 J g−1K−1，溶液密度 ≈ 1 g cm⁻³）

解： ① 溶液总质量：m=(25.0+25.0)×1=50.0 g（⚠️ 只算溶液，不加固体！） ② Q=mcΔT=50.0×4.18×6.8=1421 J ③ 生成水：n=0.0250×2.00=0.0500 mol（限量试剂） ④ ΔH=−0.0500×10001421​=−28.4 kJ mol−1（放热必带负号）

二级结论： 计算顺序永远 m→Q→n→ΔH；m 用溶液总质量，n 用限量试剂的摩尔数。

Born-Haber 循环

构建离子化合物的能量分析：

         M⁺(g) + X⁻(g)
            ↑  EA(X)     ← 电子亲和能
         M⁺(g) + X(g)
            ↑  IE(M)      ← 电离能
         M(g)  + X(g)
            ↑  ΔH_at(M)   ← 原子化焓
            ↑  ΔH_at(½X₂)
         M(s)  + ½X₂(g)
            ↓  ΔH_f       ← 生成焓
          MX(s)
            ↓  −ΔH_L      ← 晶格能

核心方程： ΔHf​=ΔHat​(M)+IE(M)+ΔHat​(X)+EA(X)−ΔHL​

Born-Haber 真题精批详见：U3

例 3：由 Born-Haber 循环求晶格能

题目： 已知 NaCl：ΔHf​=−411，ΔHat​(Na)=+107，IE(Na)=+496，½ΔHat​(Cl2​)=+122，EA(Cl)=−349（单位 kJ mol⁻¹）。求晶格能 ΔHL​。

解： 循着循环走一圈（顺时针求和 = 生成焓）： ① ΔHf​=ΔHat​(Na)+IE(Na)+ΔHat​(Cl)+EA(Cl)−ΔHL​ ② 代入：−411=107+496+122+(−349)−ΔHL​ ③ 移项：ΔHL​=107+496+122−349+411=787 kJ mol−1

二级结论： 未知量永远在「ΔHf​ 等式」的另一头；算完检查符号——晶格能必为正。

完美离子模型 vs 实际晶格能

  • 完美离子模型： 离子是完美球体，纯粹的静电引力，无共价成分
  • 实际 > 理论值： 存在共价特性（极化），额外稳定
  • 差异越大 → 共价特性越强
  • 比较晶格能： 离子越小 + 电荷越高 → 电荷密度越大 → 吸引力越强

平衡常数与 ΔG°

ΔG°=−RTlnK

ΔG°K结论
< 0> 1平衡偏向产物
= 0= 1平衡居中
> 0< 1平衡偏向反应物

例 4： 某反应 298 K 时 ΔG°=−5.7 kJ mol−1，求 K。

解： lnK=RT−ΔG°​=8.31×2985700​≈2.30⇒K=e2.30≈10。记住 RT≈2.5 kJ mol−1：ΔG°=−2.5ln10≈−5.7 就是 K=10 的「整十」题。

量热实验核心公式

Q=mcΔTΔH=n×1000Q​ (kJ mol−1)

  • ⚠️ m 只代溶液质量！不加固体的质量！
  • ⚠️ 放热 ΔH 必须加负号 (−)！

二、动力学 (Kinetics)

速率方程

Rate=k[A]m[B]n

  • k = 速率常数（温度的函数）
  • m,n = 反应级数（不是化学计量系数！，只能靠实验定）

速率常数 k 的单位推导

万能方法 — 单位消元法：

k=[A]m[B]nRate​

Rate 的固定单位：mol dm−3s−1

总级数k 的单位
0 级mol dm−3s−1
1 级s−1
2 级mol−1dm3s−1
3 级mol−2dm6s−1

例 5：由数据表求速率方程

题目： 反应 A+2B→C 的实验数据：

实验[A] / mol dm⁻³[B] / mol dm⁻³初始速率 / mol dm⁻³ s⁻¹
10.100.102.0×10−3
20.200.104.0×10−3
30.100.208.0×10−3

求速率方程和 k。

解： ① 定 A 的级数：实验 1→2，[A] ×2、[B] 不变 → 速率 ×2 → 对 A 一级 ② 定 B 的级数：实验 1→3，[B] ×2、[A] 不变 → 速率 ×4 → 对 B 二级 ③ 速率方程：Rate=k[A][B]2（⚠️ 总级数 3 与计量系数 1+2 只是巧合，不能靠系数推） ④ 求 k：k=0.10×0.1022.0×10−3​=2.0 mol−2dm6s−1

二级结论： 「控制变量」两两比：只变一个浓度，看速率变几倍——×2¹ 对一级、×2² 对二级、不变对零级。

影响反应速率的因素

因素影响机制影响什么
浓度增加碰撞频率Rate（不改 k）
温度增加碰撞能量 + 频率；更多分子突破 Ea​Rate + k
催化剂提供替代路径，降低 Ea​Rate + k
表面积增加反应接触面Rate（不改 k）

Arrhenius 方程

k=Ae−Ea​/RT

  • A = 指前因子（碰撞频率 + 取向因素）
  • Ea​ = 活化能
  • T↑ → k↑；Ea​↓ → k↑

线性化（作图法）： lnk=lnA−REa​​⋅T1​

lnk 对 1/T 作图 → 斜率 =−Ea​/R，截距 =lnA。

例 6：由两个温度求活化能

题目： 某反应 300 K 时 k1​，310 K 时 k2​=2k1​。求 Ea​。

解： ① 公式：lnk1​k2​​=REa​​(T1​1​−T2​1​) ② 代入：ln2=8.31Ea​​(3001​−3101​)=8.31Ea​​×1.08×10−4 ③ Ea​=1.08×10−40.693×8.31​≈5.3×104 J mol−1=53 kJ mol−1

二级结论： Ea​≈50 kJ mol−1 时温度每升 10 K 速率约翻倍；活化能越高，k 对温度越敏感。

例 7：催化剂的效果

题目： 催化剂把 Ea​ 从 100 kJ mol⁻¹ 降到 50 kJ mol⁻¹（298 K）。k 增大多少倍？

解： lnk1​k2​​=RTEa1​−Ea2​​=8.31×29850000​≈20.2⇒k1​k2​​=e20.2≈6×108

结论： 活化能砍一半，速率提高近 10⁹ 倍——催化剂的威力是指数级的。催化剂不改变 ΔH、ΔG、平衡位置，只改「路」。

Maxwell-Boltzmann 分布

     分布曲线
      /\
     /  \____
    /       \____
   /            \____ ← Ea 线
  /                  \__
 /______________________\__
       动能 →
  • 升温： 曲线向右拉平变矮 → 越过 Ea​ 的分子数暴增 → 速率暴增
  • 催化剂： Ea​ 线向左移 → 同样温度下更多分子够格反应

三、电化学 (Electrochemistry)

标准电极电势

Ecell∘​=ERight∘​−ELeft∘​

  • 正极 (Right)： 发生还原（得电子）
  • 负极 (Left)： 发生氧化（失电子）
  • Ecell∘​>0： 反应自发（可行）

标准氢电极 (SHE)

  • 电极： 铂黑 Pt（惰性导电）
  • 气体： H2​ at 100 kPa
  • 溶液： H+ 浓度 1.00 mol dm−3
  • 温度： 298 K

电池表示法 (Cell Representation)

格式： 负极∣负极溶液∣∣正极溶液∣正极

例: Al | Al³⁺ || Cu²⁺ | Cu
   左边(氧化)       右边(还原)

⚠️ 没有固体电极时（如 Cl2​/Cl−），必须用惰性电极 Pt！

Nernst 方程（非标准条件）

E=E∘−nFRT​lnQ或E=E∘−n0.059​logQ (298K)

例 8：非标准条件下的 EMF

题目： 电池 Zn(s)∣Zn2+(0.010 M)∣∣Cu2+(1.00 M)∣Cu(s)，E°cell​=1.10 V。求 298 K 时电动势。

解： ① 写反应：Zn+Cu2+→Zn2++Cu，转移电子数 n=2 ② 反应商：Q=[Cu2+][Zn2+]​=1.000.010​=0.010 ③ 代入：E=1.10−20.059​log(0.010)=1.10+20.059​×2=1.10+0.059=1.159 V ④ 解释：Zn2+ 被稀释 → 逆反应倾向减弱 → 电池「更有劲」，EMF 上升

二级结论： Nernst 题三步：写反应 → 算 Q → 代公式；n 是转移电子数（写半反应数！）。

影响 EMF 的因素

因素影响
电极材料决定电势值本身
离子浓度改变（Nernst）；浓度↑ → 还原倾向↑ → E 变正
温度改变（但通常控制在 298K）
电极大小不影响 EMF！（只影响容量/能用多久）

四、量子化学入门

核心思想

化学反应的本质 = 电子重新排布。量子化学用量子力学描述电子行为。

原子轨道 → 分子轨道

  • 原子轨道 (AO)： s,p,d,f → 单个原子的电子「房间」
  • 分子轨道 (MO)： 原子轨道线性组合 → 成键轨道（能量低）+ 反键轨道（能量高）
  • σ 键： 头对头重叠（s−s,s−pz​,pz​−pz​）
  • π 键： 肩并肩重叠（px​−px​,py​−py​）

核心公式

公式用途

例 9：缓冲溶液计算

题目： 50.0 cm³ 0.100 mol dm⁻³ CH3​COOH（pKa​=4.76）中加入 25.0 cm³ 0.100 mol dm⁻³ NaOH。求 pH。

解： ① 反应前：na​=0.0500×0.100=5.00×10−3 mol；nOH−​=0.0250×0.100=2.50×10−3 mol ② 反应后：剩余酸 na′​=5.00×10−3−2.50×10−3=2.50×10−3；生成盐 ns​=2.50×10−3 ③ pH=pKa​+logna​ns​​=4.76+log1=4.76 ④ 验证：加了一半碱中和 → 「半中和点」，pH 恒等于 pKa ✓

二级结论： 半中和点（ns​=na​）pH = pKa——这是缓冲题最快的检查点。

缓冲溶液计算套路

  1. 算酸的摩尔数 → na​
  2. 算盐/共轭碱摩尔数 → ns​
  3. 注意总体积两边都有 → 约掉
  4. 代入 pH=pKa​+logna​ns​​

酸碱计算详解：PH 和 U3

常见丢分点

  1. ΔG 负值才自发 — 正值不反应！
  2. ΔG=0 是平衡态 — 不是「不反应」，是正逆速率相等
  3. k 的单位必须会推导 — 每年必考
  4. 速率方程级数 ≠ 化学计量系数 — 只能实验定
  5. 催化剂不改 ΔH / ΔG / 平衡位置 — 只改 Ea​ 和速率
  6. Nernst 的 n 是转移电子数 — 写错 n 整题报废
  7. 单位不统一直接错 — kJ 与 J、cm³ 与 dm³ 换算先行
