环境化学

环境化学研究化学物质在空气、水、土壤中的迁移、转化与归宿。核心逻辑只有一条：污染物从哪里来、到哪里去、变成什么、有什么后果。

一、大气化学

1.1 臭氧层与 Chapman 循环

平流层臭氧的生成-消亡循环：

生成：O2​hν(<242nm)​2O，O+O2​+M→O3​+M 消亡：O3​hν​O2​+O，O+O3​→2O2​

稳态臭氧浓度由生成与消亡平衡决定。CFC（氟利昂）破坏臭氧的催化循环：

Cl+O3​→ClO+O2​,ClO+O→Cl+O2​

净结果 O3​+O→2O2​，Cl 原子在循环中再生——一个 Cl 可破坏上万个臭氧分子。这就是《蒙特利尔议定书》淘汰 CFC 的原因。

1.2 酸雨

来源：SO2​（燃煤）与 NOx​（汽车尾气）在大气中被氧化成强酸：

2SO2​+O2​催化​2SO3​,SO3​+H2​O→H2​SO4​ 2NO+O2​→2NO2​,3NO2​+H2​O→2HNO3​+NO

正常雨水因溶解 CO2​ 呈弱酸性（pH ≈ 5.6）；pH < 5.6 即为酸雨。危害：腐蚀建筑（大理石 CaCO3​ 与酸反应）、酸化湖泊、淋失土壤养分。

1.3 温室效应

CO2​、CH4​、N2​O、H2​O 吸收地表红外辐射，使地表温度升高。增温潜势（GWP，以 CO2​ 为 1，100 年尺度）：CH4​≈28，N2​O≈265——微量气体对温室效应的贡献可能远超其浓度占比。

二、水化学

2.1 水的 pH 与缓冲

天然水体 pH 由碳酸盐体系缓冲：CO2​⇌H2​CO3​⇌HCO3−​⇌CO32−​。缓冲容量被酸雨耗尽后 pH 骤降，会释放沉积物中吸附的重金属。

2.2 硬度

  • 总硬度 = [Ca2+]+[Mg2+]，以 CaCO3​ 当量计（mg/L）
  • 暂时硬度（碳酸氢盐硬度）：煮沸分解 Ca(HCO3​)2​→CaCO3​↓+CO2​+H2​O，可去除
  • 永久硬度（硫酸盐、氯化物）：煮沸不除，需离子交换或化学软化

2.3 例题：硬度计算

问题：某水样含 [Ca2+]=40mg/L，[Mg2+]=12mg/L。以 CaCO3​ 计的总硬度是多少？（MCa​=40，MMg​=24，MCaCO3​​=100）

解题思路：

  1. 钙：40×(100/40)=100mg/L CaCO3​ 当量
  2. 镁：12×(100/24)=50mg/L CaCO3​ 当量
  3. 总硬度 =100+50=150mg/L CaCO3​（中等硬水）

2.4 溶解氧与富营养化

  • 溶解氧（DO）：好氧微生物分解有机物的氧气来源；DO 低说明有机污染重
  • 生化需氧量（BOD）：微生物分解有机物消耗的氧量，BOD 越高污染越重
  • 富营养化：N、P 过量 → 藻华 → 藻类死亡分解耗氧 → 缺氧死水区（湖泊”水华”、近海”赤潮”）

三、土壤化学

3.1 土壤 pH 与盐碱化

  • 酸性土壤（pH < 5.5）：Al3+ 溶出毒害植物根系，用石灰（CaCO3​、CaO）改良
  • 盐碱化：灌溉水蒸发留下 Na+，Na+ 置换 Ca2+ 破坏团粒结构 → 土壤板结
  • 阳离子交换量（CEC）：土壤胶体（黏土、腐殖质）吸附阳离子的能力，决定保肥能力；Ca2+、Mg2+ 被吸附则保肥，H+、Al3+ 占位则酸化

3.2 例题：土壤改良

问题：某酸性土壤需中和 2.0×103mol 的 H+（每公顷），用 CaCO3​（M=100）中和，需多少 kg？

解题思路：

  1. 反应：CaCO3​+2H+→Ca2++CO2​+H2​O，1 mol CaCO3​ 中和 2 mol H+
  2. n(CaCO3​)=2.0×103/2=1.0×103mol
  3. m=1.0×103×100=1.0×105g=100kg/ha

四、重金属污染

4.1 典型污染物表

元素主要来源危害特征
Hg氯碱工业、燃煤神经毒（水俣病）甲基汞脂溶性，生物富集
Cd电镀、冶炼肾损伤（骨痛病）易被水稻吸收
Pb电池、冶炼神经毒，影响儿童发育土壤中持久难降解
As农药、矿业致癌价态决定毒性：As3+>As5+
Cr电镀、皮革致癌Cr6+ 剧毒，Cr3+ 为必需微量元素

4.2 生物富集与食物链放大

重金属沿食物链逐级浓缩（富集因子可达 105–106）：水 → 浮游植物 → 浮游动物 → 鱼 → 人。脂溶性形态（甲基汞）最易穿透生物膜，危害最大。

4.3 修复方法

  • 物理：客土换土、电动修复
  • 化学：调 pH 沉淀（石灰）、螯合淋洗
  • 生物：超富集植物吸收（植物修复）、微生物氧化还原转化

五、绿色化学

绿色化学 12 原则（Anastas & Warner, 1998）的核心：

  1. 预防优于治理：不产生废物好于处理废物
  2. 原子经济性：AE=所有反应物分子量之和目标产物分子量​×100%
  3. 使用更安全的化学品与合成路线
  4. 优先可再生原料
  5. 催化优于化学计量：催化剂用量少、可循环
  6. 减少衍生物与保护基的使用
  7. 产品可降解设计

例题：原子经济性

问题：比较环氧乙烷两条合成路线的原子经济性。A. 氯醇法：C2​H4​+Cl2​+Ca(OH)2​→C2​H4​O+CaCl2​+H2​O；B. 直接氧化：2C2​H4​+O2​→2C2​H4​O。

解题思路：

  1. A 路线：AE=44/(28+71+74)≈25%，大量副产物 CaCl2​
  2. B 路线：AE=2×44/(2×28+32)=100%
  3. 结论：直接氧化法原子经济性 100%，这正是现代工业改用银催化直接氧化的原因

常见丢分点

  1. 正常雨水 pH ≈ 5.6（溶解 CO2​），不是 7；酸雨判据是 pH < 5.6
  2. 暂时硬度煮沸可除、永久硬度不可——先看阴离子是 HCO3−​ 还是 SO42−​/Cl−
  3. 重金属毒性看化学形态：Cr6+、As3+ 剧毒，Cr3+、As5+ 相对温和
  4. 原子经济性只算目标产物、不算副产物，与产率（转化率）是两个指标
  5. 温室气体不只 CO2​：CH4​、N2​O 单分子增温潜势更高
