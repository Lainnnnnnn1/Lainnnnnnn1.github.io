生物化学

生物化学研究生命分子的结构与功能。核心主线：结构决定功能，代谢通路只是这条主线的展开。

氨基酸与蛋白质

20 种标准氨基酸

所有蛋白质由 20 种 α-氨基酸构成。通用结构：

H2​N−CHR−COOH

差异仅在侧链 R。按侧链性质分类：

类别氨基酸特征
非极性Gly, Ala, Val, Leu, Ile, Pro, Phe, Trp, Met疏水核心
极性不带电Ser, Thr, Cys, Tyr, Asn, GlnH 键形成
酸性（带负电）Asp, GlupH 7 去质子化
碱性（带正电）Lys, Arg, HispH 7 质子化

等电点 pI 与计算

定义： 氨基酸净电荷为零时的 pH。

计算方法（三选二原则）：

  • 中性氨基酸： pI=2pKa1​+pKa2​​（两个 α 基团取平均）
  • 酸性氨基酸（侧链 COOH）：pI=2pKa1​+pKaR​​（两个最低的 pKa 取平均）
  • 碱性氨基酸（侧链 NH2​）：pI=2pKa2​+pKaR​​（两个最高的 pKa 取平均）

例 1：pI 计算四连

氨基酸pKa₁ (α-COOH)pKa₂ (α-NH₃⁺)pKaR (侧链)pI计算
甘氨酸 Gly2.349.60—5.97(2.34+9.60)/2
天冬氨酸 Asp2.099.823.86 (COOH)2.98(2.09+3.86)/2
赖氨酸 Lys2.188.9510.53 (NH₂)9.74(8.95+10.53)/2
组氨酸 His1.829.176.00 (咪唑)7.59(6.00+9.17)/2

解题三步： ① 列出所有可电离基团的 pKa（别漏侧链！） ② 判断类型：侧链有 COOH → 酸性（取两低）；侧链有 NH2​ → 碱性（取两高）；否则中性（取两个 α） ③ 平均后检查：酸性 pI < 7，碱性 pI > 7，中性 ≈ 6

应用（电泳）： pH < pI → 带正电（向负极跑）；pH > pI → 带负电（向正极跑）；pH = pI → 不动。电泳分离混合氨基酸就靠这个。

肽键

−COOH+H2​N−→−CO−NH−+H2​O

肽键具有部分双键性质（共振），限制了旋转。ϕ（N–Cα）和 ψ（Cα–C）二面角决定主链构象——Ramachandran 图。

蛋白质四级结构

级别定义键/力例子
一级氨基酸序列共价（肽键）“MVLSPADK…”
二级局部折叠H 键（主链）α-螺旋, β-折叠
三级整条链的空间构象疏水作用, 二硫键, 离子键, H 键肌红蛋白

α-螺旋：3.6 残基/圈，H 键在 i 与 i+4 之间。β-折叠：相邻链段间 H 键，可平行或反平行。

酶与催化

酶的基本性质

酶是生物催化剂，绝大多数是蛋白质（少数 RNA 核酶）。特征：

  • 高催化效率：kcat​/kuncat​ 可达 106–1017
  • 高专一性：锁钥模型 → 诱导契合模型
  • 可调控：别构调节、共价修饰、反馈抑制

Michaelis–Menten 动力学

v0​=Km​+[S]Vmax​[S]​

  • Vmax​：最大反应速率（所有酶被底物饱和）
  • Km​：半饱和底物浓度，反映亲和力（Km​ 越小，亲和力越大）
  • kcat​=Vmax​/[E]t​：转换数

例 2：MM 方程直接计算

题目： 某酶 Km​=2.5 mM，Vmax​=100 μmol min−1。求 [S]=5.0 mM 时的初速率；[S]=Km​ 时呢？

解： ① v0​=Km​+[S]Vmax​[S]​=2.5+5.0100×5.0​=66.7 μmol min−1 ② [S]=Km​：v0​=Km​+Km​Vmax​×Km​​=2Vmax​​=50 μmol min−1

二级结论： [S]≫Km​ → v0​→Vmax​（饱和）；[S]≪Km​ → v0​≈Km​Vmax​​[S]（一级反应——「kcat​/Km​ 是催化效率」就是这么来的）。

Lineweaver–Burk 双倒数作图

v0​1​=Vmax​Km​​⋅[S]1​+Vmax​1​

  • 斜率 =Km​/Vmax​，纵截距 =1/Vmax​，横截距 =−1/Km​
  • 本质： 把双曲线方程线性化成直线 y=mx+c——数学上就是取倒数

要点内容

代谢概览

糖酵解 (Glycolysis)

葡萄糖 → 2 丙酮酸，净产 2 ATP + 2 NADH。发生在细胞质。10 步反应，3 个不可逆步骤（己糖激酶、PFK-1、丙酮酸激酶）是调控位点。

代谢路径记忆法

糖酵解 10 步 → 3 段记忆：

  1. 投资段（1–3 步）： 葡萄糖 → 果糖-1,6-二磷酸，花掉 2 ATP
  2. 裂解段（4–5 步）： 六碳糖劈成两个三碳（3-磷酸甘油醛）
  3. 收获段（6–10 步）： 每个三碳分子产 2 ATP + 1 NADH → 两个三碳共 4 ATP + 2 NADH

净账： −2+4=+2 ATP，+2 NADH。三个不可逆步骤 = 三个调控开关。

TCA 循环 8 步中文记忆（每步取首字）：

柠 → 异 → 酮 → 琥 → 琥 → 延 → 苹 → 草 柠檬酸 → 异柠檬酸 → α-酮戊二酸 → 琥珀酰-CoA → 琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸

产物账（每乙酰-CoA）： 2 CO₂ + 3 NADH + 1 FADH₂ + 1 GTP（=ATP）。

TCA 循环 (Krebs Cycle)

乙酰-CoA → 2 CO2​，产 3 NADH + 1 FADH2​ + 1 GTP。发生在线粒体基质。

回补反应：丙酮酸羧化酶补足草酰乙酸。

氧化磷酸化

电子传递链 (ETC) 将 NADH/FADH2​ 的电子传给 O2​，泵出质子建立质子梯度。ATP 合酶利用质子回流驱动 ADP + Pi → ATP。

复合体电子供体质子泵出
I (NADH 脱氢酶)NADH4 H+
II (琥珀酸脱氢酶)FADH2​0
III (细胞色素 bc1​)泛醌4 H+
IV (细胞色素 c 氧化酶)细胞色素 c2 H+

1 个 NADH → ~2.5 ATP，1 个 FADH2​ → ~1.5 ATP。一分子葡萄糖完全氧化 → ~30–32 ATP。

常见丢分点

  1. 氢键 vs 疏水作用：α-螺旋和 β-折叠靠主链 H 键，三级结构靠疏水作用驱动折叠。
  2. Km​ 的含义：Km​ 是动力学常数，不等于 Kd​，但在 k−1​≫kcat​ 时近似。
  3. 竞争性抑制的 Vmax：加足够多底物可以”挤掉”抑制剂，所以 Vmax​ 不变。
  4. TCA 循环不直接需氧：TCA 本身不需要 O2​，但需要 NAD+，其再生依赖有氧的 ETC。
  5. pI 计算别乱平均：酸性氨基酸取两个最低 pKa，碱性取两个最高——取错直接丢分。
  6. DNA 聚合酶要引物，RNA 聚合酶不要 — 一字之差，年年有人错。
