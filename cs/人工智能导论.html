人工智能导论

让机器做需要”智能”才能做的事。难点不在”做”，在定义什么算智能——所以 AI 史就是一部定义不断被推翻的历史。

AI 三大学派

学派核心信念代表成果衰落原因
符号主义智能 = 符号操作与逻辑推理专家系统、定理证明常识无法形式化，规则爆炸
连接主义智能 = 神经网络的学习感知机 → 深度学习算力/数据不足，可解释性差
行为主义智能 = 与环境交互的适应机器人、强化学习早期缺乏数学框架

1956 达特茅斯会议是 AI 的诞生标志；两次”AI 寒冬”分别由专家系统泡沫和连接主义算力瓶颈引发；2012 年 AlexNet 之后进入深度学习时代。

历史教训：对”通用智能”的过度承诺导致资金断流。现在的 AGI 叙事需要同样的警惕。

搜索算法：智能的经典形式

很多问题可以抽象为状态空间搜索：节点 = 状态，边 = 动作，目标 = 找从起点到目标的路径。

无信息搜索

算法数据结构完备性最优性时间 / 空间
BFS队列（先进先出）完备最优（步数相同）O(b^d) / O(b^d)
DFS栈（后进先出）不完备（可能有环）不保证O(b^m) / O(bm)
迭代加深限深 DFS 逐层加深完备（限深足够）最优O(b^d) / O(bd)

b = 分支因子，d = 最浅解深度，m = 搜索树最大深度。BFS 的空间是硬伤，DFS 的时间可能无限。

A*：启发式搜索

f(n)=g(n)+h(n)

  • g(n)：从起点到 n 的实际代价
  • h(n)：从 n 到目标的启发式估计

A 最优的充要条件*：h(n) 一致（consistent）——满足三角不等式 h(n)≤c(n,n′)+h(n′)，此时 f 沿路径不减，A* 第一次扩展目标即最优。一致性蕴含可采纳性（h(n)≤h∗(n)），反之不成立。

性质定义作用
可采纳从不高估真实代价A* 最优的必要条件
一致满足三角不等式更强，保证无需重开节点

8 数码问题常用启发式：错位数（弱）、曼哈顿距离（强）。曼哈顿距离可采纳：每步只把一个格子移动一格，真实步数 ≥ 曼哈顿距离。

博弈树与 Minimax

双人零和博弈：Max 想最大化，Min 想最小化。

V(n)=⎩⎨⎧​terminal(n),maxc​V(c),minc​V(c),​n 是叶子n 是 Max 层n 是 Min 层​

Alpha-Beta 剪枝：维护 α（Max 已知下限）、β（Min 已知上限），当 α≥β 时剪掉该分支。最优排序下复杂度从 O(bd) 降到 O(bd/2)——同样时间能多看一倍深度。

约束满足问题 CSP

状态 = 变量的赋值，目标 = 满足所有约束的完整赋值。与搜索的区别：没有路径代价，只有赋值是否合法。

技术思想
回溯搜索依次给变量赋值，冲突就回退（DFS + 约束检查）
前向检验赋值后立即删掉邻居域中冲突的值
弧一致性 AC-3迭代修剪域，直到每对约束都一致
最少剩余值启发式每次选”可选值最少”的变量先赋值

地图着色、数独、排课都是 CSP。数独就是 81 个变量、每格域 1–9、行/列/宫约束——用回溯 + 前向检验几毫秒解完。

机器学习与 AI 的关系

机器学习是 AI 的一个子领域：不写规则，从数据里学规则。三大范式：

范式输入目标例子
监督学习(x, y) 标签对学 f: x → y分类、回归
无监督学习只有 x找结构聚类、降维
强化学习环境 + 奖励学最优策略博弈、机器人

深度学习是连接主义的具体实现：多层神经网络 + 反向传播 + 梯度下降。详见 机器学习。

NLP 基础

NLP 的进步史 = 表示方法的演进史：

时代表示方法缺点
词袋词频向量丢失词序和语义
TF-IDF词频 × 逆文档频率仍是稀疏符号
词向量稠密向量，语义相近的词距离近一词一义，无法处理多义词
预训练模型上下文相关表示（BERT/GPT）算力成本高

TF-IDF 公式：

tf-idf(t,d)=tf(t,d)×logdf(t)N​

tf 是词在文档中的频率，df 是包含该词的文档数，N 是总文档数。log 项惩罚”到处都出现”的常见词。

n-gram 语言模型

把句子概率拆成条件概率乘积，用马尔可夫假设只保留最近 n−1 个词：

P(w1​⋯wm​)=∏i=1m​P(wi​∣wi−n+1​⋯wi−1​)

n=1 是 unigram（词独立），n=2 是 bigram，n=3 是 trigram。参数用语料统计：P(wi​∣wi−1​)=count(wi−1​)count(wi−1​,wi​)​。

零概率问题：没见过的 n-gram 概率为 0 会毁掉整个乘积——用平滑（加一平滑、Kneser-Ney）。GPT 的本质是 n 极大的语言模型 + 神经网络参数化。

AI 伦理

  • 偏见：训练数据的历史偏见被模型放大——“垃圾进，垃圾出”的放大版
  • 可解释性：深度学习是黑箱，金融风控、医疗场景要求能解释决策
  • 对齐问题：目标函数没写对，优化出来的行为与人类意图不符
  • 责任归属：出错时谁负责——算法、开发者还是使用者

伦理不是道德说教，是工程约束：无偏见数据、可审计日志、人类兜底决策。

例题

例 1：8 数码初始状态错位数 6、曼哈顿距离 10。A* 用哪个启发式扩展节点更少？

解：曼哈顿距离。它 ≥ 错位数（额外惩罚”离目标远”），更接近真实代价 h∗，启发式更强 → 扩展节点更少。两者都可采纳，但强启发式效率更高。

例 2：博弈树根节点为 Max 层，第一个子节点已算出值 5（α=5）；第二个子节点（Min 层）的第一个孙节点值为 3。能否剪枝？

解：能。该 Min 节点值 ≤ 3（取 min），而 Max 已有 5 的保底，β=3<α=5，此 Min 子树其余分支全部剪掉。

例 3：h(n) ≡ 0 的 A* 退化成什么？

解：退化为 Dijkstra（加权图的最短路）。h≡0 可采纳但信息量为零——启发式搜索退化为无信息搜索。

例 4：用 bigram 模型估计句子”猫 吃 鱼”的概率，语料中 count(猫,吃) = 3，count(吃,鱼) = 2，count(猫) = 5，count(吃) = 10。

解：P(猫吃鱼)=P(猫)P(吃∣猫)P(鱼∣吃)。若句首概率按 unigram 估计 P(猫)=5/N，则 =N5​×53​×102​=N3​。关键：联合概率被拆成可统计的条件概率，这就是马尔可夫假设的价值。

二级结论

  1. 搜索的本质是”用空间换时间”：BFS 换最优性，DFS 换空间，A* 用启发信息换效率。
  2. 可采纳性是 A* 最优的底线；一致性是工程上更常用的充分条件。
  3. Alpha-Beta 剪枝不改变结果，只砍掉不可能影响决策的分支。
  4. 符号主义死于”常识的形式化”，连接主义死于”算力”——两者都死于承诺过度。
  5. 知识表示的选择永远是表达力与推理成本的权衡。
  6. NLP 的进步史 = 表示从稀疏符号到稠密语义的演进史。
  7. 强启发式（接近 h∗）扩展节点少，但计算启发式本身也有成本——要算总账。
  8. AI 伦理问题本质是工程问题：数据、审计、兜底。
