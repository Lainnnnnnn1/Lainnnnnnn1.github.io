机器学习 Machine Learning

人话讲解

传统编程：人写规则 → 计算机执行。机器学习：给计算机数据和答案 → 它自己找出规则。 从垃圾邮件过滤到 ChatGPT，本质都是：定义一个损失函数，然后梯度下降找最优参数。

「Machine learning is the science of getting computers to act without being explicitly programmed.」— Andrew Ng

三大范式

监督学习 Supervised Learning

有标签数据 (x, y)，学一个映射 f: x → y。

无监督学习 Unsupervised Learning

没有标签，找数据自己的结构。

强化学习 Reinforcement Learning

Agent 在环境中采取行动，根据奖励信号学习最优策略。

        ┌──────────┐
        │  Agent   │
        └────┬─────┘
   动作 a_t   │   状态 s_t, 奖励 r_t
        ┌────▼─────┐
        │Environment│
        └──────────┘

核心概念：状态 s，动作 a，奖励 r，策略 π，价值函数 V(s) 或 Q(s, a)。

Bellman 方程（RL 的灵魂）：

Q(s,a)=r+γ⋅maxa′​Q(s′,a′)

损失函数 Loss Function

损失函数 = 模型预测和真实答案的差距。选错损失函数，梯度下降再厉害也白搭。

损失公式特点适用
MSE 均方误差n1​∑(y−y^​)2大误差惩罚重；对异常值敏感回归（默认）
MAE 平均绝对误差n1​∑∥y−y^​∥对异常值鲁棒；但 0 点不可导回归（有离群点）
HuberMSE 和 MAE 的折中小误差用 MSE，大误差用 MAE鲁棒回归
交叉熵 Cross-Entropy−∑ylogy^​概率分布间的距离分类（默认）
Hingemax(0,1−yy^​)间隔损失SVM

为什么分类用交叉熵不用 MSE：分类输出过 softmax，MSE 的梯度在 softmax 饱和区趋近 0，学不动；交叉熵的梯度正比于预测误差，训练快得多。回归用 MSE：回归输出没有「概率」语义。

变体对比

方法更新规则要点优点缺点
GD 批量用全量数据算梯度方向准慢，内存大
SGD每次用 1 个样本快，能跳出局部极小噪声大，震荡
Mini-batch每次用一小批（32/64/128）兼顾速度与稳定默认选择
Momentum累积历史梯度方向冲过平坦区，减少震荡可能冲过头
RMSProp按梯度平方自适应学习率每个参数自己的步长—
AdamMomentum + RMSProp + 偏置校正默认首选，几乎不用调内存多一倍

Adam 直觉：Momentum 管「方向」（像小球带惯性），RMSProp 管「步长」（陡的地方小步，平的地方大步）。工程经验：先用 Adam 跑通，追求 SOTA 再换 SGD + 学习率调度。

神经网络 Neural Network

单层感知机 → 深层网络

激活函数 Activation Function

为什么需要非线性？ 因为多层线性 = 一层线性。不加激活函数，再深的网络也只能表达线性变换。

┌──────────┬──────────────────────────┬──────────┐
│ 函数      │ 公式                      │ 特点      │
├──────────┼──────────────────────────┼──────────┤
│ Sigmoid  │ σ(x) = 1/(1+e^(-x))      │ 输出(0,1) │
│ Tanh     │ tanh(x)                   │ 输出(-1,1)│
│ ReLU     │ max(0, x)                 │ 计算快     │
│ GELU     │ x·Φ(x)                    │ Transformer│
│ Swish    │ x·σ(x)                    │ 自门控     │
└──────────┴──────────────────────────┴──────────┘

ReLU 为什么好？ 导数要么 0 要么 1，梯度不会在深层网络中消失（对比 Sigmoid 两端导数趋近 0）。

CNN 与 RNN

CNN 卷积神经网络 — 图像

输入图像 → [卷积 Conv] → [池化 Pool] → [卷积] → [池化] → 展平 → [全连接] → 输出
            提取局部特征     降采样

核心思想：卷积核（如 3×3）在图像上滑动，检测局部模式——浅层学边缘，中层学纹理，深层学部件和物体。权值共享：同一个卷积核扫遍全图，参数远少于全连接层。池化：取窗口内最大值/平均值，缩小尺寸、增强平移不变性。

参数量对比：100×100 图像接 1000 个神经元的全连接层要 10⁷ 个参数；3×3 卷积核一个通道只要 9 个参数。

RNN 循环神经网络 — 序列

        y₁        y₂        y₃
        ▲         ▲         ▲
      [h₀]→[h₁]→[h₂]→[h₃]
        ▲    ▲    ▲    ▲
       x₁   x₂   x₃   x₄

核心思想：隐藏状态 hₜ 携带「到目前为止的记忆」，同一套权重在每个时刻复用。问题：长序列梯度消失 → LSTM/GRU 用门控机制选择性记忆。Transformer 用注意力替代 RNN 的串行结构，可以并行训练。

Self-Attention 公式

Attention(Q,K,V)=softmax(dk​​QKT​)V

为什么 ÷ √d_k？ 当 d_k 很大时，QKᵀ 的值也很大，softmax 会变得很「陡」（梯度接近 0）。除以 √d_k 保持方差稳定。

评估指标 Evaluation

混淆矩阵 Confusion Matrix

              预测正  预测负
实际正         TP      FN
实际负         FP      TN
指标公式含义
Accuracy 准确率(TP+TN)/全部总体正确率（不平衡数据会骗人）
Precision 精确率TP/(TP+FP)预测为正的里面有多少是真的（宁缺毋滥）
Recall 召回率TP/(TP+FN)真的正例里抓到了多少（宁滥毋缺）
F12PR/(P+R)Precision 和 Recall 的调和平均

例题：癌症检测，1000 人里 10 个患病。模型全部预测「没病」→ Accuracy = 99%，但 Recall = 0，完全没用。所以不平衡数据看 F1。

ROC / AUC：ROC 曲线 = 不同阈值下 (FPR, TPR) 的轨迹；AUC = 曲线下面积 = 随机抽一个正例一个负例，模型给正例打分更高的概率。AUC = 0.5 是瞎猜，1.0 是完美。AUC 对类别不平衡不敏感，是二分类最稳的指标。

过拟合与正则化

过拟合 Overfitting

训练集准确率 99% → 测试集 70% → 过拟合了！

对策：
├── 更多数据
├── 正则化 L1/L2
├── Dropout（随机关神经元）
├── Early Stopping
├── 数据增强 Data Augmentation
└── 更简单的模型

偏差-方差权衡 Bias-Variance Tradeoff

总误差 = 偏差² + 方差 + 噪声
欠拟合 ← 偏差大（模型太简单）   过拟合 ← 方差大（模型太复杂）

L1 vs L2 正则化

L1 (Lasso)L2 (Ridge)
惩罚项λ∑∥wi​∥λ∑wi2​
效果把不重要的权重压成 0（特征选择）把权重缩小但不归零
解的性质稀疏平滑
几何直觉菱形约束，角上容易触到 0圆形约束

Dropout

训练时随机「关掉」一部分神经元（如 50%），迫使网络学到冗余的分布式表示，防止神经元之间过度依赖。可以理解为每次训练都在训一个不同的子网络，预测时用全部（乘保留概率）。

K 折交叉验证

把训练集分成 K 份：每次拿 1 份当验证集，其余 K-1 份训练，轮流 K 次
取 K 次验证误差的平均 → 更稳的模型评估（K 常用 5 或 10）

为什么不用测试集调参：测试集只能看一次，用它调参 = 把测试集信息泄漏进模型（数据泄露）。

梯度消失/爆炸

梯度消失：深层网络前面的层梯度 ≈ 0 → 学不动
梯度爆炸：梯度越来越大 → 参数变成 NaN

对策：
├── ReLU 代替 Sigmoid/Tanh
├── Batch Normalization
├── 残差连接 Residual Connection（Transformer 的关键）
└── 梯度裁剪 Gradient Clipping

二级结论速查

  1. 回归用 MSE，分类用交叉熵——默认配置
  2. Adam 是万能起点，SGD + 学习率调度是冲 SOTA 的终点
  3. 过拟合信号：训练误差持续下降 + 验证误差回升
  4. 不平衡数据看 F1 / AUC，不要看 Accuracy
  5. CNN 管局部、RNN 管序列、Transformer 管长程——现代模型是它们的组合
  6. 归一化要在切分训练/测试之后做，否则就是数据泄露

常见坑

  1. 数据泄露 — 用测试集的信息影响了训练（如先对整个数据集做标准化再切分）
  2. 不平衡数据 — 99% 正例，模型全猜「正」也有 99% 准确率…但这个模型没用
  3. 只盯着准确率 — 分类任务要看 Precision/Recall/F1，尤其是不平衡数据
  4. 不会调学习率 — 太大不收敛，太小收敛慢。Adam 是万能的起点
  5. 测试集反复用 — 同一份测试集调参十次，它已经变成验证集了
