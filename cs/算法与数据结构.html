算法与数据结构 Algorithms & Data Structures

人话讲解

算法 = 做事的步骤。数据结构 = 怎么把数据组织起来让算法跑得更快。 一个烂算法能把 O(n) 的事做成 O(2^n)，差出宇宙级别。搞懂 Big-O，你就拿到了分析任何代码性能的显微镜。

「Smart data structures and dumb code works a lot better than the other way around.」— Eric S. Raymond

复杂度分析 Big-O

核心概念

Big-O 描述的是增长趋势，不是精确时间。忽略常数和低阶项。

复杂度名称例子n=100 时
O(1)常数数组下标访问1
O(log n)对数二分查找~7
O(n)线性遍历数组100
O(n log n)线性对数归并排序~664
O(n²)平方冒泡排序10,000
O(2ⁿ)指数暴力子集枚举1.27×10³⁰
O(n!)阶乘旅行商暴力解💀

复杂度排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!) 主定理：递归 T(n)=aT(n/b)+f(n)，比较 nlogb​a 与 f(n) 定阶（小于→O(nlogb​a)，相等→O(nlogb​alogn)，大于→O(f(n))）。例：归并 T(n)=2T(n/2)+n → O(nlogn)。

稳定性：相等元素排序后相对顺序不变。需要「先按时间排、再按优先级排」时，必须用稳定排序。

快速排序 Quick Sort — 分治典范

关键洞察：平均 O(n log n) 因为 pivot 大致把数组分两半。最坏 O(n²) 出现在已排序数组 + 选第一个为 pivot，随机化可避免。

排序怎么选（二级结论）

  1. 小数组（< 50）：插入排序，常数极小
  2. 通用：快速排序（qsort、TimSort 都是其变体）
  3. 要稳定：归并排序
  4. 固定范围整数：计数排序 O(n+k)，绕开比较下界；内存受限 / Top-K：堆排序 O(n log k)

比较排序下界：任何基于比较的排序至少 O(n log n)。

搜索算法 Searching

二分查找 Binary Search — O(log n)

前提：数组有序。每次砍一半，log₂ n 次找到。

二分变体（面试高频）

二级结论：二分本质不是「数组有序」，而是答案单调——能把问题化成「check(mid) 是否成立」，就能二分。lo < hi + hi = mid 左闭右开写法防死循环。变体：旋转数组找最小值（比较 nums[mid] > nums[hi] 定方向）、找峰值、求平方根。

树 Trees

二叉树与遍历

记忆：前中后序的区别只在「根什么时候访问」。中序遍历 BST 得到有序序列。前序 + 中序（或后序 + 中序）可唯一重建二叉树。

二叉搜索树 BST

左子树所有值 < 根 < 右子树所有值。查找/插入/删除平均 O(log n)，最坏退化成链表 O(n)。

平衡树：AVL & 红黑树

通过旋转保持树高 O(log n)。红黑树是 C++ std::map、Java TreeMap 的底层。

堆 Heap — 优先队列

堆是完全二叉树：父节点 ≤ 子节点（最小堆）。插入/删除 O(log n)，取最值 O(1)，建堆 O(n)。

BFS vs DFS

BFS 广度优先DFS 深度优先
数据结构Queue 队列Stack/递归
用途最短路径（无权）、层序连通分量、环检测、拓扑排序
时间O(V+E)O(V+E)

DFS 例题：岛屿数量（LeetCode 200）——DFS 沉岛法：遇到 1 计数 +1 并把整岛标 0，每格只访问一次 → O(mn)。（网格 DFS 四方向递归模板同此。）

拓扑排序 Topological Sort（Kahn 算法）

DAG 的线性排序：每条边 u→v，u 都在 v 前面。

解题思路：① 算入度；② 入度为 0 的入队；③ 弹出并「删边」，新入度为 0 的入队；④ 弹出数 < 节点数 → 有环。应用：课程表、编译依赖、任务调度。

算法适用时间

Dijkstra 例题（优先队列）：

解题思路：① 每次挑 dist 最小的未确定节点（优先队列）；② 松弛更新邻居；③ 每节点最多出队一次 → O((V+E) log V)。负权边不行——用 Bellman-Ford（V−1 轮松弛）。

动态规划 Dynamic Programming

核心思想：大问题拆成子问题，记住子问题的解，避免重复计算。

DP 五步法

  1. 定义状态 dp[i] 是什么
  2. 找出状态转移方程
  3. 确定初始条件
  4. 确定计算顺序
  5. 返回答案

经典例题：0-1 背包

关键：dp[i][w] = 前 i 个物品、容量 w 下的最大价值，每个物品「选或不选」。空间优化：压成一维，容量倒序遍历防止覆盖：

经典例题：最长公共子序列 LCS

解题思路：dp[i][j] = 两前缀的 LCS。末尾相等「都取」+1；不等「丢一个」取较大。回溯可还原子序列。

经典例题：编辑距离 Edit Distance

关键：三个操作对应三个方向：删除（上）、插入（左）、替换（左上）。DNA 比对、拼写检查都是它的应用。

DP vs 贪心 Greedy

DP贪心
做选择时考虑所有可能只看当前最优
正确性保证全局最优（最优子结构时）需要证明
例子背包、编辑距离、LCSDijkstra、Huffman、活动选择

怎么判断能不能贪心：贪心选择性质——局部最优推出全局最优。反例：0-1 背包按「价值/重量比」贪心是错的（分数背包才可以）。

二级结论速查

  1. 二分：有序查找、答案单调性问题；左闭右开不易错
  2. 快排最坏 O(n²)：已有序 + 固定 pivot → 随机化或三数取中
  3. BFS 无权最短路：第一次访问到终点就是最短距离
  4. DFS 环检测：递归栈出现「灰色节点」→ 有环
  5. 拓扑排序：弹出数 < 节点数 → 有环
  6. 堆：Top-K（O(n log k)）、中位数（双堆）、Dijkstra
  7. DP 空间优化：只依赖上一行 → 滚动数组
  8. 字符串 DP：dp[i][j] 双前缀，转移看末尾字符

常见坑

  1. 递归不设 base case → 无限递归栈溢出
  2. 把 O(n²) 当成 O(n) → 嵌套循环看花眼
  3. BFS/DFS 不标记 visited → 循环图里死循环
  4. DP 状态定义错误 → 先想清楚 dp[i] 的物理含义
  5. 整数溢出 — C++/Java 用 long long；Python 自动大整数但慢
  6. 二分死循环 — lo = mid 时 mid 向上取整
