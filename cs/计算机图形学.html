计算机图形学

图形学只做一件事：把抽象的三维数据变成屏幕上的像素。渲染管线是整个学科的主动脉——理解它，其余都是枝叶。

渲染管线概览

图形学的主流程，从数据到像素：

顶点数据 → 顶点着色器 → 图元装配 → 光栅化 → 片段着色器 → 逐片元操作 → 帧缓冲
阶段输入输出可控性
顶点着色器顶点属性 (位置、法线、UV)变换后的顶点完全可编程
曲面细分/几何着色器图元新图元可编程（可选）
图元装配顶点三角形/线/点固定+配置
光栅化图元片段 (fragments)固定+配置
片段着色器片段 + 插值后的 varying颜色/深度完全可编程
逐片元操作片段颜色最终像素测试/混合可配置

坐标变换：经典三部曲

1. Model 变换（物体 → 世界）

将物体从自身坐标系移到世界坐标。组合平移、旋转、缩放：

Mmodel​=T⋅R⋅S

顺序很重要：先缩放，再旋转，最后平移。

2. View 变换（世界 → 相机）

把相机放到原点看向 −z。本质上是相机的逆变换：

Mview​=[R0​−Rt1​]

R 是相机朝向的旋转矩阵，t 是相机位置。

3. Projection 变换（相机 → 裁剪空间）

透视投影：近大远小，齐次除法做透视除法：

\frac{1}{\text{aspect} \cdot \tan(fov/2)} & 0 & 0 & 0 \\ 0 & \frac{1}{\tan(fov/2)} & 0 & 0 \\ 0 & 0 & \frac{-(f+n)}{f-n} & \frac{-2fn}{f-n} \\ 0 & 0 & -1 & 0 \end{bmatrix}$$ **正交投影**：无透视效果，常用于 UI、CAD、阴影贴图。 ### 完整变换链 $$\mathbf{p}_{\text{NDC}} = M_{\text{proj}} \cdot M_{\text{view}} \cdot M_{\text{model}} \cdot \mathbf{p}_{\text{local}}$$ 随后 $(x,y,z) / w$ 得到 NDC $[-1, 1]^3$，视口变换映射到像素。 ## 光栅化 将三角形变成像素。核心操作：判断像素中心是否在三角形内。 **边方程法**：每条边用叉积判断点在哪一侧。三边测试同时通过 → 在三角形内。 **重心坐标**：片上任意点 $p = \alpha A + \beta B + \gamma C$（$\alpha + \beta + \gamma = 1$），用于插值顶点属性。 ### 深度测试 (Z-buffer) 解决遮挡问题：每像素存最小深度，新片段更深则丢弃。 ``` for each triangle: for each covered pixel (x, y): z = interpolated_depth if z < zbuffer[x][y]: framebuffer[x][y] = shade(...) zbuffer[x][y] = z ``` ## 着色模型 ### Phong 反射模型 $$I = k_a I_a + \sum_{\text{lights}} \left[ k_d (L \cdot N) I_d + k_s (R \cdot V)^{\alpha} I_s \right]$$ | 项 | 含义 | 参数 | |---|---|---| | $k_a I_a$ | 环境光（全局近似） | 常数 | | $k_d (L \cdot N) I_d$ | 漫反射 (Lambert) | 与视角无关 | | $k_s (R \cdot V)^{\alpha} I_s$ | 镜面高光 | $\alpha$ 控制高光集中度 | ### 着色频率 | 策略 | 计算位置 | 表现 | 性能 | |---|---|---|---| | **Flat shading** | 每个面一次 | 硬朗面片感 | 最快 | | **Gouraud** | 顶点着色 + 插值颜色 | 平滑但丢高光 | 中等 | | **Phong** | 插值法线 + 每片段着色 | 高光准确 | 最慢 | > Phong shading ≠ Phong 反射模型：前者是着色频率（每片段计算），后者是光照公式。 ### PBR (Physically Based Rendering) 基于微表面理论，核心 BRDF (Cook–Torrance)： $$f_r = \frac{D \cdot F \cdot G}{4 (N \cdot L)(N \cdot V)}$$ $D$：法线分布，$F$：Fresnel 反射，$G$：几何遮蔽。能量守恒 + 基于物理的参数（金属度、粗糙度）。 ## 光栅化 vs 光线追踪 | 特性 | 光栅化 | 光线追踪 | |---|---|---| | 原理 | 物体 → 像素 | 像素 → 物体（光线反向追踪） | | 全局光照 | 需要烘焙/近似 | 天然支持（反射、折射、间接光） | | 性能 | 实时（游戏） | 慢（离线渲染，RTX 加速后可达实时） | | 软阴影 | 阴影贴图 + 滤波 | 天然 | | 复杂度 | $O(n)$ 图元 | $O(\log n)$ 加速结构 | ### 光线追踪的渲染方程 $$L_o(p, \omega_o) = L_e(p, \omega_o) + \int_{\Omega} f_r(p, \omega_i, \omega_o) L_i(p, \omega_i) (\omega_i \cdot n) \, d\omega_i$$ 递归计算的积分——这是整个路径追踪 (Path Tracing) 的基础。 ## 纹理映射 ### 基本流程 1. 模型提供 UV 坐标（$[0,1]^2$） 2. 光栅化插值 UV 3. 纹理采样 → 颜色 ### Mipmap 预生成 $1/2, 1/4, \dots$ 缩小版本，根据像素覆盖面积选择层级。解决远距离纹理混叠，代价是 $4/3$ 额外内存。 ### 过滤方式 | 过滤 | 行为 | 用途 | |---|---|---| | Nearest | 取最近纹素 | 像素风 | | Bilinear | 2×2 双线性插值 | 平滑但模糊 | | Trilinear | Mipmap 间 + 层内双线性 | 平滑过渡 | | Anisotropic | 考虑透视拉伸方向 | 斜角表面清晰度 | ## 全局光照方法 | 方法 | 原理 | 用途 | |---|---|---| | **阴影贴图** | 从光源渲染深度，对比 | 实时硬阴影 | | **环境光遮蔽 (AO/SSAO)** | 采样周围遮蔽度 | 实时软接触阴影 | | **辐射度 (Radiosity)** | 面片间能量交换 | 离线建筑可视化 | | **光子映射** | 光源发射光子，从相机收集 | 焦散、间接光 | | **路径追踪** | Monte Carlo 积分渲染方程 | 电影级离线渲染 | ## 常见丢分点 1. **矩阵乘法顺序**：OpenGL 列主序右乘，$v' = M_{proj} \cdot M_{view} \cdot M_{model} \cdot v$。 2. **透视除法后 NDC**：$z \in [-1, 1]$（OpenGL）或 $[0, 1]$（Vulkan/D3D），不同 API 不一致。 3. **深度精度**：透视投影下 z 不均匀分布——近处精度高，远处精度低（反向 z-buffer 可以改善）。 4. **Mipmap 层级选择**：需要屏幕空间导数 $dFdx/dFdy$ 估算纹理坐标变化率。 ##
