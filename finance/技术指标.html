技术指标

量化交易不是看线算命。每个指标背后是一段数学，告诉你市场在某一个维度上的状态。

RSI — 相对强弱指数

RSI=100−1+RS100​,RS=avg lossavg gain​

用的是最近 14 根 K 线的平均涨幅和平均跌幅。RS 是”平均涨了多少”除以”平均跌了多少”。

RSI 在 0 到 100 之间。低于 30 说明最近跌得比涨得多——超卖。高于 70 说明涨得比跌得多——超买。

RSI 计算例题（10 天窗口演示，14 天同理）

收盘价序列：10.0,10.5,10.2,10.8,11.0,10.9,11.3,11.1,11.5,11.8。

解题思路：

  1. 算 9 个日变化：+0.5,−0.3,+0.6,+0.2,−0.1,+0.4,−0.2,+0.4,+0.3
  2. 平均涨幅 =(0.5+0.6+0.2+0.4+0.4+0.3)/9=2.4/9≈0.267
  3. 平均跌幅 =(0.3+0.1+0.2)/9=0.6/9≈0.067
  4. RS=0.267/0.067=4.0，RSI=100−100/(1+4)=80

结论： RSI = 80 > 70，超买——连续上涨后动能已透支，均值回归视角下是卖出区。

细节： 涨跌为 0 的日子（收平）既不算涨幅也不算跌幅，只增加分母。窗口期越长 RSI 越平滑；首期计算通常用简单平均，之后用 Wilder 平滑（RSIt​=RSIt−1​+α(今日−RSIt−1​)，α=1/n）。

RSI 拐头（渡鸦实战用法）

  • 数值本身（超卖/超买）只是第一层信息
  • 拐头是第二层：RSI 从 30 下方回升 → 下跌动能衰竭，比”RSI < 30”更早给出信号
  • 背离是第三层：价格创新低但 RSI 不创新低 → 底背离，反转概率更高

渡鸦实盘验证：RSI < 35 是一个比较可靠的买入触发点。不是 < 30 才买——那样会错过很多机会。但单看 RSI 不够，需要和其他指标一起过滤。

MACD — 指数平滑异同移动平均线

DIF=EMA12​−EMA26​ DEA=EMA9​(DIF) MACD=2×(DIF−DEA)

EMA 是指数移动平均，近期的权重更大：EMAt​=αPt​+(1−α)EMAt−1​，α=2/(n+1)。MACD 柱 = 2×(DIF-DEA)，柱子变长说明趋势在加速，柱子缩短说明趋势在减速。

金叉：DIF 上穿 DEA → 买入信号。死叉：DIF 下穿 DEA → 卖出信号。

MACD 计算例题（简化窗口演示：EMA3 − EMA5，同理可换 12/26）

收盘价：10.0,10.2,10.1,10.5,10.8,11.0。

解题思路：

  1. 种子值取首日收盘：EMA3​=10.0，EMA5​=10.0
  2. EMA3（α=2/4=0.5）：10.0→0.5×10.2+0.5×10.0=10.10→10.10→10.30→10.55→10.78
  3. EMA5（α=2/6=1/3）：10.0→10.07→10.08→10.22→10.41→10.61
  4. DIF = EMA3 − EMA5：0→+0.03→+0.02→+0.08→+0.14→+0.17

结论： DIF 从 0 附近转正并持续放大 → 短期动能强于长期动能，多头趋势确认中。第 2 天 DIF 由 0 转正就是金叉点（简化窗口演示原理；真实 12/26/9 计算同理，只是权重更平滑）。

MACD 的问题是滞后——等金叉出现，行情可能已经走了一半。所以渡鸦把它当确认信号，不当触发信号。

布林带

上轨=SMA20​+k×σ 中轨=SMA20​ 下轨=SMA20​−k×σ

SMA 是 20 期简单移动平均，σ 是同期的标准差，k 通常取 2。价格在布林带内波动的概率约 95%（假设正态分布——虽然实际不是）。

布林带计算例题（5 天窗口演示）

收盘价：10.0,10.2,10.1,10.5,10.8，k=2。

解题思路：

  1. SMA5​=(10.0+10.2+10.1+10.5+10.8)/5=10.32
  2. 离差：−0.32,−0.12,−0.22,+0.18,+0.48，平方和 =0.428
  3. 总体标准差 σ=0.428/5​≈0.293；样本标准差 0.428/4​≈0.327
  4. 上轨 =10.32+2×0.293=10.91（若用样本标准差则是 10.97）
  5. 下轨 =10.32−2×0.293=9.73

结论： 最新价 10.8 未突破上轨 10.91。注意：不同平台样本/总体标准差的差异会导致上下轨不同——量化回测必须固定一种口径，否则信号不一致。

价格突破上轨 → 可能超买。跌破下轨 → 可能超卖。但趋势市中价格可以沿着轨道走很久——布林带不能单独用来判断反转。带宽（上轨−下轨）本身是波动率指标：带宽收窄到历史低位 → 变盘前兆（布林带收缩 → 突破）。

渡鸦用布林带来确认 RSI 信号：RSI < 35 且价格在布林下轨附近 → 买入信号的可信度大幅提高。

SMA — 简单移动平均

SMAn​=nP1​+P2​+...+Pn​​

就是最近 n 根 K 线收盘价的平均值。n 越小越灵敏，n 越大越平滑。

常用组合：

  • SMA20（短期趋势）+ SMA50（中期趋势）+ SMA200（长期趋势）
  • 短线上穿长线 → 金叉，短线下穿长线 → 死叉
  • 价格在 SMA200 上方 → 牛市格局，下方 → 熊市格局

SMA vs EMA： SMA 对每根 K 线等权，对跳变反应均匀；EMA 给近期更高权重，反应更快但更容易被单日噪声骗。趋势过滤用 SMA（稳），信号触发用 EMA（快）。

渡鸦用 SMA50 做趋势过滤：如果当前价格偏离 SMA50 超过 3%，说明处于极端行情，暂停买入等回归。

成交量

量价关系一句话：放量确认趋势，缩量质疑趋势。涨了但没量 → 假突破。跌了但没量 → 洗盘可能性大。

渡鸦用 rvol（相对成交量）= 当前成交量 / 过去 20 期平均成交量。rvol < 0.7 → 流动性不足，不进场。

ATR — 平均真实波幅

TR=max(H−L, ∣H−Cprev​∣, ∣L−Cprev​∣) ATRn​=nTR1​+TR2​+...+TRn​​

TR（真实波幅）取三者的最大值：当根最高最低差、向上跳空缺口、向下跳空缺口——把跳空也算进波动。ATR 就是 TR 的移动平均，衡量「这个品种一天平均动多少」。

ATR 计算例题（3 天窗口）

三天数据（H/L/C）：(10.5,10.0,10.2)，(10.8,10.1,10.4)，(11.2,10.6,10.9)，前一日收盘 10.0。

解题思路：

  1. TR1​=max(0.5,∣10.5−10.0∣,∣10.0−10.0∣)=0.5
  2. TR2​=max(0.7,∣10.8−10.2∣,∣10.1−10.2∣)=0.7
  3. TR3​=max(0.6,∣11.2−10.4∣,∣10.6−10.4∣)=0.8
  4. ATR3​=(0.5+0.7+0.8)/3≈0.67

用途：

  • 波动率止损：止损距离 = N×ATR（如 2×ATR），波动大的品种止损宽，波动小的品种止损窄——止损随市场状态自适应
  • 仓位 sizing：单笔风险固定时，仓位 =N×ATR可承受亏损​——ATR 大的时候自动减仓

指标的滞后性（数学视角）

所有基于均值的指标都有滞后，且滞后可以精确算出来：

  • SMA_n 的平均滞后 = (n−1)/2 根 K 线——SMA20 平均比价格晚 9.5 根 K 线
  • EMA_n 的平均滞后 = (n−1)/2 根 K 线（等价），但 EMA 对近期价格权重更高，拐点反应更快
  • MACD = EMA12 − EMA26，滞后 ≈ 两条 EMA 滞后的加权差——所以 MACD 是「慢确认」指标

二级结论： 信号越快（参数小）噪声越大，信号越慢（参数大）越滞后。任何指标都是「噪声-滞后」天平上的一次选择——没有免费的灵敏。

指标参数敏感性

同一指标换参数，信号完全不同——参数不是免费的午餐，每一个参数都是一次过拟合的机会。

指标参数调小调大
RSI14更敏感：信号多、假信号也多更平滑：信号少、滞后大
MACD12/26/9反应快，震荡市被反复打脸反应慢，趋势市少踏空
布林带k = 2k=1.5：带宽窄，突破信号多但假k=2.5：带宽宽，信号少但可靠
SMA20/50/200短线灵敏长线稳定

参数敏感性检验法： 把参数在邻域内扫描（如 RSI 从 10 到 20），看绩效是否平稳。

扫描例题（RSI 参数扫描结果）：

RSI 窗口回测胜率年化夏普年交易次数
748%0.9156
1453%1.387
2156%1.152
2857%0.731

解读： 14 是最优点，但 7 和 21 的夏普仍然 > 1——这是「参数平原」，策略稳健。如果 14 的夏普是 2.8 而 13、15 都掉到 0.5，那就是「孤峰」——过拟合信号，直接放弃。

  • 绩效随参数平滑变化（相邻参数结果接近）→ 参数「平原」，策略稳健
  • 绩效在某个参数点突然拔高、旁边都是坑 → 参数「孤峰」，几乎肯定是过拟合
  • 孤峰参数 = 回测神话，实盘灾难

五个指标怎么配合（多指标共振示例）

渡鸦的买入条件（五道过滤）：单一指标单独用，胜率不到 45%。五个一起过滤，胜率能到 55%+。

共振示例 1（买入触发）

BTC 15 分钟 K 线，某时刻：

  1. RSI(14) = 32 → < 35，超卖 ✓
  2. 价格在布林下轨上方 1% 内 ✓
  3. 偏离 SMA50 = 1.8% → ≤ 3%，非极端行情 ✓
  4. rvol = 1.3 → ≥ 0.7，流动性充足 ✓
  5. RSI 昨日 30 → 今日 32，拐头向上 ✓

五条件全满足 → 买入。共振的本质：五个独立维度的证据指向同一结论（超卖 + 位置 + 非极端 + 流动性 + 动能反转）。

共振示例 2（过滤掉假信号）

同样是 RSI = 32 超卖，但：

  • rvol = 0.4（缩量阴跌）→ 不买。缩量说明没有承接盘，超卖可以更超卖
  • 或偏离 SMA50 = 6%（极端行情）→ 不买。接飞刀，等回归
  • 或 RSI 仍在 28 → 30 往下走（未拐头）→ 不买。下跌动能未衰竭

人话： 每个过滤条件排除一类「看似是机会的陷阱」。条件越多，能进场的次数越少——但每次进场的质量越高。交易频率换胜率，是均值回归策略的基本权衡。

指标失效的场景（二级结论）

  1. 趋势市里均值回归指标全废——RSI 可以连续几周 > 70（单边牛市），布林带可以沿着上轨走半个月
  2. 低波动环境布林带收窄——假突破变多，带宽本身才是信号
  3. MACD 在震荡市金叉死叉反复——滞后指标的典型死法
  4. 所有指标都是价格的函数——它们不预测，只是把过去的价格重新排列组合。指标给的是「状态描述」，交易系统给的是「应对规则」
