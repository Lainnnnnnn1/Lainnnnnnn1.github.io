衍生品定价

衍生品 = 价值「衍生」自标的资产的合约。核心问题：这个合约现在值多少钱？

期货与远期

远期 (Forward)： 约定未来以价格 K 买入标的。

无套利定价： F=S0​erT

人话： 远期价格 = 今天借钱买现货，持有到交割日的成本。如果 F=S0​erT，就存在套利。

例题： S0​=100，r=5%，T=1 年 → F=100e0.05≈105.13。若市场远期报价 108：借 100 买现货、卖远期，到期交割赚 108−105.13≈2.87 无风险利润——这就是套利，市场会把远期价格压回 105.13。

期货 (Futures)： 交易所标准化的远期，逐日盯市 (mark-to-market)。每天盈亏实时划入保证金账户——所以期货价格与远期价格在利率随机时略有差异（凸性调整），考试默认相等。

期权

看涨期权 (Call)： 以 K 买入的权利（不是义务）。

看跌期权 (Put)： 以 K 卖出的权利。

到期日收益图

买方卖方
Callmax(ST​−K,0)−CC−max(ST​−K,0)
Putmax(K−ST​,0)−PP−max(K−ST​,0)

买方：亏损有限（期权费），收益无限。卖方：收益有限（期权费），亏损可能无限。

内在价值与时间价值

  • 内在价值 =max(S0​−K,0)（Call）——立即行权能拿到的钱
  • 时间价值 = 期权费 − 内在价值——「未来可能变好」的溢价
  • 深度实值期权的价格 ≈ 内在价值（时间价值趋近 0）；平值期权时间价值最大（不确定性最大）

Put-Call 平价

C+Ke−rT=P+S0​

人话： 买 Call + 存现金 = 买 Put + 买股票。两边到期收益一样 → 价格必须相等，否则套利。

例题（平价求价）： 已知 C=8.0，S0​=100，K=105，r=5%，T=1。 P=C+Ke−rT−S0​=8.0+105e−0.05−100≈8.0+99.88−100≈7.88

例题（平价套利）： 若市场 Put 报价 P=10>7.88，则 Put 偏贵 → 卖出 Put、买入 Call、卖空股票、存入现金（Ke−rT），到期无论涨跌净赚 10−7.88≈2.12。方向记法：等式右边贵了卖右边，左边贵了卖左边。

Black-Scholes 公式

C=S0​N(d1​)−Ke−rTN(d2​)

d1​=σT​ln(S0​/K)+(r+σ2/2)T​

d2​=d1​−σT​

Put 价格用平价推出：P=Ke−rTN(−d2​)−S0​N(−d1​)（或 P=C+Ke−rT−S0​）。

直觉解读

  • N(d2​)：风险中性下期权到期实值的概率
  • S0​N(d1​)：股票的「期望价值贡献」
  • Ke−rTN(d2​)：行权成本的「期望价值」

推导关键步骤（理解比背公式重要）

  1. 假设： 股价服从几何布朗运动 dS=μSdt+σSdW，μ 漂移、σ 波动率
  2. Itô 引理： 对期权价值 V(S,t) 展开 dV=(∂t∂V​+μS∂S∂V​+21​σ2S2∂S2∂2V​)dt+σS∂S∂V​dW
  3. 构造对冲组合： Π=V−ΔS，取 Δ=∂V/∂S 消掉 dW 项——组合瞬时无风险
  4. 无套利： 无风险组合只能赚无风险利率 dΠ=rΠdt，得到 Black-Scholes PDE ∂t∂V​+rS∂S∂V​+21​σ2S2∂S2∂2V​=rV
  5. 解 PDE： 变量替换 τ=T−t，x=lnS 后化成热传导方程 ∂τ∂u​=2σ2​∂x2∂2u​，配到期收益边界条件 V(ST​,T)=max(ST​−K,0)，解出即得 BS 公式

关键 insight： 推导中 μ 消失了——期权价格与标的的预期收益率无关，只与 r 和 σ 有关。这就是风险中性定价：定价时假设所有资产都赚无风险利率。

假设（全是简化）

  1. 股价服从对数正态分布（几何布朗运动）
  2. 波动率恒定——最大缺陷
  3. 无交易成本、连续交易
  4. 无风险利率恒定

希腊字母（Greeks）

Greek公式含义
Δ∂S∂C​股价变动 1 → 期权价变动 Δ
Γ∂S2∂2C​Δ 的变化率
Θ∂t∂C​时间流逝的损耗（期权的时间价值衰减）
Vega∂σ∂C​波动率变化的影响
Rho∂r∂C​利率变化的影响

欧式 Call 的解析式（无股息）：Δ=N(d1​)，Γ=SσT​N′(d1​)​，Vega=ST​N′(d1​)，Θ=−2T​SN′(d1​)σ​−rKe−rTN(d2​)，其中 N′(x)=2π​1​e−x2/2 是标准正态密度。

人话： 期权卖方赚的是 Θ（时间价值衰减），怕的是 Γ 和 Vega（大幅波动）。

Greeks 计算例题

沿用 BS 例题：S0​=100,K=105,r=5%,T=1,σ=20%，已算得 d1​=0.099，d2​=−0.101，N(d1​)≈0.539，N(d2​)≈0.460。

解题思路：

  1. N′(d1​)=2π​1​e−0.0992/2≈0.3989×0.9951≈0.397
  2. Δ=0.539——股价涨 1，Call 涨约 $0.54
  3. Γ=0.397/(100×0.2×1)=0.0199——股价再涨 1，Δ 增加 0.02
  4. Vega=100×1×0.397=39.7——波动率每升 1%（0.01），Call 涨约 $0.397
  5. Θ=−2×1100×0.397×0.2​−0.05×105e−0.05×0.460≈−3.97−2.30=−6.27（每年）→ 每天约 -$0.017

二级结论： 平值期权 Δ≈0.5、Γ 和 Vega 最大（不确定性最大）；深度实值 Call Δ→1、时间价值趋零。买期权 = 做多 Γ + Vega、做空 Θ；卖期权反过来。

二叉树定价（CRR 模型）

把 T 分成 N 步，每步股价要么乘 u 涨、要么乘 d 跌：

u=eσΔt​,d=e−σΔt​=1/u,p=u−derΔt−d​

p 是风险中性概率（不是真实概率）。从最后一期倒推：C=e−rΔt[pCu​+(1−p)Cd​]。

完整例题（两步二叉树）

S0​=100，K=105，T=1，r=5%，σ=20%。取 N=2，Δt=0.5。

解题思路：

  1. u=e0.20.5​=e0.1414≈1.152，d=1/1.152≈0.868
  2. p=1.152−0.868e0.05×0.5−0.868​=0.2841.0253−0.868​≈0.554
  3. 列终端股价：Suu​=100×1.1522≈132.7，Sud​=100×1.152×0.868≈100.0，Sdd​=100×0.8682≈75.3
  4. 终端收益：Cuu​=max(132.7−105,0)=27.7，Cud​=max(100−105,0)=0，Cdd​=0
  5. 倒推第一层：Cu​=e−0.025(0.554×27.7+0.446×0)≈0.9753×15.35≈14.97；Cd​=0
  6. 倒推根节点：C0​=e−0.025(0.554×14.97+0.446×0)≈0.9753×8.29≈8.09

结论： 两步二叉树得出 C≈8.09，与 BS 公式的 8.0 几乎一致。N 越大越接近 BS 精确值——二叉树就是 BS 的离散版本，也是考试里「不给正态分布表时」算期权价的保底方法。

美式期权 vs 欧式期权

欧式美式
行权时点只能到期日到期前任意时刻
定价方法BS 公式（解析解）二叉树/蒙特卡洛（数值解）
价值关系Veu​Vam​≥Veu​（多一个提前行权选项）

何时提前行权值得：

  • 无股息 Call： 提前行权永远不优（放弃时间价值，只拿内在价值）→ Cam​=Ceu​
  • 有股息 Call： 除息前可能提前行权（拿走股票避开除息下跌）
  • 深度实值 Put： 提前行权可能最优——早拿到 K 可以赚利息，而时间价值趋零时留着没意义 → Pam​>Peu​ 常见

二叉树处理美式： 每步倒推时取 V=max(e−rΔt[pVu​+(1−p)Vd​], 行权价值)——「持有价值」和「立即行权」谁大取谁。

期权组合策略

期权不是只能单买。组合起来可以定制收益形态：

策略构造到期收益适用场景
牛市价差买低 K Call + 卖高 K Call有限收益、有限亏损温和看涨
熊市价差买高 K Put + 卖低 K Put有限收益、有限亏损温和看跌
跨式 (Straddle)买 Call + 买 Put（同 K）两端无限、中间亏损赌大波动（财报、事件）
备兑 (Covered Call)持股 + 卖 Call有上限、有下限震荡市收权利金

例题（牛市价差）： S0​=100，买 K=100 Call 花 8，卖 K=110 Call 收 3。

解题思路：

  1. 净支出 =8−3=5（最大亏损）
  2. 到期 ST​≥110：收益 =(ST​−100)−(ST​−110)−5=5（最大盈利）
  3. 到期 ST​≤100：收益 =−5
  4. 盈亏平衡点 =105：ST​ 超过 105 才赚钱
  5. 对比裸买 Call（成本 8，盈亏平衡 108）——价差策略用 5 的成本换了 5 的盈利上限，用收益上限换成本下降和盈亏平衡点下移

Greeks 视角： 牛市价差 = 多头 Call + 空头 Call，Δ 介于 0 和 1 之间，Γ 和 Vega 被部分抵消——比裸 Call 更耐波动率变化。

隐含波动率的计算

隐含波动率 = 让 BS 公式输出等于市场价格的 σ。BS 公式没法反解，用牛顿迭代：

σn+1​=σn​−Vega(σn​)CBS​(σn​)−Cmarket​​

例题： 市场 Call 报价 10.0（S0​=100,K=105,r=5%,T=1），从 σ0​=0.2 出发。

解题思路：

  1. CBS​(0.2)=8.0<10.0——市场价格更贵说明隐含波动率更高。Vega(0.2)=39.7（每单位 σ）→ σ1​=0.2+(10.0−8.0)/39.7≈0.250
  2. 重算 CBS​(0.25)≈10.0，差趋近 0 → 收敛，隐含波动率 ≈25%（两步即达，牛顿法在 Vega 大的平值区收敛极快）
  3. 注意：深度虚值期权 Vega 小，迭代容易震荡——实务用二分法兜底

用途： 隐含波动率是市场对未来的「恐慌指数」——把同一标的、不同行权价的隐含波动率画出来就是波动率微笑。隐含波动率本身是个可交易的资产（VIX 就是标普 500 隐含波动率的指数化）。

波动率微笑

BS 模型说波动率恒定，市场说不是。

横轴 = 行权价，纵轴 = 隐含波动率。实际曲线是「微笑」形——OTM 期权的隐含波动率更高。

解释： 市场认为极端行权价的期权——对应极端事件——比 BS 模型预测的更可能发生。Fat tails（肥尾）。股指期权常呈「偏斜」(skew)——下跌侧的隐含波动率更高，因为崩盘风险比暴涨风险更被市场定价。

蒙特卡洛模拟

当解析解不存在（美式期权、奇异期权）：

  1. 模拟 N 条股价路径：St+Δt​=St​exp((r−σ2/2)Δt+σΔt​Z)
  2. 对每条路径计算期权到期收益
  3. 折现求平均

收敛速度： O(1/N​)。要 4 倍样本才能提高 1 位精度——慢。加速技巧：对偶变量法（同时跑 −Z 路径）、控制变量法、低差异序列。

例题（单条路径演示）： S0​=100，r=5%，σ=20%，Δt=1/12（月步长），随机数 Z=0.5： S1/12​=100exp((0.05−0.04/2)/12+0.21/12​×0.5)=100e0.0025+0.0289≈103.15 1 万条路径的均值折现后 ≈ BS 价格；路径数越多，方差越小。

例题

例 1：Call 期权 S0​=100,K=105,r=5%,T=1,σ=20%

  1. d1​=0.2ln(100/105)+(0.05+0.04/2)​≈0.099
  2. d2​=0.099−0.2=−0.101
  3. N(d1​)≈0.539,N(d2​)≈0.460
  4. C≈100(0.539)−105e−0.05(0.460)≈53.9−45.9≈8.0

例 2：用 Put-Call 平价求 Put 价格

P=C+Ke−rT−S0​=8.0+105e−0.05−100≈8.0+99.9−100≈7.9

例 3：直觉检验——波动率对价格的影响

同一期权把 σ 从 20% 提到 30%：d1​=0.3−0.0488+0.095​≈0.154，N(d1​)≈0.561，d2​≈−0.146，N(d2​)≈0.442 → C≈56.1−46.4×0.9512×0.442×... 直接算：C≈100×0.561−105×0.9512×0.442≈56.1−44.1≈12.0。波动率 +10%，价格从 8.0 涨到 12.0——波动率是期权价格的第一驱动力，方向判断对了但波动率判断错，照样亏钱。
