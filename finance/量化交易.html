量化交易

量化交易 = 用数学模型和代码来做交易决策。 不是「猜涨跌」——是在概率优势上重复下注。

核心框架

数据获取 → 信号生成 → 风控过滤 → 执行 → 复盘

五个环节缺一不可。信号再准，执行烂掉一样亏钱；策略再好，没有风控一次黑天鹅就出局。

常见策略类型

趋势跟踪 (Trend Following)

逻辑： 涨了的会继续涨，跌了的会继续跌（动量效应）。

经典指标：

指标公式/计算信号
SMA 交叉SMAfast​ 上穿 SMAslow​买入
MACDDIF−DEADIF 上穿 DEA → 买入
布林带SMA±k⋅σ突破上轨 → 买入；下轨 → 卖出

人话： 金叉买入，死叉卖出。趋势策略在趋势市中赚钱，在震荡市中被反复打脸。

均值回归 (Mean Reversion)

逻辑： 价格偏离均值后会回归。涨太多了会跌，跌太多了会涨。

RSI 策略： RSI=100−1+RS100​,RS=avg lossavg gain​

  • RSI < 30：超卖 → 买入信号
  • RSI > 70：超买 → 卖出信号

陷阱： 趋势市中 RSI 可以长期 < 30 或 > 70——均值回归策略在趋势市里亏钱。

统计套利 (Stat Arb)

逻辑： 两个高度相关的资产，价差偏离正常范围时会回归。

Pairs Trading：

  1. 找两只高度协整的股票
  2. 计算价差 S=PA​−βPB​
  3. S 偏离均值超过 k 个标准差 → 做多被低估的，做空被高估的
  4. S 回归均值 → 平仓

前提： 协整性要用 ADF 检验验证。没有协整的「相关」是伪回归——两个不相关的随机游走也能算出高相关系数。

做市 (Market Making)

逻辑： 同时挂买单和卖单，赚买卖价差。

P&L=spread×volume−库存风险−逆向选择损失

人话： 做市商是「流动性的批发商」。风险在于持仓方向错了。

风控（比策略重要）

凯利公式——仓位怎么定

f∗=bp⋅b−q​

  • p：胜率
  • q=1−p：败率
  • b：赔率（赢一次赚多少/输一次亏多少）

实战建议： 凯利公式给出的是理论最优——实际用半凯利或四分之一凯利，因为你的 p 和 b 估计不准。全凯利在参数估计偏差下会破产（过注）。

止损纪律

止损类型逻辑
固定百分比亏 X% 就砍
波动率止损N×ATR 为止损距离
时间止损持仓 N 根 K 线不赚钱就出
跟踪止损从最高点回落 X% 就出

熔断机制

  • 单日亏损 > X%：停一天
  • 连续 N 笔亏损：停到明天
  • 周亏损 > Y%：本周不再交易

这些不是「不信任策略」——是「策略有时会失效」的保险。

回测完整流程

回测不是「跑一遍历史数据看赚不赚钱」，而是按下面五步走完才算数：

  1. 数据准备——复权（前复权/后复权要统一）、剔除停牌日、处理缺失值；用收盘价生成信号、用下一根开盘价成交
  2. 信号生成——向量化计算指标，产出 buy/sell 序列（见上文代码）
  3. 模拟成交——计入手续费、滑点、最小交易单位。这一步省略的回测全是假的
  4. 绩效计算——算年化收益、夏普比率、最大回撤、胜率、盈亏比（公式见下）
  5. 稳健性检验——样本外测试、参数敏感性扫描、不同市场环境分段检验

每步一个验收标准： 步骤 3 做完，实盘利润应该比回测少 20-40%——如果回测和实盘几乎一样好，多半是回测漏了什么（最常见：滑点和手续费）。

绩效指标与例题

年化收益率

Rannual​=(1+Rtotal​)252/N−1

N 为交易天数，252 是 A 股/币圈常用的年化交易日数。注意几何平均——用算术平均会高估。

夏普比率

Sharpe=σp​E[Rp​]−Rf​​

例题（月度收益）： 某策略 6 个月收益为 +4%,−2%,+6%,−1%,+3%,+2%，月无风险利率 0.2%。

解题思路：

  1. 月均收益 Rˉ=(4−2+6−1+3+2)/6=2%
  2. 离差：2,−4,4,−3,1,0；平方和 =4+16+16+9+1+0=46
  3. 月波动率 σ=46/6​≈2.77%
  4. 月夏普 =(2−0.2)/2.77≈0.65
  5. 年化：0.65×12​≈2.25

判断标准： Sharpe > 1 及格，> 2 很好，> 3 要怀疑是不是过拟合。回测夏普 4+ 而实盘 1 以下，是量化圈最常见的诈骗剧本。

最大回撤

MDD=maxt1​<t2​​Vt1​​Vt2​​−Vt1​​​(取负数)

例题（净值序列）： 净值 100 → 108 → 104 → 112 → 106 → 118 → 115 → 122。

解题思路：

  1. 找每个峰值到后续谷底的跌幅：108→104 跌 3.7%；112→106 跌 5.36%；118→115 跌 2.54%
  2. 最大回撤 = 最大的那个峰值到谷底跌幅 =5.36%（112 到 106）
  3. 含义：最惨的时候账户从高点回撤 5.36%。回撤 50% 需要涨 100% 才回本——所以回撤比收益更致命

卡玛比率 (Calmar) = 年化收益 / 最大回撤，衡量「每承受 1% 回撤换多少收益」。

胜率与盈亏比

例题： 20 笔交易，11 胜 9 负。总盈利 \330，总亏损$150$。

解题思路：

  1. 胜率 p=11/20=55%
  2. 平均盈利 = 330/11 = \30，平均亏损= 150/9 \approx $16.7，盈亏比b \approx 1.8$
  3. 利润因子 (Profit Factor) =330/150=2.2（> 1.5 算合格）
  4. 期望每笔 =0.55×30−0.45×16.7=16.5−7.5=9 美元

二级结论： 胜率不重要，p 和 b 的组合才重要。胜率 35%、盈亏比 3 的策略（0.35×3−0.65=0.4 正期望）比胜率 60%、盈亏比 0.7 的策略（0.6×0.7−0.4=0.02 勉强为正）好得多。

回测注意事项

常见陷阱

陷阱说明
幸存者偏差回测用现在的股票池——过去的退市股被排除了
前视偏差不小心用了「未来数据」（如用收盘价决定当天入场）
过拟合参数太多、数据太少——回测完美，实盘崩
滑点与手续费回测不考虑→实盘利润被吃光
未来函数用了财报发布日之后才能拿到的数据
数据错误前复权价格在除权日附近出现「假跌」触发买入

铁律：样本外测试。 用 70% 数据训练参数，30% 验证。如果样本外崩了——策略就是过拟合的。

实盘 vs 回测：差异清单

回测是在理想世界的真空里交易，实盘不是：

维度回测假设实盘现实
成交价信号价直接成交滑点 + 盘口深度不足，小币种 1-2%
手续费常被忽略币安现货双边 0.2%，高频直接吃死
延迟即时执行信号→下单→成交有秒级延迟
流动性无限大单冲击成本，最小下单额限制
心态无情绪浮亏砍不下手、浮盈拿不住
容量无限资金策略容量有限，资金大了收益衰减

实盘折损经验值： 回测年化 20% 的策略，实盘通常 12-15%；回测年化 50%+ 的「完美策略」，实盘常常亏损——完美本身就是红旗。

例题（回测思维）

策略：RSI<35 买入，RSI>65 卖出

回测需验证：

  1. 胜率多少？（不是 50% 就够了——要看赔率）
  2. 最大回撤多少？
  3. 夏普比率？（> 1 及格，> 2 很好）
  4. 不同市场环境下表现？（牛市 vs 熊市 vs 震荡）

常见结果： RSI 策略在震荡市赚钱，在趋势市亏钱。纯 RSI 策略通常夏普 < 1。

进阶： 在策略上叠加趋势过滤（如价格在 SMA50 上方才允许做多），震荡市信号被过滤掉一部分，趋势市少亏钱——整体夏普往往能提升 0.3-0.5。
