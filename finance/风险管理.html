风险管理

风险管理的核心不是”消除风险”，而是量化、定价、转移和控制风险。你不管理风险，风险就会管理你。

风险度量：VaR 与 CVaR

风险价值 VaR

VaR (Value at Risk)：在给定置信水平 α 和时间窗口下，可能的最大损失。

P(L>VaRα​)=1−α

三种计算方法：

方法原理优点缺点
参数法 (方差-协方差)假设正态分布，VaRα​=μ+σ⋅zα​简单快速假设正态分布（低估肥尾）
历史模拟法按历史收益率直接取分位数无分布假设，反映真实尾部依赖历史数据，无法预测新风险
Monte Carlo 模拟模拟大量情景，取分位数灵活，可建模复杂依赖计算量大，模型风险

VaR 计算例题（参数法）

组合日收益率 μ=0.05%，日波动率 σ=2%，组合市值 100 万。

解题思路：

  1. 95% 置信水平：z0.95​=1.645 → VaR=0.05%−1.645×2%=−3.24% → 损失约 3.24 万
  2. 99% 置信水平：z0.99​=2.326 → VaR=0.05%−2.326×2%=−4.60% → 损失约 4.60 万
  3. 10 天 VaR 换算：VaR10d​=VaR1d​×10​（独立同分布假设）→ 95% 下约 3.24×3.16≈10.2 万

二级结论： 置信水平越高 VaR 越大；时间窗口按 T​ 放大（只对正态假设成立）。99% 和 95% 的差值就是尾部形状的粗测——差值异常大说明分布肥尾。

VaR 计算例题（历史模拟法）

过去 20 个交易日收益率（%）：1.2,−0.8,2.3,−1.5,0.6,−2.1,1.8,−0.3,3.1,−0.9,0.4,−1.7,2.0,−1.2,0.9,−2.8,1.5,−0.5,1.1,−0.6。

解题思路：

  1. 升序排列：−2.8,−2.1,−1.7,−1.5,−1.2,−0.9,−0.8,−0.6,−0.5,−0.3,0.4,0.6,0.9,1.1,1.2,1.5,1.8,2.0,2.3,3.1
  2. 95% 分位数位置：0.05×(20+1)=1.05 → 第 1 与第 2 个最差值之间线性插值
  3. VaR95%​≈−2.8+0.05×(−2.1+2.8)≈−2.77% → 100 万组合亏约 2.77 万
  4. 期望例外数：20×5%=1 天——20 天里平均有 1 天会亏超过 VaR

对比： 参数法算得 3.24 万 > 历史法 2.77 万——说明这 20 天的实际分布比正态略瘦尾。反过来若历史法显著大于参数法，就是肥尾信号，必须警惕。

VaR 计算例题（蒙特卡洛）

模拟 10000 条明日收益路径（用历史波动率 σ=2% 驱动），得到 10000 个损失值，排序后取第 500 个最差损失（95% 置信）。

解题思路：

  1. 模拟 Ri​=μ+σZi​，Zi​∼N(0,1)，i=1…10000
  2. 损失 Li​=−Ri​，升序排列
  3. 95% VaR = 第 10000×0.05=500 个损失值
  4. 与参数法对比：正态模拟下两者应几乎相等；若模型里加了跳跃项（Poisson 跳）或 t 分布，MC 的 VaR 会显著更大——这正是 MC 的价值：可以自由指定分布，而不是被正态绑架

组合 VaR

两资产组合的方差：σp2​=w12​σ12​+w22​σ22​+2w1​w2​ρσ1​σ2​，组合 VaR =zα​σp​V（均值近似为 0 时）。

例题： 资产 1 日波动 2%，资产 2 日波动 3%，相关系数 ρ=0.5，各占 50%，组合 100 万，95% 置信。

解题思路：

  1. σp2​=0.52×0.022+0.52×0.032+2×0.5×0.5×0.5×0.02×0.03=0.0001+0.000225+0.00015=0.000475
  2. σp​=0.000475​≈2.18%
  3. 组合 VaR =1.645×2.18%×100万≈3.59 万
  4. 单独 VaR：1.645×2%=3.29 万、1.645×3%=4.94 万，加总 8.23 万 ≫ 3.59 万

二级结论： 分散化把 8.23 万的风险压到 3.59 万——这就是组合管理的数学根基。但注意：ρ 在危机中飙升（相关性断裂），危机时的真实组合 VaR 远高于平时算的——所以压力测试必须用危机相关性，不能用平时相关性。

条件风险价值 CVaR (Expected Shortfall)

CVaRα​=E[L∣L>VaRα​]

CVaR 是超过 VaR 的损失的均值——直接回答”如果真的出事，平均有多惨”。

指标回答的问题是否满足次可加性
VaR”最坏情况下亏多少”不满足（可以不鼓励分散化）
CVaR”超过最坏情况后平均亏多少”满足（一致性风险度量）

VaR 的致命问题：两个资产的 VaR 加起来可能大于组合 VaR ⟹ VaR 可能惩罚分散化。CVaR 没有这个问题。

ES 计算例题： 沿用上面 20 天历史数据，90% 置信水平。

解题思路：

  1. 90% 置信 → 尾部 10% → 最差 20×0.1=2 天
  2. 最差两天：−2.8%,−2.1%
  3. ES90%​=(−2.8−2.1)/2=−2.45% → 平均亏 2.45 万
  4. 对比：VaR90%​≈−2.1%。ES 永远 ≥ VaR，两者差距越大尾部越厚——差距本身就是风险信号

回测 (Backtesting)

验证 VaR 模型的方法：统计实际损失超过 VaR 的天数。

Kupiec 检验（似然比检验）：

LR=−2ln((1−x/N)N−x(x/N)x(1−p)N−xpx​)∼χ2(1)

N 为总天数，x 为例外次数。LR 过大 → 拒绝”模型正确”的原假设。

例题： 95% VaR 模型回测 250 天，例外 18 天（期望 12.5 天）。 LR=−2ln((1−18/250)232(18/250)180.95232×0.0518​) 算得 LR≈2.6<χ0.052​(1)=3.84 → 不拒绝原假设，模型勉强合格。若例外 25 天，LR 显著变大 → 模型低估风险，需要调参或换方法。

观察到的例外率结论
远低于 1−α模型太保守
接近 1−α模型校准良好
远高于 1−α模型低估风险

注意例外聚簇： 例外分散出现 → 模型还行；例外连着 3-5 天出现（如 2020 年 3 月）→ 模型没抓住相关性突变，即使总例外数合格也要警惕。

压力测试与情景分析

历史情景 + 假设情景的组合：

类型示例特点
历史情景2008 金融海啸，2020 COVID 崩盘真实发生过，但未来不会简单重复
假设情景利率 +300bp、人民币贬值 20%可控参数，但主观性强
反向压力测试”什么情景会导致破产？“找最脆弱的环节

情景设计三步法（例题）： 组合为 60% 股票 + 40% 债券。

  1. 历史情景： 2022 年股债双杀——股票 −20% 且债券 −15%（相关性失效的样本）。组合损失 =0.6×20%+0.4×15%=18%——比任何单资产情景都痛，因为它打破了”股债对冲”的假设
  2. 假设情景： 利率 +300bp：债券价格近似跌 −久期×Δy=−7×3%=−21%；股票按历史贝塔联动跌 8% → 组合损失约 0.6×8%+0.4×21%=13.2%
  3. 反向压力测试： 反推”什么组合损失 > 20%”→ 答案是股票 −25% 同时债券 −12.5%。发现：只要股债相关性 > 0.8，这个组合就扛不住 20% 损失——这就是组合最脆弱的地方

设计原则： 3-5 个核心情景就够；情景要”可想象但严重”；每年重估一次（市场结构变了，老情景会失效）。

Greeks 对冲

从 衍生品定价 的 Black–Scholes 框架出发，期权价格 V 对各个风险因子的敏感度：

Greek公式风险对冲方式
Delta Δ∂V/∂S标的价格方向性风险买卖标的或期货
Gamma Γ∂2V/∂S2Delta 的变化速度需期权对冲（线性工具 Gamma=0）
Vega ν∂V/∂σ隐含波动率变化日历价差、波动率互换
Theta Θ−∂V/∂t时间衰减不可对冲，是持仓成本
Rho ρ∂V/∂r利率变化利率期货、IRS

Delta 对冲实操例题

持有 100 张 Call 合约（每张对应 100 股，共 10000 股名义），Δ=0.539，Γ=0.0199，Vega =39.7（每份）。

解题思路：

  1. Delta 中性： 卖空 0.539×10000=5390 股股票。股价涨 1：期权组合赚 0.539×10000=5390，股票亏 5390——正好抵消
  2. Gamma 修正： 股价涨 1 后 Δ 变为 0.539+0.0199=0.5589，组合不再中性，需再卖空 0.0199×10000=199 股
  3. 动态对冲： 每次价格变动都重算 Δ 再调整——这就是 Gamma 成本：低买高卖（做多 Gamma）或高买低卖（做空 Gamma）。做空 Gamma 的再平衡亏损累计起来就是 Θ 收入的对立面
  4. Vega 中性： 若担心波动率变化，需再买卖另一只期权（不同行权价/期限）构造 Vega 对冲——单一标的只能对冲 Delta

二级结论： Delta 对冲消除的是方向风险，Gamma 决定对冲频率，Vega 决定波动率风险，Theta 是持有成本。期权做市商赚的就是「卖出 Vega + Gamma，吃 Theta」的钱。

  • Delta 中性不等于没有风险——Gamma 不为零意味着 Delta 随价格变化
  • Gamma 为正：价格无论涨跌，Delta 调整都盈利 → 买期权（做多 Gamma）
  • Gamma 为负：价格无论涨跌，Delta 调整都亏损 → 卖期权（做空 Gamma）

做空 Gamma 的对冲者不断高买低卖——这就是 2018 年 2 月 “Volmageddon” 的根源。

Greeks 的 Black–Scholes 解析式

对于欧式 call option（无股息）：

Δc​=N(d1​),Γ=SσT​N′(d1​)​,ν=ST​N′(d1​),Θ=−2T​SN′(d1​)σ​−rKe−rTN(d2​)

其中 d1​=σT​ln(S/K)+(r+σ2/2)T​，d2​=d1​−σT​。

风险预算：风险是怎么分配到资产上的

组合总风险不是各资产风险的简单加总——要看边际贡献。

边际 VaR： ΔVaRi​=VaRp​×βi​，其中 βi​=Var(Rp​)Cov(Ri​,Rp​)​ 是资产对组合的贝塔。

成分 VaR： CVaRi​=wi​×ΔVaRi​，所有成分 VaR 之和恰好等于组合 VaR。

例题（沿用组合 VaR 例题）： w1​=w2​=0.5，σ1​=2%，σ2​=3%，ρ=0.5，σp​=2.18%，组合 VaR =3.59 万。

解题思路：

  1. β1​=σp2​w1​σ12​+w2​ρσ1​σ2​​=0.0004750.5×0.0004+0.5×0.5×0.02×0.03​=0.0004750.0002+0.00015​≈0.737
  2. β2​=0.0004750.5×0.0009+0.00015​≈1.263
  3. 成分 VaR：CVaR1​=0.5×0.737×3.59≈1.32 万，CVaR2​=0.5×1.263×3.59≈2.27 万；1.32+2.27=3.59 ✓
  4. 结论：资产 2 只占 50% 名义权重，却贡献 63% 的风险——因为它波动更大且与组合正相关

风险预算分配： 若要让两资产风险贡献相等，需要降低 w2​——这就是”风险平价”（Risk Parity）的思想：按风险贡献配权重，而不是按名义金额配权重。风险平价组合 wi​∝1/βi​，在危机中比等权组合更稳。

波动率建模：从常数到 GARCH

VaR 参数法假设波动率恒定——但市场波动率会聚集（volatility clustering）：大波动后面跟着大波动。GARCH(1,1) 建模这个特性：

σt2​=ω+αεt−12​+βσt−12​

  • εt−1​ 是昨日收益冲击，σt−12​ 是昨日方差
  • α+β<1 保证平稳；α+β 接近 1 → 波动率冲击消退很慢（长记忆）
  • 用 GARCH 预测的 σt​ 替代常数 σ 算 VaR → 捕捉波动率聚集，肥尾时期自动放大 VaR

二级结论： 2008 和 2020 的教训是同一句话——波动率不是常数，相关性不是常数，唯一不变的是它们都会在危机中恶化。所有”恒定”的假设都是风险模型的阿喀琉斯之踵。

其他风险类型（量化视角）

风险类型定义量化手段
流动性风险想卖时卖不掉，或要打折卖买卖价差、Amihud 非流动性指标、VaR 加流动性缓冲
操作风险代码 bug、API 断连、人为失误熔断、测试端点、日志审计（见 实盘教训）
模型风险模型假设错了（正态、恒定相关）模型回测、压力测试、多模型交叉验证
尾部风险极端事件（黑天鹅）EVT 极值理论、肥尾分布（t 分布、跳扩散）

人话： 量化圈最贵的教训是「模型假设错了，但没人检查假设」。VaR、Greeks 全是工具——工具的前提是假设，假设要年年审。

相关性风险

资产间的相关性在经济危机中急剧上升（“diversification fails when you need it most”）。

  • Copula：分离边际分布和依赖结构
  • 尾部相关性：极值事件时资产究竟多相关（用极值理论 EVT 建模）

二级结论： 平时 ρ=0.3 的两类资产，危机时可能跳到 0.9。用平时相关性做组合 VaR，等于在暴风雨里撑一把晴雨伞——压力测试必须换用危机相关性。

常见丢分点

  1. VaR 没有告诉你尾部到底多厚——同一 VaR 可以有天差地别的尾部损失。永远同时看 CVaR。
  2. Delta 对冲不是 set-and-forget——Gamma 非零意味着需要动态调仓。
  3. 波动率不是常数——BS 的 σ 假设与实际 volatility smile/skew 矛盾。
  4. 相关性 ≠ 因果，且相关性在危机中不可靠。
  5. VaR 不满足次可加性——考试常考：为什么监管机构现在要求报 ES 而不是只报 VaR。
