1. 不等式 (Inequalities)

核心内容：

主要处理分数不等式和模量分数不等式。求解的关键是找到临界值，并通过符号分析或平方转化来确定解集。

示例 1：模量分数不等式的求解

求解不等式 ∣x−1x​∣<2。

详细讲解：

  1. 平方转化法: 由于不等式两边都是非负的，我们可以直接平方来去除模量：

    (x−1x​)2<22

  2. 移项整理：

    \frac{x^2}{(x-1)^2} < 4$$$$x^2 < 4(x-1)^2$$$$x^2 < 4(x^2 - 2x + 1)$$$$x^2 < 4x^2 - 8x + 4$$$$0 < 3x^2 - 8x + 4

  3. 因式分解： 求解二次不等式 3x2−8x+4>0。

    3x2−8x+4=(3x−2)(x−2)

  4. 临界值： 临界点为 x=32​ 和 x=2。

  5. 解集： 由于二次项系数为正，抛物线开口向上，故不等式 3x2−8x+4>0 的解集为外部区间：

    x<32​或x>2

  6. 约束条件： 别忘了原式分母不为零：x−1=0⟹x=1。

  7. 最终解集： 综合上述条件，最终解集为 x<32​ 或 x>2。

2. 级数 (Series)

核心内容：

差分法 (Method of Differences) 是求和技巧的重点。它要求将通项 ur​ 拆解为两个相邻函数值之差 f(r)−f(r+1) 或 f(r−1)−f(r)。

示例 2：差分法求和

求级数 SN​=∑r=1N​r(r+1)1​ 的和。

详细讲解：

  1. 部分分式分解 (Partial Fractions): 将通项 ur​ 分解：

    r(r+1)1​=r1​−r+11​

  2. 展开求和: 将级数展开，利用相邻项的抵消：

    S_N = \sum_{r=1}^{N} \left(\frac{1}{r} - \frac{1}{r+1}\right)$$$$S_N = \left(\frac{1}{1} - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{4}\right) + \dots + \left(\frac{1}{N} - \frac{1}{N+1}\right)

  3. 中间项抵消 (Telescoping): 观察到中间项 −21​ 和 +21​ 抵消，以此类推。

  4. 剩下首尾项：

    SN​=11​−N+11​=1−N+11​

  5. 极限： 当 N→∞ 时，级数的和为 limN→∞​SN​=1。

3. 复数进阶 (Further Complex Numbers)

核心内容：

De Moivre 定理和欧拉公式是核心工具。求 n 次根和复平面上的轨迹是必考题型。

示例 3：复数的 n 次根

求方程 z4=16i 的所有根，并以 r(cosθ+isinθ) 形式表示。

详细讲解：

  1. 将 w 转化为极坐标形式：

    w = 16i$$$$r = |16i| = 16$$$$\theta = \arg(16i) = \frac{\pi}{2}$$$$w = 16 \left( \cos\left(\frac{\pi}{2}\right) + i\sin\left(\frac{\pi}{2}\right) \right)

  2. 应用 n 次根公式： n=4

    zk​=r1/n(cos(nθ+2kπ​)+isin(nθ+2kπ​)),k=0,1,2,3

  3. 代入求根： r1/4=161/4=2

    • k=0:

      z0​=2(cos(4π/2​)+isin(4π/2​))=2(cos(8π​)+isin(8π​))

    • k=1:

      z1​=2(cos(4π/2+2π​)+isin(4π/2+2π​))=2(cos(85π​)+isin(85π​))

    • k=2:

      z2​=2(cos(4π/2+4π​)+isin(4π/2+4π​))=2(cos(89π​)+isin(89π​))

    • k=3:

      z3​=2(cos(4π/2+6π​)+isin(4π/2+6π​))=2(cos(813π​)+isin(813π​))

4. 微分方程 (Differential Equations - DEs)

核心内容：

掌握一阶线性方程的积分因子法和二阶常系数非齐次方程的通解结构。

示例 4：二阶常系数非齐次 DE 的求解

求微分方程 dx2d2y​−2dxdy​−3y=4e2x 的通解。

详细讲解：

  1. 求互补函数 (CF):

    • 特征方程：m2−2m−3=0

    • 因式分解：(m−3)(m+1)=0

    • 特征根：m1​=3,m2​=−1 (两个不同的实根)

    • CF：yCF​=Ae3x+Be−x

  2. 求特解 (PI):

    • 右侧函数 f(x)=4e2x，尝试特解形式 yPI​=λe2x。

    • 求导：dxdy​=2λe2x, dx2d2y​=4λe2x。

    • 代入原方程：

      4\lambda e^{2x} - 2(2\lambda e^{2x}) - 3(\lambda e^{2x}) = 4e^{2x}$$$$e^{2x} (4\lambda - 4\lambda - 3\lambda) = 4e^{2x}$$$$-3\lambda = 4 \implies \lambda = -\frac{4}{3}

    • PI：yPI​=−34​e2x

  3. 通解 (General Solution):

    y=yCF​+yPI​=Ae3x+Be−x−34​e2x

5. Maclaurin 和 Taylor 级数 (Maclaurin and Taylor Series)

核心内容：

通过计算函数在展开点（Maclaurin 是 x=0，Taylor 是 x=a）的各阶导数来构造级数。

示例 5：Maclaurin 级数展开

求函数 f(x)=sinx 的 Maclaurin 级数的前三项（非零项）。

详细讲解：

  1. 求导数并计算 x=0 处的值：

    • f(x)=sinx⟹f(0)=0

    • f′(x)=cosx⟹f′(0)=1

    • f′′(x)=−sinx⟹f′′(0)=0

    • f′′′(x)=−cosx⟹f′′′(0)=−1

    • f(4)(x)=sinx⟹f(4)(0)=0

    • f(5)(x)=cosx⟹f(5)(0)=1

  2. 代入 Maclaurin 级数公式：

    f(x)≈f(0)+xf′(0)+2!x2​f′′(0)+3!x3​f′′′(0)+4!x4​f(4)(0)+5!x5​f(5)(0)+…

  3. 写出前三项非零项：

    f(x) \approx 0 + x(1) + \frac{x^2}{2!}(0) + \frac{x^3}{3!}(-1) + \frac{x^4}{4!}(0) + \frac{x^5}{5!}(1) + \dots$$$$\sin x \approx x - \frac{x^3}{3!} + \frac{x^5}{5!} + \dots

6. 极坐标 (Polar Coordinates)

核心内容：

掌握极坐标曲线的面积公式和坐标转换。

示例 6：极坐标曲线面积计算

求曲线 r=4cosθ 在 −2π​≤θ≤2π​ 上的面积。

详细讲解：

  1. 识别曲线 (可选)： 将极坐标转为笛卡尔坐标。

    • r=4cosθ

    • 两边同乘 r: r2=4rcosθ

    • 代入 r2=x2+y2 和 x=rcosθ: x2+y2=4x

    • 配方：(x2−4x+4)+y2=4⟹(x−2)2+y2=4。

    • 这是一条圆心在 (2,0)，半径为 2 的圆。

  2. 应用面积公式：

    A = \frac{1}{2} \int_{\alpha}^{\beta} r^2 d\theta$$$$A = \frac{1}{2} \int_{-\pi/2}^{\pi/2} (4\cos\theta)^2 d\theta = \frac{1}{2} \int_{-\pi/2}^{\pi/2} 16\cos^2\theta d\theta

  3. 利用二倍角公式： cos2θ=21​(1+cos2θ)

    A=8∫−π/2π/2​21​(1+cos2θ)dθ=4∫−π/2π/2​(1+cos2θ)dθ

  4. 积分计算：

    A = 4 \left[ \theta + \frac{1}{2}\sin 2\theta \right]_{-\pi/2}^{\pi/2}$$$$A = 4 \left( \left(\frac{\pi}{2} + \frac{1}{2}\sin(\pi)\right) - \left(-\frac{\pi}{2} + \frac{1}{2}\sin(-\pi)\right) \right)$$$$A = 4 \left( \left(\frac{\pi}{2} + 0\right) - \left(-\frac{\pi}{2} + 0\right) \right) = 4 \left( \pi \right) = 4\pi

7. 复平面上的变换 (Transformations in the Argand Diagram)

核心内容：

理解 w=f(z) 变换下的几何图形映射，特别是 w=z1​ 变换对圆和直线的影响。

示例 7：反演变换 w=z1​

给定 z 平面上的轨迹是 ∣z∣=2（以原点为圆心，半径为 2 的圆），求在变换 w=z1​ 下，w 平面上的对应轨迹。

详细讲解：

  1. 代数替换： 设 w=u+iv 且 z=x+iy。

    w=z1​⟹z=w1​

  2. 应用模量性质： 将 z=w1​ 代入 ∣z∣=2：

    ​w1​​=2

  3. 简化： 利用 ∣ba​∣=∣b∣∣a∣​，且 ∣1∣=1：

    \frac{1}{|w|} = 2$$$$|w| = \frac{1}{2}

  4. 几何解释：

    ∣w−(0+0i)∣=21​

    这表示在 w 平面上，轨迹是一个以原点 (0,0) 为圆心，半径为 21​ 的圆。

结论： 在 w=z1​ 变换下，以原点为圆心，半径为 2 的圆被映射成以原点为圆心，半径为 21​ 的圆。
