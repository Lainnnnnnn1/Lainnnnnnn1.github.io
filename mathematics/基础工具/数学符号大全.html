数学符号大全

人话讲解

数学符号就是数学的「缩写系统」。掌握了符号，读论文和教科书的速度直接翻倍。这里按领域分类整理，配合 LaTeX 代码方便写作。同一个符号在不同学科含义不同（比如 ∼），最后一节的「易混淆符号对比」是重点。

易混淆符号对比

符号对区别
ϵ vs ∈一个是「任意小正数」，一个是「属于」关系；手写时 ∈ 一横要明显
∅ vs ∅ vs ϕ前两个都是空集，ϕ 是希腊字母 phi，别混用
⊂ vs ⊆有的教材 ⊂ 允许相等，有的要求真包含；看作者定义
= vs ≡ vs ≅相等 / 恒等或同余 / 同构
≃ vs ∼ vs ≈同伦 / 等价关系或渐近 / 数值近似
→ vs ↦函数整体 f:A→B；元素对应 x↦x2
$x
Δ vs ∇ vs ∂ vs δ拉普拉斯或增量 / 梯度 / 偏导 / 小量
⊥ vs ⊥⊥垂直 / 独立（概率论）
∑ vs Σ vs ∫求和号 / 大写西格玛 / 积分（和的极限）
R vs R vs R实数集 / 向量或矩阵 / 某类集合（如关系）
o(x) vs O(x) vs ω(x)高阶无穷小 / 同阶有界 / 低阶无穷大
C vs C复数集 / 常数 C（积分常数习惯用后者）

二级结论

  • 手写区别：ϵ（任意小正数）= ∈（属于）；∅ 手写画个圈加斜杠即可
  • 上下文决定含义：∼ 在分析中是「等价无穷小」，在代数中是「等价关系」，在概率中是「服从分布」
  • 黑体 vs 空心体：R 是向量，R 是数集
  • 读论文先扫符号表：多数论文引言后有 Notation 小节，先花两分钟过一遍再读正文
  • 量词顺序敏感：∀∃ 与 ∃∀ 含义不同，证明题先写清量词
