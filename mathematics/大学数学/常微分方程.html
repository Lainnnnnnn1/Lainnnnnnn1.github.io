常微分方程

核心问题：包含未知函数及其导数的方程怎么解？——从物理过程的数学模型出发。

基本概念

  • 阶数：方程中出现的最高阶导数的阶数
  • 线性 vs 非线性：未知函数及其导数是否只是一次的
  • 通解：包含任意常数的解（n 阶方程含 n 个独立任意常数）
  • 特解：给定初始条件后确定的解
  • 初值问题（IVP）：{y(n)=f(x,y,y′,…,y(n−1))y(x0​)=y0​,…,y(n−1)(x0​)=y0(n−1)​​

人话讲解：微分方程就是描述了函数的变化规律——知道”怎么变”，要去求”是什么”。初始条件告诉你从哪儿出发。

存在唯一性定理（Picard）

若 f(x,y) 在矩形区域 R={(x,y):∣x−x0​∣≤a,∣y−y0​∣≤b} 上连续，且关于 y 满足 Lipschitz 条件：

∣f(x,y1​)−f(x,y2​)∣≤L∣y1​−y2​∣

则初值问题 y′=f(x,y)，y(x0​)=y0​ 在 ∣x−x0​∣≤min(a,b/M) 上存在唯一解（其中 M=maxR​∣f∣）。

Lipschitz 条件的充分判据：若 ∂y∂f​ 在 R 上连续（从而有界），则 f 满足 Lipschitz 条件。

⚠️ 连续保证存在，Lipschitz 保证唯一。仅有连续性不足以保证唯一性！

一阶微分方程

1. 可分离变量方程

dxdy​=f(x)g(y)⇒∫g(y)dy​=∫f(x)dx

口诀：把 y 的放一边，x 的放另一边，各自积分。

例：dxdy​=xy → ∫ydy​=∫xdx → ln∣y∣=2x2​+C → y=Cex2/2

2. 一阶线性方程

标准形式：

dxdy​+P(x)y=Q(x)​

解法 — 积分因子法：

第1步：求积分因子 μ(x)=e∫P(x)dx

第2步：两边乘 μ(x)：dxd​[μ(x)y]=μ(x)Q(x)

第3步：两边积分：y=μ(x)1​∫μ(x)Q(x)dx

人话：乘上积分因子后，左边刚好是一个乘积的导数，直接就能积出来。

3. Bernoulli 方程

y′+P(x)y=Q(x)yn(n=0,1)

解法：令 z=y1−n，化为关于 z 的一阶线性方程 z′+(1−n)P(x)z=(1−n)Q(x)。

4. 恰当方程（全微分方程）

若 M(x,y)dx+N(x,y)dy=0 满足 ∂y∂M​=∂x∂N​，则方程为恰当方程。

解法：存在函数 F(x,y) 使 dF=Mdx+Ndy，解为 F(x,y)=C。

∂y∂M​=∂x∂N​ 时，可寻找积分因子 μ(x,y) 使 μMdx+μNdy 成为恰当方程。

常见积分因子：

  • 若 NMy​−Nx​​ 仅依赖 x，则 μ(x)=e∫NMy​−Nx​​dx
  • 若 MNx​−My​​ 仅依赖 y，则 μ(y)=e∫MNx​−My​​dy
类型标准形式解法关键
可分离dxdy​=f(x)g(y)分离变量，各自积分
一阶线性y′+P(x)y=Q(x)积分因子 μ=e∫P
恰当方程Mdx+Ndy=0，My​=Nx​找势函数 F

齐次方程y′=f(y/x)令 u=y/x 化为可分离

二阶线性常系数微分方程（⭐ 重点）

齐次方程

ay′′+by′+cy=0(a,b,c 为常数)

特征方程法：

写出特征方程：aλ2+bλ+c=0

判别式 Δ=b2−4ac根的情况通解形式
Δ>0两不等实根 λ1​=λ2​y=C1​eλ1​x+C2​eλ2​x
Δ=0相等实根 λy=(C1​+C2​x)eλx
Δ<0共轭复根 α±iβy=eαx(C1​cosβx+C2​sinβx)

人话讲解：把微分方程变成代数方程（特征方程），解出根就知道通解形式。关键是 Δ 的符号决定了解的类型。

⚠️ 共振原则：若试设与齐次解重合，乘以 x（或 x2）直到不重合。

二阶变系数方程与级数解法

1. Euler 方程

x2y′′+axy′+by=0

解法：令 x=et（t=lnx），化为常系数方程：

dt2d2y​+(a−1)dtdy​+by=0

通解形式：y=C1​xr1​+C2​xr2​（r 为指示方程的根）

2. 降阶法

若已知一个特解 y1​，设 y2​=y1​v(x)，代入原方程可得关于 v′ 的一阶方程。

3. 幂级数解法

🎯 当方程无法用初等函数求解时，设解为幂级数形式 y=∑n=0∞​an​xn，代入方程比较同次幂系数得到递推关系。

例：y′=y，设 y=∑an​xn：

  • y′=∑nan​xn−1，对比得 an​=an−1​/n
  • an​=a0​/n!，y=a0​∑n!xn​=a0​ex

Frobenius 方法（正则奇点）

若 x=0 是方程的正则奇点，设解为：

y=xrn=0∑∞​an​xn

其中 r 由指标方程确定（可能有两个根 r1​≥r2​）：

  • r1​−r2​∈/Z：两个线性无关的 Frobenius 解
  • r1​−r2​∈Z：第二个解可能含 lnx 项

Sturm-Liouville 理论（入门）

1. Sturm-Liouville 问题

−(p(x)y′)′+q(x)y=λw(x)y​

其中 p(x)>0，w(x)>0，配合适当的边界条件。

📌 这是 Eigenvalue 问题在函数空间中的体现！y 是特征函数，λ 是特征值。

2. 基本性质

  1. 特征值 λn​ 是实数、可排为 λ1​<λ2​<⋯→∞
  2. 不同特征值对应的特征函数关于权 w(x) 正交：∫ym​yn​wdx=0
  3. 特征函数构成 Lw2​ 空间的完备正交基
  4. 第 n 个特征函数恰有 n−1 个零点（Sturm 比较定理）

3. 经典例子

方程特征函数应用
y′′+λy=0sinnx,cosnxFourier 级数
(1−x2)y′′−2xy′+λy=0Legendre 多项式球坐标
y′′−2xy′+λy=0Hermite 多项式量子谐振子
xy′′+(1−x)y′+λy=0Laguerre 多项式氢原子

相平面分析（定性理论入门）

1. 二维自治系统

{x˙=f(x,y)y˙​=g(x,y)​

相平面：以 (x,y) 为坐标的平面，解的轨迹为轨线。

2. 线性系统的相图分类

对于 x˙=Ax（A 为 2×2 矩阵），轨线形态由特征值决定：

特征值名称相图特征
λ1​<0<λ2​鞍点一个方向稳定，一个不稳定
λ1​,λ2​<0稳定结点所有轨线趋向原点
λ1​,λ2​>0不稳定结点所有轨线远离原点
α±iβ，α<0稳定焦点螺旋趋近原点
α±iβ，α>0不稳定焦点螺旋远离原点
±iβ（纯虚数）中心闭轨，周期运动

人话：稳定 = 回到平衡点（物理上吸引子）；不稳定 = 离开（排斥子）；中心 = 绕圈（保守系统）。

3. 线性化方法

在平衡点 (x0​,y0​) 附近做 Taylor 展开（保留线性项），得到 Jacobi 矩阵：

J=(fx​gx​​fy​gy​​)(x0​,y0​)​

若 J 的特征值实部均不为零，则非线性系统的局部行为与线性化系统定性相同（Hartman-Grobman 定理）。

例题精讲

例题 1：解 y′′−3y′+2y=ex

解题思路：

第1步（齐次解）：特征方程 λ2−3λ+2=0 → (λ−1)(λ−2)=0 → λ1​=1,λ2​=2

齐次通解：yh​=C1​ex+C2​e2x

第2步（特解试设）：f(x)=ex，正常设 yp​=Aex，但 ex 已是齐次解！所以要乘 x：设 yp​=Axex

第3步（代入求 A）：

  • yp′​=Aex+Axex=Aex(1+x)
  • yp′′​=Aex(1+x)+Aex=Aex(2+x)
  • 代入方程：Aex(2+x)−3Aex(1+x)+2Axex=ex
  • 化简：Aex[(2+x)−3(1+x)+2x]=Aex(−1)=ex
  • A=−1，yp​=−xex

第4步：通解 y=C1​ex+C2​e2x−xex

例题 2：用 Picard 迭代解 y′=y，y(0)=1

解题思路：

Picard 迭代：yn+1​(x)=y0​+∫0x​f(t,yn​(t))dt

  • y0​(x)=1
  • y1​=1+∫0x​1dt=1+x
  • y2​=1+∫0x​(1+t)dt=1+x+2x2​
  • yn​=∑k=0n​k!xk​→ex

例题 3：分析系统 x˙=−y，y˙​=x 的相图

解题思路：

J=(01​−10​)，特征方程 λ2+1=0，λ=±i（纯虚数）。

⟹ 中心，轨线是同心圆 x2+y2=C。系统守恒E=x2+y2。

二级结论

  • 一阶线性积分因子：μ=e∫Pdx
  • 二阶齐次常系数 → 特征方程（代数化！）
  • 共振情况（试设重合）→ 乘 x
  • Euler 方程 x2y′′+axy′+by=0 → 令 x=et 化为常系数
  • Picard 定理：f 连续 + Lipschitz ⟹ 存在唯一
  • 特征值实部 < 0 ⟹ 渐近稳定；实部 > 0 ⟹ 不稳定
  • Hamiltonian 系统 x˙=Hy​,y˙​=−Hx​ 的平衡点只有中心和鞍点
