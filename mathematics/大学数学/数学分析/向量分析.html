向量分析（场论）

核心问题：向量场怎么描述？沿曲线走了多少”功”？通过曲面的”流量”是多少？

散度、梯度、旋度 —— 场论三剑客

1. 梯度（Gradient）— 标量 → 向量

gradf=∇f=(∂x∂f​,∂y∂f​,∂z∂f​)

人话：梯度告诉你站在 f 的”山上”，往哪个方向爬最陡。

2. 散度（Divergence）— 向量 → 标量

对于向量场 F=(P,Q,R)：

divF=∇⋅F=∂x∂P​+∂y∂Q​+∂z∂R​

人话讲解：散度衡量一个点”往外冒”还是”往里吸”。divF>0 是源（source），divF<0 是汇（sink），divF=0 是无源场。

3. 旋度（Curl）— 向量 → 向量

curlF=∇×F=​i∂x∂​P​j∂y∂​Q​k∂z∂​R​​

展开为：

∇×F=(∂y∂R​−∂z∂Q​,∂z∂P​−∂x∂R​,∂x∂Q​−∂y∂P​)

人话：旋度衡量向量场的”旋转”程度。curlF=0 是无旋场。

算子组合结果含义
∇×(∇f)0梯度的旋度恒为零（无旋场）
∇⋅(∇×F)0旋度的散度恒为零（无源场）
∇⋅(∇f)=∇2f标量Laplace 算子
∇×(∇×F)向量=∇(∇⋅F)−∇2F

口诀：旋无散，梯无旋。（curl of grad = 0, div of curl = 0）

散度与旋度的物理意义

1. 散度 = 单位体积的”净流出率”

把 F 想成流体的速度场 v：

  • divv>0：该点有源，流体不断涌出（如水泵）
  • divv<0：该点有汇，流体被吸走（如排水口）
  • divv=0：不可压缩流体（质量守恒），如理想水流

2. 旋度 = 2 倍的”角速度”

刚体绕 z 轴以角速度 ω 旋转时，速度场 v=(−ωy,ωx,0)。计算：

curlv=(0−0,0−0,∂x∂(ωx)​−∂y∂(−ωy)​)=(0,0,2ω)

即 curlv=2ω​——旋度是局部旋转角速度的 2 倍。curl=0 的地方有涡旋（漩涡、龙卷风）。

3. 三”场”的分类与关系

场的类型条件等价说法
保守场（无旋场）∇×F=0F=∇f（有势函数）；线积分与路径无关
无源场（管形场）∇⋅F=0F=∇×A（有向量势）
调和场无旋 + 无源f 满足 ∇2f=0（Laplace 方程，静电势/稳态温度场）

三大积分定理（重中之重）

Green 公式（二维闭合曲线 ↔ 区域面积分）

设 C 为正向（逆时针）闭合曲线，D 为其所围区域：

∮C​Pdx+Qdy=∬D​(∂x∂Q​−∂y∂P​)dxdy​

人话讲解：沿闭合曲线的环流量 = 内部所有”旋度”的总和。把线积分转化为二重积分！

应用：用线积分算面积：

A=21​∮C​(xdy−ydx)

Stokes 公式（三维闭合曲线 ↔ 曲面积分）

设 C 为曲面 S 的边界曲线：

∮C​F⋅dr=∬S​(∇×F)⋅dS​

人话：沿空间闭合曲线的环流量 = 张在该曲线上任意曲面上的旋度通量。这是 Green 公式的三维推广！

选面技巧：C 固定的情况下 S 可以随便选——永远选最好算的那个面（平面、坐标面）。曲面方向与曲线方向满足右手定则。

散度定理（Gauss 公式，闭合曲面 ↔ 体积分）

设 S 为闭合曲面，Ω 为其所围体积：

∬​S​F⋅dS=∭Ω​(∇⋅F)dV​

人话：穿过闭合曲面的净流量 = 内部所有”源”的发散总量。把面积分转化为三重积分！

三定理对比速查表

定理维数左边右边物理意义
Green2D线积分 ∮C​面积分 ∬D​平面环流量
Stokes3D线积分 ∮C​曲面积分 ∬S​空间环流量
Gauss3D曲面积分 ∬​S​体积分 ∭Ω​曲面通量

🔗 统一公式（广义 Stokes 定理）：∫∂M​ω=∫M​dω，三个定理都是它的特例。

曲线积分与曲面积分

1. 第一类曲线积分（对弧长）

∫C​f(x,y,z)ds

物理意义：密度为 f 的曲线的总质量。

计算：参数化 C:r(t)=(x(t),y(t),z(t))，t∈[a,b]

ds=∣r′(t)∣dt=x′(t)2+y′(t)2+z′(t)2​dt

套路：① 参数化（直线用 t 线性表示，圆用 cost,sint）；② 算 ds；③ 代回化为定积分。注意 ds 恒为正，积分结果与方向无关。

2. 第二类曲线积分（对坐标）

∫C​F⋅dr=∫C​Pdx+Qdy+Rdz

物理意义：力 F 沿曲线 C 所做的功。

计算：参数化后 dx=x′(t)dt，dy=y′(t)dt，dz=z′(t)dt：

∫ab​[P(x(t),y(t),z(t))x′(t)+Qy′(t)+Rz′(t)]dt

注意：第二类积分与方向有关——C 反向，积分变号。

3. 曲线积分与路径无关的条件

若 F=(P,Q,R) 在单连通区域 D 上满足以下等价条件之一：

  • ∇×F=0（无旋）
  • ∮C​F⋅dr=0（任何闭曲线积分为零）
  • F=∇f（存在势函数，F 是保守场）

则曲线积分与路径无关。

4. 第一类曲面积分（对面积）

∬S​f(x,y,z)dS

若 S:z=g(x,y)：dS=1+gx2​+gy2​​dxdy

5. 第二类曲面积分（对坐标）

∬S​F⋅dS=∬S​(Pdydz+Qdzdx+Rdxdy)

物理意义：向量场穿过曲面的通量（flux）。

投影法口诀：一投、二代、三定号——把曲面投影到坐标面（如 xy 面），被积函数代入 z=g(x,y)，符号由曲面法向与坐标轴正向的夹角决定（夹角为锐角取正，钝角取负）。S 为闭合曲面时优先用 Gauss 公式。

势函数的求法

原理： 若 ∇×F=0（保守场），则存在 f 使 F=∇f。求 f 的标准流程：

  1. 猜：由 fx​=P 对 x 积分得 f=∫Pdx+g(y,z)；
  2. 补：对 y 求导比对 Q，定出 g 中含 y 的部分，再对 z 求导比对 R，定出剩余；
  3. 验：核对 ∇f=F。

替代方法（线积分法）：f(x,y,z)=∫(0,0,0)(x,y,z)​F⋅dr，取”折线路径”——先沿 x 轴、再平行 y 轴、再平行 z 轴，每段只有一个变量变化，积分极其简单。

例题精讲

例题 1：用 Green 公式计算 ∮C​(x2ydx+xy2dy)，C 为单位圆

解题思路：

第1步：识别 P=x2y，Q=xy2。

第2步：计算旋度项：

∂x∂Q​−∂y∂P​=y2−x2

第3步：用 Green 公式转二重积分，D 为单位圆：

∬D​(y2−x2)dxdy

第4步：转极坐标，y2−x2=r2(sin2θ−cos2θ)=−r2cos2θ：

∫02π​∫01​(−r2cos2θ)⋅rdrdθ=−∫02π​cos2θdθ⋅∫01​r3dr

第5步：∫02π​cos2θdθ=0，故结果为 0。

点评：y2−x2 在圆域上”关于 x,y 对称抵消”——这类对称性判断比硬算快得多。看到闭合曲线线积分，第一反应永远是 Green。

例题 2：第一类曲线积分——求 ∫C​(x2+y2)ds，C 为螺旋线 r(t)=(cost,sint,t)，0≤t≤2π

解题思路：

第1步：参数化已给出。x2+y2=cos2t+sin2t=1。

第2步：算弧长微元：

ds=x′(t)2+y′(t)2+z′(t)2​dt=sin2t+cos2t+1​dt=2​dt

第3步：代回：

∫C​(x2+y2)ds=∫02π​1⋅2​dt=22​π

点评：第一类曲线积分的”参数化 + ds + 代入”是唯一套路。本题妙在 x2+y2 沿螺旋线恒为 1，积分立即化简。

例题 3：第二类曲线积分——计算 ∫C​ydx+xdy，C 为从 (0,0) 到 (1,1) 的抛物线 y=x2

解题思路：

第1步：参数化 x=t，y=t2，t∈[0,1]。则 dx=dt，dy=2tdt。

第2步：代入：

∫C​ydx+xdy=∫01​(t2⋅1+t⋅2t)dt=∫01​3t2dt=1

第3步（路径无关性检验）：若沿直线 y=x 积分：∫01​(x+x)dx=1——结果相同！

第4步：原因：∂x∂Q​=1=∂y∂P​，场 F=(y,x) 是保守场，势函数 f=xy，故积分 =f(1,1)−f(0,0)=1。

点评：保守场中线积分 = 势函数终点值减起点值，与路径完全无关。先查 ∂x∂Q​=∂y∂P​ 再决定直接算还是找势函数，能省一半计算量。

例题 4：Green 公式求面积——椭圆 a2x2​+b2y2​=1 的面积

解题思路：

第1步：用面积公式 A=21​∮C​(xdy−ydx)。

第2步：参数化椭圆：x=acost，y=bsint，t∈[0,2π]。则 dx=−asintdt，dy=bcostdt。

第3步：代入：

A=21​∫02π​(acost⋅bcost−bsint⋅(−asint))dt=2ab​∫02π​(cos2t+sin2t)dt=πab

点评：21​∮(xdy−ydx) 是最优雅的面积公式——任何闭合曲线围成的面积都能这样算，且 ∮xdy 与 ∮−ydx 单独看也都等于面积。

例题 5：Green 公式——计算 ∮C​(exsiny−y)dx+(excosy−1)dy，C 为单位圆（逆时针）

解题思路：

第1步：P=exsiny−y，Q=excosy−1。计算：

∂x∂Q​−∂y∂P​=excosy−(excosy−1)=1

第2步：Green 公式：

∮C​=∬D​1dxdy=圆面积=π

点评：被积函数复杂到不敢直接参数化？Green 公式把”旋度”化简成常数 1——这类题专门考察”识别出 Qx​−Py​ 化简后很漂亮”的眼力。

例题 6：Stokes 公式——计算 ∮C​F⋅dr，F=(z,x,y)，C 为单位圆 x2+y2=1,z=0（逆时针）

解题思路：

第1步：C 是闭合空间曲线，用 Stokes。选 S 为 xy 平面上的单位圆盘（法向 n=(0,0,1)，与 C 的方向成右手系）。

第2步：计算旋度：

∇×F=(∂y∂y​−∂z∂x​,∂z∂z​−∂x∂y​,∂x∂x​−∂y∂z​)=(1,1,1)

第3步：Stokes 公式：

∮C​F⋅dr=∬S​(1,1,1)⋅(0,0,1)dS=∬S​1dS=π

第4步（直接验证）：参数化 x=cost,y=sint,z=0：∮xdy=∫02π​cost⋅costdt=π ✓

点评：Stokes 的三大考点——① 旋度计算；② 曲面方向与曲线方向的一致性（右手定则）；③ 选最平的曲面。本题曲面取坐标面圆盘，n 就是 (0,0,1)，一步到位。

例题 7：Gauss 公式——计算 ∬​S​F⋅dS，S 为单位球面

(a) F=(x,y,z)

第1步：divF=1+1+1=3。

第2步：Gauss 公式：

∬​S​F⋅dS=∭Ω​3dV=3⋅34π​=4π

(b) F=(x3,y3,z3)

第1步：divF=3x2+3y2+3z2=3ρ2。

第2步：球坐标：

∭Ω​3ρ2dV=3∫02π​dθ∫0π​sinϕdϕ∫01​ρ4dρ=3⋅2π⋅2⋅51​=512π​

点评：闭合曲面通量 = 内部散度积分——把”曲面上的积分”变成”球体内的积分”，物理上就是”净流出 = 内部源的总强度”。F=(x,y,z) 的通量恒为 3× 体积，是可以直接背的结论。

例题 8：求势函数——F=(2xy,x2+2yz,y2+2z) 是保守场吗？若是，求势函数

解题思路：

第1步：验证无旋：

∂y∂R​−∂z∂Q​=2y−2y=0,∂z∂P​−∂x∂R​=0,∂x∂Q​−∂y∂P​=2x−2x=0

∇×F=0，是保守场 ✓

第2步（凑微分法）：由 fx​=2xy 积分：

f=∫2xydx=x2y+g(y,z)

第3步：对 y 求导比对 Q：fy​=x2+gy​=x2+2yz，故 gy​=2yz，g=y2z+h(z)。

第4步：对 z 求导比对 R：fz​=y2+h′(z)=y2+2z，故 h(z)=z2。

第5步：势函数 f(x,y,z)=x2y+y2z+z2。验证：∇f=(2xy,x2+2yz,y2+2z)=F ✓

点评：凑微分法三步”积 x → 比 y → 比 z“是求势函数的标准流程。求出后务必验证 ∇f=F——这是防错的关键一步。

二级结论

  • 若 ∂x∂Q​=∂y∂P​，则在单连通区域上 ∮C​Pdx+Qdy=0
  • 球面 x2+y2+z2=R2 的面积：4πR2；∬​S​(x,y,z)⋅dS=4πR3（S 为半径 R 的球面）
  • 保守场 F 的势函数：f(x,y)=∫(x0​,y0​)(x,y)​F⋅dr（折线路径）
  • 面积公式：A=21​∮C​(xdy−ydx)
  • 刚体旋转场 v=ω×r 满足 curlv=2ω
  • ∮C​F⋅dr=0（C 闭合、F 保守）⟺ 线积分与路径无关
  • 调和函数（∇2f=0）满足平均值性质：f 在球心的值 = 在球面上的平均值
