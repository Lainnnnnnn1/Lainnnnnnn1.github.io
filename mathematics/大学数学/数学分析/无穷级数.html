无穷级数

核心问题：无穷多个数加起来会等于一个有限的数吗？函数能不能用多项式来逼近？

数项级数 — 收敛还是发散？

1. 基本定义

对于 ∑n=1∞​an​，定义部分和 Sn​=∑k=1n​ak​。

  • 若 limn→∞​Sn​=S（有限），则级数收敛于 S
  • 否则级数发散

人话讲解：无穷项加起来不一定等于无穷。关键是看”尾巴”是不是越来越小，小到可以忽略不计。

2. 收敛的必要条件

若 ∑an​ 收敛，则 n→∞lim​an​=0​

⚠️ 反过来不成立！liman​=0 是必要条件，但不充分。例子：调和级数 ∑n1​ 通项趋于 0 但发散。

3. Cauchy 收敛准则

∑an​ 收敛 ⟺ ∀ε>0,∃N，使得 n>m>N 时：

∣am+1​+am+2​+⋯+an​∣<ε

这是级数收敛的充要条件——不需要知道极限值就能判断。

Raabe 判别法

当 ρ=1（比值法失效）时，计算：

r=n→∞lim​n(an+1​an​​−1)
  • r>1 ⟹ 收敛
  • r<1 ⟹ 发散
  • r=1 ⟹ 需进一步判别

若 an+1​an​​=λ+nμ​+O(n1+ε1​)：

  • λ>1 或 λ=1,μ>1 ⟹ 收敛
  • λ<1 或 λ=1,μ≤1 ⟹ 发散

若 an​↘0，则 ∑an​ 与 ∑2ka2k​ 同敛散。

例：用凝聚判别法证明 ∑nlnn1​ 发散： ∑2k⋅2kln(2k)1​=∑kln21​ 发散。

敛散性判别法决策树

拿到一个级数 ∑an​，按下面的顺序走，90% 的题都能解决：

∑ a_n
├─ 第0步：lim a_n ≠ 0 ? ──────────────→ 直接发散（必要条件）
└─ lim a_n = 0
   ├─ 正项级数（或先取绝对值）:
   │   ├─ 含 n! / a^n / n^n → 比值法（ρ = 1/e 等）
   │   ├─ 含 n 次幂 / 幂指 → 根值法
   │   ├─ 比值根值 ρ = 1 → 比较判别法（对 p-级数/几何级数比阶）
   │   │       └─ 还不行 → 积分判别法（1/(n ln^p n) 型）
   │   │              └─ 还不行 → Raabe / 凝聚判别法
   ├─ 交错级数: 单调递减趋于 0 ? ──→ Leibniz 收敛
   └─ 任意项级数: 先判绝对收敛
       ├─ ∑|a_n| 收敛 → 绝对收敛
       └─ ∑|a_n| 发散但 ∑a_n 收敛 → 条件收敛（Abel / Dirichlet 帮忙）

快速自检例：∑(n+1​−n​) 发散——有理化得 n+1​+n​1​∼2n​1​，p=21​≤1。∑n2sinn​ 绝对收敛——∣n2sinn​∣≤n21​。

交错级数与任意项级数

1. 交错级数 — Leibniz 判别法

若 {bn​} 单调递减趋于 0，则交错级数 ∑(−1)n−1bn​ 收敛。

例：∑n(−1)n−1​=1−21​+31​−41​+⋯=ln2

Leibniz 误差估计：∣Rn​∣=∣S−Sn​∣≤bn+1​（余项不超过第一个被丢弃的项）

应用：用 ∑k=1n​k(−1)k−1​ 近似 ln2 时，误差 ≤n+11​——要精确到 10−3 只需取 n=1000。

2. 绝对收敛与条件收敛（深入）

类型定义性质
绝对收敛$\suma_n
条件收敛∑an​ 收敛但 $\suma_n

🎯 Riemann 重排定理：条件收敛级数通过重排可收敛到任意实数（甚至发散到 ±∞）！

Abel 判别法与 Dirichlet 判别法（任意项级数）

判别法条件结论
Abel∑an​ 收敛，{bn​} 单调有界∑an​bn​ 收敛
Dirichlet∑k=1n​ak​ 有界，bn​↘0∑an​bn​ 收敛

关系：Abel 判别法是 Dirichlet 的特殊情况；Leibniz 又是 Dirichlet 的特殊情况（an​=(−1)n−1，bn​↘0）。

例：∑nsinn​ 收敛（Dirichlet：∑k=1n​sink 有界 + 1/n↘0）

级数乘法（Cauchy 乘积）

Cauchy 乘积

给定两级数 ∑an​ 和 ∑bn​，它们的 Cauchy 乘积为 ∑cn​，其中：

cn​=k=0∑n​ak​bn−k​=a0​bn​+a1​bn−1​+⋯+an​b0​

Mertens 定理

若 ∑an​ 绝对收敛于 A，∑bn​ 收敛于 B，则 Cauchy 乘积 ∑cn​ 收敛于 AB。

如果两个都绝对收敛，则 Cauchy 乘积也绝对收敛于 AB。

例：ex⋅ey=(∑n!xn​)(∑n!yn​)=∑n!(x+y)n​=ex+y（通过 Cauchy 乘积验证二项式定理）

幂级数

1. 定义

n=0∑∞​an​(x−x0​)n=a0​+a1​(x−x0​)+a2​(x−x0​)2+⋯

以 x0​ 为中心的幂级数。

2. 收敛半径

由比值法或根值法确定收敛半径 R：

  • 比值法：R=limn→∞​​an+1​an​​​（极限存在时）
  • 根值法（Cauchy-Hadamard）：R=limsupn∣an​∣​1​

| ∣x−x0​∣ 范围 | 敛散性 | |:---|:---| | <R | 绝对收敛 | | >R | 发散 | | =R | 不确定，需单独判别 |

人话：幂级数在以 x0​ 为中心的半径 R 的圆盘内绝对收敛。端点要单独检查。

端点检查三件套：把 x=x0​±R 代入，逐项看敛散——常考组合是”内部绝对收敛、端点条件收敛”（如 ∑nxn​ 在 x=−1 条件收敛、x=1 发散）。

3. 幂级数的运算（在收敛区间内）

  • 逐项求导：(∑an​xn)′=∑nan​xn−1，收敛半径不变
  • 逐项积分：∫(∑an​xn)dx=∑n+1an​​xn+1+C，收敛半径不变

4. Abel 定理

🎯 若 ∑an​ 收敛，则 limx→1−​∑an​xn=∑an​

即”幂级数在其收敛圆周的收敛点处是连续的”（沿径向）。

应用：∑n(−1)n−1​=limx→1−​∑n(−1)n−1xn​=limx→1−​ln(1+x)=ln2

幂级数的和函数求法

原理： 和函数 S(x)=∑an​xn 在收敛区间内可以像普通函数一样求导、积分、做代数运算——“先闭式化，再反运算”。

Taylor 级数与 Maclaurin 级数

1. Taylor 级数

f(x) 在 x=x0​ 的 Taylor 展开：

f(x)=n=0∑∞​n!f(n)(x0​)​(x−x0​)n

当 x0​=0 时称为 Maclaurin 级数。

人话讲解：用多项式来”模拟”一个函数。多项式的系数由函数在该点的各阶导数决定——导数匹配得越多，逼近越精确。

2. Taylor 级数收敛到 f(x) 的充要条件

余项 Rn​(x)→0（n→∞）。特别地，若 f 是实解析函数（即 f(n) 一致有界），则 Taylor 级数在收敛区间内等于 f(x)。

⚠️ 反例：f(x)=e−1/x2（x=0），f(0)=0。f(n)(0)=0（∀n），故 Taylor 级数为 0，但 f(x)=0（x=0）。这个函数是 C∞ 但不是解析的！

Fourier 级数

周期为 2π 的函数可展开为：

f(x)=2a0​​+n=1∑∞​(an​cosnx+bn​sinnx)

其中 Fourier 系数：

an​=π1​∫−ππ​f(x)cosnxdx,bn​=π1​∫−ππ​f(x)sinnxdx
  • 偶函数：bn​=0（只有余弦项，余弦级数）
  • 奇函数：an​=0（只有正弦项，正弦级数）

Gibbs 现象：在跳跃间断点附近，Fourier 级数的部分和会出现约 9% 的超调。

Fourier 级数的逐项积分

🎯 重要性质：即使 Fourier 级数不一致收敛，Fourier 级数也可以逐项积分，积分后的级数一致收敛到 ∫f。

用 Fourier 级数求和（数项级数求和的大杀器）

原理： 把已知函数的 Fourier 展开在特殊点代入，或对展开做 Parseval 等式，直接得到著名数项级数的和。

两条路线：

路线操作产出
代入法展开式代入 x=0,π,2π​ 等使三角项简单的点∑n21​、∑n(−1)n−1​ 等

人话：Fourier 系数是 f 在正交基上的”坐标”，Parseval 说”函数的能量 = 各坐标平方和”——于是 ∫f2 就给出了 ∑(系数)2。

例题 1：求 n=1∑∞​2nn​ 的和

解题思路：

第1步：从几何级数出发：∑n=0∞​xn=1−x1​，∣x∣<1。

第2步：逐项求导：∑n=1∞​nxn−1=(1−x)21​。

第3步：两边同乘 x：∑n=1∞​nxn=(1−x)2x​。

第4步：代入 x=21​：

n=1∑∞​2nn​=(1−1/2)21/2​=1/41/2​=2

例题 2：求 n=0∑∞​2n+1(−1)n​ 的和

解题思路：

第1步：arctanx=∑n=0∞​2n+1(−1)nx2n+1​，∣x∣≤1。

第2步：代入 x=1：

n=0∑∞​2n+1(−1)n​=arctan1=4π​

例题 3：判断 n=2∑∞​nlnn1​ 的敛散性

解题思路：

第1步：比值法？an​an+1​​→1，失效。

第2步：Raabe 法：n(an+1​an​​−1)=n(nlnn(n+1)ln(n+1)​−1)→1，仍不确定。

第3步：用积分判别法：∫2∞​xlnxdx​=lnlnx​2∞​=∞，发散。

点评：∑n(lnn)p1​ 一族全部用积分判别法：∫x(lnx)pdx​ 在 p>1 收敛——与 p-级数平行的”对数标尺”。

例题 5：判断 n=1∑∞​nnn!​ 的敛散性

解题思路：

第1步：含 n! 与 nn，用比值法：

an​an+1​​=(n+1)n+1(n+1)!​⋅n!nn​=(n+1n​)n=(1+n1​)n1​

第2步：(1+n1​)n→e，故 an​an+1​​→e1​<1。

第3步：由比值判别法，级数收敛。∎

点评：nnn!​∼2πn​e−n（Stirling），通项衰减极快。凡是”阶乘对幂”的级数，比值法几乎总是一步到位。

例题 6：判断 n=1∑∞​n2+1(−1)n−1n​ 的敛散性

解题思路：

第1步：交错级数，先验证 Leibniz 条件。bn​=n2+1n​→0。

第2步：单调性：bn+1​<bn​⟺(n+1)2+1n+1​<n2+1n​⟺(n+1)(n2+1)<n(n2+2n+2)⟺n2+n−1>0，对 n≥1 成立。故 {bn​}↘0，由 Leibniz 判别法收敛。

第3步：判绝对收敛：n2+1n​∼n1​，与调和级数同阶（极限比较，L=1），故 ∑n2+1n​ 发散。

第4步：结论：条件收敛。∎

点评：”(−1)n× 有理式”的标准流程：Leibniz 证收敛 + 与 np1​ 比阶判绝对性。p>1 绝对收敛，0<p≤1 条件收敛。

例题 7：求幂级数 n=1∑∞​n(n+1)xn​ 的和函数，并求 n=1∑∞​2nn(n+1)1​

解题思路：

第1步：定收敛域。an​an+1​​=n+2n​→1，故 R=1；端点 x=±1 处通项 ∼n21​ 收敛，故收敛域为 [−1,1]。

第2步：裂项（恒等变形）：n(n+1)xn​=nxn​−n+1xn​。

第3步：两块分别求和：

n=1∑∞​nxn​=−ln(1−x),n=1∑∞​n+1xn​=x1​n=1∑∞​n+1xn+1​=x−ln(1−x)−x​

第4步：相减：

S(x)=−ln(1−x)−x−ln(1−x)−x​=1+x1−x​ln(1−x)(0<∣x∣<1)

（x=0 时 S(0)=0，由连续性定义。）

第5步：代入 x=21​：

n=1∑∞​2nn(n+1)1​=S(21​)=1+ln21​=1−ln2

点评：系数含 n(n+1)1​ 时，裂项 + 已知级数 ∑nxn​=−ln(1−x) 是最快路线；和函数求完顺手”代入求数项级数和”是标准命题方式。

例题 8：用 Fourier 级数求和——证明 n=1∑∞​n21​=6π2​ 与 n=1∑∞​n41​=90π4​

解题思路：

第1步（代入法求 ∑n21​）：x2 在 [−π,π] 的 Fourier 展开为：

x2=3π2​+4n=1∑∞​n2(−1)n​cosnx

第2步：代入 x=π（此时 cosnπ=(−1)n，两项抵消符号）：

π2=3π2​+4n=1∑∞​n21​⇒n=1∑∞​n21​=6π2​

第3步（Parseval 求 ∑n41​）：对同一个展开用 Parseval 等式：

π1​∫−ππ​x4dx=2a02​​+n=1∑∞​an2​

第4步：左边 =52π4​；a0​=32π2​，an​=n24(−1)n​，故：

52π4​=92π4​+16n=1∑∞​n41​⇒n=1∑∞​n41​=90π4​

点评：同理可由 x 的展开代入 x=2π​ 得 Leibniz 级数 ∑2n−1(−1)n−1​=4π​，由 ∥x∥ 的展开代入 x=0 得 ∑n odd​n21​=8π2​。一个展开吃三顿：代入、端点、Parseval。

  • ∑n=1∞​n41​=90π4​
