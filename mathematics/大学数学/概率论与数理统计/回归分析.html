回归分析

核心问题：如何用一组自变量 X 去”解释”和”预测”因变量 Y？模型好不好怎么判断？

简单线性回归

模型设定

Yi​=β0​+β1​Xi​+εi​,εi​∼iidN(0,σ2)

人话：Y = 截距 + 斜率 × X + 随机噪声。噪声的正态性是推断的基础。

最小二乘估计（OLS）

β^​1​=∑i=1n​(Xi​−Xˉ)2∑i=1n​(Xi​−Xˉ)(Yi​−Yˉ)​=VarX​CovXY​​​

β^​0​=Yˉ−β^​1​Xˉ

人话讲解：β^​1​ = X 和 Y 的样本协方差除以 X 的样本方差。直观——“Y 随 X 变化了多少”除以”X 变化了多少”。

矩阵形式（为多元推广做准备）：Y=Xβ+ε

β^​=(XTX)−1XTY

Gauss-Markov 定理（⭐ 理论保证）

在模型 E[ε]=0，Cov(ε)=σ2I 的假设下（不需要正态性！）：

OLS 估计量是 BLUE（Best Linear Unbiased Estimator）——在所有线性无偏估计中方差最小。

人话：只要你想要无偏的线性估计，OLS 就是最优的！高斯当年为此跟 Legendre 争 priority。

证明梗概：设 β~​=CY 是任一线性无偏估计。由无偏性得 CX=I。然后 Cov(β~​)−Cov(β^​)=σ2(CCT−(XTX)−1) 是半正定的。

模型评估

1. 决定系数 R2

R2=SSTSSR​=1−SSTSSE​=1−∑i​(Yi​−Yˉ)2∑i​(Yi​−Y^i​)2​​

符号全称含义
SSTTotal Sum of SquaresY 的总变异
SSRRegression Sum of Squares回归解释的变异
SSEResidual Sum of Squares残差的变异

R2∈[0,1]，越接近 1 拟合越好。但⚠️ 加变量 R2 必增加！

调整 R2：Radj2​=1−n−p−1n−1​(1−R2)，对变量数做惩罚。

2. 残差分析

残差 ei​=Yi​−Y^i​ 应满足：

  • E[ei​]=0（零均值）
  • 常数方差（homoscedasticity）
  • 独立性
  • 近似正态（用于推断）

诊断图：

  • Residuals vs Fitted → 检查异方差
  • Q-Q Plot → 检查正态性
  • Cook’s Distance → 检测影响点

多元线性回归

Y=β0​+β1​X1​+⋯+βp​Xp​+ε

OLS 解：β^​=(XTX)−1XTY

βj​ 的推断：β^​j​∼N(βj​,σ2(XTX)jj−1​)

t=SE(β^​j​)β^​j​​∼tn−p−1​在 H0​:βj​=0 下

共线性（Multicollinearity）

当预测变量之间高度相关时，(XTX) 接近奇异，方差膨胀。

VIF（方差膨胀因子）：VIFj​=1/(1−Rj2​)，其中 Rj2​ 是用其他 X 回归 Xj​ 的 R2。VIF > 10 意味着严重共线性。

Logistic 回归（分类入门）

模型

Y 是二元响应变量（0/1）。建模 P(Y=1∣X)：

logit(P(Y=1))=log1−PP​=β0​+β1​X1​+⋯+βp​Xp​​

即 P(Y=1∣X)=1+e−(β0​+βTX)1​

人话讲解：线性回归的输出是 (−∞,∞)，但概率必须在 [0,1]。用 sigmoid 函数（logistic 函数）把线性输出”压”到 [0,1]。换句话——logistic 回归 = 线性回归 + sigmoid 激活。

参数估计：用 MLE（无闭式解，需 Newton-Raphson 迭代）：

ℓ(β)=∑i=1n​[yi​logpi​+(1−yi​)log(1−pi​)]

系数解释：eβj​ = 对 Xj​ 增加一个单位，odds 的倍数（odds ratio）。

模型选择

1. AIC（Akaike Information Criterion）

AIC=−2logL(β^​)+2p=−2ℓmax​+2p​

其中 p = 参数个数。AIC 越小越好。

人话：AIC = 拟合优度 + 模型复杂度惩罚。第一项 −2ℓmax​ 衡量拟合好坏；第二项 2p 惩罚参数个数。

2. BIC（Bayesian Information Criterion）

BIC=−2logL(β^​)+plogn​

BIC 对复杂度的惩罚比 AIC 更重（当 n>7），倾向于选更简洁的模型。

AIC vs BIC 对比

AICBIC
目标最小化预测误差选出真实模型
大样本行为不保证选对模型一致（n→∞ 选对真模型）
哲学频率学派贝叶斯近似
选模型倾向更复杂更简单

其他方法

  • Cp​ (Mallows)：Cp​=σ^2SSEp​​−(n−2p)
  • 交叉验证（CV）：k-fold CV 是最稳健的选择方法
  • LASSO/Ridge：通过正则化自动做变量选择

例题精讲

例题：证明 OLS 的 β^​1​ 是 β1​ 的无偏估计

解题思路：

β^​1​=∑(Xi​−Xˉ)2∑(Xi​−Xˉ)(Yi​−Yˉ)​=SXX​∑(Xi​−Xˉ)Yi​​

代入 Yi​=β0​+β1​Xi​+εi​，利用 ∑(Xi​−Xˉ)=0 得：

β^​1​=β1​+SXX​∑(Xi​−Xˉ)εi​​

E[β^​1​]=β1​+SXX​∑(Xi​−Xˉ)E[εi​]​=β1​ ✓

例题 2：比较两个模型——Model 1: Y∼X1​ (AIC=123.4)，Model 2: Y∼X1​+X2​ (AIC=121.8)

解：AIC 差 1.6 < 2，Model 2 略优但不显著。若 BIC 差更大，选 BIC 更小的。

二级结论

  • OLS 是 BLUE（Gauss-Markov 定理，不需要正态性）
  • R2 总随变量数增加，调 Radj2​ 才有比较意义
  • 线性回归用 MSE 做损失；Logistic 回归用交叉熵（log-loss）
  • AIC 用于预测，BIC 用于选真模型；二者都基于信息论
  • 残差诊断不可跳过——模型好不好，看残差不看 R2
  • 共线性让系数方差爆炸，但预测可能仍 OK
