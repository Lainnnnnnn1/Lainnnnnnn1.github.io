多元统计分析

核心问题：当数据不止一维，变量之间有相关性，怎么降维、分类、可视化？

多元正态分布（⭐ 基础）

定义

X=(X1​,…,Xp​)T 服从 p 维多元正态 Np​(μ,Σ)，若其 PDF 为：

f(x)=(2π)p/2∣Σ∣1/21​exp(−21​(x−μ)TΣ−1(x−μ))​

其中 μ∈Rp 为均值向量，Σ∈Rp×p 为协方差矩阵（正定对称）。

人话讲解：多元正态 = 一元正态的推广。等密度线是椭球，椭球的形状和方向由 Σ 决定。马氏距离 (x−μ)TΣ−1(x−μ) 替代了标准化距离。

正态分布中不相关 = 独立，这是正态最重要的特性之一。

主成分分析（PCA, ⭐ 降维核心）

目标

找到一组正交方向 a1​,…,ap​，使投影方差最大：

max∥a∥=1​Var(aTX)=max∥a∥=1​aTΣa

人话：找到数据”散布最开”的方向——第一主成分就是数据方差最大的方向。

推导（Eigendecomposition）

第1步：约束优化 max∥a∥=1​aTΣa

第2步：Lagrange 乘子法：L=aTΣa−λ(aTa−1)

第3步：∂a∂L​=2Σa−2λa=0⟹Σa=λa

结论：a 是 Σ 的特征向量，λ 是对应的特征值！

最大特征值 λ1​ 对应第一主成分方向 a1​，依次类推。

PCA 步骤

  1. 中心化数据：X~i​=Xi​−Xˉ
  2. 计算协方差矩阵 S（或用相关矩阵 R 消量纲影响）
  3. 特征分解：S=AΛAT，λ1​≥λ2​≥⋯≥λp​
  4. 选前 k 个主成分：Z=X~Ak​

方差解释比例：∑i=1p​λi​λj​​；累积解释比例：∑i=1p​λi​∑i=1k​λi​​

选 k 的准则：累积方差 ≥ 80%（经验规则），或 scree plot 的”肘部”。

SVD 视角

PCA 等价于中心化数据矩阵 X~ 的 SVD：

X~=UDVT

主成分得分 Z=Uk​Dk​，载荷 A=V。

Fisher 线性判别（LDA）

目标

二分类问题：找到投影方向 w，使投影后类间距离最大、类内方差最小：

maxw​wTSW​wwTSB​w​

其中：

  • SB​=(μ1​−μ2​)(μ1​−μ2​)T（类间散度）
  • SW​=∑i=1,2​∑x∈Ci​​(x−μi​)(x−μi​)T（类内散度）

最优解：w∝SW−1​(μ1​−μ2​)

人话：Fisher 判别找到一条线，把两类投影上去后尽可能分得开。

多分类推广

c 类时：求 SW−1​SB​ 的前 c−1 个特征向量。投影到 c−1 维空间。

聚类分析

1. K-means

最小化类内平方和：

minC1​,…,CK​​∑k=1K​∑xi​∈Ck​​∥xi​−μk​∥2

算法（Lloyd）：

  1. 随机初始化 K 个中心 μ1​,…,μK​
  2. 分配：将每个点分配给最近的中心
  3. 更新：μk​=∣Ck​∣1​∑x∈Ck​​x
  4. 重复 2–3 直到收敛

⚠️ K-means 对初始值敏感，不保证全局最优。跑多次选最优；或用 K-means++ 初始化。

2. 层次聚类（Hierarchical Clustering）

类型方法说明
凝聚（Agglomerative）自底向上每个点自成类，逐步合并
分裂（Divisive）自顶向下所有点一类，逐步分裂

距离度量（linkage）：

Linkage定义特点
Singlemind(a,b)链状，对噪声敏感
Completemaxd(a,b)紧凑球状
Averagemean d(a,b)折中，常用
Ward最小化合并后方差增量倾向等大小类

Dendrogram（树状图）展示了层次聚类的合并过程，可截断得到任意 K。

多维标度（MDS）与 t-SNE

MDS 保持点间距离，t-SNE 保持局部邻域结构。两者都是可视化高维数据的常用方法。

t-SNE 核心思想：在高维用高斯核衡量相似度，在低维用 t 分布衡量相似度，最小化 KL 散度。

⚠️ t-SNE 的全局距离和类间距离不可靠——只用于可视化，不用做推断。

例题精讲

例题：给定 Σ=(21​12​)，求 PCA 的主成分方向和方差解释比例。

解题思路：

第1步：特征方程 det(Σ−λI)=(2−λ)2−1=λ2−4λ+3=0

第2步：λ1​=3，λ2​=1

第3步：对应特征向量 a1​=2​1​(1,1)T，a2​=2​1​(1,−1)T

第4步：PC1 解释 3/(3+1)=75% 方差，PC2 解释 25%。

例题 2：Fisher 判别 vs PCA 的区别

PCA 找方差最大的方向（无监督），不考虑类标签。Fisher 判别找类间可分性最好的方向（有监督）。若两类沿同一方向排布，PCA 和 LDA 方向相同；若方差方向与类间方向正交，两者截然不同。

二级结论

  • PCA 是特征分解协方差矩阵，等价于 SVD；载荷 = 特征向量，方差 = 特征值
  • 正态分布中不相关 ⇔ 独立（独有性质）
  • K-means 是 EM 算法的特例（硬分配高斯混合模型）
  • Ward 层次聚类与 K-means 有相似目标
  • 降维后解释：载荷矩阵 A 的每一列告诉你该成分是哪些原始变量的线性组合
  • t-SNE 仅用于可视化，不可用距离做推断
