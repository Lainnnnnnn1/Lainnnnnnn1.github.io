大数定律与中心极限定理

核心问题：当试验次数趋向无穷时，平均值会趋向什么？波动有多大？

收敛模式

随机变量序列 {Xn​} 收敛到 X 的四种方式：

1. 几乎必然收敛（a.s.）

P(n→∞lim​Xn​=X)=1

人话：除了概率为零的”倒霉”情况外，Xn​ 最终一定趋近于 X。

2. 依概率收敛（Xn​P​X）

∀ε>0,n→∞lim​P(∣Xn​−X∣>ε)=0

人话讲解：随着 n 增大，Xn​ 和 X 的差距超过 ε 的概率趋于 0。即”大概率接近”。

3. 依分布收敛（Xn​d​X）

n→∞lim​Fn​(x)=F(x)

在 F 的所有连续点处成立。

4. Lp 收敛（均方收敛）

n→∞lim​E[∣Xn​−X∣p]=0 a.s. 收敛⟹依概率收敛⟹依分布收敛 Lp 收敛⟹依概率收敛

其中"⟹"表示推出关系。a.s. 收敛是最强的，依分布收敛是最弱的。

大数定律（LLN）

设 X1​,X2​,… 独立同分布（i.i.d.），E[Xi​]=μ。

弱大数定律（WLLN，辛钦大数定律）

若 E[∣Xi​∣]<∞，则样本均值依概率收敛于期望：

Xˉn​=n1​i=1∑n​Xi​P​μ​

人话：样本量足够大时，样本均值”大概率”接近真实期望。赌场和保险公司的数学基础。

强大数定律（SLLN，柯尔莫哥洛夫）

若 E[∣Xi​∣]<∞，则样本均值几乎必然收敛于期望：

Xˉn​a.s.​μ​

人话：不只是概率上，而是”几乎每次”样本均值都会收敛到期望。

中心极限定理（CLT，⭐ 核心）

Lindeberg-Lévy CLT（经典 CLT）

设 X1​,X2​,… i.i.d.，E[Xi​]=μ，Var(Xi​)=σ2<∞。

则标准化部分和依分布收敛于标准正态：

n​σ∑i=1n​Xi​−nμ​d​N(0,1)​

等价地：

σ/n​Xˉn​−μ​d​N(0,1)​

人话讲解：不管原始分布是什么（二项、指数、均匀……），只要样本量足够大，样本均值的分布就近似正态！这就是为什么正态分布无处不在。

De Moivre-Laplace CLT（二项分布的正态近似）

若 X∼B(n,p)，当 n 充分大时：

np(1−p)​X−np​∼approxN(0,1)

实用近似：np≥5 且 n(1−p)≥5 时就可以用。

Chebyshev 不等式

对任意随机变量 X（E[X]=μ,Var(X)=σ2<∞）：

P(∣X−μ∣≥kσ)≤k21​​

或等价地：

P(∣X−μ∣≥ε)≤ε2σ2​

人话：偏离均值超过 k 倍标准差的概率，至多为 1/k2。这是 WLLN 证明中的关键工具。

Chebyshev 不等式的意义：

  • 不需要知道分布的具体形式
  • 给出了概率的上界（虽然通常比较保守）
  • k=2 时概率 ≤ 25%，k=3 时概率 ≤ 11.1%

例题精讲

例题：掷硬币 n 次，正面概率 p=0.5。求 n 至少多大，才能使正面频率与 0.5 的误差小于 0.01 的概率 ≥ 95%？

解题思路：

第1步：设 Xi​∼B(1,0.5)，μ=0.5，σ2=0.25。

第2步：由 CLT，Xˉn​≈N(0.5,0.25/n)。

第3步：P(∣Xˉn​−0.5∣<0.01)≥0.95

标准化：P(0.5/n​∣Xˉn​−0.5∣​<0.5/n​0.01​)≥0.95

第4步：0.5/n​0.01​≥z0.025​=1.96 → n​≥0.011.96⋅0.5​=98

第5步：n≥982=9604，即约需掷 9604 次硬币。

例题：用 Chebyshev 不等式估计 P(∣X−μ∣≥3σ)

解：P(∣X−μ∣≥3σ)≤321​=91​≈11.1%

（对比：正态分布下真实概率约 0.27%，Chebyshev 给出的是保守上界。）

二级结论

  • CLT 要求有限方差；若方差无限（如 Cauchy 分布），CLT 不成立
  • n≥30 经常作为 CLT 近似的经验法则（但看偏度！）
  • 大数定律不保证 “赌徒一定会赢回来”（Gambler’s Fallacy）
  • Chebyshev 不等式的界与分布无关，因此通常比较松
