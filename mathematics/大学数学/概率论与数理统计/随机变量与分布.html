随机变量与分布

核心问题：怎么用数学语言描述”随机性”？不同类型随机现象用什么模型？

随机变量的定义

1. 随机变量

随机变量 X 是从样本空间 Ω 到实数集 R 的可测函数：

X:Ω→R

人话讲解：随机变量 = 给每个可能结果赋予一个数值标签。比如掷骰子：Ω={⚀,⚁,⚂,⚃,⚄,⚅}，X( ⚀ )=1，X( ⚁ )=2，等等。把”模糊的随机事件”变成”具体的数字”。

2. 离散 vs 连续

类型取值描述工具例子
离散型可数个值分布律（PMF）掷骰子的点数
连续型区间上的值概率密度函数（PDF）寿命、身高

离散型分布

1. 分布律（PMF）

P(X=xk​)=pk​,k∑​pk​=1

2. 累积分布函数（CDF）

F(x)=P(X≤x)=xk​≤x∑​pk​

性质：非降、右连续、F(−∞)=0，F(+∞)=1

① 二项分布 X∼B(n,p)

n 次独立伯努利试验的成功次数：

P(X=k)=(kn​)pk(1−p)n−k,k=0,1,…,n

人话：抛 n 次硬币，每次正面概率 p，恰好 k 次正面的概率。

  • E[X]=np，Var(X)=np(1−p)

② Poisson 分布 X∼P(λ)

单位时间内随机事件发生次数：

P(X=k)=k!λke−λ​,k=0,1,2,…

人话：描述”小概率事件在大量试验中发生的次数”——车祸次数、电话呼叫次数、放射性衰变。

  • E[X]=λ，Var(X)=λ
  • 当 n 大 p 小且 np≈λ 时，B(n,p)≈P(np)

③ 几何分布 X∼Geom(p)

首次成功所需的试验次数：

P(X=k)=(1−p)k−1p,k=1,2,…
  • E[X]=p1​，Var(X)=p21−p​

④ 负二项分布（Pascal 分布）X∼NB(r,p)

第 r 次成功所需的试验次数：

P(X=k)=(r−1k−1​)pr(1−p)k−r,k=r,r+1,…
  • E[X]=pr​，Var(X)=p2r(1−p)​

⑤ 超几何分布 X∼H(N,M,n)

从 N 件（M 件次品）中不放回抽 n 件，次品数：

P(X=k)=(nN​)(kM​)(n−kN−M​)​

N 远大于 n 时 → 近似二项分布 B(n,M/N)。

连续型分布

1. 概率密度函数（PDF）

对连续型 X：

P(a≤X≤b)=∫ab​f(x)dx
  • f(x)≥0，∫−∞∞​f(x)dx=1
  • 单点概率恒为 0：P(X=a)=0

2. CDF

F(x)=P(X≤x)=∫−∞x​f(t)dt

f(x)=F′(x)（在 f 的连续点处）。

① 均匀分布 X∼U(a,b)

f(x)={b−a1​,0,​a≤x≤b其他​
  • E[X]=2a+b​，Var(X)=12(b−a)2​

② 指数分布 X∼Exp(λ)

f(x)=λe−λx,x≥0

人话：描述”等待下一个事件的时间”——与 Poisson 分布是”孪生兄弟”（Poisson 描述次数，指数描述间隔）。

  • E[X]=λ1​，Var(X)=λ21​
  • 无记忆性：P(X>s+t∣X>s)=P(X>t)

③ 正态分布 X∼N(μ,σ2)

f(x)=2π​σ1​e−2σ2(x−μ)2​,−∞<x<∞

人话：最重要的分布！中心极限定理保证了大量独立因素叠加的结果近似正态。自然界和社会科学中无处不在。

  • E[X]=μ，Var(X)=σ2
  • 标准化：Z=σX−μ​∼N(0,1)

标准正态 N(0,1) 的 3σ 法则

区间概率记忆
[−1σ,1σ]≈68.3%约 32​
[−2σ,2σ]≈95.4%约 95%
[−3σ,3σ]≈99.7%几乎肯定

④ Gamma 分布 X∼Γ(α,β)

f(x)=Γ(α)βα​xα−1e−βx,x≥0
  • E[X]=βα​，Var(X)=β2α​
  • 特殊情形：Γ(1,β)=Exp(β)，Γ(n/2,1/2)=χ2(n)

随机变量的函数（单变量）

若 Y=g(X)，求 Y 的分布：

离散型：P(Y=y)=∑x:g(x)=y​P(X=x)

连续型（g 严格单调可微）：

fY​(y)=fX​(g−1(y))⋅​dyd​g−1(y)​

一般方法（CDF 法）：先求 FY​(y)=P(g(X)≤y)，再求导得 fY​(y)。

人话：把 X 的密度按函数 g “拉扯”一下，乘上 g 的导数的绝对值校正”拉伸程度”。

多维随机变量（⭐ 进阶）

1. 联合分布

联合 CDF：FX,Y​(x,y)=P(X≤x,Y≤y)

离散型联合 PMF：pij​=P(X=xi​,Y=yj​)

连续型联合 PDF：

P((X,Y)∈A)=∬A​fX,Y​(x,y)dxdy

2. 边缘分布

从联合到个体：

  • 离散：P(X=xi​)=∑j​P(X=xi​,Y=yj​)
  • 连续：fX​(x)=∫−∞∞​fX,Y​(x,y)dy

人话：边缘分布就是把”多余的维度”积分掉（或求和掉），只看其中一个变量。

3. 条件分布

条件 PDF（连续型）：

fY∣X​(y∣x)=fX​(x)fX,Y​(x,y)​

条件期望：E[Y∣X=x]=∫y⋅fY∣X​(y∣x)dy

全期望公式：E[Y]=E[E[Y∣X]]

独立性

X 与 Y 独立 ⟺ FX,Y​(x,y)=FX​(x)FY​(y) ⟺ fX,Y​(x,y)=fX​(x)fY​(y)

独立 ⟹ 不相关（E[XY]=E[X]E[Y]），但反过来不成立！

独立随机变量和的分布 — 卷积

1. 离散型卷积

若 X,Y 独立，Z=X+Y：

P(Z=k)=i∑​P(X=i)⋅P(Y=k−i)

2. 连续型卷积

fZ​(z)=∫−∞∞​fX​(x)fY​(z−x)dx=(fX​∗fY​)(z)

人话：卷积 = 翻转一个分布、平移、相乘、积分——所有可能凑成 z 的方式的概率密度之和。

重要分布的卷积结果

XYX+Y
B(n1​,p)B(n2​,p)B(n1​+n2​,p)
P(λ1​)P(λ2​)P(λ1​+λ2​)
N(μ1​,σ12​)N(μ2​,σ22​)N(μ1​+μ2​,σ12​+σ22​)
Γ(α1​,β)Γ(α2​,β)Γ(α1​+α2​,β)

🎯 核心结论：正态分布对加法封闭（可加性），这是中心极限定理成立的根本原因。

多维随机变量函数的分布

1. 一般变换公式

若 (X,Y)→(U,V)=(g1​(X,Y),g2​(X,Y)) 是一一变换，则：

fU,V​(u,v)=fX,Y​(x(u,v),y(u,v))⋅​∂(u,v)∂(x,y)​​

其中 ∂(u,v)∂(x,y)​ 是 Jacobi 行列式。

2. 常见变换

变换Jacobi应用
U=X+Y,V=X−Y1/2和与差
U=X/Y,V=Yv比值分布
U=XY,V=Y1/v乘积分布

3. 次序统计量

X(1)​≤X(2)​≤⋯≤X(n)​（Xi​ iid，PDF 为 f，CDF 为 F）：

  • 第 k 次序统计量：fX(k)​​(x)=(k−1)!(n−k)!n!​[F(x)]k−1[1−F(x)]n−kf(x)
  • 最小值：fX(1)​​(x)=n[1−F(x)]n−1f(x)
  • 最大值：fX(n)​​(x)=n[F(x)]n−1f(x)

例题精讲

例题 1：已知 X∼N(0,1)，求 Y=X2 的分布

解题思路：

第1步：y=x2 在 x≥0 和 x<0 两段分别考虑。

第2步：对 y>0：

FY​(y)=P(X2≤y)=P(−y​≤X≤y​)=Φ(y​)−Φ(−y​)

第3步：求导得密度：

fY​(y)=FY′​(y)=2y​1​[fX​(y​)+fX​(−y​)]=2πy​1​e−y/2

结论：Y∼χ2(1)（自由度为 1 的卡方分布）。

例题 2：求 X+Y 的分布，X∼Exp(λ)，Y∼Exp(λ)，独立

解题思路：

第1步：fX​(x)=λe−λx（x≥0），fY​(y)=λe−λy（y≥0）。

第2步：卷积：

fZ​(z)=∫0z​λe−λx⋅λe−λ(z−x)dx=λ2e−λz∫0z​dx=λ2ze−λz

结论：Z∼Γ(2,λ)。

例题 3：(X,Y) 联合密度 f(x,y)=2，0<x<y<1，求边缘密度 fX​(x)

解题思路：

第1步：fX​(x)=∫y=x1​2dy=2(1−x)，0<x<1。

第2步：验证 ∫01​2(1−x)dx=1 ✓

二级结论

  • Poisson 分布：E[X]=Var(X)=λ（等均值等方差）
  • 指数分布是无记忆的（唯一连续分布）
  • B(n,p)→P(np) 当 n 大 p 小
  • 正态分布的可加性：独立正态之和仍是正态
  • 卷积：独立随机变量和的分布 = 各自分布的卷积
  • 联合 → 边缘 = 积分；联合 → 条件 = 除法（联合/边缘）
  • 独立 ⟹ 不相关，不相关 ⇏ 独立（除正态分布外）
