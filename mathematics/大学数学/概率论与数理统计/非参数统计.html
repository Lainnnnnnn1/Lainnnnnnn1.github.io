非参数统计

核心问题：如果不知道数据服从什么分布（不假设正态！），怎么检验、怎么估计、怎么推断？

为什么需要非参数方法

参数方法非参数方法
假设具体的分布族（正态等）不做分布假设（或极少假设）
假设错误 → 结论不可靠稳健，适用于更广泛的数据
效率高（当假设成立）效率略低（当参数假设成立时）
例如：t 检验、ANOVA例如：Wilcoxon、K-S、Bootstrap

人话：参数方法像”穿定制西装”——身材对了效果好；非参数方法像”穿均码”——不挑身材但可能没那么贴身。

次序统计量（Order Statistics, ⭐ 深入）

定义与分布

对 i.i.d. 样本 X1​,…,Xn​∼f，CDF 为 F，次序统计量为 X(1)​≤X(2)​≤⋯≤X(n)​。

第 k 次序统计量的 PDF：

fX(k)​​(x)=(k−1)!(n−k)!n!​[F(x)]k−1[1−F(x)]n−kf(x)​

人话讲解：要 X(k)​≈x，需要：(1) k−1 个观测 <x，(2) n−k 个 >x，(3) 正好一个 ≈x。多项式系数 (k−1)!1!(n−k)!n!​ 就是排列数。

极值分布

PDF应用
X(1)​n[1−F(x)]n−1f(x)最小值
X(n)​n[F(x)]n−1f(x)最大值

联合分布

(X(i)​,X(j)​)（i<j）的联合 PDF：

fX(i)​,X(j)​​(x,y)=(i−1)!(j−i−1)!(n−j)!n!​[F(x)]i−1[F(y)−F(x)]j−i−1[1−F(y)]n−jf(x)f(y)

这个公式是秩检验（如 Wilcoxon）分布推导的基础。

经验分布函数（EDF, ECDF）

F^n​(x)=n1​∑i=1n​1{Xi​≤x}​

Glivenko-Cantelli 定理：supx​∣F^n​(x)−F(x)∣a.s.​0

Dvoretzky-Kiefer-Wolfowitz 不等式：

P(supx​∣F^n​(x)−F(x)∣>ε)≤2e−2nε2

人话：EDF 以概率 1 一致收敛到真实 CDF。收敛速度是指数级的！

Kolmogorov-Smirnov 检验（KS Test）

单样本 KS 检验

H0​:F=F0​（数据来自指定分布），检验统计量：

Dn​=supx​∣F^n​(x)−F0​(x)∣

人话：ECDF 和假设的 CDF 之间最大的垂直差距。差距太大就拒绝 H0​。

性质：

  • Dn​ 的分布与 F0​ 无关（只要 F0​ 连续）
  • Kolmogorov 分布：n​Dn​d​K，其中 P(K≤x)=1−2∑j=1∞​(−1)j−1e−2j2x2

双样本 KS 检验

H0​:F1​=F2​（两个样本来自同一分布）：

Dn,m​=supx​∣F^1,n​(x)−F^2,m​(x)∣

KS 检验能检测任何分布差异（位置、尺度、形状），但功效不如 Wilcoxon 对位置偏移的检验。

Wilcoxon 秩检验

1. Wilcoxon 符号秩检验（单样本 / 配对）

H0​：分布关于 0 对称。

步骤：

  1. 计算 ∣Xi​∣ 并排序得秩 Ri​
  2. W+=∑Xi​>0​Ri​（正秩和）

H0​ 下 E[W+]=n(n+1)/4，Var(W+)=n(n+1)(2n+1)/24。大样本用正态近似。

人话：t 检验的非参数替代。不需要正态性，只需要对称性。

2. Wilcoxon 秩和检验（两独立样本，Mann-Whitney U）

H0​:FX​=FY​（两样本同分布）

将所有 n+m 个观测混合排序得秩，令 WX​= 样本 X 的秩和。

Mann-Whitney 形式：

U=∑i=1n​∑j=1m​1{Xi​>Yj​}​

U 的含义：随机取一个 X 和一个 Y，X>Y 的次数。

H0​ 下 E[U]=nm/2。U 过大或过小都拒绝 H0​。

与 t 检验的对比

t 检验Wilcoxon
假设正态对称（符号秩）/ 同分布（秩和）
检验对象均值差中位数差 / 随机优势
ARE（效率）10.955（正态下，即只需多 5% 样本）
重尾分布差远优于 t

ARE = Asymptotic Relative Efficiency。正态下 Wilcoxon 效率是 t 的 95.5%，重尾下远超 t。

Bootstrap（自助法, ⭐ 现代统计利器）

核心思想

从样本 {X1​,…,Xn​} 中有放回地重复抽样 B 次（通常 B≥1000），每次得到一个 bootstrap 样本 {X1∗​,…,Xn∗​}。用 bootstrap 样本计算感兴趣的量，构造其抽样分布。

θ^b∗​=θ^(X1,b∗​,…,Xn,b∗​),b=1,…,B

人话讲解：不知道真实分布？用样本经验分布来模拟！从数据中”拔着鞋带把自己提起来”（pull oneself up by one’s bootstraps）。

Bootstrap 置信区间

百分位法（Percentile）：[θ^(α/2)∗​,θ^(1−α/2)∗​]

BCa 方法（Bias-Corrected and Accelerated）：对偏差和偏度做校正，更准确。

Bootstrap-t：用 bootstrap 估计 t=(θ^−θ)/SE(θ^) 的分布。

Bootstrap 适用场景

适用不适用
标准误估计样本量极小（n<10）
置信区间（无解析解时）极值统计量（max, min）
偏差校正重尾或依赖严重时需特殊 bootstrap
假设检验非光滑统计量（需 subsampling）

核密度估计（KDE）

从直方图到 KDE

直方图的分箱边界人为且不连续。KDE 用平滑的核函数替代分箱：

f^​h​(x)=nh1​i=1∑n​K(hx−Xi​​)​

其中 K 是核函数（通常对称且积分为 1），h 是带宽。

常用核函数

核K(u)支撑
Gaussian2π​1​e−u2/2R
Epanechnikov43​(1−u2)[−1,1]
Uniform21​[−1,1]

Epanechnikov 核在 MSE 意义下最优，但 Gaussian 核最常用（数学性质好）。

带宽选择（最关键！）

h 太小 → 过拟合（undersmoothed），太多噪声峰；h 太大 → 过平滑（oversmoothed），丢失结构。

Silverman 规则（Gaussian 核）：

hopt​=(3n4σ^5​)1/5≈1.06σ^n−1/5

用 IQR 鲁棒化：σ^=min(s,IQR/1.34)

交叉验证选择带宽：最小化积分平方误差 ∫(f^​h​−f)2，等价于最大化：

CV(h)=n2​∑i=1n​f^​h,−i​(Xi​)−∫f^​h​(x)2dx

KDE 的渐近性质

  • 偏差：Bias(f^​h​(x))≈2h2​f′′(x)∫u2K(u)du
  • 方差：Var(f^​h​(x))≈nhf(x)​∫K(u)2du
  • 最优 h：∝n−1/5，收敛速率 MISE∝n−4/5

KDE 收敛速率 n−4/5 慢于参数估计的 n−1——这是非参数方法的”代价”。

例题精讲

例题 1：证明 X(k)​ 的分布

解题思路：

FX(k)​​(x)=P(X(k)​≤x)=P(至少 k 个 Xi​≤x)=∑j=kn​(jn​)[F(x)]j[1−F(x)]n−j

对 x 求导即得 PDF（telescoping 求和）。或者用”多项式思路”：n 个 i.i.d. 分成三组——k−1 个 < x，1 个 ≈ x，n−k 个 > x，乘以排列数。

例题 2：比较 KS 检验和 Wilcoxon 的功效

对位置偏移的检测，Wilcoxon 检验的功效通常高于 KS。但 KS 更普适——能检测任何形式的分布差异（尺度、形状、多峰等）。

二级结论

  • 次序统计量的分布由排列组合直接导出（多项式系数）
  • ECDF 以 n​ 速率一致收敛到真实 CDF（Glivenko-Cantelli + DKW）
  • 正态假设下 Wilcoxon 只比 t 检验效率低约 5%，重尾下远优于 t 检验
  • Bootstrap 用经验分布替代未知真实分布——万能但依赖大样本
  • KDE 的带宽 h 比核函数重要得多；最优 h∝n−1/5
  • 非参数方法的核心 trade-off：更少假设 ⇔ 更慢的收敛速率
