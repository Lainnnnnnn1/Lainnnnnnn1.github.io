积分变换

核心问题：把微分方程变成代数方程，把卷积变成乘积——用一个积分核让难题脱胎换骨。

积分变换的共通思想

一般形式

积分变换将函数 f(t) 映射为另一个函数 F(s)： F(s)=T{f(t)}(s)=∫D​f(t)K(s,t)dt

  • K(s,t) 是积分核（变换的「DNA」）
  • 不同的核定义了不同的变换
  • 逆变换将 F(s) 变回 f(t)

人话讲解：把信号从「时域」换到「频域」或「复频域」去看——有些在时域很复杂的操作（如卷积、微分），在变换域就变成了简单的乘法和加减。

Laplace 与 Fourier 的关系

Laplace 变换可视为 Fourier 变换的「加权版」。令 s=σ+iω：

F(s)=∫0∞​f(t)e−(σ+iω)tdt=F{f(t)e−σtu(t)}(ω)

即：Laplace = Fourier ∘ 指数衰减窗 ∘ 单位阶跃。

人话：Fourier 看纯频率（虚轴），Laplace 看「衰减 + 频率」（右半平面）。衰减因子 e−σt 让很多 Fourier 变换不存在的函数（如 et）有了 Laplace 变换。

用变换求解 ODE/PDE

求解 ODE：标准流程

第1步：对 ODE 两边取 Laplace 变换，将初始条件融入 第2步：得到关于 Y(s) 的代数方程，求解 第3步：对 Y(s) 作逆 Laplace 变换（部分分式 + 查表）

例：y′′+4y=0，y(0)=1,y′(0)=0

取 Laplace：[s2Y−s⋅1−0]+4Y=0 → Y(s)=s2+4s​

逆变换：y(t)=cos(2t) ✓

求解 PDE：热方程

ut​=αuxx​，u(x,0)=f(x)，−∞<x<∞

对 x 取 Fourier 变换：∂t∂u^​=−αω2u^ → u^(ω,t)=f^​(ω)e−αω2t

逆变换（Gauss 核的 Fourier 逆变换）： u(x,t)=4παt​1​∫−∞∞​f(ξ)exp(−4αt(x−ξ)2​)dξ

这正是热核卷积。

卷积定理的核心价值

积分方程 y(t)=f(t)+∫0t​k(t−τ)y(τ)dτ（Volterra 型）

取 Laplace：Y(s)=F(s)+K(s)Y(s) → Y(s)=1−K(s)F(s)​

只需一次代数运算，逆变换即可。

二级结论

  • Laplace 变换的核心：微分 → 乘 s，卷积 → 乘积
  • Fourier 变换是 Laplace 在虚轴上的限制：s=iω
  • 部分分式展开是用 Laplace 解 ODE 的主力工具
  • Mellin 变换处理乘性结构（尺度、幂次），Laplace/Fourier 处理加性结构（平移、卷积）
  • 初值定理和终值定理允许不经逆变换就直接获知渐近行为
  • Bromwich 积分 + Jordan 引理 = 复分析技巧逆 Laplace
