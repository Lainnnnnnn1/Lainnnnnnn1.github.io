二次型与合同

核心问题：一个多元二次多项式 ax2+2bxy+cy2 能通过换元变成”纯平方和”吗？能变成什么样、有多少种变法是”本质不同”的？

二次型的矩阵表示

1. 基本定义

n 元二次型是 n 个变量的二次齐次多项式：

f(x1​,…,xn​)=i=1∑n​aii​xi2​+21≤i<j≤n∑​aij​xi​xj​

令 A=(aij​) 为对称矩阵（aij​=aji​），则

f(x)=xTAx,x=(x1​,…,xn​)T​

交叉项系数 2aij​ 的”2”来自 xi​xj​ 与 xj​xi​ 两项合并——写矩阵时交叉项系数要除以 2 再填进 A。

2. 标准形与规范形

  • 标准形：只含平方项 d1​y12​+⋯+dn​yn2​（无交叉项）
  • 规范形：标准形中再把系数归一为 +1,−1,0，即 y12​+⋯+yp2​−yp+12​−⋯−yp+q2​
  • 正惯性指数 p = 正平方项个数；负惯性指数 q = 负平方项个数；符号差 s=p−q

合同变换

1. 定义

设 A,B 为 n 阶实对称矩阵。若存在可逆矩阵 C 使

B=CTAC​

则称 A 与 B 合同，记 A≃B。可逆线性替换 x=Cy 把二次型 xTAx 变为 yTBy。

2. 合同 vs 相似 vs 等价（必考辨析）

关系定义保持的量联系
等价B=PAQ（P,Q 可逆）秩最弱
相似B=P−1AP特征值、迹、行列式、秩特征多项式
合同B=CTAC惯性指数、秩、对称性实对称矩阵的相似 ⟺ 合同

🎯 对实对称矩阵：正交相似（QTAQ，Q 正交）就是合同的特例（Q−1=QT）。特征值相同 ⟺ 正交相似 ⟺ 合同（对实对称阵）。

化标准形的方法

1. 配方法（Lagrange 配方法）

操作步骤：

  1. 若 a11​=0：把所有含 x1​ 的项配成 (x1​+⋯)2 的完全平方，余下部分不含 x1​
  2. 对余下部分继续配 x2​，依此类推
  3. 若某步平方项系数全为 0（如只有 x1​x2​ 项）：先做替换 x1​=y1​+y2​, x2​=y1​−y2​ 制造平方项

配方法同时给出可逆线性替换矩阵 C（把每一步替换矩阵乘起来）。

2. 初等变换法（合同对角化）

对 A 做成对的初等行、列变换（行变换和对应的列变换同时做），把 A 化为对角矩阵 Λ，同时 I 经同样的列变换化为 C：

(AI​)成对初等变换​(ΛC​),CTAC=Λ

3. 正交变换法

实对称矩阵 A 可正交对角化：QTAQ=diag(λ1​,…,λn​)。特征值 λi​ 即为标准形系数，Q 的列是标准正交特征向量。

三种方法比较：正交变换保长度（几何意义好，二次曲线/曲面分类用）；配方法计算量小（判定惯性指数首选）；初等变换法机械不易错。

惯性定理与正定

1. 惯性定理（Sylvester 惯性定律）

实二次型经任何可逆线性替换，正惯性指数 p、负惯性指数 q 不变（即规范形唯一）。

规范形唯一：y12​+⋯+yp2​−yp+12​−⋯−yp+q2​​

推论：两个实对称矩阵合同 ⟺ 它们的惯性指数相同 ⟺ p 与 q 分别相等。这是合同关系的完全分类。

2. 正定二次型的判定

f(x)=xTAx 正定 ⟺ 对一切 x=0，f(x)>0。等价条件：

判定法条件
顺序主子式（Sylvester 准则）A 的全部顺序主子式 >0：Δ1​>0,Δ2​>0,…,Δn​>0
特征值A 的全部特征值 >0
惯性指数正惯性指数 p=n（规范形为单位阵）
合同标准A 合同于单位阵 I：存在可逆 C，A=CTC
CholeskyA=LLT，L 为下三角可逆阵

半正定：Δk​≥0 且 p=n−dimkerA（注意：仅所有顺序主子式 ≥0 不充分）；负定：A 正定 ⟺−A 正定。

应用：二次曲线与二次曲面的分类

1. 二次曲线 ax2+2bxy+cy2+dx+ey+f=0

用正交变换消去交叉项（旋转坐标轴），按 λ1​λ2​ 符号分类：

特征值符号曲线类型规范方程示例
λ1​λ2​>0（同号）椭圆型a2x′2​+b2y′2​=1
λ1​λ2​<0（异号）双曲型a2x′2​−b2y′2​=1
λ1​λ2​=0（含零）抛物型y′2=2px′

2. 二次曲面 f(x,y,z)=0 按惯性指数 (p,q) 分类

(3,0) 椭球面、(2,1) 单叶双曲面/双曲抛物面（马鞍面）、(1,2) 双叶双曲面、(0,3) 虚椭球、含 0 的为各类柱面/锥面。

判别二次型符号差是仿射不变量——这正是惯性定理的几何意义。

常考题型与例题

例题 1：写出二次型的矩阵

写出 f(x1​,x2​,x3​)=x12​+2x1​x2​−4x1​x3​+3x22​−6x2​x3​+x32​ 的矩阵。

解题思路：

第1步：对角线放平方项系数：a11​=1,a22​=3,a33​=1。

第2步：交叉项系数除以 2：a12​=1, a13​=−2, a23​=−3。

第3步：A=​11−2​13−3​−2−31​​（对称）。

验证：xTAx 展开核对交叉项系数：2×1=2，2×(−2)=−4，2×(−3)=−6 ✓

例题 2：配方法化标准形并求惯性指数

化 f=x12​+2x1​x2​+2x22​+4x2​x3​+5x32​ 为标准形，求 p,q。

解题思路：

第1步：配 x1​：f=(x1​+x2​)2+x22​+4x2​x3​+5x32​。

第2步：配 x2​：=(x1​+x2​)2+(x2​+2x3​)2+x32​。

第3步：令 ⎩⎨⎧​y1​=x1​+x2​y2​=x2​+2x3​y3​=x3​​（可逆），标准形 f=y12​+y22​+y32​。

结论：p=3,q=0，符号差 s=3，二次型正定。

验证：对应矩阵 ​110​122​025​​ 的顺序主子式 1,1,1>0，Sylvester 准则一致 ✓

例题 3：参数正定问题

求 λ 的范围，使 f=x12​+2x22​+3x32​+2λx1​x2​+2x1​x3​ 正定。

解题思路：

第1步：矩阵 A=​1λ1​λ20​103​​。

第2步：Sylvester 准则：Δ1​=1>0；Δ2​=2−λ2>0；Δ3​=detA。

第3步：detA=1⋅(6−0)−λ(3λ−0)+1(0−2)=6−3λ2−2=4−3λ2。

第4步：联立 ∣λ∣<2​ 且 ∣λ∣<3​2​：得 ∣λ∣<3​2​​。

验证：λ=1 时 Δ3​=1>0 正定；λ=1.2 时 Δ3​<0 不正定 ✓

例题 4：二次曲线分类

判断曲线 5x2+4xy+2y2−24x−12y+20=0 的类型。

解题思路：

第1步：二次项矩阵 A=(52​22​)，特征值满足 λ2−7λ+6=0，得 λ1​=6,λ2​=1。

第2步：两特征值同号为正 → 椭圆型曲线。

第3步：配平移后可化为 a2x′2​+b2y′2​=1（具体计算略，几何类型已定）。

验证：Δ=λ1​λ2​=6>0，且 I1​=7>0，属于椭圆型 ✓

例题 5：合同关系的判断

判断 A=(10​01​) 与 B=(10​0−1​) 是否合同、是否相似。

解题思路：

第1步：惯性指数：A 为 (p,q)=(2,0)；B 为 (1,1)。

第2步：惯性指数不同 → 不合同。

第3步：特征值不同（1,1 vs 1,−1）→ 不相似。

验证：若合同则规范形相同，矛盾；若相似则迹相同（2 vs 0），矛盾 ✓

二级结论（背下来直接用）

  • 实对称矩阵：相似 ⟺ 合同 ⟺ 特征值相同；一般矩阵只保各自不变量
  • 配方法步骤固定：先 x1​ 后 x2​……缺平方项先做 xi​=yi​+yj​ 型替换
  • 惯性指数 = 特征值中正/负的个数（对实对称矩阵），可用特征值快速求 p,q
  • Sylvester 正定准则只用顺序主子式（从左上角开始），不是任意主子式
  • 半正定判定陷阱：全部顺序主子式 ≥0 不够，还需 rankA 信息
  • 二次曲线分类看 λ1​λ2​ 符号；二次曲面分类看惯性指数 (p,q)
  • A 正定 ⇒ A−1、Ak、主子矩阵均正定；detA>0 是正定的必要不充分条件
  • 实对称矩阵 A 正定 ⟺ 存在可逆 C 使 A=CTC
