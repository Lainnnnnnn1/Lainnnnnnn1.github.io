信号处理中的数学

任何信号——声音、图像、雷达波——都可以用数学来分析和改造。三大变换（Fourier, Laplace, Z）是信号处理的「三件套」：Fourier 看频谱，Laplace 管稳定性，Z 理离散系统。

傅里叶变换（连续时间）

正变换与逆变换

X(f)=∫−∞∞​x(t)e−i2πftdt​

x(t)=∫−∞∞​X(f)ei2πftdf

人话： X(f) 告诉你信号里频率为 f 的成分有多强。就像把白光大卸八块看里面每种颜色的比例。

Parseval 定理（能量守恒）

∫−∞∞​∥x(t)∥2dt=∫−∞∞​∥X(f)∥2df

人话： 信号的总能量在时域和频域是一样的——Fourier 变换只是换了个坐标系，不丢失也不创造能量。

采样定理（Nyquist-Shannon）

核心结论

若信号 x(t) 的带宽为 B（X(f)=0 对 ∥f∥>B），则以采样频率 fs​>2B 采样后可完美重建原信号。

fs​>2B（Nyquist 条件）​

重建公式

x(t)=∑n=−∞∞​x(nT)⋅sinc(Tt−nT​)

其中 T=1/fs​，sinc(t)=πtsin(πt)​。

混叠（Aliasing）

若 fs​≤2B，高频信号会被「折叠」到低频——这就是车轮看起来倒转的原因。

人话（混叠）： 少于每秒 2 个点去采样一个波，你就分不清它是高频还是低频。

混叠频率公式： 频率 f 的信号以 fs​ 采样后表现为 falias​=mink​∥f−kfs​∥。常用采样率：电话语音 8 kHz（带宽 4 kHz）、CD 音频 44.1 kHz（22.05 kHz）、SD 视频 13.5 MHz（6.75 MHz）——都是「略高于 2 倍带宽」。

离散傅里叶变换（DFT）

定义

N 点序列 x[0],…,x[N−1]：

X[k]=n=0∑N−1​x[n]e−i2πkn/N,k=0,…,N−1​

逆变换：

x[n]=N1​∑k=0N−1​X[k]ei2πkn/N

FFT（快速傅里叶变换）

直接算 DFT 是 O(N2)，FFT 降到 O(NlogN)——这是工程上 DFT 真正能用的原因。

算法复杂度发明者

FFT（Gauss 先发现）O(NlogN)Gauss (1805, 未发表)

FFT 的分治原理（蝶形运算）：

X[k]=Xeven​[k]+WNk​Xodd​[k],X[k+N/2]=Xeven​[k]−WNk​Xodd​[k]

其中 WN​=e−i2π/N，k=0,…,N/2−1；Xeven​,Xodd​ 分别是偶、奇下标子序列的 N/2 点 DFT。

人话： 把 N 点 DFT 拆成两个 N/2 点 DFT，每个输出只多一次复乘——递归下去就是 O(NlogN)。N=8 时只需 log2​8=3 层蝶形。

人话： 拉普拉斯 = 带阻尼的傅里叶。那个实部 σ 让「可能不收敛」的积分变得收敛。

Z 变换（离散系统）

定义

X(z)=Z{x[n]}=∑n=−∞∞​x[n]z−n

实际滤波器

理想滤波器因果不可实现。常用近似：

  • Butterworth：通带最平坦
  • Chebyshev：陡峭过渡带，通带波动
  • 椭圆滤波器：过渡带最窄，通带和阻带均有波动

一阶 RC 低通（最简单的因果滤波器）

H(jω)=1+jωRC1​,fc​=2πRC1​

f≪fc​≈1（通过）≈0°
f=fc​1/2​≈−3 dB−45°
f≫fc​每十倍频程 −20 dB→−90°

卷积定理（贯穿始终）

F{x∗y}=X⋅Y​

在三个域都成立：Fourier（乘积）、Laplace（乘积）、Z（乘积）。

人话： 时域的卷积 = 频域的乘积。这个对偶关系是滤波器设计的基石——想滤波？频域乘一下就行。

卷积的计算（离散表格法）

y[n]=∑k​x[k]h[n−k]。用「竖排错位相乘」：把 h 反转后逐位滑过 x，重叠部分相乘求和。两序列长度 M,N 时，结果长度 M+N−1。

小波变换入门

傅里叶的局限

傅里叶变换给出全局频率信息——你知道了「有哪些频率」，但不知道「什么时候出现」。

小波的核心思想

用有限长度、可平移缩放的「小波」代替无限的正弦波：

W(a,b)=a​1​∫x(t)ψ∗(at−b​)dt

  • a = 缩放（频率）
  • b = 平移（时间）

人话： 小波 = 同时告诉你「什么频率在什么时刻」——JPEG2000 和 FBI 指纹识别都用它。

例题

例 1：x(t)=e−atu(t)（a>0）的傅里叶变换

解题思路：

  1. X(f)=∫0∞​e−ate−i2πftdt=∫0∞​e−(a+i2πf)tdt
  2. =a+i2πf1​
  3. 幅度谱：∥X(f)∥=a2+(2πf)2​1​（低通特性）

例 2：判断 fs​=100 Hz 能否无混叠采样 x(t)=sin(2π⋅60t)

解题思路：

  1. 信号频率 f=60 Hz，带宽 B=60 Hz
  2. Nyquist 要求 fs​>2B=120 Hz
  3. fs​=100<120，不满足
  4. 会发生混叠：60 Hz 的信号会被采成 ∥100−60∥=40 Hz

例 3：混叠的通用计算

信号含 90 Hz 分量，以 fs​=100 Hz 采样。采样后它表现为？

解题思路：

  1. falias​=mink​∥90−100k∥=min(90,10,110,…)=10 Hz
  2. 恢复出的 10 Hz 假信号与真实存在的 10 Hz 分量完全无法区分
  3. 对策： 采样前必须用抗混叠低通滤波器把高于 fs​/2 的成分滤掉

例 4：采样与 sinc 重建

x(t)=5cos(2π⋅10t)，fs​=40 Hz。

解题思路：

  1. 带宽 B=10 Hz <fs​/2=20 Hz → 满足 Nyquist，可完美重建
  2. 采样点：x[n]=5cos(2π⋅10⋅n/40)=5cos(nπ/2)，即 5,0,−5,0,5,…
  3. 重建：x(t)=∑n​x[n]sinc(Tt−nT​)，T=1/40 s——每个采样点处插一个 sinc 并叠加
  4. 检验： 采样时刻 t=nT 处 sinc(0)=1、其余 sinc 全为 0——重建值与采样值逐点相等

例 5：4 点 DFT 手算（FFT 蝶形）

x={1,2,3,4}，N=4。

解题思路（两层蝶形）：

  1. 偶子序列 {1,3}：E[0]=4，E[1]=1−3=−2
  2. 奇子序列 {2,4}：O[0]=6，O[1]=2−4=−2
  3. W4​=e−i2π/4=−i，则：
    • X[0]=E[0]+O[0]=4+6=10
    • X[1]=E[1]+W41​O[1]=−2+(−i)(−2)=−2+2i
    • X[2]=E[0]−O[0]=−2
    • X[3]=E[1]−W41​O[1]=−2−2i
  4. 对称性检验： 实序列的 DFT 满足 X[N−k]=X∗[k]：X[3]=X∗[1] ✓——利用这个性质可以省一半计算

例 6：离散卷积

x[n]={1,2,3}，h[n]={1,1}。求 y=x∗h。

解题思路（表格法）：

  1. 结果长度 M+N−1=4
  2. y[0]=x[0]h[0]=1⋅1=1
  3. y[1]=x[0]h[1]+x[1]h[0]=1+2=3
  4. y[2]=x[1]h[1]+x[2]h[0]=2+3=5
  5. y[3]=x[2]h[1]=3
  6. y={1,3,5,3}

卷积定理检验： X(z)H(z)=(1+2z−1+3z−2)(1+z−1)=1+3z−1+5z−2+3z−3 ✓

例 7：一阶 RC 低通设计

设计截止频率 1 kHz 的低通滤波器。

解题思路：

  1. RC=2π×10001​≈1.59×10−4 s
  2. 取 C=0.1μF → R=1.59 kΩ
  3. 检验：f=10 kHz 时 ∥H∥=1/1+102​≈0.0995，即 20log10​0.0995≈−20 dB——每十倍频程衰减 20 dB（一阶特性）
  4. 局限： 一阶滚降太慢，抗混叠等场合需要更高阶（Butterworth/Chebyshev）

例 8：Z 变换判断系统稳定性

y[n]−0.5y[n−1]+0.25y[n−2]=x[n]。

解题思路：

  1. 传递函数：H(z)=z2−0.5z+0.25z2​
  2. 极点：z=20.5±i0.75​​=0.25±0.433i=0.5e±iπ/3
  3. 模长 ∥z∥=0.5<1 → 稳定
  4. 物理图像：脉冲响应按 0.5n 衰减、以 π/3 弧度/样本振荡——数字「谐振器」的特性。对比： y[n]−2y[n−1]=x[n] 的极点 z=2 在单位圆外，h[n]=2nu[n] 指数发散 → 不稳定——工程上 H(z) 的极点必须全在单位圆内，数字滤波器和控制器才可用。
