博弈论

博弈论 = 研究「我的决策取决于你的决策，你的决策又取决于我的决策」这种互相依赖的局面。Nash 均衡告诉你，当所有人都没有动机单方面改变策略时，系统就「定」住了。

基本概念

博弈的核心要素

要素含义
参与者（Players）做决策的主体
策略（Strategies）每个参与者的可选行动
收益（Payoffs）每种策略组合下各参与者的得失
信息（Information）参与者知道什么

策略分类

类型定义
纯策略确定地选择一个行动
混合策略以概率分布在多个行动中随机选择
占优策略无论别人选什么，这个策略都最优
被占优策略存在另一个策略在任何情况下都不比它差，且在有些情况下更好

人话： 纯策略 = 每次都出剪刀。混合策略 = 以 1/3 概率出石头/剪刀/布。

博弈的类型学

分类维度类型
是否合作合作博弈 / 非合作博弈
信息完全信息 / 不完全信息
顺序静态（同时行动）/ 动态（序贯行动）
收益结构零和 / 非零和
次数一次性 / 重复

人话： 同一局面可以建出完全不同的博弈模型——先看「信息」和「顺序」，再决定用什么工具。

Nash 均衡

定义

策略组合 (s1∗​,…,sn∗​) 是 Nash 均衡 ⟺ 对每个玩家 i：

ui​(si∗​,s−i∗​)≥ui​(si​,s−i∗​)∀si​∈Si​

人话： Nash 均衡下，没有人可以通过单方面改变策略来获得更高收益。一个人「叛变」只会更惨。

Nash 定理

每个有限博弈（有限个参与者和有限个策略）至少存在一个混合策略 Nash 均衡。

求 Nash 均衡的三板斧

方法适用操作
划线法纯策略对每个对手策略，划出自己收益最高的格子；双方都被划的格子 = 纯策略均衡
无差异法2×2 混合让对方在两个纯策略间无差异，解概率方程
最佳响应函数一般画双方最佳响应曲线，交点即均衡

零和博弈

定义

∑i​ui​(s)=0对所有策略组合

一人之得即他人之失。

极小极大定理（von Neumann）

对两人零和博弈（收益矩阵 A）：

pmax​qmin​pTAq=qmin​pmax​pTAq​

这个值 = 博弈的值 v。

人话： 先手和后手的价值相等。你选择使最坏情况最好的策略，和对方选择使你最好情况最坏的策略——这两者等价。

极小极大定理的线性规划形式

\max_{p, v} \quad & v \\ \text{s.t.} \quad & p^T A \geq v \cdot \mathbf{1}^T \\ & \sum_i p_i = 1, \; p_i \geq 0 \end{aligned}$$ **人话：** 零和博弈可以直接转化为线性规划求解。运筹学的单纯形法 + 博弈论的均衡 = 一套完整的计算工具。 ## 经典博弈 ### 囚徒困境 | | 对方合作 | 对方背叛 | |---|---|---| | **我合作** | (-1, -1) | (-3, 0) | | **我背叛** | (0, -3) | (-2, -2) | 占优策略：背叛（两人都选）。 Nash 均衡：(背叛, 背叛) → (-2, -2)。 **悖论：** 个人理性 → 集体非理性。两人合作 (-1, -1) 比 Nash 均衡 (-2, -2) 好，但没有一方敢先合作。 ### 囚徒困境的结构与变形 **结构条件：** $T > R > P > S$ - $T$ = 背叛对方合作的收益（诱惑） - $R$ = 双方合作的收益（回报） - $P$ = 双方背叛的收益（惩罚） - $S$ = 合作而被背叛的收益（傻瓜） **公地悲剧（n 人版囚徒困境）：** 每个牧民多养一头牛，好处全归自己、草场成本大家分摊 → 人人都多养 → 草场退化。个人理性 → 集体毁灭。 **重复囚徒困境：** 博弈重复无限次时，「合作」可以成为均衡——只要贴现因子 $\delta$ 足够大，以牙还牙（Tit-for-Tat）就是最优应对：第一轮合作，之后复制对方上一轮的选择。 $$\text{合作可持续} \iff \delta \geq \frac{T - R}{T - P}$$ **人话：** 一次性博弈里背叛是理性的；无限次博弈里「名声」有了价值，合作反而理性。价格战、军备竞赛都是这个逻辑的实例。 ### 懦夫博弈（Chicken） | | 对方让 | 对方冲 | |---|---|---| | **我让** | (0, 0) | (-1, 1) | | **我冲** | (1, -1) | (-10, -10) | 两个不对称纯策略均衡：(我冲, 对方让) 和 (我让, 对方冲)——谁先软谁输。**与鹰鸽博弈数学同构。** 冷战对峙、商业补贴战是典型场景。 ### 协调博弈（Battle of Sexes） | | 对方选 A | 对方选 B | |---|---|---| | **我选 A** | (3, 2) | (0, 0) | | **我选 B** | (0, 0) | (2, 3) | 两个纯策略 Nash 均衡：(A, A) 和 (B, B)。还有一个混合策略均衡。 **混合均衡（无差异法）：** 设我选 A 的概率为 $p$，对方选 A 的概率为 $q$。 - 对方无差异：$2p + 0(1-p) = 0p + 3(1-p) \Rightarrow p = 3/5$ - 我无差异：$3q + 0(1-q) = 0q + 2(1-q) \Rightarrow q = 2/5$ - 混合均衡收益 $= 6/5$——比两个纯策略均衡的收益（3 和 2）都差。**「协调失败」的数学化。** ### 二级结论：常见博弈的 Nash 均衡 | 博弈 | 均衡 | |---|---| | 囚徒困境 | 纯策略：都背叛 | | 石头剪刀布 | 混合：各 1/3 | | 鹰鸽博弈 | 混合策略均衡 + 两个纯策略不对称均衡 | | 猜硬币 | 混合：各 1/2 | | 性别战 | 两个纯策略 + 一个混合（各 3/5, 2/5） | | 懦夫博弈 | 两个不对称纯策略 + 一个混合 | ## 混合策略的求解 ### 两人两策略 收益矩阵（玩家 1 的收益）： $$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$ 玩家 1 混合策略 $p = (p, 1-p)$，玩家 2 混合策略 $q = (q, 1-q)$。 玩家 1 使玩家 2 无差异：$a p + c(1-p) = b p + d(1-p)$ $$\Rightarrow p^* = \frac{d-c}{a-b-c+d}$$ 同理 $q^* = \frac{d-b}{a-b-c+d}$。 **人话：** Nash 均衡的混合概率要恰好让对方在两个纯策略之间「无所谓」。 **为什么必须无差异：** 如果对方严格偏好某个纯策略，他就不会随机化；而若他知道你会固定某个概率，他就能针对性选择。均衡要求双方都无法利用对方。 ## 演化博弈论 ### 核心思想 策略不是理性选择的，而是通过「适者生存」自然演化出来的——收益 = 适应度。 ### 复制动力学（Replicator Dynamics） $$\dot{x}_i = x_i \left(f_i(\mathbf{x}) - \bar{f}(\mathbf{x})\right)$$ 其中 $x_i$ 是策略 $i$ 在种群中的比例，$f_i$ 是其收益，$\bar{f}$ 是平均收益。 **人话：** 收益高于平均的策略，比例增长；反之萎缩。 ### 演化稳定策略（ESS） 策略 $s^*$ 是 ESS，若对任何变异策略 $s \neq s^*$： 1. $u(s^*, s^*) \geq u(s, s^*)$（均衡条件） 2. 若 $u(s^*, s^*) = u(s, s^*)$，则 $u(s^*, s) > u(s, s)$（稳定性条件） **人话：** 变异者要么在主流群体中表现更差，要么当变异者多起来后互相干不过。 **ESS 与 Nash 的关系：** ESS 一定是 Nash 均衡，但 Nash 均衡不一定是 ESS（如性别战的两个纯策略均衡——一旦出现变异者就瓦解）。ESS = 能抵抗小规模入侵的 Nash 均衡。 ## 纳什讨价还价解 两人分 $1$，各自保留效用 $(d_1, d_2)$（谈崩了的收益）： $$\max (u_1 - d_1)(u_2 - d_2), \quad u_1 + u_2 \leq 1, \; u_i \geq d_i$$ 当 $d_1 = d_2 = 0$，解为 $u_1 = u_2 = 1/2$。 **人话：** 讨价还价 = 最大化双方「相对谈崩」的乘积。保留效用越强的人，分得越多。 ## 例题 ### 例 1：划线法求纯策略均衡 | | 对方 L | 对方 R | |---|---|---| | **我 U** | (3, 2) | (1, 1) | | **我 D** | (0, 0) | (2, 4) | **解题思路：** 1. 对方选 L 时：我选 U（3 > 0）→ 划 (U,L) 2. 对方选 R 时：我选 D（2 > 1）→ 划 (D,R) 3. 我选 U 时：对方选 L（2 > 1）→ 划 (U,L) 4. 我选 D 时：对方选 R（4 > 0）→ 划 (D,R) 5. 两个格子都被划：(U,L) 和 (D,R) 都是纯策略 Nash 均衡 **注意：** 划线法只找纯策略均衡。本例其实还有一个混合均衡——用无差异法继续。 ### 例 2：求两人零和博弈的均衡 收益矩阵（玩家 1）：$A = \begin{pmatrix} 3 & 1 \\ 0 & 2 \end{pmatrix}$ **解题思路：** 1. $p^* = \frac{d-c}{a-b-c+d} = \frac{2-0}{3-1-0+2} = \frac{2}{4} = \frac{1}{2}$ 2. $q^* = \frac{d-b}{a-b-c+d} = \frac{2-1}{3-1-0+2} = \frac{1}{4}$ 3. 博弈值 $v = p^T A q = \frac{1}{2} \cdot \frac{1}{4} \cdot 3 + \frac{1}{2} \cdot \frac{3}{4} \cdot 1 + \frac{1}{2} \cdot \frac{1}{4} \cdot 0 + \frac{1}{2} \cdot \frac{3}{4} \cdot 2 = \frac{3}{8} + \frac{3}{8} + 0 + \frac{3}{4} = \frac{3}{2}$ ### 例 3：零和博弈的 LP 化 把例 2 的博弈写成线性规划并求解： $$\max v, \quad 3p_1 \geq v, \quad p_1 + 2p_2 \geq v, \quad p_1 + p_2 = 1, \quad p \geq 0$$ **解题思路：** 1. 代入 $p_1 = p_2 = 1/2$：$3/2 \geq v$，$1/2 + 1 = 3/2 \geq v$ 2. 最优 $v = 3/2$——和公式法一致 3. **为什么：** 两个约束同时取等，说明玩家 2 的两个纯策略都「有用」——玩家 1 的混合策略恰好让它们无差异，这正是均衡条件 ### 例 4：猜硬币的混合策略 收益矩阵（玩家 1，双方同面玩家 1 赢 \$1）： | | 对方正面 | 对方反面 | |---|---|---| | **我正面** | (1, -1) | (-1, 1) | | **我反面** | (-1, 1) | (1, -1) | **解题思路：** 1. 无差异：$p - (1-p) = -p + (1-p) \Rightarrow 2p - 1 = 1 - 2p \Rightarrow p = 1/2$ 2. 同理 $q = 1/2$ 3. 博弈值 $v = 0$——长期不输不赢 4. **关键：** 纯策略下没有均衡（划线法永远只有一边被划）——随机化是唯一出路。点球大战中门将必须「猜方向」就是这个道理 ### 例 5：鹰鸽博弈的 ESS 计算 资源价值 $V = 4$，争斗成本 $C = 6$。收益矩阵（鹰 vs 鹰各得 $(V-C)/2 = -1$；鹰 vs 鸽鹰得 $V = 4$；鸽 vs 鸽各得 $V/2 = 2$）： | | 对方鹰 | 对方鸽 | |---|---|---| | **我鹰** | (-1, -1) | (4, 0) | | **我鸽** | (0, 4) | (2, 2) | **解题思路（设鹰的比例为 $x$）：** 1. 鹰的收益：$f_H = -x + 4(1-x) = 4 - 5x$；鸽的收益：$f_D = 2(1-x) = 2 - 2x$ 2. 无差异：$4 - 5x = 2 - 2x \Rightarrow x^* = 2/3$ 3. **ESS 验证：** 对变异策略「全鹰」：$u(x^*, \text{鹰}) = \frac{2}{3}(-1) + \frac{1}{3}(0) = -\frac{2}{3} > u(\text{鹰},\text{鹰}) = -1$ ✓；对「全鸽」：$u(x^*, \text{鸽}) = \frac{2}{3}(4) + \frac{1}{3}(2) = \frac{10}{3} > u(\text{鸽},\text{鸽}) = 2$ ✓ 4. 复制动力学：$\dot{x} = x(f_H - \bar{f}) = x(2 - 5x + 3x^2) = x(3x-2)(x-1)$ 5. 不动点 $x = 0, 2/3, 1$：$x < 2/3$ 时 $\dot{x} > 0$、$x > 2/3$ 时 $\dot{x} < 0$ → $x = 2/3$ **稳定**；$x = 0, 1$ 不稳定 6. **结论：** 种群中 2/3 鹰、1/3 鸽。一般地 $x^* = V/C$——争斗成本 $C$ 越大，鹰的比例越低（需 $V < C$；若 $V \geq C$ 则全鹰是 ESS） ### 囚徒困境的启示 结构上个人理性导致集体困境的，必须具备： - $T > R > P > S$（背叛对方合作的收益 > 合作 > 背叛 > 合作而被背叛） - $2R > T + S$（轮流剥削不如持续合作） **真实世界的囚徒困境：** 军备竞赛、价格战、公共资源的过度使用。 ## 知识链接 - **前驱：** [[概率]] — 混合策略的概率基础 - **前驱：** [[数学期望与方差]] — 收益的计算 - **后继：** [[优化与凸分析]] — 极小极大定理的凸分析证明 -
