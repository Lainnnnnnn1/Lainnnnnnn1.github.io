控制理论

控制 = 如何让一个系统按照你想要的方式运行。 恒温器是控制，自动驾驶也是控制——核心是反馈。

开环 vs 闭环

开环闭环（反馈）
原理预设输入，不检查输出测量输出，调整输入
优点简单能对抗扰动和不确定性
示例定时浇水根据土壤湿度浇水

反馈的魔力： 反馈改变了系统的极点位置。一个不稳定的系统，加上反馈可能变稳定——这就是控制的本质。没有反馈控制，飞机不能飞（天然不稳定），火箭不能入轨。

状态空间表示

x˙=Ax+Bu y=Cx+Du

  • x：状态向量（系统的「记忆」）
  • u：控制输入
  • y：观测输出

人话： 这是把微分方程组写成矩阵形式。A 描述系统自身的动力学，B 描述输入怎么影响系统。这叫现代控制理论（状态空间方法），区别于经典的传递函数方法。

从微分方程到状态空间

例：质量-弹簧-阻尼系统 mx¨+cx˙+kx=F

令 x1​=x,x2​=x˙，则： (x˙1​x˙2​​)=(0−k/m​1−c/m​)(x1​x2​​)+(01/m​)F

任何高阶 ODE 都可以转化为一阶状态空间形式——代价是矩阵维度变大。

稳定性

系统 x˙=Ax 渐近稳定 ⟺ A 的所有特征值都有负实部。

直觉： 特征值实部 <0 → 扰动随时间衰减 → 系统自己回归平衡点。

稳定性分类：

  • 渐近稳定： 所有特征值实部 < 0，系统最终回到平衡点
  • 临界稳定： 有特征值实部 = 0（且是单根），系统不增长也不衰减（如无摩擦的弹簧——持续振荡）
  • 不稳定： 任意特征值实部 > 0，系统发散

能控性与能观性

这两个概念是卡尔曼（Rudolf Kálmán）在 1960 年提出的，是现代控制理论的基石。

能控性 (Controllability)

定义： 是否存在控制输入 u(t)，能在有限时间内把系统从任意初始状态 x(0) 驱动到任意目标状态 x(tf​)？

判定（能控性矩阵）： C=[B,AB,A2B,…,An−1B]

系统能控 ⟺rank(C)=n（满秩）。

人话： 如果 C 不满秩，表示有些状态维度你是碰不到的——不管你输入什么，系统的某些方向不受影响。比如：控制火箭位置但不能控制速度 → 你会撞毁。

能观性 (Observability)

定义： 能否通过观测输出 y(t) 重构出全部状态 x(t)？

判定（能观性矩阵）： O=​CCACA2⋮CAn−1​​

系统能观 ⟺rank(O)=n。

人话： 如果 O 不满秩，则有些状态变化在输出中完全看不到——就像你只能看到汽车的位置但看不到速度，就无法准确预测下一秒在哪。

PID 控制

u(t)=Kp​e(t)+Ki​∫0t​e(τ)dτ+Kd​dtde​

项作用调大效果
P（比例）当前误差响应快速但有超调
I（积分）历史误差累积消除稳态误差，但可能振荡
D（微分）误差变化率抑制超调，但对噪声敏感

人话： PID 是工程界最广泛使用的控制器。90% 的工业控制问题用 PID 就够了。

PID 的参数直觉

参数过大时症状
Kp​ 过大振荡严重，可能不稳定
Ki​ 过大响应慢，超调大，积分饱和
Kd​ 过大对噪声极度敏感，执行器抖动

积分饱和（Integral Windup）： 当执行器饱和时（如阀门全开），误差持续积累导致 I 项变得极大——系统需要很长时间才能”退”回来。解决方案：积分分离、抗饱和（clamping）。

状态反馈与极点配置

比 PID 更系统化的方法：直接用全状态来反馈。

u=−Kx

闭环系统：x˙=(A−BK)x

极点配置定理： 如果系统能控，则可以任意配置 A−BK 的特征值（极点）。换句话说——只要系统能控，你就能把它的动态放到任何你想要的位置。

设计流程：

  1. 指定期望极点位置（如：虚轴左侧某处，决定响应速度和阻尼）
  2. 解出 K 使 A−BK 的特征值等于期望极点
  3. 实现 u=−Kx

局限： 需要全部状态的测量。现实中往往只有部分状态可测 → 需要状态观测器。

LQR（线性二次型调节器）

不要手动选极点，而是让数学帮你选。

目标： 最小化代价函数 J=∫0∞​(xTQx+uTRu)dt

  • Q：对状态偏差的惩罚权重（Q 大 → 更快回归，更大控制力）
  • R：对控制能量的惩罚权重（R 大 → 节省能量，状态收敛较慢）

解： u=−R−1BTPx，其中 P 是代数 Riccati 方程的解： ATP+PA−PBR−1BTP+Q=0

LQR 最优控制的美丽之处：不管你选什么 Q,R，闭环系统总是稳定的（只要 (A,B) 能控且 Q,R 正定）。

卡尔曼滤波器

当状态不能直接测量且有噪声时，卡尔曼滤波器是最优的状态估计器。

问题设定： x˙=Ax+Bu+w（过程噪声 w∼N(0,Q)） y=Cx+v（测量噪声 v∼N(0,R)）

卡尔曼滤波 = 预测 + 更新：

预测步骤： x^k∣k−1​=Ax^k−1​+Buk​ Pk∣k−1​=APk−1​AT+Q

更新步骤（用新测量修正）： Kk​=Pk∣k−1​CT(CPk∣k−1​CT+R)−1（卡尔曼增益） x^k​=x^k∣k−1​+Kk​(yk​−Cx^k∣k−1​) Pk​=(I−Kk​C)Pk∣k−1​

直觉： Kk​ 决定了更信任模型预测还是更信任测量。Q 大（模型不准）→ 更信任测量。R 大（传感器不准）→ 更信任模型。

应用： 阿波罗登月导航、GPS 定位、自动驾驶融合多传感器、金融时间序列。

鲁棒控制简介

现实世界的系统永远有不确定性——参数不精确、未建模的动态、外部扰动。鲁棒控制保证系统在”最坏情况”下仍然稳定和满足性能。

基本思想： 不是用一个精确模型设计控制器，而是考虑一个模型的集合（名义模型 + 不确定性的界），设计一个控制器使整个集合都满足要求。

H∞​ 控制： 最小化从扰动到输出的最大增益（H∞​ 范数）。形式上： ∥Tzw​∥∞​=supω​σˉ(Tzw​(jω))<γ

其中 σˉ 是最大奇异值。直观：γ<1 意味着扰动在传递过程中被衰减。

Lyapunov 函数

判断非线性系统稳定性的最强工具。

如果存在函数 V(x) 满足：

  • V(x)>0（正定），V(0)=0
  • V˙(x)<0（沿系统轨线递减）

则系统渐近稳定。

直觉： V(x) 是「能量函数」。如果能量一直减少，系统最终停在最低点。

Lyapunov 的物理起源： 如果力学系统的总能量（动能+势能）不断被摩擦消耗，系统最终静止。Lyapunov 的洞察：不需要真正的能量——任何满足正定+递减的函数都行。这极大地扩展了适用范围。
