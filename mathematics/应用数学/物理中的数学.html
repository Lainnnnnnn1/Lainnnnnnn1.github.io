物理中的数学

物理规律用数学语言写成。每一种基本力对应一种数学结构。 全篇主线：一个物理问题 = 一个微分方程 + 边界/初始条件。会解方程，物理就完成了一大半。

经典力学

谐振子 (Harmonic Oscillator)

mx¨+kx=0

解：x=Acos(ωt+ϕ)，ω=k/m​

完整求解（从特征方程到通解）：

  1. 设 x=eλt，代入得特征方程 mλ2+k=0
  2. λ=±ik/m​=±iω——纯虚根
  3. 通解 x=C1​eiωt+C2​e−iωt，用欧拉公式化为实形式： x(t)=Acos(ωt)+Bsin(ωt)=Ccos(ωt+ϕ)

其中 C=A2+B2​ 是振幅，tanϕ=−B/A 是初相——都由初始条件 x(0),x˙(0) 决定。

能量守恒： 总能量 E=21​mx˙2+21​kx2=21​kA2 与时间无关——振动就是动能和势能的反复转换。

数学本质： 这是最简单的二阶线性 ODE。特征方程 mλ2+k=0⇒λ=±ik/m​，纯虚根→正弦波。

人话： 弹簧拉得越远，往回拉的力越大——比例系数 k 决定了振动多快。

阻尼谐振子

mx¨+cx˙+kx=0

特征根：λ=2m−c±c2−4mk​​

判别式 c2−4mk特征根运动类型
<0共轭复根欠阻尼（振荡衰减）x=Ae−ct/2mcos(ωd​t+ϕ)
=0重根临界阻尼（最快回到平衡）x=(A+Bt)e−ct/2m
>0两个负实根过阻尼（缓慢爬回平衡）

其中阻尼振荡频率 ωd​=k/m−(c/2m)2​<ω0​。

人话： 阻尼让频率变慢、振幅指数衰减。临界阻尼是「最快」的——汽车减震器就调在临界附近。

受迫振动与共振

mx¨+cx˙+kx=F0​cos(Ωt)

稳态解（特解）： xp​(t)=(k−mΩ2)2+(cΩ)2​F0​​cos(Ωt−δ)

共振频率（振幅最大处）： Ωres​=mk​−2m2c2​​

阻尼 c共振行为
c=0Ω→ω0​ 时振幅 →∞（灾难性共振）
c 小尖峰，峰位略低于 ω0​
c 大峰变矮变宽，几乎看不出共振

人话： 驱动力频率和固有频率接近时，能量持续注入、振幅飙升——荡秋千、塔科马大桥坍塌都是这个机制。

拉格朗日力学

L=T−V

欧拉-拉格朗日方程： dtd​∂q˙​∂L​−∂q∂L​=0

人话： 不用画力分析图。写出动能和势能，然后机械地代入 EL 方程——方程自动出来。

为什么好用： 力是矢量（要分解），能量是标量（直接写）。约束复杂时（摆、滑轮系统），拉格朗日方法优势巨大。

电磁学

麦克斯韦方程组（微分形式）

∇⋅E=ϵ0​ρ​(Gauss) ∇⋅B=0(无磁单极) ∇×E=−∂t∂B​(Faraday) ∇×B=μ0​J+μ0​ϵ0​∂t∂E​(Ampeˋre-Maxwell)

人话：

  1. 电荷产生电场（散度）
  2. 没有孤立的磁极
  3. 变化的磁场产生电场
  4. 电流 + 变化的电场产生磁场

这四条方程统一了电磁学。 注意第四条中 μ0​ϵ0​ 的乘积——它等于 1/c2，揭示了光速是电磁波的速度。

从方程组推出波动方程： 对 Faraday 定律取旋度并代入 Ampère-Maxwell 定律，得 ∇2E=μ0​ϵ0​∂t2∂2E​——电场本身满足波动方程，波速 c=1/μ0​ϵ0​​。麦克斯韦方程组 + 数学推导 = 预言电磁波。

波动方程

∂t2∂2u​=c2∇2u

一维弦振动：∂t2∂2u​=c2∂x2∂2u​

解（分离变量法）： u(x,t)=∑n=1∞​sin(Lnπx​)(An​cos(Lnπct​)+Bn​sin(Lnπct​))

人话： 任何波形都可以分解成不同频率的正弦波叠加——这就是傅里叶分析的物理意义。

定系数： 初始条件 u(x,0)=f(x)、ut​(x,0)=g(x) 给出： An​=L2​∫0L​f(x)sinLnπx​dx,Bn​=nπc2​∫0L​g(x)sinLnπx​dx

量子力学

薛定谔方程

iℏ∂t∂ψ​=−2mℏ2​∇2ψ+Vψ

数学本质： 这是一个复数值的 PDE。特征值问题——Hψ=Eψ。

人话： 量子态 ψ 不是粒子的「位置」，而是概率幅——∣ψ∣2 告诉你粒子在某处的概率。

定态方程与简单系统

不含时方程：−2mℏ2​ψ′′+Vψ=Eψ。解出 ψn​,En​ 后，含时解为 ψn​(x,t)=ψn​(x)e−iEn​t/ℏ。

人话： 能量是量子化的——只有特定的离散能级。量子力学的核心特征。谐振子零点能 21​ℏω=0——粒子永远不能完全静止。

无穷深势阱

En​=2mL2n2π2ℏ2​

波函数归一化：ψn​=2/L​sin(nπx/L)（由 ∫0L​∣ψn​∣2dx=1 定出系数）。

人话： 能量是量子化的——只有特定的离散能级。量子力学的核心特征。

广义相对论

爱因斯坦场方程

Rμν​−21​Rgμν​+Λgμν​=c48πG​Tμν​

人话（极度简化）：

  • 左边 = 时空的弯曲（几何）
  • 右边 = 物质和能量的分布（物理）
  • 「物质告诉时空怎么弯，时空告诉物质怎么动」

例题

例 1：简谐振子 m=1,k=4,x(0)=1,x˙(0)=0

解题思路：

  1. ω=4/1​=2
  2. x(t)=Acos(2t)+Bsin(2t)
  3. x(0)=1⇒A=1，x˙(0)=0⇒B=0
  4. x(t)=cos(2t)，振幅 C=1，总能量 E=21​kA2=2

例 2：受迫振动共振频率

m=1,k=4,c=1，F0​=2。求共振频率与共振振幅。

解题思路：

  1. 无阻尼固有频率 ω0​=4​=2
  2. Ωres​=4−2⋅1212​​=3.5​≈1.87
  3. 共振振幅 Amax​=(k−mΩres2​)2+(cΩres​)2​F0​​=0.25+3.5​2​≈1.03
  4. 若 c=0：Ω=ω0​=2 时振幅发散——阻尼是共振的「安全阀」

例 3：一维波动方程 utt​=4uxx​，x∈[0,π]，固定边界，u(x,0)=2sinx，ut​(x,0)=0

解题思路：

  1. 分离变量 u=X(x)T(t)
  2. X′′+λX=0，X(0)=X(π)=0⇒λn​=n2，Xn​=sin(nx)
  3. T′′+4n2T=0⇒Tn​=An​cos(2nt)+Bn​sin(2nt)
  4. u(x,t)=∑sin(nx)(An​cos(2nt)+Bn​sin(2nt))
  5. 代入 u(x,0)=2sinx：A1​=2，其余 An​=0
  6. ut​(x,0)=∑2nBn​sin(nx)=0⇒Bn​=0
  7. 解：u(x,t)=2sinxcos(2t)——初始波形原地振动，不传播

对照（初速度激发的驻波）： 若 u(x,0)=0，ut​(x,0)=sin(3x)，则 6B3​=1⇒B3​=1/6，u=61​sin(3x)sin(6t)。用恒等式 sinAsinB=21​[cos(A−B)−cos(A+B)] 展开——两个反向传播的行波叠加成驻波，这就是「波被边界反射」的数学。

例 4：无限深势阱的能级与概率

L=1 nm 的电子（me​=9.1×10−31 kg）。

解题思路：

  1. E1​=2me​L2π2ℏ2​=2×9.1×10−31×10−18π2(1.055×10−34)2​≈6.0×10−20 J ≈0.38 eV
  2. 归一化：ψ1​=2/L​sin(πx/L)（用到 ∫0L​sin2(πx/L)dx=L/2）
  3. 基态粒子出现在 x∈[0,L/2] 的概率：∫0L/2​∣ψ1​∣2dx=L2​⋅4L​=21​——左右对称
  4. 能级间隔 En+1​−En​=(2n+1)E1​——n 越大能级越密

例 5：量子谐振子零点能

ω=1015 rad/s（典型分子振动）：

E0​=21​ℏω=21​×1.055×10−34×1015≈5.3×10−20 J≈0.33 eV

物理意义： 即使温度降到绝对零度，分子仍在振动——零点能不可消除。这也是量子力学与经典物理最直观的分野。

例 6：拉格朗日方法求单摆运动方程

摆长 l、摆锤质量 m、摆角 θ。

解题思路：

  1. 速度 v=lθ˙，动能 T=21​ml2θ˙2
  2. 势能 V=−mglcosθ（最低点为零点），L=T−V=21​ml2θ˙2+mglcosθ
  3. ∂θ˙∂L​=ml2θ˙，∂θ∂L​=−mglsinθ
  4. EL 方程：ml2θ¨+mglsinθ=0⇒θ¨+lg​sinθ=0
  5. 小角度 sinθ≈θ：θ¨+lg​θ=0——又是谐振子！周期 T=2πl/g​ 与振幅无关（伽利略的发现）

人话： 整个过程没有画一个力的分解图——动能、势能写出来，机械代入 EL 方程，运动方程自动出现。这就是拉格朗日力学的威力。
