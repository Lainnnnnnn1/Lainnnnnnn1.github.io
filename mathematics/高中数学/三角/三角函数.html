三角函数

sin, cos, tan 是把「角度」变成「长度比值」的函数。它们不是魔法——是单位圆上的坐标。

核心直觉

三角函数就是单位圆上点的坐标。

(cosθ,sinθ)=单位圆上角度 θ 对应的点的 (x,y)

画一个半径为 1 的圆。从 (1,0) 出发，逆时针走 θ 弧度到达的点，其坐标就是 (cosθ,sinθ)。

人话： cos 是横坐标，sin 是纵坐标。tan=cossin​ 是斜率。

图像变换：y=Asin(Bx+C)+D

参数名称效果
A振幅纵向拉伸，值域 [−A,A]
B频率横向压缩，周期 T=B2π​
C相位水平平移，向左移 BC​
D纵向平移整体上下移

人话步骤（五步绘图法）：

  1. 写出 y=Asin(B(x+BC​))+D（提取 B）
  2. 画出 y=sinx 基础图
  3. 横向缩放：周期变为 B2π​
  4. 水平移 BC​（注意符号： y=sin(2x−π) 向右移 2π​，不是 π）
  5. 纵向缩放 A 倍 + 纵向平移 D

函数叠加：y=asinx+bcosx

核心技巧——辅助角公式：

asinx+bcosx=a2+b2​sin(x+φ)

其中 tanφ=ab​，φ 的象限由 (a,b) 符号决定。

实例： y=sinx+3​cosx=2sin(x+3π​)

人话： 任何 sin + cos 的线性组合，本质上还是一个正弦波——只是振幅和相位变了。用 a2+b2​ 提振幅，用 φ 调相位。

核心恒等式（必背）

sin2θ+cos2θ=1

推导： 单位圆方程 x2+y2=1，代入 x=cosθ,y=sinθ 即得。

1+tan2θ=sec2θ

推导： 上式除以 cos2θ 即得。

1+cot2θ=csc2θ

推导： 上式除以 sin2θ 即得。

三角方程求解

通解公式（必须背）

sinx=acosx=atanx=a​⇒x=kπ+(−1)karcsina(k∈Z)⇒x=2kπ±arccosa(k∈Z)⇒x=kπ+arctana(k∈Z)​

方程通解结构人话
sinx=akπ+(−1)kα奇数次翻到补角区
cosx=a2kπ±α左右对称各一个
tanx=akπ+α每 π 重复一次

限定区间求解

步骤： 先写出通解 → 代入 k=0,±1,±2… → 筛选落在目标区间的解。

反三角函数

反三角函数 = “已知比值，求角度”的工具。不是多值函数——人为截断了主值区间。

函数符号定义域值域（主值）人话
反正弦arcsinx[−1,1][−2π​,2π​]正弦是 x 的那个角
反余弦arccosx[−1,1][0,π]余弦是 x 的那个角
反正切arctanxR(−2π​,2π​)正切是 x 的那个角

核心关系（二级结论）

arcsinx+arccosx=2π​(∣x∣≤1)

arctanx+arccotx=2π​

arctanx+arctanx1​=2π​(x>0)

sin(arccosx)=1−x2​(∣x∣≤1)

cos(arcsinx)=1−x2​(∣x∣≤1)

人话： arcsin 和 arccos 互为余角——这跟 sinθ=cos(2π​−θ) 是对称的。

例题

例 1：解 sinx=21​ 在 [0,2π) 上的所有解

解题思路：

  1. sinx=21​ 在第一和第二象限都有解
  2. 参考角：arcsin(21​)=6π​
  3. 第一象限解：x=6π​
  4. 第二象限解：x=π−6π​=65π​

答案： x=6π​,65π​

例 2：求 y=2sin(3x−2π​)+1 的振幅、周期、相位和值域

解题思路：

  1. 振幅 A=2
  2. 周期 T=32π​
  3. 相位平移：3x−2π​=0⇒x=6π​，向右移 6π​
  4. 值域：[1−2,1+2]=[−1,3]

例 3：解 cos(2x+3π​)=22​​，x∈[0,π]

解题思路：

  1. 令 u=2x+3π​，则 cosu=22​​
  2. cosu=22​​⇒u=4π​+2kπ 或 u=−4π​+2kπ
  3. 限制 x∈[0,π]⇒u∈[3π​,2π+3π​]
  4. 检验：u=4π​+2π=49π​ 在区间内 → x=2423π​
  5. u=−4π​+2π=47π​ 在区间内 → x=2417π​

答案： x=2417π​,2423π​

例 4：求 y=3sinx+4cosx 的最大值和最小值

解题思路：

  1. 辅助角公式：32+42​=5
  2. tanφ=34​⇒φ=arctan34​
  3. y=5sin(x+φ)
  4. 最大值 5，最小值 −5

例 5：求 arcsin(sin35π​) 的值

解题思路：

  1. sin35π​=−23​​
  2. arcsin(−23​​)=−3π​（因为 −3π​ 在主值区间 [−2π​,2π​] 内）
  3. 陷阱： 不能直接写 35π​！arcsin 值域限制在 [−2π​,2π​]

答案： −3π​
