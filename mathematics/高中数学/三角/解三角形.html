解三角形

「解」三角形 = 已知三个独立条件（至少一条边），求其余三个量。 两把钥匙：正弦定理 + 余弦定理。

正弦定理

sinAa​=sinBb​=sinCc​=2R

其中 R 为外接圆半径。

直觉： 边越长，对角越大——且比值恒定为外接圆直径。这是在说：三角形的「形状」和它外接圆的大小之间有一个精确的比例关系。

使用条件： 已知两角一边（AAS/ASA）或两边一对角（SSA，注意歧义情况）。

正弦定理的变形（二级结论）

变形用途
a=2RsinA边化角
sinA=2Ra​角化边
a:b:c=sinA:sinB:sinC比例关系
a>b⟺sinA>sinB⟺A>B大边对大角

人话： 正弦定理不只是算长度——它是「边角互换」的桥梁。三角形形状判断题的核心思路就是正弦定理边角互化。

余弦定理

a2=b2+c2−2bccosA

b2=a2+c2−2accosB

c2=a2+b2−2abcosC

直觉： 这是勾股定理的推广。当 A=90° 时 cosA=0，退化回 a2=b2+c2。cosA 这一项修正了「不是直角」带来的偏差。

使用条件： 已知三边（SSS）或两边夹角（SAS）。

余弦定理的变形

cosA=2bcb2+c2−a2​

cosB=2aca2+c2−b2​

cosC=2aba2+b2−c2​

人话： 这个形式用来「由三边求角」——SSS 情况的直接工具。

面积公式（6种，全面掌握）

1. 基本公式

S=21​aha​=21​bhb​=21​chc​

2. 两边夹角公式（最常用）

S=21​absinC=21​bcsinA=21​casinB

直觉： 底×高÷2，但「高」用邻边乘 sin 夹角得到。

3. Heron 公式（已知三边）

S=s(s−a)(s−b)(s−c)​

其中 s=2a+b+c​ 为半周长。

4. 外接圆半径公式

S=4Rabc​

其中 R 为外接圆半径。

5. 内切圆半径公式

S=rs

其中 r 为内切圆半径，s 为半周长。

推导： S=S△IAB​+S△IBC​+S△ICA​=21​cr+21​ar+21​br=rs

6. 坐标/行列式公式

已知三点 A(x1​,y1​),B(x2​,y2​),C(x3​,y3​)：

S=21​​det(x2​−x1​x3​−x1​​y2​−y1​y3​−y1​​)​

三角形的心与半径

外接圆半径 R

R=2sinAa​=2sinBb​=2sinCc​=4Sabc​

内切圆半径 r

r=sS​=a+b+c2S​

r=4Rsin2A​sin2B​sin2C​

旁切圆半径 ra​,rb​,rc​

旁切圆切于一边和另两边的延长线：

ra​=s−aS​=4Rsin2A​cos2B​cos2C​

rb​=s−bS​,rc​=s−cS​

二级结论： r1​=ra​1​+rb​1​+rc​1​

中线长公式

ma​=21​2b2+2c2−a2​

直觉： 这是平行四边形对角线定理的一半——中线 = 补全平行四边形后对角线的一半。

角平分线长公式

la​=b+c2bccos2A​​

SSA 歧义情况（容易错，深度展开）

已知两边 a,b 和角 A（非夹角），用正弦定理求 B：

判断流程图

sinB=absinA​

条件结果人话
absinA​>1无解边 a 太短，根本构不成三角形
absinA​=1唯一解（直角 △）B=90°，恰好一个三角形
absinA​<1 且 A≥90°唯一解（B 必须是锐角）钝角三角形只能有一个钝角
absinA​<1 且 A<90° 且 a≥b唯一解大边对大角，B 只能是锐角
absinA​<1 且 A<90° 且 a<b两解（B 和 180°−B）两个都可能！需要进一步判断

关键判断原则

a<b 且 A<90° → 必须警惕双解！

为什么有歧义？ 给定 a, b, A，以 C 点为圆心、a 为半径画弧，可能与 AB 边交于 0/1/2 个点。

SSA 实战四步法

  1. 算 sinB=absinA​
  2. 检查 sinB≤1？否则无解
  3. 若 A≥90°：B 只能锐角
  4. 若 A<90°：B 和 180°−B 两个候选 → 检验 A+B<180°

例题

例 1：已知 a=7,b=5,C=60°，求 c 和面积

解题思路：

  1. 余弦定理：c2=72+52−2⋅7⋅5⋅cos60°
  2. c2=49+25−70⋅0.5=74−35=39
  3. c=39​
  4. 面积：S=21​⋅7⋅5⋅sin60°=4353​​

例 2：判断三角形形状——acosA=bcosB

解题思路：

  1. 用正弦定理：sinAa​=sinBb​=2R
  2. 代入：2RsinAcosA=2RsinBcosB
  3. sin(2A)=sin(2B)
  4. ∴2A=2B 或 2A=180°−2B
  5. 即 A=B（等腰）或 A+B=90°（直角）

答案： 等腰三角形或直角三角形。

例 3（SSA 双解）：a=4,b=5,A=30°，解三角形

解题思路：

  1. sinB=absinA​=45⋅0.5​=85​=0.625
  2. B1​=arcsin(0.625)≈38.7°，B2​=180°−38.7°=141.3°
  3. 检验 B1​：A+B1​=68.7°<180° ✓ → C1​=111.3°，c1​=sinAasinC1​​≈7.47
  4. 检验 B2​：A+B2​=171.3°<180° ✓ → C2​=8.7°，c2​=sinAasinC2​​≈1.21

答案： 两个三角形！(B,C,c)=(38.7°,111.3°,7.47) 或 (141.3°,8.7°,1.21)

例 4（SSA 无解）：a=3,b=7,A=30°，解三角形

解题思路：

  1. sinB=absinA​=37⋅0.5​=67​>1
  2. 无解！边 a=3 太短。

例 5：已知 S=103​，a=5，b=8，求 C

解题思路：

  1. S=21​absinC⇒103​=21​⋅5⋅8⋅sinC
  2. 20sinC=103​⇒sinC=23​​
  3. C=60° 或 120°（都是合理的三角形内角）

答案： C=60° 或 C=120°

例 6（综合）：在 △ABC 中，a=4,b=3,C=120°，求 S、R、r

解题思路：

  1. c2=16+9−2⋅4⋅3⋅(−21​)=25+12=37，c=37​
  2. S=21​⋅4⋅3⋅sin120°=6⋅23​​=33​
  3. R=4Sabc​=123​4⋅3⋅37​​=3111​​
  4. r=sS​=(4+3+37​)/233​​=7+37​63​​
