参数方程与极坐标

核心问题：一条曲线除了 y=f(x)，还能怎么描述？当一个坐标”卡住”时，引入第三个变量 t 或角度 θ，常常让问题豁然开朗。

参数方程 — 用第三个变量描述曲线

1. 基本定义

若曲线 C 上点 (x,y) 满足

{x=φ(t)y=ψ(t)​,t∈I​

且对 t 的取值与 C 上的点一一对应，则称上式为曲线 C 的参数方程，t 为参数。

  • 参数 t 通常取时间、角度或斜率
  • 消去参数 t 得到普通方程 F(x,y)=0
  • 参数方程的优势：能表达非函数曲线（圆、摆线），且物理意义明确

2. 参数方程求导（重要考点）

设 x=φ(t)，y=ψ(t) 均可导且 φ′(t)=0，则

dxdy​=dx/dtdy/dt​=φ′(t)ψ′(t)​​

二阶导（极易算错，务必记住）：

dx2d2y​=dtd​(dxdy​)⋅dx/dt1​​

⚠️ 不能直接对 dxdy​ 再对 t 求导就完事——还必须除以 dtdx​。

3. 常见曲线的参数方程（必背表）

曲线参数方程参数含义
直线过 (x0​,y0​) 方向 (a,b){x=x0​+aty=y0​+bt​t 为位移倍数
圆 x2+y2=r2{x=rcosθy=rsinθ​θ 为极角
椭圆 a2x2​+b2y2​=1{x=acosθy=bsinθ​θ 为离心角（非极角！）
双曲线 a2x2​−b2y2​=1{x=asecθy=btanθ​θ 为参数角
抛物线 y2=2px{x=2pt2y=2pt​t 为斜率 xy​ 相关量
摆线（旋轮线）{x=a(θ−sinθ)y=a(1−cosθ)​θ 为滚动角
圆的渐开线{x=a(cosθ+θsinθ)y=a(sinθ−θcosθ)​θ 为展开角

椭圆离心角陷阱：x=acosθ 中的 θ 不是极坐标角，而是”辅助圆”上的角度。点 (acosθ,bsinθ) 与原点连线的斜率是 ab​tanθ，不是 tanθ。

极坐标 — 用距离和角度描述曲线

1. 基本定义

平面内取定点 O（极点）与射线 Ox（极轴），点 P 用 (ρ,θ) 表示：ρ 为极径（P 到 O 的距离），θ 为极角（OP 与极轴的夹角）。

{x=ρcosθy=ρsinθ​​ρ2=x2+y2,  tanθ=xy​ (x=0)​

⚠️ ρ 可以取负值：(−ρ,θ) 与 (ρ,θ+π) 表示同一点。极坐标下点的表示不唯一。

2. 常见极坐标方程（必背表）

曲线极坐标方程形状
圆心在极点的圆ρ=r圆
过极点的圆（直径 a）ρ=acosθ 或 ρ=asinθ圆心在轴上
过极点的直线θ=α射线
一般直线 xcosα+ysinα=pρcos(θ−α)=p法线式
心形线ρ=a(1+cosθ)心脏形
玫瑰线ρ=asinkθk 奇：k 瓣；k 偶：2k 瓣
阿基米德螺线ρ=aθ等距螺线
双纽线ρ2=a2cos2θ∞ 形

3. 极坐标下的面积与弧长

由 θ=α 到 θ=β、曲线 ρ=ρ(θ) 围成的扇形区域面积：

S=21​∫αβ​ρ2(θ)dθ​

曲线弧长：

s=∫αβ​ρ2(θ)+[ρ′(θ)]2​dθ​

记忆法：面积公式形似扇形面积 21​r2θ 的积分版；弧长公式是 dx2+dy2​ 在极坐标下的展开。

4. 参数方程下的面积与弧长

曲线 {x=x(t)y=y(t)​（t∈[α,β]）与 x 轴围成的面积：

S=∫αβ​∣y(t)x′(t)∣dt

弧长：

s=∫αβ​[x′(t)]2+[y′(t)]2​dt

常考题型与例题

例题 1：参数方程化普通方程

曲线 C:{x=2cosθy=3sinθ​，求普通方程并判断形状。

解题思路：

第1步：cosθ=2x​，sinθ=3y​，利用 cos2θ+sin2θ=1 消参。

第2步：4x2​+9y2​=1，即椭圆（长轴在 y 轴，a=3,b=2）。

验证：取 θ=0 得 (2,0)，θ=2π​ 得 (0,3)，均在椭圆上 ✓

例题 2：参数方程求切线斜率

求摆线 {x=a(θ−sinθ)y=a(1−cosθ)​ 在 θ=2π​ 处的切线斜率。

解题思路：

第1步：dθdx​=a(1−cosθ)，dθdy​=asinθ。

第2步：dxdy​=a(1−cosθ)asinθ​=1−cosθsinθ​。

第3步：代入 θ=2π​：斜率 =1−01​=1。

验证：θ→0 时 1−cosθsinθ​→∞，即摆线起点处切线竖直，符合物理直觉（轮子底部瞬间静止）✓

例题 3：极坐标下求面积

求心形线 ρ=a(1+cosθ) 围成的面积。

解题思路：

第1步：心形线关于极轴对称，θ 从 0 到 2π 扫完一周。

第2步：S=21​∫02π​a2(1+cosθ)2dθ。

第3步：展开 (1+cosθ)2=1+2cosθ+cos2θ，∫02π​cosθdθ=0，∫02π​cos2θdθ=π。

第4步：S=2a2​(2π+π)=23πa2​​。

验证：单位圆面积 πa2 的 1.5 倍，心形线比圆”胖”一些，量级合理 ✓

例题 4：极坐标与直角坐标互化

将极坐标方程 ρ=1−cosθ2​ 化为直角坐标方程。

解题思路：

第1步：两边同乘分母：ρ(1−cosθ)=2，即 ρ−ρcosθ=2。

第2步：代入 ρ=x2+y2​，ρcosθ=x：x2+y2​−x=2。

第3步：移项平方：x2+y2=(x+2)2，化简得 y2=4x+4，即 y2=4(x+1)——抛物线，焦点在极点 O。

验证：抛物线 y2=4(x+1) 的焦点为 (0,0)，即极点；极坐标形式 ρ=1−cosθp​ 正是焦点在极点的抛物线（p=2）✓

例题 5：极坐标求弧长

求圆 ρ=2acosθ（圆心 (a,0)，半径 a）的周长。

解题思路：

第1步：ρ′(θ)=−2asinθ，弧长公式 s=∫αβ​ρ2+ρ′2​dθ。

第2步：ρ2+ρ′2=4a2cos2θ+4a2sin2θ=4a2。

第3步：θ 从 −2π​ 到 2π​（否则 ρ<0 重复描点）：s=∫−π/2π/2​2adθ=2πa ✓ 与半径 a 的圆周长一致。

验证：结果与几何事实吻合，说明积分限选择正确 ✓

二级结论（背下来直接用）

  • 椭圆参数方程中 θ 是离心角，点 (acosθ,bsinθ) 的极角 φ 满足 tanφ=ab​tanθ
  • 过椭圆上点 (acosθ0​,bsinθ0​) 的切线：axcosθ0​​+bysinθ0​​=1
  • 摆线一拱长 8a，一拱与 x 轴围成的面积 3πa2（弧长公式可证）
  • ρ=asinkθ：k 为奇数有 k 瓣，k 为偶数有 2k 瓣（k∈Z+）
  • 双纽线 ρ2=a2cos2θ 一叶面积 2a2​
  • 极坐标下求面积先检查 ρ 是否变号、图形是否对称，再定积分限
  • 参数方程求二阶导：dx2d2y​=(φ′)3ψ′′φ′−ψ′φ′′​（等价形式，直接套）
  • 直线参数方程 {x=x0​+tcosαy=y0​+tsinα​ 中 ∣t∣ 恰为点到 (x0​,y0​) 的距离，弦长问题首选
