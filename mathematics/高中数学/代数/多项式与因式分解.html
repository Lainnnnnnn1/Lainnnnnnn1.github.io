多项式与因式分解

多项式的核心是一个定理：f(a)=0⟺(x−a) 是 f(x) 的因式。一切因式分解都从这里来。

多项式的标准形

f(x)=an​xn+an−1​xn−1+⋯+a1​x+a0​

次数 (degree)： n=deg(f)，最高次项的次数。

因式分解基本公式

公式展开/分解
平方差a2−b2=(a−b)(a+b)
完全平方a2±2ab+b2=(a±b)2
立方和a3+b3=(a+b)(a2−ab+b2)
立方差a3−b3=(a−b)(a2+ab+b2)
和的立方(a+b)3=a3+3a2b+3ab2+b3
差的立方(a−b)3=a3−3a2b+3ab2−b3
十字相乘x2+(p+q)x+pq=(x+p)(x+q)
n 次差an−bn=(a−b)(an−1+an−2b+⋯+bn−1)

人话： 公式表只是工具。因式分解的思维顺序：提公因式 → 套公式 → 十字相乘 → 分组 → 试根 + 综合除法。高次多项式一律走最后一步。

因式分解方法总纲

操作顺序（按优先级）：

  1. 提公因式： 每项都有的因子先拿出来
  2. 套公式： 平方差、完全平方、立方和差
  3. 十字相乘： 二次三项式专用
  4. 分组分解： 四项及以上，两两分组找公因式
  5. 换元： 出现重复结构时，令整体为 t
  6. 试根 + 综合除法： 高次多项式的最终武器

分组分解示例： x3+x2+x+1=x2(x+1)+(x+1)=(x+1)(x2+1)

换元示例： (x2+x)2−8(x2+x)+12，令 t=x2+x：t2−8t+12=(t−2)(t−6)=(x2+x−2)(x2+x−6)=(x+2)(x−1)(x+3)(x−2)

人话： 六步走下来，没有分解不了的多项式。卡住就往下走一步——高次多项式别硬拆，直接试根。

余式定理

f(x) 除以 (x−a) 的余数 =f(a)。

推广 1（除以一次式 ax+b）： 余数 =f(−ab​)

推广 2（除以二次式）： f(x) 除以 (x−α)(x−β) 的余式设为 px+q，代入 f(α)=pα+q，f(β)=pβ+q 解出 p,q。

人话： 想知道 f(3) 是多少？把它写成 f(x)=(x−3)Q(x)+R，余数 R 就是 f(3)。

因式定理

f(a)=0⟺(x−a) 是 f(x) 的因式

这是多项式理论的基石。 找有理根 → 代入验证 → 因式分解 → 降次 → 继续找。

有理根定理

若 f(x)=an​xn+⋯+a0​ 有有理根 qp​（既约分数），则 p∣a0​，q∣an​。

人话： 分子是常数项的约数，分母是首项系数的约数。

综合除法

快速计算 f(a) 和 f(x)÷(x−a) 的商和余数。

系数an​an−1​…a0​
乘 aa⋅an​…
加an​an−1​+a⋅an​…R

最后一行是商的系数，最后一个数是余数 R=f(a)。

步骤： 下拉首项 → 乘 a 写下一列 → 相加 → 重复。比长除法快一个数量级，考试必用。

算例： 求 f(x)=3x3−5x2+2x−8 除以 x−2 的商与余数：

步骤系数3−52−8
下拉3
3×2=6，加到下一列1
1×2=2，加到下一列4
4×2=8，加到下一列0

商：3x2+x+4，余数 0，即 f(x)=(x−2)(3x2+x+4)。

验证： f(2)=24−20+4−8=0 ✓（余数为 0，说明 x−2 是因式）

高次韦达定理（对称多项式）

三次方程 ax3+bx2+cx+d=0，三根 α,β,γ：

α+β+γ=−ab​ αβ+βγ+γα=ac​ αβγ=−ad​

二级结论（对称式速算）： α2+β2+γ2=(α+β+γ)2−2(αβ+βγ+γα) α3+β3+γ3−3αβγ=(α+β+γ)(α2+β2+γ2−αβ−βγ−γα)

人话： 高次韦达 = 二次韦达的推广：系数的符号一负一正交替。任何对称式都能用三个基本对称式拼出来。

代数基本定理

n 次多项式（复系数）恰有 n 个复根（计重数）。

实系数推论： 虚根成对出现——a+bi 是根则 a−bi 也是根。所以奇次实系数多项式至少有一个实根。

待定系数法

原理： 两个多项式恒等 ⟺ 对应项系数相等。

步骤： 设出含未知系数的形式 → 展开 → 对比系数列方程组 → 解出系数。

人话： 知道因式的”形状”但不知道具体系数时，把形状写出来，用系数相等把未知数挤出来。余式定理的推广 2 本质就是待定系数。

例题

例 1：x3−6x2+11x−6=0，求所有根

解题思路：

  1. 有理根候选：±1,±2,±3,±6
  2. f(1)=0⇒(x−1) 是因式
  3. 综合除法：(x3−6x2+11x−6)÷(x−1)=x2−5x+6
  4. x2−5x+6=(x−2)(x−3)

答案： x=1,2,3

例 2：分解 f(x)=2x3−x2−7x+6

解题思路：

  1. 有理根候选：±1,±2,±3,±6,±21​,±23​
  2. 代入检验：f(1)=0，f(−2)=0
  3. 综合除法（除以 x−1）： 2x3−x2−7x+6=(x−1)(2x2+x−6)
  4. 十字相乘：2x2+x−6=(2x−3)(x+2)

答案： f(x)=(x−1)(2x−3)(x+2)，根为 1,23​,−2

套路： 首项系数不是 1 时，候选根要包含 首项系数约数常数项约数​ 的分数。

例 3：f(x) 除以 x−1 余 3，除以 x−2 余 5，求除以 (x−1)(x−2) 的余式

解题思路：

  1. 设余式 R(x)=px+q（次数低于除式次数 2）
  2. 由余式定理：R(1)=f(1)=3，R(2)=f(2)=5
  3. 解方程组：p+q=3，2p+q=5，得 p=2,q=1

答案： R(x)=2x+1

套路： 除以二次式的余式是一次的——设 px+q，用两个点的函数值把它定出来。

例 4：分解 x4+4（实数范围）

解题思路（配方成平方差）：

  1. 加一项再减一项：x4+4=x4+4x2+4−4x2
  2. =(x2+2)2−(2x)2
  3. 平方差：=(x2−2x+2)(x2+2x+2)

答案： (x2−2x+2)(x2+2x+2)（两个二次因子判别式都 <0，实数范围分解到头）

套路： 缺项式想配方——凑完全平方再减一个平方，制造平方差。

例 5：α,β,γ 是 x3−6x2+11x−6=0 的三根，求 α2+β2+γ2 与 α3+β3+γ3

解题思路（高次韦达）：

  1. α+β+γ=6，αβ+βγ+γα=11，αβγ=6
  2. α2+β2+γ2=62−2⋅11=36−22=14
  3. α3+β3+γ3=(α+β+γ)(α2+β2+γ2−11)+3αβγ
  4. =6⋅(14−11)+18=18+18=36

验证（根是 1,2,3）： 1+8+27=36 ✓

答案： 14，36

例 6：用综合除法求 f(4)，其中 f(x)=2x3−5x2+3x−7

解题思路（综合除法一步出值）：

  1. 系数表：2, −5, 3, −7，除数为 a=4
  2. 下拉 2；2×4=8，−5+8=3；3×4=12，3+12=15；15×4=60，−7+60=53
  3. 最后一行：2, 3, 15, 53 —— 商 2x2+3x+15，余数 53

答案： f(4)=53（直接代入验证：128−80+12−7=53 ✓）

套路： 求 f(a) 不要老老实实代入——综合除法一次算完商和余数，还顺便给了因式分解的线索。

例 7：分解 f(x)=x4−5x3+5x2+5x−6

解题思路：

  1. 有理根候选：±1,±2,±3,±6
  2. f(1)=1−5+5+5−6=0，综合除法得 f(x)=(x−1)(x3−4x2+x+6)
  3. 对三次因子继续试根：f(−1)=−1−4−1+6=0，再除：x3−4x2+x+6=(x+1)(x2−5x+6)
  4. x2−5x+6=(x−2)(x−3)

答案： f(x)=(x−1)(x+1)(x−2)(x−3)

套路： 高次多项式 = 反复”试根 + 综合除法”降次，直到二次为止。试根从 ±1 开始，命中率最高。

例 8：分解 (x2+x)2−8(x2+x)+12

解题思路（换元法）：

  1. 令 t=x2+x：t2−8t+12=(t−2)(t−6)
  2. 代回：(x2+x−2)(x2+x−6)
  3. 两个二次因子分别十字相乘：(x+2)(x−1)(x+3)(x−2)

答案： (x+2)(x−1)(x+3)(x−2)

套路： 出现”重复结构”（这里是 x2+x 出现两次）→ 换元。换元后是二次式，十字相乘收尾。

例 9：f(x)=x4+2x3−x+1，求 f(x) 除以 x−1 的余数

解题思路（余式定理直接秒）：

  1. 余数 =f(1)
  2. f(1)=1+2−1+1=3

答案： 余数 =3

套路： 求”除以一次式的余数”永远用余式定理——代入一个点，比任何长除法都快。

例 10：分解 f(x)=x4−2x3−7x2+8x+12

解题思路（反复试根）：

  1. 有理根候选：±1,±2,±3,±4,±6,±12
  2. f(−1)=1+2−7−8+12=0，综合除法： x4−2x3−7x2+8x+12=(x+1)(x3−3x2−4x+12)
  3. 继续试根：f(2)=8−12−8+12=0，再除： x3−3x2−4x+12=(x−2)(x2−x−6)
  4. x2−x−6=(x−3)(x+2)

答案： f(x)=(x+1)(x−2)(x−3)(x+2)，根为 −1,2,3,−2

套路： 四次多项式最多试两次根就降成二次。每次降次后都要重新列候选根——但 ±1,±2 命中率依然最高。

例 11：x=1 和 x=2 是 f(x)=x3+ax2+bx−6 的根，求 a,b 及第三个根

解题思路（代入 + 韦达）：

  1. f(1)=1+a+b−6=0⟹a+b=5
  2. f(2)=8+4a+2b−6=0⟹2a+b=−1
  3. 解得 a=−6，b=11，即 f(x)=x3−6x2+11x−6
  4. 韦达：αβγ=6，已知两根 1,2，第三根 =1×26​=3

答案： a=−6，b=11，第三个根 3（这正是例 1 的多项式）

套路： “已知某些根求参数” = 把根代进去列方程组。参数齐了之后再回头用韦达补缺失的根。
