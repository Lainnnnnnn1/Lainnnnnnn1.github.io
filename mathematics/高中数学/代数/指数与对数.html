指数与对数

指数是「自己乘自己 N 次」的缩写。对数是指数的逆——问「这是底数的几次方」。

指数法则（刻进骨子里）

法则公式为什么
同底相乘am⋅an=am+na 乘 m 次再乘 n 次 = m+n 次
幂的幂(am)n=amn把 m 个 a 的整体再乘 n 次
同底相除anam​=am−n约掉 n 个 a
积的幂(ab)n=anbn分开分别乘
零指数a0=1（a=0）anan​=an−n=1

人话： 指数法则的本质就三条——同底相乘指数相加、幂的幂指数相乘、积的幂分开乘。其他全是推论。

对数法则

loga​(bc)=loga​b+loga​c loga​(cb​)=loga​b−loga​c loga​(bc)=cloga​b

基本值： loga​1=0，loga​a=1

对数恒等式： aloga​b=b（定义本身，直接能用）

人话： 对数把”乘除”降级成”加减”，把”幂”降级成”乘”。这是对数在计算器出现前统治世界的原因，也是现在所有化简题的引擎。

自然对数 ln——为什么无处不在

lnx=loge​x,e≈2.71828…

e 不是数学家随便选的字母。 y=ex 的导数等于它自己：

dxd​ex=ex

这是微积分里唯一一个「变化率等于当前值」的函数。所以 ln 是所有涉及增长率问题的自然语言——利息、衰变、人口、冷却。

y=ax 和 y=loga​x 的图像

  • 互为反函数，关于 y=x 对称
  • a>1：ax 递增增长，loga​x 递增但越来越慢
  • 0<a<1：ax 递减，loga​x 递减
  • ax 过 (0,1)，loga​x 过 (1,0)
  • y=0 是 ax 的渐近线，x=0 是 loga​x 的渐近线

人话： 指数函数的定义域是别人的值域，值域是别人的定义域——互为反函数就是这个意思。

比较大小三件套：

  1. 先看符号： 负的 < 0 的 < 正的
  2. 再看 1： loga​b 与 1 比（b 与 a 比）；ax 与 1 比（x 与 0 比）
  3. 最后单调性： 底数相同用单调性，指数相同比底数，都不行找中间值

指数方程与不等式

核心思想： 同底化 → 指数相等；不同底 → 取对数。

  • af(x)=ag(x)⟺f(x)=g(x)（a>0,a=1）
  • af(x)=b⟺f(x)=loga​b
  • 换元： 形如 A⋅a2x+B⋅ax+C=0，令 t=ax>0，化为二次方程。t>0 是隐含条件，永远不能丢
  • af(x)>ag(x)：a>1 时 f(x)>g(x)；0<a<1 时 f(x)<g(x)（翻号）

对数方程与不等式

步骤铁律： 先定定义域，再解方程，最后验证。

  • loga​f(x)=b⟺f(x)=ab（且 f(x)>0）
  • loga​f(x)=loga​g(x)⟺f(x)=g(x)（且 f,g>0）
  • loga​f(x)>b：a>1 时 f(x)>ab；0<a<1 时 0<f(x)<ab（翻号 + 保正）
  • 换元： loga2​x+ploga​x+q=0，令 t=loga​x

人话： 对数不等式的两个陷阱：底数小于 1 要翻号；解完必须回代定义域。丢掉任何一个都是送分变送命。

增长速度（大 O 直觉）

当 x→+∞：

指数≫幂≫对数

limx→∞​xkax​=+∞(a>1),limx→∞​xklnx​=0(k>0)

人话： 指数函数最终碾压一切多项式，多项式最终碾压对数。直觉比公式重要：2100 有 30 位数，1002 才 1 万。

例题

例 1：解 2x+1=32x−1

解题思路：

  1. 两边取 ln：(x+1)ln2=(2x−1)ln3
  2. 展开：xln2+ln2=2xln3−ln3
  3. 移项：x(ln2−2ln3)=−ln3−ln2
  4. x=2ln3−ln2ln6​

答案： x=2ln3−ln2ln6​

套路： 底数不同又没法同底 → 两边取对数，把指数”拉下来”变成系数。

例 2：求 log2​8+log3​91​

解题思路：

  1. log2​8=log2​(23)=3
  2. log3​91​=log3​(3−2)=−2
  3. 3+(−2)=1

答案： 1

例 3：解方程 4x−3⋅2x−4=0

解题思路（换元）：

  1. 4x=(2x)2，令 t=2x>0
  2. t2−3t−4=0⟹(t−4)(t+1)=0
  3. t=4（t=−1 舍去，因为 2x>0）
  4. 2x=4⟹x=2

答案： x=2

套路： 看到 a2x 和 ax 同时出现 → 换元成二次方程。t>0 的舍根一步是本题全部考点。

例 4：计算 log2​3⋅log3​4⋅log4​5⋅log5​8

解题思路（换底连锁）：

  1. 全部换成自然对数：ln2ln3​⋅ln3ln4​⋅ln4ln5​⋅ln5ln8​
  2. 分子分母连环约分：ln2ln8​=log2​8=3

答案： 3

套路： 连乘的不同底对数 = 换底后连环约分，只剩首尾。

例 5：解 log2​(x+1)+log2​(x−2)=2

解题思路：

  1. 先定定义域： x+1>0 且 x−2>0，即 x>2
  2. 合并：log2​[(x+1)(x−2)]=2
  3. 去对数：(x+1)(x−2)=22=4
  4. x2−x−6=0⟹x=3 或 x=−2
  5. 回代定义域： x=−2∈/(2,+∞) 舍去

答案： x=3

例 6：解不等式 log21​​(x−1)>2

解题思路（底数 < 1 翻号）：

  1. 定义域： x−1>0，即 x>1
  2. 底数 21​<1，不等式翻号：x−1<(21​)2=41​
  3. x<45​

答案： 1<x<45​

例 7：比较 a=0.32，b=20.3，c=log2​0.3 的大小

解题思路（三件套）：

  1. 看符号： c=log2​0.3<log2​1=0，所以 c<0
  2. 看 1： a=0.09∈(0,1)；b=20.3>20=1
  3. 排序：c<0<a<1<b

答案： c<a<b

例 8：求 y=log31​​(x2−2x) 的单调区间

解题思路（复合函数单调性）：

  1. 定义域： x2−2x>0，即 x<0 或 x>2
  2. 内层 u=x2−2x：在 (−∞,1) 递减，在 (1,+∞) 递增
  3. 外层 log31​​u 递减（底数 <1）
  4. 同增异减：y 在 (−∞,0) 递增（u 减 + 外层减），在 (2,+∞) 递减

答案： 增区间 (−∞,0)，减区间 (2,+∞)

套路： 复合函数单调性 = 同增异减，但先求定义域，单调区间必须在定义域内。

例 9：解不等式 2x>8 与 (31​)x<9

解题思路（同底化）：

  1. 2x>23，底数 2>1 单调递增：x>3
  2. (31​)x<9：先化 (31​)x=3−x，9=32
  3. 3−x<32，底数 3>1：−x<2，x>−2

答案： x>3；x>−2

套路： 指数不等式永远先化成同底，再比指数。底数 <1 记得翻号——本题第二问用 3−x 巧妙地绕开了翻号。

例 10：计算 3log3​5+2log2​3⋅3log3​4

解题思路（对数恒等式）：

  1. aloga​b=b：3log3​5=5
  2. 2log2​3=3，3log3​4=4
  3. 原式 =5+3×4=17

答案： 17

例 11：求 y=log2​(x2+2x+3) 的值域

解题思路（复合函数值域）：

  1. 真数 u=x2+2x+3=(x+1)2+2≥2（恒正，定义域为全体实数）
  2. log2​u 在 (0,+∞) 递增
  3. 最小值：log2​2=1，无最大值

答案： [1,+∞)

套路： 对数函数值域 = 先求真数的取值范围，再套外层单调性。真数能取到 (0,+∞) 的全体，值域才是全体实数。
