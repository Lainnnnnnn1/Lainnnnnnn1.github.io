数列与求和

数列 = 一串按规律排列的数。核心是两类：等差数列（加常数）和等比数列（乘常数）。求和的尽头是裂项和错位相减。

等差数列

通项： an​=a1​+(n−1)d

求和（前 n 项）： Sn​=2n​(a1​+an​)=2n​[2a1​+(n−1)d]=na1​+2n(n−1)​d

直觉： 首尾配对！a1​+an​,a2​+an−1​,… 每对和相等，共有 2n​ 对。

性质：

  • 等差中项： a,b,c 成等差 ⟺2b=a+c，即 b=2a+c​
  • 等和下标： m+n=p+q⟹am​+an​=ap​+aq​（特例 am​+an​=2a2m+n​​）
  • Sn​ 的结构： Sn​=An2+Bn（无常数项）——反过来，若 Sn​=An2+Bn+C 且 C=0，则 {an​} 从第二项起才是等差
  • 最值： d>0 时 Sn​ 有最小值（加到最后一个负项）；d<0 时有最大值（加到最后一个正项）
  • 片段和： Sk​,S2k​−Sk​,S3k​−S2k​,… 仍成等差（公差 k2d）

人话： Sn​ 是 n 的二次函数且过原点。求最值 = 找 an​ 变号的临界位置，不用求导。

等比数列

通项： an​=a1​⋅rn−1

求和（r=1）： Sn​=1−ra1​(1−rn)​=1−ra1​−an​r​

无穷等比级数（∣r∣<1）： S∞​=1−ra1​​

直觉： 公比 ∣r∣<1 时项越来越小，总和趋近有限值；∣r∣≥1 则发散（r=−1 是振荡发散）。

性质：

  • 等比中项： a,b,c 成等比 ⟺b2=ac（b=±ac​，注意符号）
  • 等积下标： m+n=p+q⟹am​an​=ap​aq​
  • Sn​ 的结构： Sn​=Aqn−A（A=q−1a1​​）——题目给你 Sn​=3n+k 是等比前 n 项和 ⟺k=−1
  • 连续片段： Sk​,S2k​−Sk​,S3k​−S2k​,… 仍成等比（公比 rk）

求和符号 Σ

∑i=mn​ai​=am​+am+1​+⋯+an​

基本性质：

  • ∑(ai​+bi​)=∑ai​+∑bi​
  • ∑cai​=c∑ai​
  • ∑i=1n​c=nc

人话： Σ 只做三件事——拆开、提常数、数个数。所有求和技巧都是在 Σ 里面做变形。

裂项求和（伸缩和）

原理： 把通项拆成相邻两项的差 Ti​=f(i)−f(i−1)（或 f(i)−f(i+k)），求和时中间项全部抵消，只剩首尾。

∑i=mn​[f(i)−f(i−1)]=f(n)−f(m−1)

常考裂项模型表：

模型裂项分解

人话： 裂项是”拆了再还”。关键是凑出 f(i)−f(i+1) 的形式，系数 k1​ 或 21​ 别丢。

错位相减法

适用范围： 等差 × 等比，即 Ti​=(Ai+B)⋅qi。

步骤：

  1. 写出 Sn​
  2. 两边乘公比 q，得到 qSn​，各项错开一位
  3. 相减 Sn​−qSn​，中间变成等比数列求和
  4. 解出 Sn​

一般公式（二级结论）： ∑i=1n​iqi=(1−q)2q−(n+1)qn+1+nqn+2​(q=1)

人话： 错位相减的答案永远长这样：Sn​=(一次式)×qn+常数。算完用 n=1 代回去验一遍——错位相减最容易错在符号。

分组求和

适用范围： 通项是几类简单数列的和，如 an​=等比+等差。

原理： ∑(bn​+cn​)=∑bn​+∑cn​——拆开分别求，各自套公式。

例： an​=2n+2n−1，则 Sn​=∑2n+∑(2n−1)=(2n+1−2)+n2。

人话： 分组求和是最省脑子的方法——看到”杂合通项”先想能不能拆成两个熟悉数列的和。拆得开，就赢了。

递推数列求通项

常考递推模型表：

递推式方法通项结构
an+1​=an​+f(n)累加法an​=a1​+∑k=1n−1​f(k)
an+1​=f(n)⋅an​累乘法an​=a1​∏k=1n−1​f(k)
an+1​=pan​+q（p=1）构造等比an+1​−λ=p(an​−λ)，λ=1−pq​
an+1​=pan​直接等比an​=a1​pn−1
an+1​=an​常数列an​=a1​

人话： 一阶线性 an+1​=pan​+q 是重中之重——两边同时减去 λ=1−pq​（不动点），立刻变成等比数列。

数学归纳法

证明 ∀n∈N,P(n) 成立：

  1. 基始： 验 P(1)（或 P(n0​)）真
  2. 归纳步： 假设 P(k) 真，推出 P(k+1) 真
  3. 结论： P(n) 对所有 n≥n0​ 真

直觉： 你推倒第一张多米诺骨牌，然后确保每张牌倒下会推倒下一张。

适用场景： 求和公式、整除性、不等式、递推通项。关键动作：P(k+1) 的式子中强制拆出 P(k) 的部分，剩下的部分单独处理。

例题

例 1：求 ∑k=1n​(2k−1)——前 n 个奇数和

解题思路：

  1. ∑(2k−1)=2∑k−∑1
  2. =2⋅2n(n+1)​−n=n(n+1)−n=n2

答案： 前 n 个奇数和 =n2。（第一个奇数 1，前两个 1+3=4=22，前三个 1+3+5=9=32……）

例 2：无穷等比级数 21​+41​+81​+⋯

解题思路：

  1. a1​=21​,r=21​，∣r∣<1 收敛
  2. S∞​=1−1/21/2​=1

直觉： 一根一米长的棍子，每次折半，加起来恰好等于 1。

例 3：等差数列 a1​=10,d=−3，求 Sn​ 的最大值

解题思路：

  1. 通项：an​=10−3(n−1)=13−3n
  2. 找最后一个正项：an​>0⟹n<313​≈4.33，故 a4​=1>0，a5​=−2<0
  3. 最大值在 S4​ 取得：S4​=24(10+1)​=22

答案： S4​=22

套路： d<0 的等差求和最大值 = 加到最后一个正项为止；d>0 同理找最小值。

例 4：求 ∑k=1n​k(k+2)1​

解题思路（裂项）：

  1. 裂项：k(k+2)1​=21​(k1​−k+21​)
  2. 展开抵消： ∑k=1n​k(k+2)1​=21​[(1−31​)+(21​−41​)+(31​−51​)+⋯+(n1​−n+21​)]
  3. 剩首尾：21​(1+21​−n+11​−n+21​)

答案： 21​(23​−n+11​−n+21​)

套路： 隔项裂项（分母差 k）会剩前 k 项和后 k 项，别只留一项。

例 5：求 Sn​=1⋅2+2⋅22+3⋅23+⋯+n⋅2n

解题思路（错位相减）：

  1. Sn​=∑k=1n​k⋅2k
  2. 乘公比：2Sn​=∑k=1n​k⋅2k+1=∑k=2n+1​(k−1)2k
  3. 错位相减： Sn​−2Sn​=2+22+23+⋯+2n−n⋅2n+1
  4. −Sn​=2−12(2n−1)​−n⋅2n+1=2n+1−2−n⋅2n+1
  5. Sn​=(n−1)2n+1+2

验证（n=1）： S1​=2，公式给 (0)⋅4+2=2 ✓

答案： Sn​=(n−1)2n+1+2

例 6：a1​=1，an+1​=2an​+1，求通项

解题思路（构造等比）：

  1. 求不动点：λ=1−pq​=1−21​=−1
  2. 两边加 1（即减 λ）：an+1​+1=2(an​+1)
  3. {an​+1} 是首项 a1​+1=2、公比 2 的等比数列
  4. an​+1=2⋅2n−1=2n

答案： an​=2n−1（验证：a2​=3=2⋅1+1 ✓）

例 7：a1​=1，an+1​=an​+2n+1，求通项

解题思路（累加法）：

  1. an​=a1​+∑k=1n−1​(2k+1)
  2. =1+2⋅2(n−1)n​+(n−1)=1+n(n−1)+n−1=n2

答案： an​=n2（验证：a2​=4=1+3 ✓，a3​=9=4+5 ✓）

套路： 递推差是 n 的多项式 → 累加；递推比是 n 的分式 → 累乘；an+1​=pan​+q → 构造等比。

例 8：用数学归纳法证明 1⋅2+2⋅3+⋯+n(n+1)=3n(n+1)(n+2)​

解题思路：

  1. 基始（n=1）： 左边 =1⋅2=2，右边 =31⋅2⋅3​=2 ✓
  2. 归纳假设： 设 P(k) 真，即 ∑i=1k​i(i+1)=3k(k+1)(k+2)​
  3. 归纳步（证 P(k+1)）： ∑i=1k+1​i(i+1)=3k(k+1)(k+2)​+(k+1)(k+2) =(k+1)(k+2)(3k​+1)=3(k+1)(k+2)(k+3)​
  4. 形式与 P(k+1) 一致，归纳完成

答案： 对一切 n∈N 成立

套路： 归纳步的固定动作——把 P(k+1) 的和式拆成 P(k) 的部分 + 新的一项，然后只处理新项。

例 9：数列 an​=2n+2n−1，求前 n 项和

解题思路（分组求和）：

  1. 拆开：Sn​=∑k=1n​2k+∑k=1n​(2k−1)
  2. 等比部分：∑k=1n​2k=2−12(2n−1)​=2n+1−2
  3. 等差部分（前 n 个奇数和）：n2
  4. Sn​=2n+1+n2−2

答案： Sn​=2n+1+n2−2

例 10：a1​=2，an​an+1​​=nn+1​，求通项

解题思路（累乘法）：

  1. an​=a1​⋅∏k=1n−1​kk+1​
  2. 连环约分：2×12​×23​×34​×⋯×n−1n​=2n
  3. an​=2n

答案： an​=2n（验证：a2​=4，而 a1​a2​​=12​ ✓）

套路： 累乘的连乘积几乎总是能约成首尾两项——写出来别急着算，先看约分。

例 11：等差数列前 10 项和 S10​=100，前 20 项和 S20​=250，求 S30​

解题思路（片段和性质）：

  1. S10​,S20​−S10​,S30​−S20​ 成等差数列
  2. 100,150,S30​−250 等差 → 公差 50
  3. S30​−250=200，S30​=450

答案： S30​=450

套路： 等差片段和 Sk​,S2k​−Sk​,S3k​−S2k​,… 成等差——给两组和求第三组，秒杀。
