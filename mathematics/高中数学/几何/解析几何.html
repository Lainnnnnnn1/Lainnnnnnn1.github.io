解析几何

把几何画在坐标纸上——每一条线、每一个圆都变成方程。几何问题变成代数问题。

距离公式与中点公式

两点距离： d=(x2​−x1​)2+(y2​−y1​)2​

中点： M=(2x1​+x2​​,2y1​+y2​​)

斜率： m=x2​−x1​y2​−y1​​

定比分点： P 分 AB 为 AP:PB=λ，则 P=(1+λx1​+λx2​​,1+λy1​+λy2​​)

直线

一般式

Ax+By+C=0

法向量 n=(A,B)，方向向量 d=(B,−A)。

斜截式

y=mx+b

点斜式

y−y1​=m(x−x1​)

人话： 四个形式里一般式最通用（不怕竖直线），斜截式最直观（一眼看出斜率和截距）。给了点+斜率用点斜式，给了截距用斜截式。

直线系（二级结论）

直线系方程
与 Ax+By+C=0 平行Ax+By+C′=0
与 Ax+By+C=0 垂直Bx−Ay+C′=0（系数交换、变号）
过点 (x0​,y0​)y−y0​=k(x−x0​)（竖直线单独写 x=x0​）
过两直线 l1​,l2​ 交点l1​+λl2​=0（交点系）

两直线关系

条件判定
平行m1​=m2​ 或 A2​A1​​=B2​B1​​=C2​C1​​
垂直m1​⋅m2​=−1 或 A1​A2​+B1​B2​=0
夹角$\tan\theta = \left

人话： 一般式判平行看比例：A2​A1​​=B2​B1​​ 是平行，=C2​C1​​ 才不是同一条线。垂直看 A1​A2​+B1​B2​=0——这个条件对竖直线也成立，比斜率乘积 −1 更安全。

点到直线的距离

d=A2+B2​∣Ax0​+By0​+C∣​

平行线间距离： 两平行线 Ax+By+C1​=0 与 Ax+By+C2​=0 的距离：

d=A2+B2​∣C1​−C2​∣​

对称问题

点关于点： P(x0​,y0​) 关于 M(a,b) 的对称点 P′=(2a−x0​,2b−y0​)（中点公式反解）

点关于直线（三步法）：

  1. 设对称点 P′(a,b)
  2. 中点 (2x0​+a​,2y0​+b​) 在直线上
  3. PP′ 与直线垂直（斜率乘积 −1）
  4. 解方程组

线关于线： 转化为”线上两点各自对称”或”交点不动 + 方向对称”。

反射问题套路： 光线反射 = 把光源关于镜面做对称，反射光线就是”对称点”到”入射点”的连线。

三角形的面积（坐标版）

三点 A(x1​,y1​),B(x2​,y2​),C(x3​,y3​)：

S=21​∣x1​(y2​−y3​)+x2​(y3​−y1​)+x3​(y1​−y2​)∣

人话： 就是 21​∣det(AB,AC)∣——平行四边形面积的一半。

圆

标准方程：(x−h)2+(y−k)2=r2

一般方程：x2+y2+Dx+Ey+F=0

圆心：(−2D​,−2E​)，半径：r=4D2+E2​−F​（根号内为负则方程不代表实圆）

点与圆： ∥PO∥2−r2 的符号决定点在圆内/上/外。

直线与圆（设圆心到直线距离 d）：

条件位置关系交点
d<r相交两个交点
d=r相切一个交点
d>r相离无交点

弦长公式： L=2r2−d2​

圆与圆（设圆心距 d，半径 r1​≥r2​）：

条件位置关系
d>r1​+r2​外离
d=r1​+r2​外切
∥r1​−r2​∥<d<r1​+r2​相交（公共弦 = 根轴）
d=∥r1​−r2​∥内切
d<∥r1​−r2​∥内含

根轴： 两圆方程相减得到的直线，过两圆交点（相交时即公共弦），垂直于连心线。

圆的切线

情况切线方程
圆 x2+y2=r2 上一点 P(x0​,y0​)x0​x+y0​y=r2
圆 (x−a)2+(y−b)2=r2 上一点(x0​−a)(x−a)+(y0​−b)(y−b)=r2
圆外一点引两条切线设 y−y0​=k(x−x0​)，用”圆心到直线距离 =r“解 k（别漏竖直线）
切点弦（两切点连线）圆 x2+y2=r2 外点 P(x0​,y0​)：x0​x+y0​y=r2

人话： 过圆上点的切线 = “一半替换”（x2→x0​x）。过圆外点设斜率时，解出来可能只有一条——另一条是竖直线，被斜率公式吃了。

圆锥曲线简介

曲线标准方程关键参数
圆x2+y2=r2半径 r
椭圆a2x2​+b2y2​=1半长轴 a，半短轴 b，焦距 c=a2−b2​
双曲线a2x2​−b2y2​=1渐近线 y=±ab​x
抛物线y2=4px焦点 (p,0)，准线 x=−p

统一定义： 到定点（焦点）与到定直线（准线）的距离之比为常数 e（离心率）的点轨迹。

  • e=0：圆
  • 0<e<1：椭圆
  • e=1：抛物线
  • e>1：双曲线

点差法（中点弦）： 圆锥曲线上两点 P1​,P2​ 关于点 M 对称（M 是中点）时，把两点坐标分别代入曲线方程再相减，可得弦 P1​P2​ 的斜率与 M 的关系——不必求交点。

例题

例 1：求过两圆 x2+y2=1 和 (x−2)2+y2=4 交点的直线方程

解题思路（根轴）：

  1. 两圆方程相减：x2+y2−1−[(x−2)2+y2−4]=0
  2. x2−1−(x2−4x+4−4)=4x−1=0
  3. x=41​

答案： 根轴 x=41​——过两圆交点的直线

例 2：求点 P(1,2) 关于直线 y=2x+1 的对称点

解题思路（三步法）：

  1. 设对称点 P′(a,b)，中点 M(21+a​,22+b​) 在直线上： 2⋅21+a​−22+b​+1=0⟹2a−b+2=0
  2. PP′ 与直线垂直（直线斜率 2）：a−1b−2​=−21​，即 a+2b=5
  3. 联立解得 a=51​，b=512​

答案： P′(51​,512​)

例 3：求圆 x2+y2=25 在点 P(3,4) 处的切线

解题思路（一半替换）：

  1. 32+42=25，P 在圆上 ✓
  2. 切线：x0​x+y0​y=r2，代入 x0​=3,y0​=4：3x+4y=25

答案： 3x+4y=25

例 4：从点 P(2,2) 向圆 x2+y2=4 引切线，求切线方程

解题思路（设斜率 + 距离）：

  1. ∣OP∣=22​>2，P 在圆外，应有两条切线
  2. 设 y−2=k(x−2)，即 kx−y+2−2k=0
  3. 圆心到切线距离 = 半径：k2+1​∣2−2k∣​=2
  4. 平方：(2−2k)2=4(k2+1)⟹k=0，得切线 y=2
  5. 斜率法漏了竖直线： 补上 x=2（验证：圆心到 x=2 距离 =2=r ✓）

答案： y=2 和 x=2

套路： 过圆外一点的切线永远两条。设斜率只解出一条？另一条必是竖直线。

例 5：求直线 y=x+1 被圆 x2+y2=4 截得的弦长

解题思路（弦长公式）：

  1. 直线化为 x−y+1=0，圆心 (0,0) 到直线距离 d=2​∣1∣​=2​1​
  2. 弦长 L=2r2−d2​=24−21​​=227​​=14​

答案： L=14​

例 6：求 A(1,2),B(3,5),C(−1,4) 围成的三角形面积

解题思路（坐标公式）：

  1. S=21​∣x1​(y2​−y3​)+x2​(y3​−y1​)+x3​(y1​−y2​)∣
  2. =21​∣1(5−4)+3(4−2)+(−1)(2−5)∣
  3. =21​∣1+6+3∣=5

答案： S=5

例 7：证明直线 (2k−1)x+(k+1)y+(3−k)=0 过定点，并求定点坐标

解题思路（按参数整理）：

  1. 把 k 提出来：k(2x+y−1)+(−x+y+3)=0
  2. 对任意 k 成立 ⟺ 两个括号同时为 0： 2x+y−1=0,−x+y+3=0
  3. 解得 x=34​，y=−35​

答案： 定点 (34​,−35​)

套路： “直线系过定点” = 把参数当未知数整理成 k⋅(⋯)+(⋯)=0，两个括号解方程组。

例 8：光线从 A(2,3) 射向 x 轴上的点 P，反射后经过 B(5,1)，求 P

解题思路（对称法）：

  1. B 关于 x 轴（镜面）对称：B′(5,−1)
  2. 入射光线 = 直线 AB′：斜率 5−2−1−3​=−34​，方程 y−3=−34​(x−2)
  3. 与 x 轴交点（y=0）：−3=−34​(x−2)⟹x=417​

答案： P(417​,0)

套路： 反射 = 把端点关于镜面翻过去，两点连线与镜面的交点就是反射点。入射角 = 反射角自动满足。

例 9：求两平行线 3x+4y+5=0 与 3x+4y−10=0 的距离

解题思路（平行线距离公式）：

  1. 两线 A,B 相同，直接用公式
  2. d=A2+B2​∣C1​−C2​∣​=32+42​∣5−(−10)∣​=515​=3

答案： d=3

套路： 平行线距离公式只差一个”取两点到线的距离”——两线平行时，任取一条线上的点到另一条线的距离都相等。

例 10：椭圆 16x2​+4y2​=1 的弦 AB 中点为 M(2,1)，求直线 AB 的方程

解题思路（点差法）：

  1. 设 A(x1​,y1​),B(x2​,y2​)，代入椭圆方程： 16x12​​+4y12​​=1,16x22​​+4y22​​=1
  2. 两式相减：16(x1​−x2​)(x1​+x2​)​+4(y1​−y2​)(y1​+y2​)​=0
  3. 中点条件：x1​+x2​=4，y1​+y2​=2，代入： 164(x1​−x2​)​+42(y1​−y2​)​=0⟹x1​−x2​y1​−y2​​=−21​
  4. 弦过 M 且斜率 −21​：y−1=−21​(x−2)

答案： x+2y−4=0

套路： “弦中点”三个字 = 点差法。两点代入曲线方程相减，中点坐标直接给出 x1​+x2​ 和 y1​+y2​，斜率不战而屈人之兵。

例 11：判断圆 x2+y2=1 与圆 (x−2)2+y2=4 的位置关系

解题思路（圆心距判定）：

  1. 圆心 O1​(0,0)，O2​(2,0)，圆心距 d=2
  2. 半径 r1​=1，r2​=2：r1​+r2​=3，∣r2​−r1​∣=1
  3. 1<2<3：两圆相交

答案： 相交（这正是例 1 中根轴存在的几何原因）
