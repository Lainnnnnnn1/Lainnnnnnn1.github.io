排列组合进阶

排列组合的本质就一句话：不重不漏地数东西。基础计数（加乘原理、阶乘）搞懂后，真正拉开差距的是分组分配、隔板法、容斥和递推——这些才是竞赛和难题的主战场。

分组分配问题

核心区分

类型组之间有区别吗？组内有无顺序？典型问法
分配有区别（标号）可能有”分给 A, B, C 三人”
分组无区别（不标号）无”分成三堆”

二级结论：分组分配公式速查

将 n 个不同元素分成 k 组，各组元素数分别为 n1​,n2​,…,nk​（∑ni​=n）：

场景公式说明
组有标号，组内无序n1​!n2​!⋯nk​!n!​多项式系数
组无标号，且 ni​ 互异n1​!n2​!⋯nk​!⋅k!n!​除以组的排列数
组无标号，有 mi​ 个组等大∏ni​!⋅∏(mi​!)n!​消除等大组的交换

人话： 组有标号 = 不用除 k!，组无标号 = 要除 k!。有等大组 = 还要除 mi​!。

例题：10 个不同球放入 3 个不同盒子

  • 允许空盒：310（每个球 3 种选择）
  • 不允许空盒：310−(13​)210+(23​)110（容斥原理）

隔板法进阶

标准隔板法

方程 x1​+x2​+⋯+xk​=n 的正整数解个数：

(k−1n−1​)

人话： n 个球排一排，中间有 n−1 个缝隙，插 k−1 块板子。

非负整数解

方程 x1​+x2​+⋯+xk​=n 的非负整数解个数：

(k−1n+k−1​)

推导： 令 yi​=xi​+1，则 yi​≥1 且 ∑yi​=n+k，变成正整数解。

二级结论：带限制的隔板法

限制条件转化方法
xi​≥ai​令 yi​=xi​−ai​+1，转到正整数
xi​≤m容斥：总数 − 超过 m 的情况
x1​<x2​<⋯<xk​(kn​)，直接选组合

容斥原理进阶

基本公式

∥⋃i=1n​Ai​∥=∑∥Ai​∥−∑∥Ai​∩Aj​∥+∑∥Ai​∩Aj​∩Ak​∥−⋯+(−1)n−1∥A1​∩⋯∩An​∥

二级结论：容斥应用模板

问题容斥解法
n 封信装错信封（错排）Dn​=n!(1−1!1​+2!1​−⋯+n!(−1)n​)
n 个物品，k 个有性质至少有一个性质 = 总数 − 全无性质
恰好 m 个满足容斥 + 组合系数

错排问题（Derangement）

n 个元素每个都不在原来位置的排列数 Dn​：

Dn​=n!∑i=0n​i!(−1)i​≈en!​

递推关系： Dn​=(n−1)(Dn−1​+Dn−2​)，D1​=0,D2​=1

递推法与生成函数入门

递推法三步走

  1. 找 n=1,2 等小情况
  2. 建立 an​ 与 an−1​,an−2​,… 的关系
  3. 解递推（特征根法或生成函数）

例题

例 1：8 个不同球分给 3 个不同盒子，每盒至少 2 个

解题思路：

  1. 总数 38=6561
  2. 容斥：设 Ai​ = 盒子 i 少于 2 个
  3. ∥Ai​∥：盒 i 有 0 个 → 28=256；有 1 个 → 8×27=1024，共 1280
  4. ∥Ai​∩Aj​∥：两盒都少于 2 → 分类讨论
  5. 最终用容斥：6561−3×1280+⋯

例 2：方程 x1​+x2​+x3​=10，x1​≥2,x2​≥3,x3​≥1 的正整数解

解题思路：

  1. 令 y1​=x1​−1,y2​=x2​−2,y3​=x3​（都移成 ≥1）
  2. y1​+y2​+y3​=10−3=7
  3. 正整数解 = (3−17−1​)=(26​)=15
