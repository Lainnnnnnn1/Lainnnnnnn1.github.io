计算复杂性理论 Computational Complexity

人话讲解

有些问题很快能解（比如排序），有些问题理论上可解但太阳爆炸了也算不完（比如最优旅行路线）。复杂性理论给问题按「难度」分级——P是「容易的」，NP是「容易验证的」。P = NP？ 是千禧年七大难题之一，至今未解。

图灵机 Turing Machine

定义

图灵机 = 无限长纸带 + 读写头 + 有限状态控制器

  • 确定性图灵机 (DTM)：每个状态-符号组合有唯一下一步
  • 非确定性图灵机 (NTM)：可以有多个选择

Church-Turing 论题

「可计算」=「图灵机可计算」。任何合理的计算模型都不比图灵机更强。

复杂度类

P (Polynomial Time)

能在多项式时间内被确定性图灵机解决的问题。

例子说明
排序O(nlogn)
最短路径 (Dijkstra)O(E+VlogV)
矩阵乘法O(n3)
判断素数 (AKS)O(log6n)

NP (Nondeterministic Polynomial)

能在多项式时间内验证解的问题。即：猜一个解，快速检查对不对。

例子说明
SAT (布尔可满足性)第一个被证明 NP-完全的
旅行商问题 (TSP)最短路线访问所有城市
子集和问题能选出和为某值的子集吗
图着色能用 k 种颜色给图着色吗

NP-完全性 NP-Completeness

Cook-Levin 定理 (1971)

SAT 是 NP-完全的。即所有 NP 问题都可以多项式归约到 SAT。

多项式归约

A≤p​B：问题 A 可以转化为问题 B（用多项式时间的预处理）。

例题：证明 3-SAT ≤p​ 团问题 (CLIQUE)

解题思路：把 3-SAT 的每个 clause 的三个文字各连一条边，不矛盾的文字之间连边，则存在大小为 k（clause 数）的团 ⟺ 公式可满足。

复杂度类地图

         EXPTIME
        ┌─────────┐
        │   PSPACE │
        │ ┌──────┐ │
        │ │  NP  │ │
        │ │ ┌──┐ │ │
        │ │ │P │ │ │
        │ │ └──┘ │ │
        │ └──────┘ │
        └─────────┘
  • P ⊆ NP ⊆ PSPACE ⊆ EXPTIME
  • 已知 P ≠ EXPTIME，但 P ≠ NP 未解

可判定性 Decidability

停机问题 Halting Problem

给定程序 P 和输入 I，判断 P 在 I 上是否会停机。

图灵 (1936)：停机问题不可判定！（对角化证明）

人话：不存在通用算法能判断任意程序会不会进入死循环。

二级结论

结论说明
P = NP 如果真密码学基本完蛋（RSA 可快速破解）
Ladner 定理若 P≠NP，存在 NP-中间问题（非 P 也非 NP-完全）
NP-完全问题之间互相归约解决一个 = 解决所有
量子计算 = 解决 NP-完全BQP 类未必包含 NP（Shor 算法针对特定问题）
