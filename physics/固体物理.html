固体物理

固体物理回答一个根本问题：1023 个原子排列成晶体后，电子会做什么？答案就是能带理论——它解释了为什么有导体、半导体、绝缘体，为什么有磁性和超导。

1. 晶体结构

1.1 晶格与基元

晶体 = 晶格（数学点的规则排列）+ 基元（每个格点上的原子组）。

R=n1​a1​+n2​a2​+n3​a3​,ni​∈Z

2. 倒易空间 (Reciprocal Space)

2.1 倒易晶格

bi​⋅aj​=2πδij​

对于正格子 a1​,a2​,a3​： b1​=2πa1​⋅(a2​×a3​)a2​×a3​​

人话：倒格子搬到了动量空间。X 射线衍射图上看到的斑点，是倒格点。大实空间 → 小倒空间，反之亦然。

2.2 第一 Brillouin 区

Wigner-Seitz 原胞在倒空间中的对应物就是第一 Brillouin 区——它是能带结构绘制的标准画布。

结构第一 BZ 形状
SC立方体
BCC截角八面体
FCC截角八面体（但不同方向）

例题 1：Bragg 衍射 —— X 射线晶体学

问题：用波长 λ=0.154 nm（Cu Kα）的 X 射线照射 NaCl 晶体，一级衍射角 θ1​=15.9°。求相邻原子面的间距 d。

解题思路：

  1. Bragg 方程：2dsinθ=mλ
  2. 一级（m=1）：d=2sinθ1​λ​=2sin15.9°0.154​=2×0.2740.154​≈0.281 nm
  3. NaCl 晶格常数 a=2d(100)​=0.562 nm（立方结构，d100​=a）
  4. 量级检验：d∼0.3 nm 与原子间距量级一致 ✅——X 射线波长必须与晶格常数同量级才能衍射（可见光 λ∼500 nm 太大，直接穿过）
  5. 若改用二级峰：θ2​=arcsin(2d2λ​)=arcsin(0.548)≈33.2°

二级结论：Bragg 公式中 θ 是掠射角（与晶面的夹角），不是入射线与法线的夹角——这是最常见的符号陷阱。测 d 的流程：已知 λ 测 θ，或已知 d 标定 λ。

例题 2：BCC 的倒格子是 FCC

问题：证明体心立方（BCC，格常数 a）的倒格子是面心立方（FCC），并求倒格常数。

解题思路：

  1. BCC 正格子基矢：a1​=2a​(−x^+y^​+z^)，a2​=2a​(x^−y^​+z^)，a3​=2a​(x^+y^​−z^)
  2. 原胞体积：V=a1​⋅(a2​×a3​)=a3/2
  3. 用 b1​=2π(a2​×a3​)/V 计算： a2​×a3​=4a2​[(x^−y^​+z^)×(x^+y^​−z^)]=2a2​(y^​+z^)
  4. b1​=a3/22π​⋅2a2​(y^​+z^)=a2π​(y^​+z^)
  5. 这正是 FCC 倒格子的形式（FCC 基矢 a2π​(y^​+z^) 等）——BCC 的倒格子是 FCC，反之亦然 ✅

二级结论：正、倒格子的”互易”关系：BCC ↔ FCC，SC ↔ SC。倒格常数 b=4π/a（BCC）与 b=4π/a（FCC 对应的倒格子是 BCC）。记住”BCC 的倒格子是 FCC”这一对是考试常客。

3. 能带理论 — 固体物理的核心

3.1 Bloch 定理

在周期势 V(r+R)=V(r) 中，单电子波函数必为 Bloch 波：

ψnk​(r)=eik⋅runk​(r)

其中 unk​(r+R)=unk​(r) 具有晶格周期性。

Bloch 定理是平移对称性的直接结果——又是一个 Noether 定理的影子。

3.2 能带的起源

从孤立原子到晶体：

  1. 孤立原子：分立能级
  2. 两个原子靠近：能级分裂（成键 + 反键）
  3. N 个原子排列成晶体：N 个能级密集排列成能带

内层电子（紧束缚）→ 窄能带 外层电子（近自由）→ 宽能带

3.3 两种极限模型对比

近自由电子 (NFE)紧束缚 (Tight-Binding)
出发点自由电子 + 弱周期势孤立原子 + 轨道重叠
适用s,p 电子（金属）d,f 电子（过渡金属）
能带公式Ek​≈2mℏ2k2​+gapsEk​=E0​−2tcos(ka) (1D)

3.4 能隙 (Band Gap) 的来源

在 Brillouin 区边界 k=±π/a，Bragg 反射产生驻波：

  • 驻波 1：∣ψ+​∣2∝cos2(πx/a) — 电荷积聚在离子实上 → 低能
  • 驻波 2：∣ψ−​∣2∝sin2(πx/a) — 电荷积聚在离子实间 → 高能

能隙 Eg​ = 两个驻波的能量差。Eg​ 越大，晶体越”绝缘”。

例题 3：紧束缚能带与有效质量

问题：一维紧束缚能带 E(k)=E0​−2tcos(ka)（最近邻跳跃积分 t>0，格常数 a）。(a) 带宽？(b) 能带底部（k=0）的有效质量？(c) t 增大时带宽和有效质量如何变？

解题思路：

  1. cos(ka)∈[−1,1]：E∈[E0​−2t,E0​+2t]，带宽 W=4t
  2. 有效质量定义：m∗1​=ℏ21​dk2d2E​
  3. dkdE​=2tasin(ka)，dk2d2E​=2ta2cos(ka)
  4. 带底 k=0：m∗=2ta2ℏ2​>0（正常，像电子）；带顶 k=π/a：m∗=−2ta2ℏ2​<0（空穴！）
  5. t 增大 → 带宽 4t 增大，m∗ 减小——轨道重叠越大，电子越”轻”，越像自由电子

二级结论：能带计算两板斧：带宽 =4t（1D 紧束缚）、有效质量 = 能带曲率的倒数。带顶负质量就是空穴概念的起源——半导体物理全靠这个符号翻转。

4. 能带填充与导电性

4.1 决定导电性的三要素

要素含义
能带结构允带和禁带怎么分布
填充因子每个原子有几个价电子
Fermi 能级位置EF​ 落在哪儿

4.2 金属 / 半导体 / 绝缘体

类型Eg​T→0 导电性举例
金属0（带重叠或无隙）导Cu, Al, Na
半导体0<Eg​≲3 eV不导Si (1.1 eV), GaAs (1.4 eV)
绝缘体Eg​≳3 eV不导金刚石 (5.5 eV), SiO₂

人话总结：导电 = 有电子在部分填充的能带里能自由移动。满带不通电（电子没地方去）。

4.3 自由电子气与 Fermi 能级

T=0 时电子填满到 Fermi 能级：

EF​=2mℏ2​(3π2n)2/3,kF​=(3π2n)1/3

  • Fermi 温度：TF​=EF​/kB​（典型 104–105 K——室温永远是”低温”）
  • 电子比热：Cel​=2π2​NkB​TF​T​（∝T，与声子 T3 不同！）

例题 4：铜的 Fermi 能级

问题：铜（密度 8.96 g/cm3，摩尔质量 63.5 g/mol，每个原子贡献 1 个自由电子）。(a) 电子数密度？(b) EF​？(c) TF​？(d) 室温（300 K）下 T/TF​ 是多少？

解题思路：

  1. n=MρNA​​=63.58.96×6.02×1023​≈8.5×1028 m−3
  2. EF​=2mℏ2​(3π2n)2/3：kF​=(3π2×8.5×1028)1/3≈1.36×1010 m−1，EF​=2×9.11×10−31(1.055×10−34)2×(1.36×1010)2​≈1.13×10−18 J≈7.0 eV
  3. TF​=EF​/kB​=7.0×1.6×10−19/1.38×10−23≈8.2×104 K
  4. T/TF​=300/82000≈3.7×10−3≪1——室温下电子气处于深度简并态
  5. 记忆锚点：典型金属 EF​∼1–10 eV，TF​∼104–105 K

二级结论：EF​=7 eV 意味着电子即使在绝对零度也有 ∼ eV 量级的动能——这解释了为什么金属电子气不塌缩、为什么经典 Drude 模型（kT 能量）算出的比热差了 100 倍。

5. 半导体物理

5.1 本征半导体

热激发产生电子-空穴对：

ni​=Nc​Nv​​e−Eg​/2kB​T

其中 Nc​,Nv​ 是导带和价带的有效态密度。

T 越高，ni​ 越大——半导体高温下更像金属。

5.2 掺杂

类型掺杂物多数载流子例
n 型施主 (P, As → Si)电子n≈ND​
p 型受主 (B, Al → Si)空穴p≈NA​

质量作用定律：np=ni2​（平衡时永远成立）

例题 5：本征载流子浓度

问题：硅 Eg​=1.12 eV，Nc​=2.8×1019 cm−3，Nv​=1.0×1019 cm−3。(a) 300 K 时 ni​？(b) 掺杂 ND​=1016 cm−3 后电子浓度和空穴浓度？(c) 温度升到 400 K，ni​ 增大多少倍（近似）？

解题思路：

  1. ni​=2.8×1019×1.0×1019​×e−1.12/(2×0.0259)=5.3×1019×e−21.6≈5.3×1019×4.1×10−10≈2.2×1010 cm−3
  2. kB​T=0.0259 eV（300 K 的”标准数”）；ni​(Si,300K)≈1010 cm−3——记忆锚点
  3. 掺杂后：n≈ND​=1016 cm−3（多数载流子）；p=ni2​/n=1016(2.2×1010)2​≈4.8×104 cm−3（少数载流子）
  4. 400 K：kB​T=0.0345 eV，指数因子 e−1.12/0.069=e−16.2≈9.2×10−8；Nc​Nv​​ 还随 T3/2 增大：ni​(300)ni​(400)​≈(300400​)3/2e(1/0.0518−1/0.069)≈1.54×e4.8≈180
  5. 结论：温度每升高 100 K 附近，ni​ 涨两个数量级——这就是为什么半导体器件对温度极其敏感

二级结论：ni​ 对 Eg​ 和 T 指数敏感。ni​≈1010 cm−3（Si, 300K）是器件物理的”基本常数”；np=ni2​ + 电中性条件 n=p+ND​−NA​ 是解一切掺杂问题的方程组。

5.3 p-n 结

接触电势差（内建电场）： Vbi​=ekB​T​ln(ni2​NA​ND​​)

耗尽层宽度：W∝Vbi​​

I-V 特性 (Shockley 方程)： I=Is​(eeV/kB​T−1)

正向：指数增长。反向：饱和。这就是整流的本质。

例题 6：霍尔效应测载流子浓度

问题：厚 t=0.1 mm 的 n 型半导体条，通电流 I=1 mA，置于 B=0.5 T 的垂直磁场中，测得霍尔电压 VH​=25 mV。(a) 霍尔系数？(b) 载流子浓度？(c) 若改用 p 型材料，VH​ 符号如何？

解题思路：

  1. 霍尔电压：VH​=nqtIB​（q=e 带符号，I 沿 x，B 沿 z，VH​ 沿 y）
  2. n=eVH​tIB​=1.6×10−19×0.025×10−410−3×0.5​≈1.25×1021 m−3=1.25×1015 cm−3
  3. 霍尔系数：RH​=nq1​=1.25×1021×1.6×10−191​≈5×10−3 m3/C
  4. 物理图像：洛伦兹力 qv×B 把电子推向一侧，横向电场建立后平衡：qEH​=qvd​B，EH​=vd​B，VH​=vd​Bw
  5. p 型材料：载流子是空穴（正电荷），偏转方向相反，VH​ 反号——霍尔效应直接读出载流子符号！

二级结论：霍尔效应三用：测载流子浓度（n）、判载流子类型（VH​ 符号）、测磁场（霍尔传感器）。公式 VH​=IB/(nqt) 中 t 是沿 B 方向的厚度。

6. 晶格振动 — 声子

6.1 一维单原子链

色散关系： ω(k)=2mK​​​sin(2ka​)​

  • 长波极限 (k→0)：ω=vs​k（声学支）
  • BZ 边界 (k=π/a)：ωmax​=2K/m​

6.2 一维双原子链 — 光学支与声学支

支ω(k→0)振动模式
声学支 (Acoustic)ω→0同向振动
光学支 (Optical)ω→ω0​=0反向振动（可被红外光激发）

6.3 声子比热

  • Einstein 模型（1907）：所有振子同一频率 ωE​ CV​=3NkB​(TΘE​​)2(eΘE​/T−1)2eΘE​/T​

  • Debye 模型（1912）：连续介质色散 ω=vs​k，截止频率 ωD​

    • 低温：CV​∝T3（T3 定律 ✅）
    • 高温：CV​→3NkB​（Dulong-Petit 定律）

Debye 模型比 Einstein 模型好在低温拟合——因为它正确描述了长波声学模。

7. 超导电性入门

7.1 两大标志

  1. 零电阻：T<Tc​ 时电阻突然降为 0
  2. Meissner 效应：完全抗磁性——超导体将磁场完全排出体外

B=0inside superconductor

Meissner 效应说明超导不是”理想导体”——它把磁通主动排出去。

7.2 BCS 理论要点

  • 电子通过声子交换形成 Cooper 对
  • Cooper 对是玻色子，可以凝聚到同一个基态
  • 能隙 2Δ 打开：
    • kB​Tc​≈1.13ℏωD​e−1/N(0)V

同位素效应 (Tc​∝M−1/2) 证明声子参与了配对。

7.3 London 方程

∇×Js​=−mns​e2​B

结合 Maxwell 方程得到： ∇2B=λL2​B​

磁场在超导体内部以指数衰减，穿透深度 λL​∼10−100 nm。
