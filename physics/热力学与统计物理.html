热力学与统计物理

热力学给你规则，统计物理告诉你为什么有这些规则。从 1023 个粒子的微观混沌中涌现出精确的宏观定律——这是物理学最美的 emergent phenomenon。

热力学 (Thermodynamics)

1. 四大定律

定律表述数学
第零热平衡是传递的：A∼B,B∼C⟹A∼C定义了温度
第一能量守恒dU=δQ−δW
第二熵增原理dS≥0（孤立系统）
第三绝对零度不可达S→0 as T→0

人话讲解：

  • 第零定律 = “温度计能用”的理由
  • 第一定律 = 换个马甲的能量守恒
  • 第二定律 = 时间有方向（为什么鸡蛋碎了不能复原？熵告诉你的）
  • 第三定律 = 你可以无限接近 0K，但永远到不了

1.1 第一定律

dU=δQ−δW

  • dU：内能增量（状态函数，是全微分）
  • δQ：吸热
  • δW：对外做功，W=∫PdV

⚠️ δQ 和 δW 不是全微分——它们依赖于过程！

1.2 常见热力学过程速查

过程条件第一定律简化特征
等温T=constΔU=0 (理想气体) ⟹Q=WPV=const
绝热Q=0ΔU=−WPVγ=const
等容V=constΔU=QW=0
等压P=constΔU=Q−PΔV用 CP​
自由膨胀真空，W=0,Q=0ΔU=0不可逆！

其中 γ=CP​/CV​，对于单原子理想气体 γ=5/3，双原子 γ=7/5。

1.3 理想气体状态方程

PV=nRT=NkB​T

  • R=8.314 J/(mol⋅K)，kB​=R/NA​=1.38×10−23 J/K
  • 微观版本：P=nkB​T（n 是分子数密度，不是摩尔数！）
  • 理想气体内能只依赖温度：U=2i​nRT（i 为自由度）

例题 1：状态方程与分子数密度

问题：标准状况（P0​=1.013×105 Pa，T0​=273 K）下，1 m3 空气中有多少分子？若把空气抽成 10−3 Pa 的”真空”（仍为室温 300 K），每立方米还剩多少分子？

解题思路：

  1. 由 P=nkB​T：n=kB​T0​P0​​=1.38×10−23×2731.013×105​≈2.69×1025 m−3
  2. 这是 Loschmidt 数：标准状况下每立方米约 2.7×1025 个分子
  3. 真空情形：n=1.38×10−23×30010−3​≈2.4×1017 m−3
  4. 对比：真空度 10−3 Pa 时仍有每立方厘米 2.4×1011 个分子——“真空不空”

二级结论：P=nkB​T 是状态方程最有用的形式：给了压强和温度，分子数密度直接除出来。记住 kB​ 的数值 1.38×10−23 是估数量级的基本功。

2. 熵 — 宇宙的方向之箭

2.1 Clausius 定义

dS=TδQrev​​

2.2 第二定律的多种表述

表述内容
Clausius热量不能自发地从低温物体传到高温物体
Kelvin-Planck不可能从单一热源吸热全部变成功
熵形式ΔSuniverse​≥0

三者等价。都是说同一件事：自然过程有方向。

2.3 热机效率的绝对上限

Carnot 热机在两个热源 TH​>TC​ 之间工作：

ηCarnot​=1−TH​TC​​

任何真实热机的效率严格小于 Carnot 效率。这是物理定律，不是工程限制。

2.4 熵变的计算套路

计算 ΔS 的唯一正确姿势：设计一条可逆路径，沿可逆路径积分 ∫δQrev​/T。因为熵是状态函数，结果与真实（可能不可逆的）路径无关。

过程熵变公式
等温膨胀（理想气体，V1​→V2​）ΔS=nRln(V2​/V1​)
等压加热（T1​→T2​）ΔS=nCP​ln(T2​/T1​)
等容加热（T1​→T2​）ΔS=nCV​ln(T2​/T1​)
绝热可逆过程ΔS=0（等熵！）
相变（潜热 L）ΔS=mL/T（温度不变）

例题 2：等温自由膨胀的熵变

问题：n mol 理想气体向真空自由膨胀，体积从 V1​ 变为 V2​=2V1​。求 ΔSgas​、ΔSsurrounding​ 与 ΔSuniverse​。

解题思路：

  1. 自由膨胀：Q=0，W=0，ΔU=0，温度不变
  2. 但不能用 ΔS=∫δQ/T=0——该过程不可逆，δQ=0 不可用于熵积分！
  3. 设计可逆等温膨胀 V1​→2V1​ 替代：ΔSgas​=nRln(V2​/V1​)=nRln2
  4. 外界没有吸热放热：ΔSsurrounding​=0
  5. ΔSuniverse​=nRln2>0 ✅——孤立系统熵增，过程不可逆

二级结论：自由膨胀 ΔS=nRln(V2​/V1​) 是必考题。陷阱在于：不可逆过程必须设计可逆路径算熵变。温度不变 + 熵增加 = 不可逆等温膨胀的招牌特征。

例题 3：热传导的熵变

问题：TH​=400 K 的热库向 TC​=300 K 的冷库传递 Q=1000 J 的热量（直接接触）。求 ΔSuniverse​。

解题思路：

  1. 热库放出 Q（视为等温可逆放热）：ΔSH​=−Q/TH​=−1000/400=−2.5 J/K
  2. 冷库吸收 Q：ΔSC​=+Q/TC​=1000/300≈+3.33 J/K
  3. ΔSuniverse​=−2.5+3.33=+0.83 J/K>0
  4. 关键观察：总熵变与传热量成正比、与温度差成正比——温差越大，熵产生越多
  5. 若两库温度相同（TH​=TC​），ΔS=0：可逆传热不产生熵

二级结论：ΔS=Q(TC​1​−TH​1​)。热量从高温流向低温是熵增的必然要求——这就是 Clausius 表述的数学证明。

2.5 Carnot 循环详解

步骤过程吸/放热做功
1→2等温膨胀 TH​吸热 QH​=nRTH​ln(V2​/V1​)W1​=QH​
2→3绝热膨胀0W2​=nCV​(TH​−TC​)
3→4等温压缩 TC​放热 QC​=nRTC​ln(V3​/V4​)W3​=−QC​
4→1绝热压缩0W4​=nCV​(TC​−TH​)

利用绝热关系 TH​V2γ−1​=TC​V3γ−1​、TH​V1γ−1​=TC​V4γ−1​，可证 V2​/V1​=V3​/V4​，从而：

η=1−QH​QC​​=1−TH​TC​​

例题 4：热机效率与制冷系数

问题：Carnot 热机工作在 TH​=500 K 与 TC​=300 K 之间，每个循环从高温热源吸热 QH​=2000 J。求：(a) 效率；(b) 每循环对外做功；(c) 若把它当制冷机用，制冷系数多大？

解题思路：

  1. η=1−TH​TC​​=1−500300​=0.4=40%
  2. W=ηQH​=0.4×2000=800 J；放热 QC​=QH​−W=1200 J
  3. 制冷系数（逆 Carnot 循环）：COP=WQC​​=TH​−TC​TC​​=200300​=1.5
  4. 验证：QC​/TC​=1200/300=4=QH​/TH​=2000/500 ✅——可逆循环熵不增
  5. 对比：真实冰箱 COP 通常 2–4，空调在 ∼3 量级——Carnot 值是最优上限

二级结论：Carnot 热机效率只由温度比决定，与工质无关（Carnot 定理）。制冷机 COP 公式 TH​−TC​TC​​ 与热机效率 TH​TH​−TC​​ 互为倒数关系。

3. 热力学势

势定义自然变量微分关系
内能US,V,NdU=TdS−PdV+μdN
HelmholtzF=U−TST,V,NdF=−SdT−PdV+μdN
焓H=U+PVS,P,NdH=TdS+VdP+μdN
GibbsG=U−TS+PVT,P,NdG=−SdT+VdP+μdN

Legendre 变换统一了这四个势。选哪个取决于你控制什么变量（T vs S, P vs V）。

二级结论：Maxwell 关系

从全微分的混合偏导相等得到：

(∂V∂T​)S​=−(∂S∂P​)V​

(∂P∂T​)S​=(∂S∂V​)P​

(∂V∂S​)T​=(∂T∂P​)V​

(∂P∂S​)T​=−(∂T∂V​)P​

用法：把不好测的量（如 (∂S/∂V)T​）换成好测的量（如 (∂P/∂T)V​）。

统计物理 (Statistical Mechanics)

4. 从微观到宏观的桥梁

4.1 Boltzmann 熵公式

S=kB​lnΩ

这是热力学第二定律的微观起源：系统总往 Ω（微观状态数）最大的方向演化，因为那个方向的可能性压倒性地大。

4.2 Boltzmann 分布

在温度 T 的平衡态，系统处于能量 Ei​ 的状态概率为：

Pi​=Z1​e−βEi​,β=kB​T1​

5. 配分函数 — 一切宏观量的母函数

5.1 正则系综配分函数

Z=∑i​e−βEi​=∑i​gi​e−βEi​

其中 gi​ 是简并度。

5.2 从 Z 导出热力学量

量公式
内能U=−∂β∂lnZ​
Helmholtz 自由能F=−kB​TlnZ
熵S=kB​lnZ+kB​T∂T∂lnZ​
压强P=kB​T(∂V∂lnZ​)T​
热容CV​=(∂T∂U​)V​

人话讲解：配分函数 Z 是统计物理的 Holy Grail。算出 Z，你对这个系统就全知道了。

例题 5：二能级系统

问题：一个系统只有基态 (E=0) 和激发态 (E=ε)，求 Z、U、CV​。

解题思路：

  1. Z=1+e−βε
  2. U=−∂β∂lnZ​=1+e−βεεe−βε​=eβε+1ε​
  3. T→0：U→0（全在基态）
  4. T→∞：U→ε/2（等概率在两个态）
  5. CV​=kB​(βε)2(eβε+1)2eβε​ —— 这就是 Schottky 异常峰

例题 6：谐振子 —— 配分函数求平均能量

问题：一维量子谐振子能级 En​=(n+21​)ℏω。求配分函数与平均能量 Eˉ。

解题思路：

  1. Z=∑n=0∞​e−βℏω(n+1/2)=e−βℏω/2∑n=0∞​(e−βℏω)n=1−e−βℏωe−βℏω/2​
  2. 用几何级数 ∑xn=1/(1−x)（x=e−βℏω<1）
  3. Eˉ=−∂β∂lnZ​=2ℏω​+eβℏω−1ℏω​
  4. 两项的物理：ℏω/2 是零点能；第二项是 Planck 平均能量——黑体辐射公式的统计来源！
  5. 高温极限 kB​T≫ℏω：Eˉ→ℏω/2+kB​T（能量均分 ✅）；低温极限：Eˉ→ℏω/2（冻结在基态）

二级结论：算 Z 的通用顺序：写出能级 → 求和（几何级数/高斯积分）→ 对 β 取对数求导。谐振子配分函数直接通向 Einstein 固体比热模型。

统计分布函数适用粒子

6.3 经典极限条件

当 eβ(ε−μ)≫1（即 nˉ≪1），量子统计退化到 Maxwell-Boltzmann。条件：

gnλdB3​​≪1

其中 λdB​=h/2πmkB​T​ 是热 de Broglie 波长。

8. Maxwell 速率分布

8.1 速率分布函数

气体分子速率处于 v∼v+dv 的概率：

f(v)dv=4π(2πkB​Tm​)3/2v2e−mv2/2kB​Tdv

8.2 三个特征速率

速率公式比值 (相对 vp​)
最概然速率vp​=m2kB​T​​=M2RT​​1
平均速率vˉ=πm8kB​T​​2/π​≈1.128
方均根速率vrms​=m3kB​T​​=M3RT​​3/2​≈1.225

人话讲解：三个速率是同一个分布的三种平均方式。vp​ 是分布峰值（最常见），vrms​>vˉ>vp​——分布长尾把高阶平均拉大了。

例题 7：室温下氮分子的速率

问题：T=300 K 时，氮分子（M=28 g/mol）的三个特征速率各是多少？什么温度下 vrms​ 翻倍？

解题思路：

  1. vrms​=M3RT​​=0.0283×8.314×300​​≈517 m/s
  2. vˉ=3π8​​vrms​≈0.921×517≈476 m/s；vp​=32​​vrms​≈0.816×517≈422 m/s
  3. 声速在空气中的量级 ∼340 m/s——分子的平均热运动比声速还快（声速 ∝vˉ）
  4. vrms​∝T​：翻倍需要 T′=4T=1200 K
  5. 量级检验：vrms​∼500 m/s 是室温气体的”常识数字”

二级结论：三个速率只差常数因子，记住 vrms​=3RT/M​ 即可推出其他两个。所有速率 ∝T/M​——轻分子（H₂）跑得快，高温跑得快。
