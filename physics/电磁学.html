电磁学

电磁学是经典物理的”第二支柱”：电荷产生电场，电流产生磁场，变化的磁场又产生电场。Maxwell 用四个方程统一了全部电磁现象，并预言了光就是电磁波。本章从 Coulomb 定律出发，一路推到电磁感应。

1. 静电场

1.1 Coulomb 定律

两个点电荷 q1​,q2​ 相距 r，相互作用力：

F=4πε0​1​r2q1​q2​​r^

  • ε0​=8.85×10−12 C2/(N⋅m2) 是真空介电常数
  • k=1/(4πε0​)≈8.99×109 N⋅m2/C2
  • 同号相斥、异号相吸；力满足叠加原理（这是”静电学的一切”）

例题 1：库仑定律 —— 三点电荷的平衡位置

问题：两个同号点电荷 +4q 和 +q 相距 L。在连线上放第三个电荷，使三电荷均静止。求第三电荷的位置、电荷量与符号。

解题思路：

  1. 平衡位置必在两电荷之间（同号电荷之间才可能静力平衡；外部区域合力方向一致，不可能平衡）
  2. 设第三电荷 Q 距 +4q 为 x。对 Q：kx24qQ​=k(L−x)2qQ​
  3. 消去 Q：x24​=(L−x)21​⟹x2​=L−x1​，解得 x=32​L
  4. Q 的符号：若 Q 为正，它推 +4q 和 +q 但方向相反，无法使二者都平衡——实际取 Q<0 且满足 kx24q∣Q∣​=k(L−x)2q∣Q∣​ 对任意 ∣Q∣ 成立
  5. 结论：Q（负电荷）放在距 +4q 为 32​L 处，任意电量均可平衡（因为两侧受力都正比于 ∣Q∣）

二级结论：两点电荷间平衡点位置只由电量比决定：距 q1​ 为 q1​​+q2​​q1​​​L。中间电荷必须与两端异号。

1.2 电场强度

试探电荷 q0​ 所受的力除以 q0​：

E=q0​F​=4πε0​1​r2q​r^

点电荷系与连续分布的电场（叠加原理）：

E=4πε0​1​∑i​ri2​qi​​r^i​,E=4πε0​1​∫r2dq​r^

1.3 连续电荷分布的计算套路

分布dq适用对称性
线分布dq=λdl细杆、圆环、圆弧
面分布dq=σdA圆盘、平板
体分布dq=ρdV球体、柱体

例题 2：均匀带电细杆中垂线上的电场

问题：长度 2a、线电荷密度 λ 的细杆，求其中垂线上距杆 y 处的场强。

解题思路：

  1. 取中点为原点，对称性：水平分量 Ex​ 相互抵消，只剩竖直分量 Ey​
  2. 微元 dq=λdx 在 P 点产生的场：dE=4πε0​1​x2+y2λdx​
  3. 竖直分量：dEy​=dEcosθ=4πε0​1​x2+y2λdx​⋅x2+y2​y​
  4. 积分：E=4πε0​λy​∫−aa​(x2+y2)3/2dx​=2πε0​yλ​⋅a2+y2​a​
  5. 极限检验：y≫a 时 E→4πε0​y2λ⋅2a​=4πε0​y2Q​（退化回点电荷 ✅）；a→∞ 时 E→2πε0​yλ​（无限长直线）

二级结论：先看对称性、再选微元、最后验极限。三个极限（远场退化为点电荷）是检查积分结果的标准手段。

1.4 Gauss 定理

通过闭合曲面的电通量等于面内总电荷除以 ε0​：

∮E⋅dA=ε0​Qenc​​

适用条件：电荷分布具有高度对称性（球对称、柱对称、平面对称），此时可把 E 提到积分号外。

例题 3：Gauss 定理 —— 无限长均匀带电直线

问题：线电荷密度 λ 的无限长直线，求距轴线 r 处的场强。

解题思路：

  1. 对称性：E 沿径向（柱对称），大小只依赖 r
  2. 取半径 r、长 l 的同轴圆柱面为 Gauss 面：侧面通量 E⋅2πrl，上下底面通量为零
  3. E⋅2πrl=ε0​λl​
  4. E=2πε0​rλ​——与例题 2 的 a→∞ 极限一致 ✅
  5. 注意与点电荷 E∝1/r2 的区别：线电荷 E∝1/r（二维问题少一次幂）

二级结论：Gauss 定理的经典三例：球对称 E=4πε0​r2Qenc​​、柱对称 E=2πε0​rλ​、平面对称 E=2ε0​σ​（与距离无关！）。

2. 电势

2.1 定义

电场是保守场，可定义电势（取无穷远为零点）：

V(r)=−∫∞r​E⋅dl,V=4πε0​1​∑i​ri​qi​​

  • 电势差：Vab​=Va​−Vb​=Wab​/q0​（单位正电荷从 a 移到 b 电场做的功）
  • 场强与电势：E=−∇V

2.2 常见电势速查

分布电势
点电荷V=4πε0​rq​
均匀带电球壳（外）V=4πε0​rQ​
均匀带电球壳（内）V=4πε0​RQ​（常数，电场为零）
均匀带电圆环（轴上）V=4πε0​R2+x2​Q​

例题 4：带电球壳的电势分布

问题：半径 R 的均匀带电球壳，总电荷 Q。求 V(r) 的完整表达式，并验证 r=R 处连续。

解题思路：

  1. 先用 Gauss 定理求场强：球壳外（r>R）E=4πε0​r2Q​；球壳内（r<R）E=0
  2. 球外电势：V(r)=∫r∞​4πε0​r′2Q​dr′=4πε0​rQ​
  3. 球内电势：电场为零，电势不变，V(r)=V(R)=4πε0​RQ​
  4. 连续性检验：r→R+ 与 r→R− 都给 4πε0​RQ​ ✅
  5. 对比实心球：内部 E=4πε0​R3Qr​，V(r)=4πε0​RQ​(23​−2R2r2​)——考试常考区分

二级结论：球壳内部是等势体（V=Q/4πε0​R），导体静电平衡时内部处处等势——这正是屏蔽效应的来源。

3. 导体与电容

3.1 静电平衡条件

导体内部 E=0；电荷全部分布在外表面；表面场强垂直于表面，E=σ/ε0​。

3.2 电容

C=VQ​,单位：F (法拉)

电容器电容
平行板C=dε0​εr​A​
球形C=4πε0​εr​R2​−R1​R1​R2​​
圆柱形C=ln(R2​/R1​)2πε0​εr​l​
  • 串联：C1​=∑Ci​1​（电荷相同）；并联：C=∑Ci​（电压相同）
  • 储能：U=21​CV2=2CQ2​

例题 5：插入介质的平行板电容器

问题：平行板电容器极板面积 A、间距 d，充电到电压 V0​ 后断开电源，再插入相对介电常数 εr​ 的电介质充满极板间。求插入前后电容、电压、储能的变化。

解题思路：

  1. 插入前：C0​=dε0​A​，Q=C0​V0​，U0​=21​C0​V02​
  2. 断开电源 → 电荷 Q 不变（关键判据！）
  3. 插入后：C=εr​C0​，电压 V=Q/C=V0​/εr​（下降）
  4. 储能 U=2CQ2​=U0​/εr​（减少）——减少的能量去哪了？介质被”吸”进极板间时电场对它做正功
  5. 若不断开电源（电压 V0​ 不变）：则 Q′=εr​Q0​ 增大，U′=εr​U0​ 增大——能量来自电源

二级结论：介质题先判断”电荷不变（断电源）还是电压不变（接电源）“。断电源：V,U 都除以 εr​；接电源：Q,U 都乘以 εr​。

4. 电路基础

4.1 欧姆定律与功率

  • 电流：I=dQ/dt，电流密度 J=I/A
  • 欧姆定律：V=IR，电阻 R=ρl/A（ρ 电阻率）
  • 焦耳定律：P=I2R=V2/R=IV

4.2 RC 电路

过程方程解
充电V0​=IR+Q/CQ(t)=CV0​(1−e−t/τ)
放电0=IR+Q/CQ(t)=Q0​e−t/τ

时间常数 τ=RC：经过一个 τ，充到满值的 1−e−1≈63%；经过 5τ 基本充满。

例题 6：RC 充电电路

问题：R=10 kΩ，C=100 μF，V0​=12 V。求：(a) 时间常数；(b) 2 s 时电容上的电压；(c) 稳态储能。

解题思路：

  1. τ=RC=104×10−4=1.0 s
  2. VC​(t)=V0​(1−e−t/τ)=12(1−e−2)≈12×0.865=10.4 V
  3. 稳态 t→∞：VC​=12 V，U=21​CV2=21​×10−4×144=7.2 mJ
  4. 检验：t=τ 时 VC​=12(1−e−1)=7.58 V（63% 规则 ✅）

二级结论：RC 电路所有量的时间依赖都形如 e±t/τ。记住 τ=RC 的单位是秒：Ω⋅F=s。

5. 静磁场

5.1 电流的磁效应与安培定则

任何通有电流的导线在其周围空间都会产生磁场，磁场的强弱与电流强度成正比，方向遵循右手法则。

安培定则 (Right-Hand Rule)：右手握住导线，拇指指向电流方向，弯曲四指的方向就是磁场环绕方向；对螺线管，弯曲四指与电流方向一致时，大拇指所指一端为 N 极。

5.2 Biot-Savart 定律与安培环路定理

B=4πμ0​​∫r2Idl×r^​,∮B⋅dl=μ0​Ienc​

μ0​=4π×10−7 T⋅m/A。与 Gauss 定理对称：安培环路定理用于高对称电流分布。

例题 7：安培环路定理 —— 无限长直导线与螺线管

问题：(a) 无限长直导线电流 I，求距导线 r 处的 B；(b) 密绕长螺线管（单位长度匝数 n），求管内 B。

解题思路：

  1. (a) 取半径为 r 的同心圆为回路（B 沿切向、大小不变）：B⋅2πr=μ0​I
  2. B=2πrμ0​I​——磁场随 1/r 衰减（与线电荷电场同构！）
  3. (b) 取矩形回路（长 l，一边在管内、一边在管外）：管外 B≈0，管内 Bl=μ0​nlI
  4. B=μ0​nI——管内匀强，与位置无关，这是螺线管最漂亮的性质
  5. 通电螺线管磁感线形状与条形磁铁类似：一端 N、一端 S

二级结论：μ0​nI 是”每米安匝数”。螺线管内部磁场均匀、外部很弱——电磁铁、MRI 都用这个原理。

5.3 铁芯磁化：磁场”放大器”

在螺线管中插入铁磁性材料（如软铁芯）：铁芯在外部磁场作用下发生磁化，内部原本紊乱的磁畴变得趋向一致。铁芯就像一个磁性”放大器”，能让原本微弱的磁场增强数百倍（B=μr​μ0​nI，软铁 μr​∼103）。

5.4 磁场对电流与运动电荷的作用

  • 安培力：F=Il×B（大小 F=BIlsinθ）
  • 洛伦兹力：F=qv×B（不做功，只改变速度方向）
  • 回旋半径与周期：r=qBmv⊥​​，T=qB2πm​（周期与速度无关——回旋加速器的原理）

6. 电磁感应

6.1 Faraday 定律

当闭合电路的磁通量发生变化时，电路中将产生感应电动势：

E=−dtdΦ​,Φ=∫B⋅dA

原理解析：产生电的关键不在于磁场多强，而在于磁场”变化”得有多快。磁场一动不动，电表读数永远是零。

磁通量类比：把磁场比作”雨水”，线圈比作”接水桶”——桶面越大（面积 A）接的水越多；雨下得越暴（B 越大）接的水越多。

6.2 楞次定律：阻碍变化

感应电流的磁场总要阻碍引起感应电流的磁通量的变化。线圈具有”趋稳性”：

  • 外部磁场变强？它产生反向磁场顶回去
  • 外部磁场变弱？它产生同向磁场拉回来

能量视角：楞次定律的”阻碍”正是能量守恒的体现——你必须付出做功的代价，才能换取电能。

例题 8：动生电动势

问题：光滑水平导轨间距 l，处于竖直向下的匀强磁场 B 中。导体棒以速度 v 匀速向右滑动，回路总电阻 R。求感应电动势、感应电流及维持匀速所需的外力功率。

解题思路：

  1. 动生电动势：E=Blv（导体切割磁感线，dΦ/dt=Bldx/dt）
  2. 感应电流：I=E/R=Blv/R（方向由楞次定律：阻碍磁通量增加，逆时针）
  3. 安培力：FB​=BIl=RB2l2v​，方向向左（阻碍运动）
  4. 匀速条件：外力 F=FB​，功率 P=Fv=RB2l2v2​
  5. 能量核对：电阻发热功率 Pheat​=I2R=RB2l2v2​=P ✅——机械能全部转化为焦耳热

二级结论：动生电动势 E=Blv 三要素：B 垂直分量、有效切割长度、切割速度。电磁感应题的能量守恒核对（Pmech​=Pheat​）是必做步骤。

6.3 电磁阻尼

列车高速经过轨道感应装置时，产生强大的感应电流；根据楞次定律，这个电流产生的力会拼命”往回拉”列车，从而实现无磨损制动。磁阻尼摆、电磁刹车都是同一原理。

7. 电动机与发电机

7.1 电动机：电能 → 机械能

处于磁场中的通电导体，由于电荷的定向移动，会受到安培力的作用。能量转换路径：电能 → 机械能。

  • 磁场是一阵看不见的风，通电线圈是一面帆——电流通过时，磁场推着线圈转动
  • 换向器 (Commutator)：电动机能持续转动的关键。它每转半周就自动换一次电流方向，保证推力的方向始终如一

7.2 发电机：机械能 → 电能

  • 转换方向：机械能 → 电能
  • 运行条件：闭合电路、磁场环境、持续的切割动作
  • 发电机是搬运工：消耗人的体力、风力或水力，把这些机械动能转化为流动的电能
电动机发电机
输入 → 输出电能 → 动能动能 → 电能
核心原理安培力驱动Faraday 电磁感应
关键部件换向器电刷 + 旋转线圈

7.3 现代应用

  • MRI（核磁共振）：利用超强电磁场让体内原子核产生能级跃迁，实现高精度的无辐射扫描
  • 无线充电：充电底座产生交变磁场，手机线圈捕捉磁场变化并感应出电流，实现跨空间能量传递
  • 电磁悬浮：磁悬浮列车利用”同名磁极相斥”将数百吨列车推离轨道，消除摩擦力

9. 一些个人小提示

  1. 动态性原则：没有磁通量的变化，就没有电能的产生。静止是电磁感应的大忌。
  2. 定则判别：安培定则判定极性，楞次定律判定电流方向，切记不可混淆。
  3. 能量守恒：楞次定律中的”阻碍”正是能量守恒的体现——你必须付出做功的代价，才能换取电能。
