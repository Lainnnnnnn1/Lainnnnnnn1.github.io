相对论

狭义相对论说：时空是一体的，光速是绝对的。 广义相对论说：引力不是力——是时空弯曲。 一百多年了，没有一个实验证伪相对论。Einstein 在 1905 和 1915 年做的事，至今仍是物理学的巅峰。

狭义相对论 (Special Relativity)

1. 两个基本假设

假设内容
相对性原理物理定律在所有惯性系中形式相同
光速不变真空光速 c 在所有惯性系中都是同一个值

人话讲解：不管你跑多快，你测出来的光速永远是 c。这不是测不准——这是时空本身的几何。

2. Lorentz 变换

2.1 从 Galilei 到 Lorentz

惯性系 S′ 以速度 v 相对 S 沿 x 轴运动：

Galilei (经典)Lorentz (相对论)
x′x−vtγ(x−vt)
t′tγ(t−vx/c2)
y′,z′y,zy,z

其中 γ=1−v2/c2​1​ 是 Lorentz 因子。

⚠️ 关键：t′=t！时间不再是绝对的——“同时”取决于参考系。

2.2 速度加法

u′=1−uv/c2u−v​

经典：u′=u−v（直接减） 相对论：分母做修正。当 u=c，u′=c —— 光速还是光速。

例题 1：速度叠加公式的应用

问题：(a) 飞船以 0.6c 前进，向正前方发射导弹，导弹相对飞船速度 0.8c。地面观测导弹速度？(b) 两束光以 0.5c 相向而行，一束光看另一束的速度？

解题思路：

  1. (a) 以地面为 S，飞船为 S′：u=0.8c（导弹相对飞船），v=0.6c
  2. uground​=1+uv/c2u+v​=1+0.480.8c+0.6c​=1.481.4c​≈0.946c——小于光速！
  3. 经典答案会是 1.4c——相对论的速度加法保证任何速度叠加都不超 c
  4. (b) 取一束光为参考系：u=−0.5c（另一束光），v=0.5c：u′=1−(−0.5)(0.5)−0.5c−0.5c​=1.25−c​=−0.8c——不是 −c！
  5. 但若 u=c：u′=1−v/cc−v​=c ✅——光速在任何系中都是 c，这就是第二公设

二级结论：速度叠加的通用形式 u′=1−uv/c2u−v​（同向时分子取减号，注意符号约定）。所有”超光速”悖论（如剪刀交叉点）都是忘了分母修正。

3. 相对论运动学效应

3.1 时间膨胀

运动的钟走得慢：

Δt=γΔt0​=1−v2/c2​Δt0​​

Δt0​ = 固有时间（在时钟静止系中测得的时间）。

μ 子实验：宇宙线 μ 子以 v≈0.998c 运动，γ≈16。本应活 2.2 μs 就死了，但实际活了 35 μs——完美验证时间膨胀。

例题 2：时间膨胀

问题：宇航员以 0.8c 飞向 4 光年外的恒星。地球看要 5 年。宇航员自己觉得花了多久？

解题思路：

  1. 地球测：Δt=5 年
  2. γ=1/1−0.82​=1/0.6=5/3
  3. 宇航员固有时：Δt0​=Δt/γ=5/(5/3)=3 年
  4. 从宇航员视角：长度收缩，距离 = 4/γ=2.4 光年，t=2.4/0.8=3 年 ✅

3.2 长度收缩

运动方向的长度缩短：

L=γL0​​

L0​ = 固有长度（在物体静止系中测得的长度）。

例题 3：长度收缩 —— μ 子能到达地面吗

问题：μ 子（寿命 τ0​=2.2 μs，固有系中）以 v=0.998c 从高度 H0​=10 km 产生并飞向地面。(a) 经典预测能飞多远？(b) 相对论修正后？(c) 从 μ 子视角看，大气层有多厚？

解题思路：

  1. (a) 经典：Lclass​=vτ0​=0.998×3×108×2.2×10−6≈659 m≪10 km——按经典物理 μ 子到不了地面，但实验上大量到达！
  2. (b) γ=1/1−0.9982​≈15.8；Δt=γτ0​≈34.8 μs；L=vΔt≈10.4 km>10 km ✅——时间膨胀救了 μ 子
  3. (c) μ 子视角：大气层长度收缩为 H=H0​/γ=10/15.8≈0.63 km，以 0.998c 穿过只需 2.1 μs<2.2 μs ✅——两种视角给出同一结论
  4. 关键：时间膨胀和长度收缩是同一枚硬币的两面——没有哪个参考系更”真实”

二级结论：运动学效应题先定固有系（钟静止/杆静止的那个系），再套 Δt=γΔt0​ 或 L=L0​/γ。μ 子到地面是相对论最经典的”实验判决”。

3.3 同时的相对性

在 S 系中同时发生的两个事件，在 S′ 系中不一定同时。

t2′​−t1′​=γ[(t2​−t1​)−c2v​(x2​−x1​)]

在 S 系中 t2​=t1​ 但 x2​=x1​ → t2′​=t1′​。

3.4 孪生子悖论

问题：双胞胎 A 留在地球，B 以 v=0.6c 飞往 3 光年外的行星并立即返回。(a) 地球系看全程多久？(b) B 的固有时？(c) 悖论在哪里、如何解决？

解题思路：

  1. (a) 单程 t=3/0.6=5 年，往返 tearth​=10 年
  2. (b) γ=1/1−0.36​=1.25；单程固有时 t0​=5/1.25=4 年，往返 8 年——B 回来时比 A 年轻 2 岁
  3. (c) 悖论：B 看地球也在运动，凭什么不是 A 更年轻？——对称性被加速度打破：B 在折返点经历加速，全程不在单一惯性系中；A 始终在惯性系中
  4. 严谨版本：B 的固有时由 τ=∫1−v(t)2/c2​dt 沿其世界线积分给出，世界线长度（固有时）是几何量，与谁看谁无关
  5. 实验佐证：GPS 卫星、μ 子、高能粒子存储环（如 CERN 的 muon g-2 实验）都验证了运动粒子”活得更久”

二级结论：孪生子悖论的标准解法三句话：加速的是谁谁更年轻；固有时 = 世界线长度；时间膨胀永远是对称的，加速度打破对称。任何”悖论”题先找谁经历了加速度。

3.5 相对论 Doppler 效应

情形频率公式说明
纵向趋近ν′=ν1−β1+β​​光源迎面而来，蓝移
纵向远离ν′=ν1+β1−β​​红移，β=v/c
横向（垂直）ν′=ν1−β2​=ν/γ纯时间膨胀效应，经典 Doppler 没有此项

经典 Doppler 只由相对速度决定；相对论 Doppler 多出横向项 γ——横 Doppler 是时间膨胀的直接证据。

应用：测星系退行速度。光谱红移 z=λ0​λobs​−λ0​​，低速极限 z≈v/c（Hubble 定律 v=H0​d 就是这么来的）。快速天体用精确式 1+z=1−β1+β​​：z=1 意味着 β=0.6（退行速度 0.6c，不是 1.0c！）。

4. 时空图 (Minkowski 图)

4.1 时空不变量

(Δs)2=(cΔt)2−(Δx)2−(Δy)2−(Δz)2

这是 Lorentz 变换下的不变量——所有惯性系测得的 Δs2 相同。

4.2 类时 / 类光 / 类空

Δs2名称含义
>0类时可以因果联系
=0类光只有光可以连接
<0类空绝对不可能因果联系

光锥是宇宙的因果结构：你的过去在 backward cone 里，你的未来在 forward cone 里。光锥之外的事件和你永远没有关系。

5. 相对论动力学

5.1 四维动量

Pμ=(E/c,p​)=m0​γ(c,v)

不变量：PμPμ​=c2E2​−p2=m02​c2

5.2 质能关系 (Physics’ most famous equation)

E=γm0​c2

  • 静止能量：E0​=m0​c2
  • 动能：K=(γ−1)m0​c2
  • 能量-动量关系：E2=(pc)2+(m0​c2)2

5.3 零质量粒子

对于光子 (m0​=0)： E=pc,v=c

5.4 相对论动量与力

p​=γm0​v=m0​v/1−v2/c2​

  • 低速极限：p→m0​v（经典动量 ✅）
  • v→c 时 p→∞——需要无穷大的冲量才能把有质量物体推到光速
  • 相对论第二定律：F=dtdp​​（必须用动量形式；F=ma 在高速下失效，且 F 与 a 不再平行）
  • 光子动量：p=E/c=h/λ——光压、Compton 散射的出发点

例题 4：E=mc2 的应用 —— 核能

问题：1 g 物质完全转化为能量（如正反物质湮灭），释放多少能量？相当于多少吨 TNT（4.2×109 J/吨）？若这些能量由煤（3×107 J/kg）提供，需多少煤？

解题思路：

  1. E=mc2=10−3×(3×108)2=9×1013 J
  2. 折合 TNT：9×1013/4.2×109≈2.1×104 吨——广岛原子弹的当量级（1.5 万吨）
  3. 折合煤：9×1013/3×107=3×106 kg=3000 吨煤
  4. 注意：1 g=10−3 kg，c2≈9×1016——一克物质里藏着两万吨炸药的能量
  5. 对比核裂变：铀-235 裂变只释放约 0.1% 的质量亏损——效率远低于湮灭，但仍比化学能高百万倍

二级结论：质量亏损计算三步：反应前后质量差 Δm → E=Δmc2 → 换算单位（1 u≈931.5 MeV）。记住 1 uc2≈931 MeV 是核物理的换算口诀。

例题 5：四动量与不变质量

问题：一个质量为 m 的静止粒子衰变为两个光子。(a) 每个光子的能量？(b) 若粒子以动能 K=mc2 运动时衰变，两个光子沿运动方向前后发射，它们的能量各是多少？

解题思路：

  1. (a) 静止：总能量 E=mc2 全部给两个光子，动量守恒要求两个光子背对背：Eγ​=mc2/2
  2. (b) 运动粒子：E=γmc2，K=(γ−1)mc2=mc2⟹γ=2
  3. 四动量守恒：Pparticleμ​=Pγ1​μ​+Pγ2​μ​（光子四动量 (E/c,±E/c) 沿 x 轴）
  4. 能量：2mc2=E1​+E2​；动量：γmv=p1​−p2​，其中 γmv=2m⋅23​​c=3​mc
  5. 解得 E1​=21​(2+3​)mc2≈1.87mc2，E2​=21​(2−3​)mc2≈0.13mc2
  6. 检验：E1​E2​=(mc2)2/4——与静止衰变时两光子能量乘积相同（不变量！）✅

二级结论：四矢量题的标准动作：写出四动量守恒、平方取不变量（PμPμ​=m2c2）。"s​"（质心系总能量）在粒子物理里就是不变质量——LHC 对撞能量就是这么算的。

广义相对论入门 (General Relativity)

6. 等效原理

6.1 Einstein 的”最快乐的想法”

一个自由下落的人感觉不到自己的重量。

弱等效原理：引力质量 = 惯性质量。在局部，引力和加速不可区分。

强等效原理：在局部自由下落参考系中，所有物理定律还原为狭义相对论形式（不含引力）。

6.2 从等效原理到时空弯曲

如果加速 = 引力，那么引力导致的光线偏折 = 加速导致的偏折 = 时空本身是弯的。

人话讲解：引力不是一种”力”，它是时空弯曲的几何表现。地球绕太阳转，不是因为太阳在”拉”它，而是太阳质量把周围的时空压弯了，地球沿着弯曲时空的”直线”（测地线）在走。

7. 度规与弯曲时空

7.1 时空度规

平坦时空 (Minkowski)： ds2=−c2dt2+dx2+dy2+dz2

弯曲时空： ds2=gμν​dxμdxν

gμν​ 是度规张量 —— 它包含时空的所有几何信息。

7.2 Schwarzschild 度规 (球对称静态解)

ds2=−(1−c2r2GM​)c2dt2+(1−c2r2GM​)−1dr2+r2dΩ2

Schwarzschild 半径：rs​=c22GM​

事件视界：在 r=rs​ 处，gtt​=0。任何东西（包括光）都无法从里面出来。这就是黑洞。

8. Einstein 场方程

8.1 核心方程

Gμν​+Λgμν​=c48πG​Tμν​

项意义
Gμν​Einstein 张量（描述曲率）
Λgμν​宇宙学常数（暗能量）
Tμν​应力-能量张量（物质分布）

人话：物质告诉时空怎么弯，时空告诉物质怎么动。—— John Wheeler

8.2 宇宙学常数

Einstein 最初引入 Λ 是为了得到静态宇宙（他后来称为”最大的错误”）。1998 年发现宇宙加速膨胀——Λ 回来了，代表暗能量。

8.3 引力波

在线性近似下，场方程预言了以光速传播的时空涟漪。2015 年 LIGO 首次直接探测到引力波（GW150914，两个黑洞并合）。

h∼c4G​rQ¨​​

探测器精度达到 10−21——相当于在 4 光年的距离上测出一个原子核直径的变化。
