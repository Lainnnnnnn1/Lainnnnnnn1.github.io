🏆 D1 核心算法与 TSP (旅行商问题) 保姆级套路模板

在 D1 考试中，最后的大题往往是 TSP (Travelling Salesperson Problem 旅行商问题)。题目要求找一个“逛遍所有点并回到起点”的最短环游路线。 因为这个问题太难，我们通常算不出精确的“完美答案”，所以考试只会让你算它的 上限 (Upper Bound) 和 下限 (Lower Bound)。

🎯 套路一：如何求 Upper Bound (上限)

上限的意思是：随便找一条能走通的完整路线，最差最差我也只要走这么远。（找一个相对较好的笨办法）

考试只考两种方法算上限，具体看题目要求哪种：

方法 1：NNA (Nearest Neighbour Algorithm 最近邻居法) - 【最常考，比如你这道题】

  • 怎么做： 从起点（比如 A）出发，每次只看跟自己相连的、还没去过的点里，哪个数字最小，就去哪。最后强制回到起点 A。

  • 写法： 必须连成一条线。 A - B - D - E - F - G - H - C - A

  • 结果： 把这一路的数字加起来，就是 Upper Bound。

方法 2：2 × MST (最小生成树乘 2) - 【只在题目明确提及时用】

  • 怎么做： 题目如果说 “using your minimum spanning tree to find an upper bound…”

  • 公式： Upper Bound = MST的总权重 × 2

  • (原理：顺着树枝走过去再原路返回，一定能覆盖所有点并回到起点)

🎯 套路二：如何求 Lower Bound (下限) - 【必考：删点法 Deleted Vertex】

下限的意思是：理论上的物理极限，真正的完美路线绝对不可能比这个数字更低。

你记忆中的“减去、加上”有点混乱，请直接记住这个**“删点法三步走绝对不出错模板”**：

【前置条件】题目会让你 Delete 掉一个点（通常是起点 A，或者题目指定的点）。

  • 第一步：算 RMST (剩下的最小生成树) 把 A 点，以及所有连着 A 的线，用手捂住（当它们不存在）。 对剩下的所有点（B, C, D, E…），用 Prim 算法 或 Kruskal 算法 算一个 Minimum Spanning Tree。 把这棵“残缺树”的边加起来，得到 RMST 的总和。(比如你卷子上的 29)。

  • 第二步：找 A 的两条最短腿 现在把手拿开，看回那个被你删掉的 A 点。 找找 A 连向其他所有点的线里面，数字最小的两条线。 (比如你卷子里，A 连出去的线有：AB=7, AC=8, AE=19… 最小的两个是 7 和 8)。

  • 第三步：套用终极公式 Lower Bound = RMST + 第一条最短腿 + 第二条最短腿 (卷子对应：Lower Bound = 29 + 7 + 8 = 44)

🎯 套路三：写出 Optimal Interval (最佳区间)

题目只要问你：Write down the smallest interval / be confident contains the optimal route… 直接无脑套用不等式：

Lower Bound ≤ Optimal Distance ≤ Upper Bound

(注：左边通常有等号，右边通常也有等号。把算出来的数字填进去即可： 44 ≤ optimal ≤ 57)

💡 终极防混淆指南：四大核心算法到底在干嘛？

  1. Dijkstra (迪杰斯特拉): * 作用： 算两点之间的最短路径 (Shortest Path)。比如 A 到 H 怎么走最快。

    • 特征： 画表格，标临时值、永久值。只关心起点到终点，不管其他点。

  2. Kruskal (克鲁斯卡尔):

    • 作用： 算最小生成树 (MST)。连通所有点，成本最低。

    • 特征： 全局找最小边，必须写 Reject（判断是否成环）。

  3. Prim (普里姆):

    • 作用： 也是算最小生成树 (MST)，结果和 Kruskal 一模一样。

    • 特征： 从一个起点开始“蔓延”。不需要写 Reject，每次只能连到已经长出来的树干上。通常看表格做题，划横线划竖线。答案写成两两字母 (比如 CE, DE)。

  4. Route Inspection / Chinese Postman (中国邮递员问题):

    • 作用： 每条**马路（边）**都要扫一遍垃圾，再回到起点，总路程最短。

    • 特征： 找奇数点 (Odd Nodes)，两两配对，看哪种配对加起来最小，然后加到总和里。

Decision Mathematics 1 (D1) 极简背诵速记卡 (满分关键词版)

考官改卷只找粗体字！把粗体字当单词背下来直接往卷子上写，不需要管复杂的语法，保证拿满分。

1. 图论基础 (Graphs & Networks)

  • Tree (树): * A connected graph with no cycles.

    • (连通，没环)

  • Spanning Tree (生成树): * A tree that includes all vertices.

    • (是一棵树，包含所有点)

  • Minimum Spanning Tree (MST, 最小生成树): * A spanning tree with minimum total weight (or length).

    • (总权重/长度最小)

  • Path (路径): * A sequence of edges where no vertex appears more than once.

    • (点不重复)

  • Cycle (环): * A closed path.

    • (闭合的路径)

  • Bipartite Graph (二分图): * Two sets of vertices. Edges only join vertices from different sets.

    • (分两组，只在不同组之间连线)

2. 路线与旅行商 (Route & TSP)

  • Eulerian Graph (欧拉图):

    • All vertices are even.

    • (全是偶数点)

  • Semi-Eulerian Graph (半欧拉图):

    • Exactly two odd vertices.

    • (刚好两个奇数点)

  • Route Inspection 的目的 (邮递员问题):

    • Find shortest route traversing every edge at least once.

    • (最短路，走遍每条线)

  • TSP 的目的 (旅行商问题):

    • Find shortest route visiting every vertex exactly once.

    • (最短路，走遍每个点)

  • Triangle Inequality (三角不等式 - 为什么直接走最近):

    • The longest side ≤ sum of the other two sides.

    • (最长边 ≤ 另外两边之和)

3. 关键路径 (Critical Path Analysis - CPA)

  • Critical Activity (关键活动):

    • Any delay will delay the whole project.

    • (一拖延，整个项目就拖延)

  • Total Float (总浮动时间):

    • 解释：Maximum delay without delaying the whole project.

    • 算式 (必背)：Latest Finish Time - Earliest Start Time - Duration

  • Dummy Activities (虚线的两个原因 - 必考大题!):

    • 原因 1 (Identity 身份): To uniquely identify activities. (或者背: Stop activities sharing same start and end nodes)

    • 原因 2 (Logic 逻辑): To preserve correct logic/precedence.

4. 算法与装箱 (Algorithms & Sorting)

  • Algorithm (算法):

    • A finite sequence of steps to solve a problem.

    • (有限的步骤)

  • FFD (降序装箱) 对比 FF (直接装箱) 的优缺点:

    • Advantage (优点): Uses fewer bins. (用更少的箱子)

    • Disadvantage (缺点): Takes longer (needs to be sorted first). (花时间长，因为要先排序)
