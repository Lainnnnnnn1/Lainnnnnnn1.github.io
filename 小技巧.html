组合数学进阶：从“两两配对”到“万能分组”

如果你掌握了“两两配对”的 (n−1)!!，那么面对三三配对、四四配对，你只需要掌握一个通用推导模板。

1. 通用推导法：分步计数法

假设你有 N 个人，要分成每组 k 人的若干组。

核心模板（三步走）：

  1. 先抽人（组合 C）：按照组的顺序，一组一组地选人。

  2. 乘起来：把每一步选人的方案数相乘。

  3. 除以“组的阶乘”：这是最关键的一步！如果各组之间是没有区别的（均匀分组），必须除以组数的阶乘，用来消除重复。

2. 深度拆解：四四配对（以8人分为2组为例）

问题：8个人，每4人一组，分两组。有多少种分法？

  1. 第一步：从8人选4人组成第一组 →C84​=4×3×2×18×7×6×5​=70。

  2. 第二步：剩下4人自动成第二组 →C44​=1。

  3. 第三步（去重）：因为“第一组是ABCD，第二组是EFGH”和“第一组是EFGH，第二组是ABCD”是同一种分法。我们分了2个组，所以要除以 2!（即 2）。

    • 结果：270×1​=35 种。

3. 深度拆解：三三配对（以9人分为3组为例）

问题：9个人，每3人一组，分三组。有多少种分法？

  1. 第一步：9选3 →C93​=3×2×19×8×7​=84。

  2. 第二步：剩6选3 →C63​=3×2×16×5×4​=20。

  3. 第三步：剩3选3 →C33​=1。

  4. 第四步（去重）：分了3个组，除以 3!（即 3×2×1=6）。

    • 结果：684×20×1​=280 种。

4. 考试与生活中的实用小技巧

A. 判定是否需要“除以阶乘”

  • 要除的情况：组是没有名字的。例如：“把6个学生平均分成三组去打扫卫生”。（A组和B组互换没区别）

  • 不要除的情况：组是有名字的。例如：“把6个学生平均分成三组，分别去打扫教室、走廊和厕所”。（去教室和去厕所区别大了！）

B. 快速验算“两两配对”

我们之前说的 6 个人两两配对 (6−1)!!=15，用这个通用公式验算一下：

  1. 选第一对：C62​=15

  2. 选第二对：C42​=6

  3. 选第三对：C22​=1

  4. 除以组数阶乘：3!=6

  • 结果：615×6×1​=15。完全吻合！

C. 生活中的应用：分组比赛/团建

  • 场景：12个好友去密室逃脱，每4人一个主题房。

    • 如果你是组织者，你要知道总共有 3!C124​×C84​×C44​​=6495×70×1​=5775 种不同的分组方案。

  • 场景：20个零件分两堆存放，每堆10个。

    • 方案数 = 2C2010​​。

5. 总结：一个万能公式

把 n 个元素分成 m 个组，每组 k 个（满足 n=m×k）：

方案数=m!Cnk​×Cn−kk​×Cn−2kk​×⋯×Ckk​​

记口诀：一选、二乘、三除序。

  1. 选：用组合数 C 一个个选。

  2. 乘：结果乘起来。

  3. 除序：有几个人数相同且没名字的组，就除以几的阶乘。

生活中的组合数学：从手机号到双阶乘

1. 深度拆解：双阶乘 (n)!! 到底在算什么？

双阶乘不是“阶乘的阶乘”，它的计算规则非常简单：从自己开始，每次跳过一个数往回乘，直到乘到 1 或 2 为止。

机械化计算公式

根据 n 是奇数还是偶数，计算路径分为两条：

  • 如果 n 是奇数（像下奇数楼梯）：

    n!!=n×(n−2)×(n−4)×⋯×3×1

    • 例：5!!=5×3×1=15

    • 例：7!!=7×5×3×1=105

  • 如果 n 是偶数（像下偶数楼梯）：

    n!!=n×(n−2)×(n−4)×⋯×4×2

    • 例：6!!=6×4×2=48

    • 例：8!!=8×6×4×2=384

为什么配对题要用 (n−1)!! ？

在“相亲会排位”（两两配对）的逻辑里，我们关心的是剩下多少个可选对象。因为选走一个人就要带走一个伙伴，所以人数是两个两个减少的。

形象理解：4 个人（A, B, C, D）配对

  1. A 先挑：此时他面前有 3 个人可选（B, C, D）。

  2. A 挑走一个（比如 B），房间里剩下 1 对（C 和 D）。

  3. C 挑：他面前只有 1 个人可选。

  • 计算：3×1=3!!=3 种。

形象理解：6 个人（A, B, C, D, E, F）配对

  1. A 先挑：他面前有 5 个人可选。

  2. A 挑走一个，房间里剩 4 个人。

  3. 下一个挑的人：他面前有 3 个人可选。

  4. 再挑走一个，房间里剩 2 个人。

  5. 最后一个人挑：他面前只有 1 个人可选。

  • 计算：5×3×1=5!!=15 种。

总结：如果你有 n 个奇点，配对方案数就是 (n−1)!!。这个公式保证了你每一次“挑人”时，都只乘那个剩下的、可供选择的人数。

2. 中国手机号：11位数字背后的天文数字

中国手机号有 11 位，但它不是随意排列的，它有固定的结构。

结构分析：

  • 前3位：网号（如 138, 186, 199 等）。目前大约有 100 多个号段。

  • 中间4位：地区编码（HLR标识）。

  • 后4位：用户末尾号。

如果 11 位可以随便乱排：

假设每一位都可以从 0-9 选（第一位不为 0），那么总数是：

9×1010=90,000,000,000 (900亿个)

如果是用你自己的 11 位数字“重新洗牌”：

假设你的手机号里没有重复数字（这不可能，总共才 10 个数字），排列方式是 11!。 但实际上，手机号有很多重复数字。比如号码 138-0000-0000，它的排列组合非常少：

  • 公式：全排列 / 重复数字的阶乘

  • 11个位置，9个“0”，1个“1”，1个“3”：

9!×1!×1!11!​=9!11×10×9!​=110 种

3. 日常生活中的组合数学例子

A. 密码的安全性：为什么增加一位长度更有用？

如果你设置 4 位纯数字密码，只有 104=10,000 种可能。 如果你增加到 6 位，可能数变味 1,000,000 种。 如果你把数字（10个）换成大小写字母+数字（62个），6位密码的可能性就是：

626≈568 亿种

B. 足球/篮球比赛的场次（握手原理）

场景：你们班有 8 支球队打单循环赛（每两队都要踢一场），一共多少场？

  • 这是组合 Cn2​ 的典型应用。

  • 每个人都要和另外 7 个人握手，但 A 和 B 握手算一次。

  • 计算：28×7​=28 场。

4. 组合数学思维：为什么它能让你变聪明？

  1. 避免穷举：当你意识到可能性有几万种时，你就不会去试错，而是去寻找筛选逻辑。

  2. 理解概率：所有的概率都是“符合条件的组合 / 总组合”。懂了组合，你就懂了为什么中彩票是不可能的任务。

  3. 优化资源：比如在复杂的网络布线或物流配送中，利用组合逻辑寻找最短路径。

双阶乘与组合数学：两两配对的秘密

在图论的“路线检查问题”中，我们需要将 n 个奇点进行两两配对。理解背后的数学原理能帮你快速验算并查漏补缺。

1. 什么是双阶乘 (n)!! ？

双阶乘并不是阶乘的阶乘，它的规则是：每隔一个数乘一次。

计算公式

对于正整数 n：

  • 如果 n 是奇数：n!!=n×(n−2)×(n−4)×⋯×3×1

  • 如果 n 是偶数：n!!=n×(n−2)×(n−4)×⋯×4×2

为什么配对方案数是 (n−1)!! ？

假设有 n 个点（n 为偶数）要进行两两配对：

  1. 随意选定一个点，它有 (n−1) 个伙伴可以选。

  2. 选好一对后，剩下 (n−2) 个点。

  3. 再从剩下的点里选一个，它有 (n−3) 个伙伴可以选。

  4. 以此类推，方案数就是 (n−1)×(n−3)×⋯×1=(n−1)!!。

常用数值速查：

  • 2个点：(2−1)!!=1!!=1 种（如：AB）

  • 4个点：(4−1)!!=3!!=3×1=3 种（如题中：FJ+KM,FK+JM,FM+JK）

  • 6个点：(6−1)!!=5!!=5×3×1=15 种

  • 8个点：(8−1)!!=7!!=7×5×3×1=105 种

2. 组合数学日常实用小技巧

A. 插空法 (The Gap Method)

场景：有 n 个元素，其中某些元素不能相邻。

  • 技巧：先排列可以相邻的元素，产生 n+1 个空隙，再将不能相邻的元素插进去。

  • 例子：5个人排队，甲乙不能站一起。先排剩下3人（3!），产生4个空隙，甲乙选2个空隙坐（A42​）。

B. 捆绑法 (The Tie-together Method)

场景：某些元素必须相邻。

  • 技巧：把必须相邻的元素看作一个“整体”，先和别人一起排，最后再考虑这个整体内部的排列。

  • 例子：5个人排队，甲乙必须站一起。把甲乙看作1人，总共排4人（4!），最后甲乙内部换位（2!），总数 4!×2!。

C. 隔板法 (Stars and Bars)

场景：把 n 个相同的物品分给 k 个不同的人，每人至少一个。

  • 技巧：在 n 个物品产生的 n−1 个空隙中，插入 k−1 块隔板。

  • 公式：Cn−1k−1​。

  • 例子：10个苹果分给3个小朋友。方案数 = C92​=36。

D. 正难则反 (Complementary Counting)

场景：正面分类讨论太复杂（例如包含“至少”、“最多”字眼）。

  • 技巧：用 总方案数 - 不符合条件的方案数。

  • 例子：从10人中选3人，至少有1个女生。方案数 = 总选法 C103​ - 全是男生的选法 C男生数3​。

3. 图论考试中的“防坑”验算单

在做路线检查题时，用以下组合逻辑自查：

  1. 点数校验：确定的配对点数一定是偶数吗？（如果算出是奇数个点，一定是度数数错了）。

  2. 算式校验：我有几行算式？如果是4个点，必须有 3 行。

  3. 路径校验：每一对路径我是否都检查了“绕路”的情况？（注意 KM 这种由 KG+GM 组成的隐藏最短路）。

  4. 起终点校验：题目要求回起点还是去异地？

    • 回起点：配对所有奇点。

    • 去异地：保持起终点为奇数，配对剩下的点。

掌握了 (n−1)!!，你就再也不会漏掉任何一种配对的可能性了！
