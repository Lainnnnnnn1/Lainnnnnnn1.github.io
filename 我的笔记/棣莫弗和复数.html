核心知识点总结：复数与棣莫弗定理

复数（Complex Numbers）是高等代数中的基石，其核心在于将数轴拓展到平面，并利用角度（辐角）进行乘除和幂运算。

I. 复数的表示形式

复数 z 可以用三种方式表示，每种形式都有其独特的运算优势。

形式表达式组成部分运算优势
1. 代数/笛卡尔形式 (Rectangular)z=x+iy实部 Re(z)=x；虚部 Im(z)=y加减法、共轭操作
2. 极坐标形式 (Polar)z=r(cosθ+isinθ)模长 r=x2+y2​；辐角 θ乘除法、几何意义
3. 指数形式 (Exponential, Euler)z=reiθ模长 r；辐角 θ幂运算（棣莫弗定理）

关键定义：

  • 共轭复数 (zˉ): zˉ=x−iy=re−iθ (虚部取反，辐角取反)。

    • 几何意义: 复平面上关于实轴的镜像对称。

  • 模长 (r): 向量的长度，代表复数到原点的距离。r=∣z∣.

  • 主辐角 (Arg(z)): θ 在特定区间内的取值。通常约定为 −π<θ≤π。

II. 棣莫弗定理 (De Moivre’s Theorem)

棣莫弗定理是处理复数乘方（求 zn）的核心工具，它使复数的乘方运算变得极其简洁。

1. 棣莫弗定理公式 (Powers)

如果 z=r(cosθ+isinθ)，且 n 是任意实数：

zn=rn(cos(nθ)+isin(nθ))

在指数形式中更为简洁：

(reiθ)n=rneinθ

人话讲解： “复数乘方时，模长做乘方运算 (rn)，辐角做乘法运算 (nθ)。”

2. 棣莫弗定理的推论：求 n 次根 (Roots)

求解方程 w=zn（即求 w 的 n 次根 z），其中 w=ReiΦ。

方程 zn=w 有 n 个互不相同的根。设 z=reiθ。

步骤：

  1. 写出 w 的周期性：

    w=Rei(Φ+2kπ)(k∈Z)

  2. 等价方程：

    rneinθ=Rei(Φ+2kπ)

  3. 求解 r 和 θ：

    • 模长： r=nR​ (必须取唯一的正实数根)

    • 辐角： nθ=Φ+2kπ⟹θk​=nΦ​+n2kπ​

  4. 确定 k： 取 n 个连续的整数 k 值，例如 k=0,1,2,…,n−1，或选择 k 值使得 θk​ 落在主辐角区间 (−π,π] 内。

所有 n 个根为：

zk​=nR​exp(i(nΦ​+n2kπ​)),k=0,1,…,n−1

人话讲解： “求 n 次根时，模长做开 n 次方运算 (nR​)，辐角除以 n 后，再以 n2π​ 为间隔，在复平面上均匀分布 n 个根。”

题型 A 详细案例：z=−1+i3​ 转换

目标： 将 z=−1+i3​ 转换为 reiθ 形式。

  1. 求模长 r：

    r=∣−1+i3​∣=(−1)2+(3​)2​=1+3​=2

  2. 求辐角 θ：

    • z 位于第二象限 (x<0,y>0)。

    • 参考角 α=arctan​−13​​​=3π​。

    • 第二象限的 θ=π−α=π−3π​=32π​。

    • 最终形式： z=2ei32π​。

题型 B 详细案例：(1+i)6 的值

目标： 求 (1+i)6 的值。

  1. 转换底数 z=1+i：

    • r=12+12​=2​

    • θ=4π​ (第一象限)

    • z=2​ei4π​

  2. 应用棣莫弗定理：

    z6=(2​)6ei(6⋅4π​)z6=8ei23π​

  3. 转换回代数形式：

    • 注意 23π​ 不在主辐角范围，但 23π​=−2π​+2π。

    • ei23π​=cos(23π​)+isin(23π​)=0+i(−1)=−i

    • 最终结果： z6=8(−i)=−8i。

题型 C 详细案例：求解 z3=8i

目标： 求解 z3=8i。

  1. 转换右侧复数 w=8i：

    • R=8

    • 主辐角 Φ=2π​ (正虚轴)

    • 周期形式： w=8ei(2π​+2kπ)

  2. 求解 r 和 θk​：

    • r=38​=2

    • θk​=3π/2+2kπ​=6π​+32kπ​

  3. 确定 k (取 k=0,1,2)：

    • k=0:θ0​=6π​⟹z0​=2ei6π​

    • k=1:θ1​=6π​+64π​=65π​⟹z1​=2ei65π​

    • k=2:θ2​=6π​+68π​=69π​=23π​。

      • 转换为主辐角： 23π​−2π=−2π​。

      • z2​=2e−i2π​

题型 D 详细案例：几何轨迹 ∣z−(3+4i)∣≤2

目标： 描述满足 ∣z−(3+4i)∣≤2 的复数 z 的几何轨迹。

  1. 复数减法的几何意义： ∣z−z0​∣ 代表复数 z 到固定点 z0​ 的距离。

  2. 固定点 z0​： z0​=3+4i (复平面上的点 (3,4))。

  3. 约束条件： ∣z−z0​∣≤2 表示 z 到点 z0​ 的距离小于或等于 2。

  4. 结论： 轨迹是一个以 z0​=3+4i 为圆心，半径 R=2 的闭圆盘（包含圆周及其内部）。

    • 如果 ∣z−z0​∣=2，则是圆周。

    • 如果 ∣z−z0​∣<2，则是开圆盘（不含圆周）。

题型 E 详细案例：涉及共轭的代数方程 z⋅zˉ+3(z+zˉ)=4

目标： 求解满足 z⋅zˉ+3(z+zˉ)=4 的复数 z。

  1. 利用共轭性质简化：

    • z⋅zˉ=∣z∣2=x2+y2

    • z+zˉ=(x+iy)+(x−iy)=2x

  2. 代入方程：

    ∣z∣2+3(2x)=4x2+y2+6x=4

  3. 配方得到标准形式 (圆的方程)：

    (x2+6x+9)+y2=4+9(x+3)2+y2=13

  4. 结论： 所有满足条件的复数 z 位于复平面上以 (−3,0) 为圆心，半径为 13​ 的圆周上。

IV. 二级结论与速记技巧

1. 关于 i 的周期性

i1=ii2=−1i3=−ii4=1

  • 速记： i 的幂以 4 为周期循环。任何整数 n， in=in(mod4)。

  • 应用： i+i2+i3+i4=i−1−i+1=0。连续四个 i 的幂相加和为 0。

4. 单位根 (Roots of Unity) 的几何分布

单位根是方程 zn=1 的 n 个根。

  1. 公式： zk​=1⋅ein2kπ​,k=0,1,…,n−1。

  2. 几何： 这 n 个根位于复平面上单位圆 ∣z∣=1 上，从 z=1 开始，均匀地将圆周分成 n 份。

  3. 重要二级结论：

    • 所有 n 个单位根的和为 0（除了 n=1 时）。即 ∑k=0n−1​zk​=0。

    • 所有 n 个单位根的乘积为 (−1)n−1。

    • 单位根的 m 次方仍然是单位根。
