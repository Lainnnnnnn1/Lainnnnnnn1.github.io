常微分方程“神之一手”：逆算子法 (D-Operator Method) 完全指南

忘记那些繁琐的待定系数法吧！当你面对常系数线性微分方程求特解时，逆算子法（D-Operator Method）是大学理工科乃至考研数学中的超级秒杀技。

它能将复杂的“求导和积分”过程，直接降维成“代入数字”和“多项式展开”。

核心基石：到底什么是“算子 D”？

在讲技巧之前，我们先统一一下语言。 设想有一个“切片机”，你把函数扔进去，它就给你切出一阶导数。我们把这台机器命名为 D。

  • D=dtd​ （求一阶导数）

  • D2=dt2d2​ （求二阶导数）

  • 以此类推……

那么，一个标准的微分方程，比如 x′′−5x′+6x=f(t)，用 D 机器写出来就是：

(D2−5D+6)x=f(t)

我们把括号里这堆东西看作一个整体机器，记作 P(D)。所以方程变成了：

P(D)x=f(t)

【神级思路来了】：既然 D 满足分配律和结合律，就像普通的代数符号一样，那我们能不能把它“除”过去？ 答案是可以的！这就得到了特解 (Particular Integral, PI) 的终极公式：

xpi​=P(D)1​f(t)

这里的 P(D)1​ 就是传说中的逆算子。它本质上代表了一连串复杂的积分操作。但幸运的是，针对三种最常见的 f(t)，前人已经帮我们推导出了极简的“代数替换法则”。

绝招一：遇到“指数函数” eat —— 直接代入法

这是最爽的一种情况。

【底层原理】：指数函数是微积分里的“VIP”。你看，D(eat)=aeat，D2(eat)=a2eat。每次求导，就相当于前面乘了一个常数 a。所以，作用了一堆 D 的 P(D)eat，其实就等于把 D 全换成 a，也就是 P(a)eat。把这个过程反过来，就得到了逆算子的绝招。

【秒杀法则】： 求 P(D)1​eat 时，直接把所有的 D 替换成数字 a。

🌰 基础例题

求特解： x′′+3x′+2x=5e4t 心算过程：

  1. 写出逆算子式：xpi​=D2+3D+21​5e4t

  2. 观察到 a=4。

  3. 直接把 D=4 代入分母： xpi​=42+3(4)+21​5e4t=16+12+21​5e4t=301​5e4t=61​e4t (搞定！不需要设 λe4t，不需要求导两遍再去解方程！)

💥 进阶情况（代入后分母为0，即“共振”怎么办？）

如果你代入 a 之后，发现分母变成了 0，说明这个右边的激励频率和系统本身的固有频率重合了（这就是物理上的共振，也是你之前疑惑的“重复”）。

【破局法则】：分子乘 t，分母对 D 求导。 (原理极其类似洛必达法则！)

求特解： x′′−4x′+4x=e2t

  1. 式子：xpi​=D2−4D+41​e2t

  2. 这里 a=2，代入分母发现：22−4(2)+4=0。炸了！

  3. 启动破局法则：分子乘一个 t，把分母对 D 求导，变成 2D−4。 式子变成：xpi​=t⋅2D−41​e2t

  4. 再次把 D=2 代入新的分母：2(2)−4=0。竟然又炸了！

  5. 别慌，再用一次破局法则：分子再乘一个 t（变成 t2），分母再对 D 求导（2D−4 变成 2）。 式子变成：xpi​=t2⋅21​e2t=21​t2e2t (完美解决！)

绝招二：遇到“三角函数” sin(at) 或 cos(at) —— 平方代入法

三角函数没有指数函数那么乖巧，它求导一次会变号换形：D(sinat)=acosat。 但是！求两次导它就露馅了：D2(sinat)=−a2sinat。 发现了吗？遇到 D2，它就只是乖乖地乘上一个常数 −a2。

【秒杀法则】： 求 P(D)1​sin(at) 或 P(D)1​cos(at) 时，只能将 D2 替换为 −a2。 (⚠️ 极其重要的警告：是把 D2 换成 −(a2)，负号在外面！绝对不是 (−a)2！而且遇到一阶的 D 绝对不能直接代入！)

🌰 基础例题

求特解： x′′+4x=7cos(3t) 心算过程：

  1. 逆算子式：xpi​=D2+41​7cos(3t)

  2. 观察到 a=3，所以我们要把 D2 替换为 −32=−9。

  3. 代入：xpi​=−9+41​7cos(3t)=−57​cos(3t)

💥 进阶情况（分母代完 D2 后，还剩下一个一阶的 D 怎么办？）

求特解： x′′+2x′+5x=10sin(t)

  1. 逆算子式：xpi​=D2+2D+51​10sin(t)

  2. 观察到 a=1，我们要把 D2 替换为 −1。

  3. 代入 D2=−1 后，分母变成了：−1+2D+5=2D+4。 此时式子为：xpi​=2D+41​10sin(t)=2(D+2)1​10sin(t)=D+25​sin(t)

  4. 【破局法则：分母有理化】：我们需要硬造出 D2 来！怎么造？利用平方差公式，分子分母同乘 (D−2)。

    xpi​=(D+2)(D−2)5(D−2)​sin(t)=D2−45(D−2)​sin(t)

  5. 爽了，分母又出现 D2 了！再次代入 D2=−1：

    xpi​=−1−45(D−2)​sin(t)=−55(D−2)​sin(t)=−(D−2)sin(t)

  6. 最后一步，把算子展开。记住 D(sint) 就是对 sint 求导：

    xpi​=−(Dsin(t)−2sin(t))=−(cos(t)−2sin(t))=2sin(t)−cos(t)

    (行云流水，一气呵成！)

绝招三：遇到“多项式” tn —— 泰勒展开（长除法）

多项式的特点是：只要你一直对它求导，它总有一天会变成 0。 比如对 t2，求三次导 D3(t2) 就等于 0 了。

【秒杀法则】： 利用泰勒级数或多项式长除法，将逆算子 P(D)1​ 按照 D 的升幂展开。展开到 D 的次数恰好等于多项式的最高次幂即可。

你只需要记住高中学过的等比数列求和公式逆运用：

  • 1−D1​=1+D+D2+D3+...

  • 1+D1​=1−D+D2−D3+...

🌰 基础例题

求特解： x′′+x=t2 心算过程：

  1. 逆算子式：xpi​=1+D21​t2

  2. 把 D2 看作上面公式里的那个 D，直接套用第二条公式展开：

    1+(D2)1​=1−(D2)+(D2)2−...=1−D2+D4−...

  3. 把这个展开式作用在 t2 上：

    xpi​=(1−D2+D4−...)t2

  4. 分配进去：

    • 1⋅t2=t2

    • D2(t2) 是对 t2 求二阶导，等于 2

    • D4(t2) 及以后的项全都是 0！直接扔掉。

  5. 结果秒出：xpi​=t2−2。

终极总结清单 (Cheat Sheet)

把这个表印在脑子里，考场上你就是没有感情的求特解机器：

右侧函数 f(t) 类型秒杀操作指南如果分母出现 0 (发生共振) 怎么办？
指数 eat直接把 D 替换成常数 a分子乘 t，分母对 D 求导，再代入 a。若还为 0 则重复此操作。
三角 sin(at),cos(at)仅将 D2 替换成 −a2（一般不会直接出现分母为0，除非是纯二阶系统发生共振，同样采用分子乘t分母求导的法则）
多项式 tn将分母化为 (1±某坨D)，按升幂展开提出最低次的 D 因子，先做积分，剩下的部分再展开。
